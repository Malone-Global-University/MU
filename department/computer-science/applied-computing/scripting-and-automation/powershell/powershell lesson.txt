On **Windows 11**, PowerShell saves your command history through **PSReadLine**. You can access commands from previous PowerShell sessions, including sessions opened in VS Code.

## **1. Find your saved PowerShell history**

Run this command in PowerShell:

```
(Get-PSReadLineOption).HistorySavePath
```

For Windows PowerShell 5.1, the default location is typically:

```
C:\Users\<YourUsername>\AppData\Roaming\Microsoft\Windows\PowerShell\PSReadLine\ConsoleHost_history.txt
```

For PowerShell 7, it is typically:

```
C:\Users\<YourUsername>\AppData\Roaming\Microsoft\PowerShell\PSReadLine\ConsoleHost_history.txt
```

To open the history file directly in Notepad:

```
notepad (Get-PSReadLineOption).HistorySavePath
```

## **2. View commands from previous sessions**

To display all saved commands:

```
Get-Content (Get-PSReadLineOption).HistorySavePath
```

To display the most recent 100 commands:

```
Get-Content (Get-PSReadLineOption).HistorySavePath -Tail 100
```

To search your command history for a particular command, such as `git`:

```
Select-String -Path (Get-PSReadLineOption).HistorySavePath -Pattern "git"
```

## **3. Understand the difference between session and saved history**

| Command                                              | What it retrieves                                |
| ---------------------------------------------------- | ------------------------------------------------ |
| `Get-History`                                        | Commands from the current PowerShell session     |
| `Get-Content (Get-PSReadLineOption).HistorySavePath` | Saved commands across sessions                   |
| `Get-History -Count 100`                             | Up to 100 recent commands in the current session |
| `notepad (Get-PSReadLineOption).HistorySavePath`     | Opens saved history for inspection               |

## **4. PowerShell history in VS Code**

VS Code's integrated terminal can use a different history file from the standalone PowerShell console.

Run this **inside the VS Code PowerShell terminal**:

```
(Get-PSReadLineOption).HistorySavePath
```

It may return a file named:

```
Visual Studio Code Host_history.txt
```

This is particularly important if you perform development work using both standalone PowerShell and VS Code.

## **5. Can you recover complete previous sessions?**

There is an important limitation: **PowerShell's normal saved history records commands, not their output.**

It generally does not preserve session timestamps, terminal output, errors, or the full screen contents of closed sessions.

For future sessions, you can record commands and output with:

```
Start-Transcript -Path "$HOME\Documents\PowerShell-Session.log" -Append
```

Stop recording using:

```
Stop-Transcript
```

**My recommendation:** Start with `(Get-PSReadLineOption).HistorySavePath`. This is the fastest way to locate your existing persistent PowerShell command history without configuring anything.

If you are trying to recover **everything displayed in a PowerShell session that you already closed**, rather than just the commands you typed, the recovery options are different.
