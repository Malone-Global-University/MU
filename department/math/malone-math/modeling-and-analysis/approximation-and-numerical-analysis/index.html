Approximation and Numerical Analysis

Numerical analysis studies how mathematical problems are solved reliably when exact symbolic answers are unavailable, impractical, or represented only approximately. This sequence develops the full numerical workflow: representing numbers in finite precision, understanding error and conditioning, solving equations and matrix systems, approximating functions, computing derivatives and integrals, solving differential equations, measuring convergence, and adapting computational effort to control error.

About This Sequence

Approximation and numerical analysis connect exact mathematics with practical computation. The central question is not only whether a numerical answer can be produced, but whether it is accurate, stable, efficient, and appropriate for the sensitivity of the problem.

The lessons below are arranged as a progression. Begin with finite-precision representation and error, then move into numerical algorithms, convergence, and adaptive error control.

Lessons

  1. Floating-Point Representation

    Learn how real numbers are stored approximately in finite precision, including binary representation, machine epsilon, rounding, overflow, underflow, cancellation, and the limits of floating-point arithmetic.

  2. Sources and Propagation of Error

    Identify measurement, modeling, representation, truncation, and iteration errors, then analyze how those errors propagate through arithmetic, functions, and multivariable calculations.

  3. Conditioning and Stability

    Distinguish sensitivity of the mathematical problem from stability of the numerical algorithm using condition numbers, perturbation analysis, forward and backward error, residuals, scaling, and stable reformulation.

  4. Root-Finding

    Solve nonlinear equations numerically using bracketing, bisection, fixed-point iteration, Newton's method, secant methods, convergence tests, safeguards, and stopping criteria.

  5. Numerical Linear Algebra

    Develop reliable matrix computation through Gaussian elimination, pivoting, LU, Cholesky and QR factorizations, least squares, iterative solvers, conditioning, eigenvalue methods, and the singular value decomposition.

  6. Interpolation

    Construct functions that pass through known data using linear, Lagrange, Newton, barycentric, Hermite, piecewise, and spline interpolation while studying interpolation error and node placement.

  7. Approximation of Functions

    Replace complicated functions with simpler representations using least-squares methods, orthogonal bases, Chebyshev polynomials, Taylor approximations, minimax ideas, rational approximations, and adaptive approximation.

  8. Numerical Differentiation

    Estimate derivatives from sampled values using forward, backward, central, and higher-order finite differences, Richardson extrapolation, step-size analysis, smoothing, and convergence checks.

  9. Numerical Integration

    Approximate definite integrals with rectangle, midpoint, trapezoidal, Simpson, Romberg, Gaussian, adaptive, and Monte Carlo methods together with practical error estimates.

  10. Numerical Differential Equations

    Approximate differential-equation solutions using Euler, Runge-Kutta, multistep, implicit, stiff, and adaptive methods while tracking local error, global error, and stability.

  11. Convergence Rates

    Measure how rapidly numerical errors decrease through linear, superlinear, quadratic, algebraic, and spectral convergence, observed order, error ratios, refinement studies, and Richardson extrapolation.

  12. Adaptive and Error-Controlled Methods

    Bring the numerical-analysis sequence together through a posteriori error estimates, embedded methods, adaptive step sizes, mesh refinement, tolerance scaling, error budgets, stopping logic, and verification.

Core Numerical Questions

Across all of these topics, numerical analysis repeatedly asks five connected questions:

  1. Representation: How are the quantities stored and computed in finite precision?
  2. Error: Where does approximation error enter, and how does it propagate?
  3. Conditioning: How sensitive is the mathematical problem to small perturbations?
  4. Stability and convergence: Does the algorithm control error and approach the intended solution?
  5. Efficiency: How much computational work is needed to achieve the required accuracy?

A Unifying Error Model

Many methods in this sequence can be understood through an asymptotic error relation such as

\[ \boxed{ E(h)\approx Ch^p }. \]

The constant \(C\), the convergence order \(p\), the problem's conditioning, and floating-point effects together determine how useful refinement will be.

Recommended Learning Path

The sequence is designed to move from foundations to algorithms and then to error-controlled computation:

Floating-Point Representation \(\rightarrow\) Error Propagation \(\rightarrow\) Conditioning and Stability \(\rightarrow\) Numerical Algorithms \(\rightarrow\) Convergence Rates \(\rightarrow\) Adaptive Error Control.

The individual algorithm lessons can also be revisited independently as needed in calculus, linear algebra, differential equations, optimization, modeling, statistics, and scientific computing.

What This Sequence Builds Toward

After completing this sequence, the goal is to be able to judge a numerical result rather than merely produce one.

A strong numerical analysis should be able to answer:

  • What is being approximated?
  • What are the major sources of error?
  • How sensitive is the problem?
  • Is the algorithm stable?
  • How fast should the error decrease?
  • How can the result be checked independently?
  • When should the computation stop?
