Singular Values and Dimensional Reduction

Singular value decomposition separates a matrix into orthogonal input directions, independent scaling factors, and orthogonal output directions. This makes it one of the most useful structural tools in linear algebra. Singular values reveal rank, sensitivity, information strength, and effective dimension, while low-rank approximations use the strongest singular directions to compress data and simplify multidimensional systems.

The Central Idea

Every real \(m\times n\) matrix \(A\) can be factored as

\[ \boxed{A=U\Sigma V^T}. \]

This is the singular value decomposition, or SVD.

The matrices play distinct roles:

  • \(V\) supplies orthonormal input directions;
  • \(\Sigma\) scales those directions by nonnegative singular values;
  • \(U\) supplies orthonormal output directions.

Why the SVD Is So Powerful

Diagonalization requires a square matrix and enough eigenvectors.

The SVD is more general:

  • it works for square matrices;
  • it works for rectangular matrices;
  • it always exists for real matrices;
  • it uses orthonormal directions;
  • it directly reveals rank and approximation structure.

Dimensions of the Factors

For

\[ A\in\mathbb{R}^{m\times n}, \]

a full SVD has

\[ U\in\mathbb{R}^{m\times m}, \] \[ \Sigma\in\mathbb{R}^{m\times n}, \]

and

\[ V\in\mathbb{R}^{n\times n}. \]

Both \(U\) and \(V\) are orthogonal.

Orthogonal Factors

Because \(U\) and \(V\) are orthogonal,

\[ \boxed{U^TU=I} \]

and

\[ \boxed{V^TV=I}. \]

Therefore,

\[ U^{-1}=U^T, \qquad V^{-1}=V^T. \]

The Singular-Value Matrix

The matrix \(\Sigma\) is diagonal in the rectangular sense:

\[ \Sigma= \begin{bmatrix} \sigma_1&0&\cdots&0\\ 0&\sigma_2&\cdots&0\\ \vdots&\vdots&\ddots&\vdots\\ 0&0&\cdots&\sigma_r\\ &&&\\ 0&0&\cdots&0 \end{bmatrix}. \]

The nonnegative numbers

\[ \boxed{ \sigma_1\ge\sigma_2\ge\cdots\ge\sigma_r>0} \]

are the nonzero singular values.

What Is a Singular Value?

Singular values are the square roots of the eigenvalues of

\[ A^TA. \]

If

\[ A^TAv_i=\lambda_i v_i, \]

then

\[ \boxed{\sigma_i=\sqrt{\lambda_i}}. \]

Because \(A^TA\) is positive semidefinite, its eigenvalues are nonnegative.

Right Singular Vectors

The columns

\[ v_1,\ldots,v_n \]

of \(V\) are the right singular vectors.

They are orthonormal eigenvectors of

\[ A^TA. \]

They identify special input directions.

Left Singular Vectors

The columns

\[ u_1,\ldots,u_m \]

of \(U\) are the left singular vectors.

They are orthonormal eigenvectors of

\[ AA^T. \]

They identify corresponding output directions.

The Fundamental Singular-Vector Relation

For each nonzero singular value,

\[ \boxed{Av_i=\sigma_i u_i}. \]

The matrix \(A\) takes the right singular vector \(v_i\), scales it by \(\sigma_i\), and sends it into the left singular direction \(u_i\).

The Reverse Relation

For each nonzero singular value,

\[ \boxed{A^Tu_i=\sigma_i v_i}. \]

Thus the input and output singular directions are linked symmetrically by \(A\) and \(A^T\).

Geometric Interpretation

The SVD decomposes the action of \(A\) into three stages:

  1. rotate or reflect input coordinates using \(V^T\);
  2. scale along perpendicular directions using \(\Sigma\);
  3. rotate or reflect output coordinates using \(U\).

Symbolically,

\[ \boxed{ x \xrightarrow{V^T} V^Tx \xrightarrow{\Sigma} \Sigma V^Tx \xrightarrow{U} U\Sigma V^Tx}. \]

Unit Sphere to Ellipsoid

A linear transformation maps the unit sphere in the domain to an ellipsoid or a lower-dimensional degenerate ellipsoid in the codomain.

The right singular vectors identify the principal input directions.

The left singular vectors identify the principal output directions.

The singular values give the lengths of the corresponding semiaxes.

Largest Singular Value

The largest singular value

\[ \sigma_1 \]

gives the greatest stretching produced by \(A\) on unit vectors:

\[ \boxed{ \sigma_1 = \max_{\|x\|=1}\|Ax\|}. \]

Smallest Singular Value

For a full-rank square matrix,

\[ \sigma_n \]

gives the smallest stretching over unit input vectors:

\[ \boxed{ \sigma_n = \min_{\|x\|=1}\|Ax\|}. \]

If the smallest singular value is zero, the matrix loses a dimension.

Rank from Singular Values

The rank of a matrix equals the number of nonzero singular values:

\[ \boxed{ \operatorname{rank}(A) = \#\{\sigma_i:\sigma_i>0\}}. \]

This provides a direct structural reading of the SVD.

Null Space from the SVD

If

\[ \sigma_i=0, \]

then

\[ Av_i=0. \]

Therefore the corresponding right singular vectors lie in

\[ \boxed{\operatorname{Null}(A)}. \]

Column Space from the SVD

The left singular vectors corresponding to nonzero singular values span the column space:

\[ \boxed{ \operatorname{Col}(A) = \operatorname{span}\{u_1,\ldots,u_r\}}. \]

Row Space from the SVD

The right singular vectors corresponding to nonzero singular values span the row space:

\[ \boxed{ \operatorname{Row}(A) = \operatorname{span}\{v_1,\ldots,v_r\}}. \]

Null Space and Row-Space Complement

The remaining right singular vectors

\[ v_{r+1},\ldots,v_n \]

span the null space.

This matches the orthogonality relationship

\[ \operatorname{Null}(A) = \operatorname{Row}(A)^\perp. \]

Left Null Space

The remaining left singular vectors

\[ u_{r+1},\ldots,u_m \]

span

\[ \boxed{\operatorname{Null}(A^T)}. \]

Thus the SVD organizes all four fundamental subspaces at once.

Compact SVD

If \(A\) has rank \(r\), the zero singular directions can be omitted.

The compact SVD is

\[ \boxed{A=U_r\Sigma_rV_r^T}, \]

where

\[ U_r\in\mathbb{R}^{m\times r}, \qquad \Sigma_r\in\mathbb{R}^{r\times r}, \qquad V_r\in\mathbb{R}^{n\times r}. \]

This is often the most efficient form for computation.

Rank-One Expansion

The compact SVD can be expanded as

\[ \boxed{ A = \sigma_1u_1v_1^T + \sigma_2u_2v_2^T + \cdots+ \sigma_ru_rv_r^T}. \]

Each term

\[ \sigma_i u_i v_i^T \]

is a rank-one matrix.

Why the Rank-One View Matters

The SVD expresses a matrix as a sum of simple directional components.

The first component carries strength \(\sigma_1\), the next carries \(\sigma_2\), and so on.

If later singular values are small, their contributions may be discarded with limited error.

Low-Rank Approximation

Keep only the first \(k\) singular components:

\[ \boxed{ A_k = \sum_{i=1}^k \sigma_i u_i v_i^T}. \]

Then

\[ \operatorname{rank}(A_k)\le k. \]

This produces a lower-dimensional approximation to \(A\).

Best Rank-\(k\) Approximation

Truncating the SVD does more than produce a convenient approximation.

The Eckart-Young theorem says that \(A_k\) is the best rank-\(k\) approximation to \(A\) under standard matrix norms such as the spectral norm and Frobenius norm.

Approximation Error in Spectral Norm

For the best rank-\(k\) approximation,

\[ \boxed{ \|A-A_k\|_2 = \sigma_{k+1}}. \]

The first omitted singular value controls the worst-case directional approximation error.

Approximation Error in Frobenius Norm

The Frobenius error is

\[ \boxed{ \|A-A_k\|_F^2 = \sigma_{k+1}^2+\cdots+\sigma_r^2}. \]

The discarded singular-value energy measures total squared approximation error.

Effective Dimension

A matrix may have full mathematical rank while still behaving as though it has fewer important dimensions.

If only a small number of singular values are large and the rest are very small, then most of the matrix's action is concentrated in a low-dimensional subspace.

This motivates the idea of effective dimension.

Dimensional Reduction

Dimensional reduction replaces a high-dimensional representation with a lower-dimensional one while preserving as much important structure as possible.

With the SVD, one common strategy is to keep only the leading

\[ k \]

singular directions.

Compression by Truncated SVD

A full \(m\times n\) matrix contains

\[ mn \]

entries.

A rank-\(k\) truncated SVD stores approximately

\[ mk+k+nk \]

scalar values through \(U_k\), \(\Sigma_k\), and \(V_k\).

When \(k\ll m,n\), this can produce major compression.

Compression Trades Detail for Simplicity

Keeping fewer singular values reduces storage and complexity.

But discarded singular components also remove information.

The practical question is therefore:

\[ \boxed{ \text{how small can }k\text{ be while preserving useful structure?}} \]

Energy Interpretation

The squared Frobenius norm satisfies

\[ \boxed{ \|A\|_F^2 = \sigma_1^2+\cdots+\sigma_r^2}. \]

Thus the fraction

\[ \frac{\sigma_1^2+\cdots+\sigma_k^2} {\sigma_1^2+\cdots+\sigma_r^2} \]

measures how much of the matrix's total squared magnitude is retained by the first \(k\) singular components.

Choosing a Reduced Dimension

Common strategies include:

  • retain enough singular components to reach a chosen energy fraction;
  • keep singular values above a practical threshold;
  • look for a sharp drop or spectral gap;
  • choose \(k\) using downstream prediction or reconstruction performance;
  • balance computational cost against approximation error.

SVD and Principal Component Analysis

Principal component analysis can be computed using the SVD of a centered data matrix.

The leading right singular vectors identify important feature directions, while the singular values measure the strength of variation along those directions.

PCA and SVD are closely related but are not identical concepts.

Centering Data

Before PCA-style dimensional reduction, data are commonly centered by subtracting each feature's mean.

Centering shifts the origin to the data mean so that the leading directions describe variation around that mean.

Without centering, the dominant singular directions may reflect offset from the origin rather than variation around the data cloud.

Covariance and Singular Values

If \(X\) is a centered data matrix, then its covariance structure is proportional to

\[ X^TX. \]

Since the right singular vectors of \(X\) are eigenvectors of \(X^TX\), they also identify principal covariance directions.

Pseudoinverse from the SVD

Suppose

\[ A=U\Sigma V^T. \]

Replace each nonzero singular value

\[ \sigma_i \]

by

\[ \frac1{\sigma_i} \]

and transpose the rectangular structure to form \(\Sigma^+\).

Then

\[ \boxed{ A^+ = V\Sigma^+U^T}. \]

Least Squares from the Pseudoinverse

The canonical least-squares solution is

\[ \boxed{\hat{x}=A^+b}. \]

If the least-squares solution is not unique, this choice gives the minimum-norm coefficient vector.

SVD and Invertible Matrices

If \(A\) is square and invertible, every singular value is positive.

Then

\[ A^{-1} = V\Sigma^{-1}U^T. \]

Thus the pseudoinverse reduces to the ordinary inverse:

\[ \boxed{A^+=A^{-1}}. \]

Condition Number

For an invertible matrix, the spectral condition number is

\[ \boxed{ \kappa_2(A) = \frac{\sigma_{\max}}{\sigma_{\min}}}. \]

It compares the largest and smallest directional scaling factors.

Well-Conditioned versus Ill-Conditioned

If the singular values are of similar magnitude, the matrix is relatively well-conditioned.

If the smallest singular value is tiny compared with the largest, then \(\kappa_2(A)\) is large and the system is ill-conditioned.

Small input or measurement errors can then be strongly amplified.

Near Dependence

Exact linear dependence produces a zero singular value.

Near dependence produces a very small singular value.

This makes singular values especially useful in numerical work, where exact zero tests may be too rigid.

Numerical Rank

In floating-point computation, a matrix may contain singular values that are nonzero mathematically but negligible relative to the largest scale.

A practical algorithm may treat sufficiently small singular values as zero.

The resulting count is sometimes called the numerical rank.

Thresholding Singular Values

A thresholding rule may keep singular values satisfying

\[ \sigma_i>\tau \]

for a chosen tolerance \(\tau\).

The tolerance should reflect matrix scale, numerical precision, noise level, and application requirements.

Denoising with the SVD

If noise is concentrated in weak directions, small singular components may contain more noise than useful structure.

Truncating those components can therefore produce a cleaner approximation.

This is one reason low-rank methods are widely used in signal and image processing.

Image Compression

A grayscale image can be represented as a matrix of pixel intensities.

A truncated SVD replaces the full image matrix with a low-rank approximation.

Large singular components often preserve broad visual structure, while smaller components encode finer detail.

Text and Recommendation Systems

Large matrices can represent relationships such as:

  • documents by terms;
  • users by products;
  • people by preferences;
  • entities by measured attributes.

Low-rank approximations can reveal latent directional structure hidden in the original high-dimensional representation.

SVD and Latent Structure

The leading singular vectors can be interpreted as dominant hidden directions that organize the data.

These directions need not coincide with the original coordinate axes.

Dimensional reduction therefore replaces many original coordinates with a smaller set of composite directions.

Singular Values versus Eigenvalues

Singular values and eigenvalues are related but different.

  • eigenvalues are defined for square matrices;
  • singular values are defined for rectangular or square matrices;
  • eigenvalues may be negative or complex;
  • singular values are always nonnegative real numbers;
  • eigenvectors satisfy \(Av=\lambda v\);
  • right singular vectors satisfy \(A^TAv=\sigma^2v\).

Symmetric Positive Semidefinite Case

If \(A\) is symmetric positive semidefinite, its eigenvalues are nonnegative.

In that case, the singular values equal the eigenvalues when ordered appropriately.

For general matrices, the two concepts should not be confused.

Singular Values and Determinants

For a square matrix,

\[ |\det(A)| = \sigma_1\sigma_2\cdots\sigma_n. \]

This matches the geometric interpretation: the determinant's magnitude is the total volume-scaling factor, while the singular values are the principal directional scaling factors.

Singular Values and the Frobenius Norm

The Frobenius norm satisfies

\[ \boxed{ \|A\|_F = \sqrt{ \sigma_1^2+\cdots+\sigma_r^2}}. \]

This makes singular values a natural measure of how the matrix's total magnitude is distributed across independent directions.

Spectral Norm

The matrix spectral norm is

\[ \boxed{\|A\|_2=\sigma_1}. \]

Thus the largest singular value is also the operator norm measuring the maximum stretching of a unit vector.

Example: Diagonal Matrix SVD

Consider

\[ A= \begin{bmatrix} 4&0\\ 0&2 \end{bmatrix}. \]

The standard coordinate directions are already orthonormal singular directions.

Therefore one SVD is

\[ U=I, \qquad \Sigma= \begin{bmatrix} 4&0\\ 0&2 \end{bmatrix}, \qquad V=I. \]

The singular values are

\[ \boxed{4,\ 2}. \]

Example: Rank-One Matrix

Consider

\[ A= \begin{bmatrix} 1&2\\ 2&4 \end{bmatrix}. \]

The second column is twice the first, so

\[ \operatorname{rank}(A)=1. \]

Therefore exactly one singular value is nonzero.

The second singular value is

\[ \boxed{0}. \]

Example: Compute Singular Values from \(A^TA\)

Let

\[ A= \begin{bmatrix} 3&0\\ 0&1 \end{bmatrix}. \]

Then

\[ A^TA= \begin{bmatrix} 9&0\\ 0&1 \end{bmatrix}. \]

Its eigenvalues are

\[ 9,\quad1. \]

Therefore the singular values are

\[ \boxed{3,\quad1}. \]

Example: Condition Number

For

\[ A= \begin{bmatrix} 3&0\\ 0&1 \end{bmatrix}, \]

we have

\[ \sigma_{\max}=3, \qquad \sigma_{\min}=1. \]

Thus

\[ \boxed{\kappa_2(A)=3}. \]

Example: Truncated Rank-One Approximation

Suppose

\[ A = 10u_1v_1^T + 2u_2v_2^T + 0.1u_3v_3^T. \]

A rank-one approximation keeps only the strongest component:

\[ \boxed{ A_1=10u_1v_1^T}. \]

Its spectral-norm error is

\[ \boxed{\|A-A_1\|_2=2}. \]

Example: Rank-Two Approximation

Using the same singular expansion,

\[ A_2 = 10u_1v_1^T + 2u_2v_2^T. \]

The spectral-norm error becomes

\[ \boxed{\|A-A_2\|_2=0.1}. \]

The third direction contributes very little compared with the first two.

Low Rank Does Not Mean Low Ambient Dimension

A matrix may have thousands of rows and columns but still have small rank.

Rank measures the number of independent directions, not the number of coordinates used to store the data.

Dimensional reduction exploits this distinction.

Exact Rank versus Approximate Rank

Exact rank counts strictly nonzero singular values.

Approximate or numerical rank counts singular values that remain meaningful relative to noise, precision, or an application threshold.

This distinction is essential in real data.

Common Error: Treating Singular Values as Signed

Singular values are defined to be nonnegative:

\[ \boxed{\sigma_i\ge0}. \]

Orientation or sign information is carried by the orthogonal factors, not by negative singular values.

Common Error: Confusing \(U\) and \(V\)

The columns of \(V\) are input directions.

The columns of \(U\) are output directions.

The relation

\[ Av_i=\sigma_i u_i \]

is a reliable way to remember which is which.

Common Error: Forgetting the Square Root

The eigenvalues of

\[ A^TA \]

are

\[ \sigma_i^2, \]

not \(\sigma_i\) directly.

Therefore,

\[ \boxed{\sigma_i=\sqrt{\lambda_i(A^TA)}}. \]

Common Error: Assuming SVD Requires a Square Matrix

Unlike ordinary eigenvalue decomposition,

\[ \boxed{\text{SVD works for rectangular matrices}}. \]

This is one of its major advantages.

Common Error: Assuming Every Singular Direction Must Be Kept

The full SVD exactly reconstructs the matrix.

But dimensional reduction deliberately discards weaker directions when the resulting approximation is acceptable.

Common Error: Treating Small Singular Values as Automatically Useless

A small singular value may represent noise, but it may also encode meaningful fine-scale structure.

Whether to discard it depends on the application, data quality, and error tolerance.

Common Error: Using Exact Zero Tests in Numerical Data

Real computations involve rounding and measurement noise.

A theoretically zero singular value may appear as a tiny positive number.

Numerical rank therefore requires a scale-aware tolerance.

Common Error: Confusing PCA with Raw SVD

Applying SVD directly to an uncentered data matrix is not generally the same as performing standard PCA.

PCA typically begins by centering the features.

A Reliable Procedure for Computing Singular Values

  1. Form \(A^TA\).
  2. Find the eigenvalues of \(A^TA\).
  3. Order them from largest to smallest.
  4. Take nonnegative square roots.
  5. The results are the singular values.

A Reliable Procedure for Constructing an SVD

  1. Compute eigenvectors \(v_i\) of \(A^TA\).
  2. Normalize them to form the columns of \(V\).
  3. Compute \(\sigma_i=\sqrt{\lambda_i}\).
  4. For each nonzero \(\sigma_i\), compute \(u_i=Av_i/\sigma_i\).
  5. Complete the orthonormal basis of \(U\) if a full SVD is required.
  6. Place the singular values into \(\Sigma\).
  7. Verify \(A=U\Sigma V^T\).

A Reliable Procedure for Dimensional Reduction

  1. Compute or estimate the leading singular values and vectors.
  2. Inspect how rapidly the singular values decrease.
  3. Choose a reduced dimension \(k\).
  4. Keep \(U_k,\Sigma_k,V_k\).
  5. Form \(A_k=U_k\Sigma_kV_k^T\) when reconstruction is needed.
  6. Measure approximation error or retained energy.
  7. Adjust \(k\) based on the application.

A Reliable Procedure for a Pseudoinverse

  1. Compute \(A=U\Sigma V^T\).
  2. Replace each nonzero \(\sigma_i\) by \(1/\sigma_i\).
  3. Leave zero singular values at zero.
  4. Transpose the rectangular diagonal structure to obtain \(\Sigma^+\).
  5. Compute \(A^+=V\Sigma^+U^T\).
  6. Use \(\hat{x}=A^+b\) for the canonical least-squares solution.

Example: Full Singular-Value Workflow

Consider

\[ A= \begin{bmatrix} 3&0\\ 0&1 \end{bmatrix}. \]

First compute

\[ A^TA= \begin{bmatrix} 9&0\\ 0&1 \end{bmatrix}. \]

The eigenvalues are

\[ 9,\qquad1. \]

Therefore,

\[ \sigma_1=3, \qquad \sigma_2=1. \]

Finish the SVD Example

The eigenvectors of \(A^TA\) are the standard basis vectors,

\[ v_1=e_1, \qquad v_2=e_2. \]

Then

\[ u_1=\frac{Av_1}{\sigma_1}=e_1, \]

and

\[ u_2=\frac{Av_2}{\sigma_2}=e_2. \]

Thus

\[ \boxed{ U=I, \qquad \Sigma= \begin{bmatrix} 3&0\\ 0&1 \end{bmatrix}, \qquad V=I}. \]

Example: Full Dimensional-Reduction Interpretation

Suppose a data matrix has singular values

\[ 20,\quad7,\quad1,\quad0.2,\quad0.05. \]

The first two directions are much stronger than the remaining three.

A rank-two approximation keeps the components associated with

\[ 20 \quad\text{and}\quad 7. \]

The remaining singular values quantify the information discarded by the reduction.

Why Singular Values Matter in Multidimensional Systems

Singular values reveal which directions in a multidimensional system are strong, weak, redundant, or nearly redundant.

The SVD organizes those directions into orthonormal coordinate systems, provides stable tools for least squares and pseudoinverses, and gives the mathematically optimal low-rank approximations used in compression and dimensional reduction.

This makes the SVD a central bridge between pure linear algebra and modern numerical computing, statistics, signal processing, machine learning, scientific modeling, and large-scale data analysis.

What to Remember

Every real matrix admits a singular value decomposition:

\[ \boxed{A=U\Sigma V^T}. \]
  • \(V\) contains orthonormal input singular directions.
  • \(U\) contains orthonormal output singular directions.
  • \(\Sigma\) contains nonnegative singular values.
  • Singular values are square roots of eigenvalues of \(A^TA\).
  • The number of nonzero singular values equals the rank.
  • The largest singular value gives the maximum stretching factor.
  • Small singular values indicate weak or nearly dependent directions.
  • Truncated SVD gives optimal low-rank approximations.
  • The pseudoinverse is \(A^+=V\Sigma^+U^T\).
  • The condition number is the ratio of largest to smallest nonzero singular value for an invertible matrix.
  • SVD supports compression, denoising, least squares, PCA, and dimensional reduction.

The central structural idea is:

\[ \boxed{ \text{a matrix acts through orthogonal directions with measurable strengths}}. \]
