Numerical Integration

A definite integral measures exact accumulation, but exact symbolic antiderivatives are not always available or convenient. In many practical situations, the function is known only through measured data. Numerical integration estimates a definite integral by replacing a continuously varying quantity with simpler local approximations that can be added.

The Central Idea

Numerical integration approximates

\[ \int_a^b f(x)\,dx \]

using a finite collection of function values.

The general strategy is:

  1. divide the interval into subintervals;
  2. approximate the function on each subinterval;
  3. compute the corresponding local area or accumulation;
  4. add the local contributions.

Different numerical methods use different local approximations.

Why Numerical Integration Is Needed

Numerical integration is useful when:

  • an antiderivative is difficult to find;
  • no elementary antiderivative exists;
  • the function is available only as a table of measured values;
  • a computer or calculator is being used for approximation;
  • a quick estimate is more useful than an exact symbolic expression.

Equal Subintervals

Divide

\[ [a,b] \]

into \(n\) equal subintervals.

The width is

\[ \boxed{\Delta x=\frac{b-a}{n}}. \]

The partition points are

\[ x_i=a+i\Delta x. \]

Left Endpoint Rule

The left endpoint rule uses the left endpoint of each subinterval:

\[ \boxed{ L_n= \Delta x \left[ f(x_0)+f(x_1)+\cdots+f(x_{n-1}) \right] }. \]

This is the same left Riemann sum introduced earlier.

Right Endpoint Rule

The right endpoint rule uses the right endpoint of each subinterval:

\[ \boxed{ R_n= \Delta x \left[ f(x_1)+f(x_2)+\cdots+f(x_n) \right] }. \]

Midpoint Rule

The midpoint rule evaluates the function at the center of each subinterval.

If

\[ m_i=\frac{x_{i-1}+x_i}{2}, \]

then

\[ \boxed{ M_n= \Delta x \sum_{i=1}^{n}f(m_i) }. \]

Midpoint estimates are often much more accurate than left or right sums using the same number of subintervals.

The Trapezoidal Rule

Instead of approximating the graph by horizontal rectangles, the trapezoidal rule connects neighboring data points with straight line segments.

Each subinterval contributes the area of a trapezoid.

\[ \boxed{ \text{trapezoid area} = \frac12 (\text{left height}+\text{right height}) (\text{width}) }. \]

Composite Trapezoidal Rule

For \(n\) equal subintervals,

\[ \boxed{ T_n= \frac{\Delta x}{2} \left[ f(x_0) +2f(x_1) +2f(x_2) +\cdots +2f(x_{n-1}) +f(x_n) \right] }. \]

The endpoint values appear once, while interior values appear twice.

The Trapezoidal Rule as an Average

For equal subintervals,

\[ \boxed{ T_n=\frac{L_n+R_n}{2} }. \]

This provides a useful connection between rectangle approximations and trapezoidal approximation.

Simpson’s Rule

Simpson’s Rule improves the local approximation further by fitting quadratic curves rather than horizontal or straight-line pieces.

It is usually substantially more accurate for smooth functions.

The standard composite Simpson’s Rule requires an even number of subintervals.

Composite Simpson’s Rule

If \(n\) is even and

\[ \Delta x=\frac{b-a}{n}, \]

then

\[ \boxed{ S_n= \frac{\Delta x}{3} \left[ f(x_0) +4f(x_1) +2f(x_2) +4f(x_3) +\cdots +2f(x_{n-2}) +4f(x_{n-1}) +f(x_n) \right] }. \]

The interior weights alternate:

\[ \boxed{4,2,4,2,\ldots,4}. \]

Remembering the Simpson Pattern

For \(n\) even, the coefficient pattern is

\[ \boxed{ 1,\ 4,\ 2,\ 4,\ 2,\ \ldots,\ 4,\ 1 }. \]

Then multiply the weighted sum by

\[ \boxed{\frac{\Delta x}{3}}. \]

Example: Approximate \(\int_0^2 x^2\,dx\)

Use \(n=4\) equal subintervals.

The width is

\[ \Delta x=\frac{2-0}{4}=\frac12. \]

The partition points are

\[ 0,\quad\frac12,\quad1,\quad\frac32,\quad2. \]

Left Endpoint Approximation

\[ L_4= \frac12 \left[ 0^2+ \left(\frac12\right)^2+ 1^2+ \left(\frac32\right)^2 \right]. \]

Therefore,

\[ L_4= \frac12 \left[ 0+\frac14+1+\frac94 \right]. \] \[ \boxed{L_4=\frac74=1.75}. \]

Right Endpoint Approximation

\[ R_4= \frac12 \left[ \left(\frac12\right)^2+ 1^2+ \left(\frac32\right)^2+ 2^2 \right]. \]

Thus,

\[ \boxed{R_4=\frac{15}{4}=3.75}. \]

Midpoint Approximation

The midpoints are

\[ \frac14,\quad\frac34,\quad\frac54,\quad\frac74. \]

Therefore,

\[ M_4= \frac12 \left[ \left(\frac14\right)^2+ \left(\frac34\right)^2+ \left(\frac54\right)^2+ \left(\frac74\right)^2 \right]. \]

Hence,

\[ \boxed{M_4=\frac{21}{8}=2.625}. \]

Trapezoidal Approximation

Since

\[ T_4=\frac{L_4+R_4}{2}, \]

we have

\[ T_4= \frac{1.75+3.75}{2}. \]

Therefore,

\[ \boxed{T_4=2.75}. \]

Simpson Approximation

Use

\[ S_4= \frac{\Delta x}{3} \left[ f(x_0)+4f(x_1)+2f(x_2)+4f(x_3)+f(x_4) \right]. \]

Thus,

\[ S_4= \frac{1/2}{3} \left[ 0+ 4\left(\frac14\right)+ 2(1)+ 4\left(\frac94\right)+ 4 \right]. \]

The weighted sum is

\[ 0+1+2+9+4=16. \]

Hence,

\[ \boxed{ S_4=\frac16(16)=\frac83 }. \]

In this case Simpson’s Rule is exact because \(x^2\) is quadratic.

Comparing the Estimates

The exact value is

\[ \int_0^2x^2\,dx=\frac83\approx2.667. \]

Our estimates were

\[ L_4=1.75, \] \[ M_4=2.625, \] \[ T_4=2.75, \]

and

\[ S_4=\frac83. \]

This illustrates how different approximation rules can have very different accuracy.

Unequal Subintervals

The simple composite formulas above assume equal spacing.

With unequal spacing, the trapezoidal rule can still be applied interval-by-interval:

\[ \boxed{ T = \sum_{i=1}^{n} \frac{f(x_{i-1})+f(x_i)}{2} (x_i-x_{i-1}) }. \]

Each trapezoid uses its own width.

Approximation Error

Numerical integration replaces a curved function with a simpler local model.

The difference between the approximation and the true integral is the numerical integration error.

In general, error becomes smaller as the partition is refined.

Monotonicity and Endpoint Errors

If \(f\) is increasing and positive:

  • left sums tend to underestimate;
  • right sums tend to overestimate.

If \(f\) is decreasing and positive, the pattern reverses.

Concavity and the Trapezoidal Rule

If \(f\) is concave up, secant lines tend to lie above the graph.

Therefore the trapezoidal rule tends to overestimate.

If \(f\) is concave down, secant lines tend to lie below the graph, so the trapezoidal rule tends to underestimate.

Concavity and the Midpoint Rule

For smooth functions, midpoint behavior typically goes in the opposite direction from trapezoidal behavior.

  • concave up: midpoint tends to underestimate;
  • concave down: midpoint tends to overestimate.

Trapezoidal Error Bound

If

\[ |f''(x)|\leq K \]

on \([a,b]\), then

\[ \boxed{ |E_T| \leq \frac{K(b-a)^3}{12n^2} }. \]

This shows that trapezoidal error decreases on the order of \(1/n^2\).

Midpoint Error Bound

If

\[ |f''(x)|\leq K, \]

then

\[ \boxed{ |E_M| \leq \frac{K(b-a)^3}{24n^2} }. \]

The midpoint bound has half the constant of the trapezoidal bound.

Simpson Error Bound

If \(n\) is even and

\[ |f^{(4)}(x)|\leq K \]

on \([a,b]\), then

\[ \boxed{ |E_S| \leq \frac{K(b-a)^5}{180n^4} }. \]

Simpson error decreases on the order of \(1/n^4\), which explains its strong performance for smooth functions.

Exactness for Certain Functions

Numerical methods are approximations in general, but some are exact for particular classes of functions.

  • the trapezoidal rule is exact for linear functions;
  • the midpoint rule is exact for linear functions;
  • Simpson’s Rule is exact for all polynomials of degree at most \(3\).

Choosing a Numerical Method

A practical hierarchy is:

  • use left or right sums when only endpoint-style estimates are needed;
  • use midpoint for a simple but often strong approximation;
  • use trapezoidal when tabular endpoint data are natural;
  • use Simpson’s Rule when the spacing is equal, \(n\) is even, and higher accuracy is desired.

Data Quality Matters

Numerical integration cannot recover information that was never measured.

Sparse, noisy, or irregularly spaced data can limit the reliability of an integral estimate.

A mathematically precise quadrature formula does not eliminate uncertainty in the underlying measurements.

Units in Numerical Integration

Each numerical term has the same units as

\[ f(x)\Delta x. \]

For example, if \(v(t)\) is in meters per second and \(\Delta t\) is in seconds, then each contribution is in meters.

The numerical integral therefore approximates displacement.

Refining the Partition

If the number of equal subintervals is doubled, the width is halved:

\[ \Delta x=\frac{b-a}{n}. \]

Smaller widths usually improve the local representation of the function.

Comparing estimates for \(n\), \(2n\), and \(4n\) is a practical way to assess numerical stability.

Common Error: Confusing Data Points with Subintervals

If a table contains \(n+1\) equally spaced data points, then there are \(n\) subintervals.

For example, five data points create four subintervals.

Common Error: Using Simpson’s Rule with Odd \(n\)

The standard composite Simpson’s Rule requires

\[ \boxed{n\text{ even}}. \]

If \(n\) is odd, adjust the partition or use another method.

Common Error: Losing the Simpson Weights

The pattern must be

\[ \boxed{1,4,2,4,2,\ldots,4,1}. \]

The two endpoints receive coefficient \(1\), odd-indexed interior values receive \(4\), and even-indexed interior values receive \(2\).

Common Error: Forgetting the Width Factor

Every numerical integration rule contains the subinterval width.

A weighted sum of function values alone does not yet have the correct accumulated scale or units.

Common Error: Applying Equal-Spacing Formulas to Unequal Data

Before using a composite formula, verify that the \(x\)-values are equally spaced.

For irregular spacing, compute contributions interval by interval unless a method specifically designed for nonuniform spacing is being used.

A Reliable Numerical Integration Procedure

  1. Identify the interval and available data.
  2. Determine the number of subintervals.
  3. Check whether the spacing is uniform.
  4. Choose an appropriate rule.
  5. Write the formula before substituting numbers.
  6. Apply the correct weights.
  7. Multiply by the width factor.
  8. Carry units through the calculation.
  9. Estimate whether the result should be high or low when possible.
  10. Refine the partition if greater accuracy is needed.

What to Remember

Numerical integration estimates

\[ \boxed{\int_a^b f(x)\,dx} \]

using finitely many function values.

For equal subintervals,

\[ \boxed{\Delta x=\frac{b-a}{n}}. \]

The main rules are:

\[ \boxed{ L_n,\quad R_n,\quad M_n,\quad T_n,\quad S_n }. \]

The trapezoidal rule uses straight-line approximations, while Simpson’s Rule uses quadratic approximations.

As a practical principle:

use the simplest method that matches the available data and the accuracy you need, then refine the partition when greater precision is required.
