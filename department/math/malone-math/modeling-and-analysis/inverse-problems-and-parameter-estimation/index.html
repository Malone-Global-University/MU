Inverse Problems and Parameter Estimation

Inverse problems begin with observations and ask what hidden parameters, states, causes, or spatial structures could have produced them. This section develops the complete estimation pipeline: implementing forward models, understanding identifiability, fitting parameters, constructing statistical estimators, stabilizing ill-posed problems, representing measurement error, comparing models, assimilating sequential data, and reconstructing images and fields.

Overview

A forward model begins with unknown quantities and predicts observable data:

\[ \boldsymbol{\theta} \longrightarrow F(\boldsymbol{\theta}) = \hat{\mathbf{y}}. \]

An inverse problem reverses that direction:

\[ \mathbf{y}_{\text{obs}} \longrightarrow \text{inference about } \boldsymbol{\theta}. \]

The challenge is that real observations contain noise, models may be imperfect, several parameter combinations may explain the same data, and direct inversion may be unstable. The lessons below build the mathematical and computational tools needed to handle those difficulties systematically.

Learning Path

The section is organized as a progression from model construction to inverse inference and finally to high-dimensional reconstruction:

  1. Implement the forward model correctly.
  2. Distinguish forward and inverse questions.
  3. Determine whether the unknown quantities are identifiable.
  4. Fit parameters to observations.
  5. Develop least-squares and likelihood-based estimators.
  6. Extend estimation through Bayesian inference.
  7. Stabilize weak or ill-conditioned inverse problems.
  8. Understand ill-posedness and measurement uncertainty.
  9. Compare competing model structures.
  10. Update evolving states and parameters as new data arrive.
  11. Apply the framework to imaging and reconstruction.

Core Mathematical Structure

Many of the lessons in this section can be organized around the observation model

\[ \boxed{ \mathbf{y} = F(\boldsymbol{\theta}) + \boldsymbol{\varepsilon} }. \]

The major questions are:

  • What does the forward model \(F\) predict?
  • Can different parameter values produce the same observations?
  • How should mismatch between prediction and data be measured?
  • What probability model describes \(\boldsymbol{\varepsilon}\)?
  • How sensitive is the inverse solution to noise?
  • What regularization or prior information is justified?
  • How should uncertainty be represented?
  • Which model structure is best supported?

Estimation Frameworks

Several major estimation frameworks appear repeatedly.

Least Squares

\[ \hat{\boldsymbol{\theta}} = \operatorname*{arg\,min}_{\boldsymbol{\theta}} \| \mathbf{y} - F(\boldsymbol{\theta}) \|_2^2. \]

Maximum Likelihood

\[ \hat{\boldsymbol{\theta}}_{\mathrm{MLE}} = \operatorname*{arg\,max}_{\boldsymbol{\theta}} p( \mathbf{y} \mid \boldsymbol{\theta} ). \]

Bayesian Estimation

\[ p( \boldsymbol{\theta} \mid \mathbf{y} ) \propto p( \mathbf{y} \mid \boldsymbol{\theta} ) p( \boldsymbol{\theta} ). \]

Regularized Estimation

\[ \hat{\boldsymbol{\theta}}_{\lambda} = \operatorname*{arg\,min}_{\boldsymbol{\theta}} \left[ \Phi( \boldsymbol{\theta} ) + \lambda R( \boldsymbol{\theta} ) \right]. \]

Recurring Themes

Across the section, several ideas should remain connected:

  • Forward modeling: estimation is only as reliable as the model used to predict observations.
  • Identifiability: parameters cannot be recovered if the data do not distinguish them.
  • Stability: a unique solution may still be unusable if small data errors create large parameter changes.
  • Noise modeling: measurement uncertainty determines appropriate weighting and likelihood structure.
  • Regularization: weak directions often require additional structure for stable recovery.
  • Validation: fitting the observed data is not enough; residuals and predictive behavior must be checked.
  • Uncertainty: point estimates should be accompanied by information about what remains weakly determined.

What to Remember

Inverse problems transform observations into statements about hidden quantities. That transformation is rarely a simple reversal of the forward model.

Reliable inference requires the combined study of:

\[ \boxed{ \text{model structure} + \text{identifiability} + \text{estimation} + \text{noise} + \text{regularization} + \text{validation} }. \]

The strongest inverse conclusions are those that remain stable under realistic measurement error, reasonable modeling alternatives, and appropriate uncertainty analysis.
