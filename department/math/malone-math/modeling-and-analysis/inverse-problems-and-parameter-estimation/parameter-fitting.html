Parameter Fitting

Parameter fitting is the process of choosing model parameters so that model predictions agree as closely as possible with observed data. The task sits at the center of inverse problems: a forward model predicts observations from parameters, while fitting works in the opposite direction by using observed discrepancies to estimate the unknown parameters. Good fitting requires more than running an optimizer. It requires a clear residual definition, an appropriate objective function, sensible parameter constraints, diagnostic checks, and evidence that the fitted parameters are both numerically and scientifically meaningful.

The Central Idea

Suppose a model depends on parameters

\[ \boldsymbol{\theta} = (\theta_1,\theta_2,\ldots,\theta_p) \]

and predicts observations through

\[ \mathbf{y}_{\text{pred}} = F(\boldsymbol{\theta}). \]

We also have measured data

\[ \mathbf{y}_{\text{obs}}. \]

Parameter fitting seeks a parameter vector for which

\[ F(\boldsymbol{\theta}) \]

agrees well with the observed data.

In compact form,

\[ \boxed{ \boldsymbol{\theta}^{*} = \operatorname*{arg\,min}_{\boldsymbol{\theta}} \Phi(\boldsymbol{\theta}) } \]

where \(\Phi\) measures model-data disagreement.

From Forward Model to Fitting Problem

The forward problem starts with parameters and predicts data:

\[ \boldsymbol{\theta} \longrightarrow F(\boldsymbol{\theta}). \]

The fitting problem begins with observations and searches for parameters:

\[ \mathbf{y}_{\text{obs}} \longrightarrow \boldsymbol{\theta}^{*}. \]

Because the inverse direction is usually not available as a simple formula, parameter fitting is commonly performed by repeated forward evaluations.

The Residual

The difference between an observed value and a predicted value is called a residual.

For one observation,

\[ r_i(\boldsymbol{\theta}) = y_i^{\text{obs}} - y_i^{\text{pred}}(\boldsymbol{\theta}). \]

Since

\[ y_i^{\text{pred}}(\boldsymbol{\theta}) = F_i(\boldsymbol{\theta}), \]

we may write

\[ \boxed{ r_i(\boldsymbol{\theta}) = y_i^{\text{obs}} - F_i(\boldsymbol{\theta}) }. \]

The Residual Vector

With \(n\) observations, collect the residuals into a vector:

\[ \mathbf{r}(\boldsymbol{\theta}) = \begin{bmatrix} r_1(\boldsymbol{\theta})\\ r_2(\boldsymbol{\theta})\\ \vdots\\ r_n(\boldsymbol{\theta}) \end{bmatrix}. \]

Equivalently,

\[ \boxed{ \mathbf{r}(\boldsymbol{\theta}) = \mathbf{y}_{\text{obs}} - F(\boldsymbol{\theta}) }. \]

The residual vector is the fundamental bridge between prediction and estimation.

Why Residuals Matter

Residuals tell us both the magnitude and direction of mismatch.

If

\[ r_i>0, \]

then the model prediction is smaller than the observation.

If

\[ r_i<0, \]

then the model prediction is larger than the observation.

If

\[ r_i=0, \]

then the model matches that observation exactly.

From Residuals to an Objective Function

An optimizer usually requires a single scalar quantity to minimize.

The residual vector must therefore be summarized by an objective function or loss function.

A common choice is the sum of squared residuals:

\[ \Phi(\boldsymbol{\theta}) = \sum_{i=1}^{n} r_i(\boldsymbol{\theta})^2. \]

In vector notation,

\[ \boxed{ \Phi(\boldsymbol{\theta}) = \|\mathbf{r}(\boldsymbol{\theta})\|_2^2 }. \]

Why Square the Residuals?

Squaring residuals provides several useful properties:

  • positive and negative residuals do not cancel;
  • larger errors receive greater penalty;
  • the objective is differentiable in many common models;
  • the method connects naturally to Gaussian measurement error;
  • efficient numerical algorithms are available.

The resulting method is called least squares, which will be developed in greater detail in the next lesson.

A Simple One-Parameter Fit

Suppose the model is

\[ y=\theta x \]

and the observed data are

\[ (x_1,y_1),\ldots,(x_n,y_n). \]

The predicted values are

\[ \hat{y}_i=\theta x_i. \]

The residuals are

\[ r_i=y_i-\theta x_i. \]

A least-squares fit chooses \(\theta\) to minimize

\[ \Phi(\theta) = \sum_{i=1}^{n}(y_i-\theta x_i)^2. \]

Exact Fit Versus Approximate Fit

If there exists a parameter vector such that

\[ F(\boldsymbol{\theta})=\mathbf{y}_{\text{obs}}, \]

then the residual vector is zero:

\[ \mathbf{r}(\boldsymbol{\theta})=\mathbf{0}. \]

Real data usually contain noise, however, so an exact match is often neither possible nor desirable.

Parameter fitting usually seeks the best compromise among many imperfect observations.

Overdetermined Fitting Problems

A fitting problem is often overdetermined, meaning that the number of observations exceeds the number of parameters:

\[ n>p. \]

In this situation, the model generally cannot satisfy every observation exactly.

The objective function provides a systematic way to choose the parameter vector that best balances the discrepancies.

Underdetermined Fitting Problems

If

\[ n there are fewer observations than unknown parameters.

Such a problem may have many parameter vectors that fit the data equally well.

Additional information may be required through:

  • more observations;
  • parameter constraints;
  • regularization;
  • prior information;
  • model simplification.

Parameter Fitting Depends on Identifiability

A fitting algorithm can produce a numerical answer even when the model is nonidentifiable.

If many parameter vectors produce nearly the same predictions, the optimizer may simply select one member of a broad family of solutions.

Therefore,

\[ \boxed{ \text{successful optimization does not prove successful identification} }. \]

Weighted Residuals

Not all observations should necessarily contribute equally to the objective.

Suppose observation \(i\) has scale or uncertainty \(\sigma_i\). A scaled residual may be defined as

\[ \tilde{r}_i = \frac{y_i^{\text{obs}}-F_i(\boldsymbol{\theta})}{\sigma_i}. \]

The corresponding weighted least-squares objective is

\[ \boxed{ \Phi(\boldsymbol{\theta}) = \sum_{i=1}^{n} \frac{ \left[y_i^{\text{obs}}-F_i(\boldsymbol{\theta})\right]^2 }{\sigma_i^2} }. \]

Why Weighting Matters

Suppose one measurement is expressed in thousands while another is expressed in tenths.

If raw residuals are squared without scaling, the numerically larger variable may dominate the fit even when it is not more scientifically important.

Weighting can account for:

  • measurement uncertainty;
  • different physical units;
  • different response magnitudes;
  • different confidence levels;
  • different sampling frequencies.

Matrix Form of a Weighted Objective

Let \(W\) be a weighting matrix. Then a general quadratic objective can be written

\[ \Phi(\boldsymbol{\theta}) = \mathbf{r}(\boldsymbol{\theta})^{T} W \mathbf{r}(\boldsymbol{\theta}). \]

If the measurement errors are independent with variances \(\sigma_i^2\), a common choice is

\[ W = \operatorname{diag} \left( \frac{1}{\sigma_1^2}, \ldots, \frac{1}{\sigma_n^2} \right). \]

Correlated Measurement Errors

Measurement errors are not always independent.

If the error covariance matrix is

\[ \Sigma, \]

then a natural quadratic objective is

\[ \boxed{ \Phi(\boldsymbol{\theta}) = \mathbf{r}^{T} \Sigma^{-1} \mathbf{r} }. \]

Off-diagonal covariance terms represent statistical relationships among measurement errors.

Absolute-Error Objectives

Squared residuals are not the only possible choice.

An absolute-error objective is

\[ \Phi(\boldsymbol{\theta}) = \sum_{i=1}^{n} |r_i(\boldsymbol{\theta})|. \]

Compared with squared error, absolute error reduces the influence of very large residuals.

The choice of objective should reflect the assumed error structure and the goals of the analysis.

Relative-Error Objectives

When observations span several orders of magnitude, relative errors may be more informative than absolute errors.

One form is

\[ r_i^{\text{rel}} = \frac{y_i^{\text{obs}}-F_i(\boldsymbol{\theta})} {y_i^{\text{obs}}}. \]

A corresponding objective is

\[ \Phi = \sum_i \left(r_i^{\text{rel}}\right)^2. \]

Care is required when observed values are zero or very close to zero.

Logarithmic Residuals

For positive quantities spanning wide ranges, one may compare logarithms:

\[ r_i^{\log} = \log y_i^{\text{obs}} - \log F_i(\boldsymbol{\theta}). \]

This treats multiplicative differences more naturally than raw additive differences.

For example, predicting \(20\) instead of \(10\) produces the same logarithmic ratio error as predicting \(200\) instead of \(100\).

Choosing the Parameterization

A parameter can often be represented in several equivalent ways.

If a parameter must remain positive, instead of fitting

\[ \theta>0 \]

directly, one may introduce

\[ \eta=\log\theta. \]

Then

\[ \theta=e^{\eta} \]

is automatically positive for every real \(\eta\).

Why Reparameterization Can Help

Reparameterization can improve:

  • constraint handling;
  • parameter scaling;
  • numerical conditioning;
  • optimization geometry;
  • interpretation of identifiable combinations.

A good parameterization makes the structure of the fitting problem easier for both the optimizer and the analyst to interpret.

Parameter Bounds

Physical knowledge may restrict parameters to an interval:

\[ \theta_j^{\min} \le \theta_j \le \theta_j^{\max}. \]

Examples include:

  • positive rate constants;
  • probabilities between \(0\) and \(1\);
  • material properties within feasible ranges;
  • geometric dimensions constrained by design.

Bounds can prevent meaningless trial values and improve computational efficiency.

Bounds Do Not Replace Identifiability

If an optimizer returns a parameter at a boundary, this can indicate that:

  • the true optimum lies outside the allowed region;
  • the data are weakly informative;
  • the model is misspecified;
  • the parameter is poorly identifiable;
  • the bound itself is influencing the result.

A fitted boundary value should therefore be interpreted carefully.

Initialization

Many nonlinear fitting algorithms require an initial guess

\[ \boldsymbol{\theta}^{(0)}. \]

The initial guess can influence:

  • which local minimum is reached;
  • how quickly the algorithm converges;
  • whether the solver enters an invalid region;
  • whether the fit succeeds at all.

Initialization is therefore part of the modeling workflow, not merely a software detail.

Local and Global Minima

A nonlinear objective function can possess several minima.

A local minimum is better than nearby parameter values.

A global minimum is at least as good as every admissible parameter value.

A local optimization algorithm can converge successfully while still missing the global best fit.

Multi-Start Fitting

One practical strategy is to solve the fitting problem repeatedly from several initial guesses.

If many starts converge to the same parameter vector and objective value, confidence in the optimization result increases.

If different starts converge to substantially different solutions, the objective may contain multiple basins or flat directions that deserve further investigation.

Grid Searches

For one or two parameters, a direct grid evaluation can be highly informative.

Evaluate

\[ \Phi(\theta_1,\theta_2) \]

over a range of parameter values.

The resulting surface can reveal:

  • multiple minima;
  • flat valleys;
  • parameter correlations;
  • boundary effects;
  • poor scaling.

Gradient-Based Fitting

If the objective is differentiable, gradient-based methods use

\[ \nabla_{\boldsymbol{\theta}}\Phi \]

to determine directions of decrease.

These methods can converge efficiently when the objective is smooth and the derivatives are accurate.

They can be less reliable when the model is discontinuous, noisy, poorly scaled, or contains many local minima.

Derivative-Free Fitting

Derivative-free methods estimate progress using function evaluations rather than explicit gradients.

They may be useful when:

  • the forward model is a black box;
  • derivatives are unavailable;
  • the model includes nondifferentiable components;
  • numerical noise corrupts finite differences.

Their efficiency can deteriorate as the number of parameters grows.

The Jacobian of the Residuals

For nonlinear least squares, an important matrix is the residual Jacobian

\[ J_r = \frac{\partial\mathbf{r}} {\partial\boldsymbol{\theta}}. \]

Since

\[ \mathbf{r} = \mathbf{y}_{\text{obs}} - F(\boldsymbol{\theta}), \]

we have

\[ J_r = - \frac{\partial F} {\partial\boldsymbol{\theta}}. \]

Thus the fitting Jacobian is directly connected to the model sensitivity matrix.

Gradient of a Least-Squares Objective

For

\[ \Phi = \mathbf{r}^{T}\mathbf{r}, \]

the gradient is

\[ \nabla\Phi = 2J_r^{T}\mathbf{r}. \]

This equation connects residual size and parameter sensitivity.

A direction is important to the optimizer when changing parameters both affects the predictions and reduces the observed residuals.

Linearization Near a Current Estimate

Around a current parameter estimate

\[ \boldsymbol{\theta}_k, \]

the residual vector can be approximated by

\[ \mathbf{r}(\boldsymbol{\theta}_k+\Delta\boldsymbol{\theta}) \approx \mathbf{r}(\boldsymbol{\theta}_k) + J_r(\boldsymbol{\theta}_k)\Delta\boldsymbol{\theta}. \]

Many nonlinear least-squares algorithms use this local linear approximation to choose the next parameter update.

Gauss-Newton Structure

In a least-squares problem, the Gauss-Newton step approximately solves

\[ J_r^{T}J_r \Delta\boldsymbol{\theta} = - J_r^{T}\mathbf{r}. \]

The parameter estimate is then updated:

\[ \boldsymbol{\theta}_{k+1} = \boldsymbol{\theta}_k + \Delta\boldsymbol{\theta}. \]

This connects nonlinear parameter fitting to repeated linear least-squares problems.

Ill-Conditioned Parameter Updates

If the columns of \(J_r\) are nearly dependent, then

\[ J_r^{T}J_r \]

can be poorly conditioned.

Small changes in the data or residuals may then cause large changes in the computed parameter update.

This is one way practical identifiability problems appear inside fitting algorithms.

Parameter Scaling

Suppose one parameter is of order

\[ 10^{-6} \]

while another is of order

\[ 10^{5}. \]

Treating both parameters on the same raw numerical scale can make optimization inefficient.

Scaled parameters may be introduced as

\[ q_j = \frac{\theta_j}{s_j}, \]

where \(s_j\) is a characteristic parameter scale.

Residual Scaling

Residual components may also require scaling.

If one observable naturally has values near \(10^6\) and another near \(10^{-2}\), raw squared residuals may overwhelmingly favor the first.

Good residual scaling makes the objective reflect scientific relevance, measurement uncertainty, or meaningful relative error rather than arbitrary numerical units.

Fitting Multiple Data Sets

A single parameter vector may need to explain several experiments.

Suppose experiments \(1,\ldots,m\) produce residual vectors

\[ \mathbf{r}^{(1)}, \ldots, \mathbf{r}^{(m)}. \]

A combined objective may be

\[ \Phi = \sum_{j=1}^{m} w_j \left\| \mathbf{r}^{(j)} \right\|^2. \]

Joint fitting can reveal whether one parameter set consistently explains multiple operating conditions.

Shared and Experiment-Specific Parameters

In multi-experiment fitting, some parameters may be shared while others vary by experiment.

For example,

\[ \boldsymbol{\theta} = (\boldsymbol{\theta}_{\text{shared}}, \boldsymbol{\theta}_{1}, \ldots, \boldsymbol{\theta}_{m}). \]

This structure can separate universal model properties from experiment-specific initial conditions, offsets, or nuisance parameters.

Nuisance Parameters

A nuisance parameter affects the observations but is not the main scientific quantity of interest.

Examples include:

  • instrument offsets;
  • background levels;
  • calibration factors;
  • unknown initial states;
  • timing shifts.

Nuisance parameters may still need to be fitted so that the parameters of interest are not biased.

Data Preprocessing and Fitting

Fitting results can depend strongly on preprocessing choices.

Examples include:

  • baseline subtraction;
  • smoothing;
  • normalization;
  • outlier removal;
  • time alignment;
  • unit conversion.

Preprocessing should be documented because it changes the data presented to the inverse problem.

Outliers

An outlier is an observation that differs substantially from the pattern of the remaining data.

Under squared-error fitting, large residuals receive disproportionately large weight because

\[ r^2 \]

grows rapidly with \(|r|\).

Outliers can therefore pull fitted parameters away from values supported by most of the data.

Robust Fitting

Robust loss functions reduce the influence of unusually large residuals.

A robust objective may behave approximately like

\[ r^2 \]

for small residuals but grow more slowly for large residuals.

Robust fitting can be appropriate when occasional contamination or outliers are expected, but the choice should reflect the data-generation process.

Fitting Is Not Interpolation

Interpolation constructs a function that passes exactly through specified data points.

Parameter fitting instead chooses parameters within a prescribed model family.

The fitted model generally does not pass through every observation.

Its purpose is to infer a parameterized relationship, not merely to reproduce each data point exactly.

Fitting Is Not Model Validation

A low fitting error does not prove that a model is correct.

A flexible model may fit one data set closely while failing under new conditions.

Model validation asks whether the fitted model makes adequate predictions outside the information directly used to determine its parameters.

Training and Validation Data

One strategy is to divide the available data into:

  • a fitting or training set;
  • a validation or testing set.

Parameters are estimated using the fitting data.

The resulting parameter values are then used to predict observations that were not used during fitting.

Good out-of-sample performance provides stronger evidence than fit quality alone.

Residual Plots

After fitting, residuals should be inspected rather than summarized only by a single objective value.

Useful plots include residuals versus:

  • time;
  • predicted value;
  • input value;
  • experimental condition;
  • measurement index.

Structured residual patterns can reveal model deficiencies that a single goodness-of-fit number hides.

Residuals Should Not Contain Obvious Structure

Ideally, residuals should look consistent with the assumed measurement noise.

Persistent trends, oscillations, clusters, or systematic sign changes can indicate:

  • missing dynamics;
  • incorrect functional form;
  • unmodeled dependence;
  • measurement bias;
  • incorrect weighting.

Underfitting

Underfitting occurs when the model is too simple to capture important structure in the data.

Symptoms can include:

  • large residuals;
  • systematic residual patterns;
  • poor prediction across conditions;
  • consistent bias.

Underfitting cannot be repaired simply by optimizing the same inadequate model more aggressively.

Overfitting

Overfitting occurs when a model adapts too closely to the particular noise or accidental features of the fitting data.

An overfit model may have:

  • very small training residuals;
  • unstable parameter estimates;
  • poor performance on new data;
  • unnecessarily large parameter count.

Model selection and regularization help address this tradeoff.

Parameter Uncertainty After Fitting

A best-fit value alone does not describe how strongly the parameter is determined.

A complete analysis should ask how much the parameter could vary while remaining consistent with the data.

Uncertainty can be investigated through:

  • covariance approximations;
  • confidence intervals;
  • profile likelihoods;
  • bootstrap methods;
  • Bayesian posterior distributions.

Approximate Covariance Near a Least-Squares Solution

Under suitable assumptions, local parameter uncertainty is connected to

\[ J_r^{T}J_r. \]

Roughly speaking, if this matrix is well conditioned and has large curvature in all parameter directions, the data strongly constrain the parameters.

Small eigenvalues indicate directions in which the objective changes only weakly.

Confidence Regions and Objective Geometry

In two parameters, a well-constrained fit may produce a compact region around the optimum.

A long narrow region indicates strong parameter correlation.

A nearly open valley indicates weak identifiability.

The shape of the objective surface is therefore as informative as the location of its minimum.

Parameter Fitting with Constraints

Some models require equality or inequality constraints in addition to simple bounds.

For example,

\[ \theta_1+\theta_2+\theta_3=1, \]

or

\[ \theta_1\theta_2\ge c. \]

Constrained optimization methods can enforce these relationships during the fitting process.

Transforming a Sum-to-One Constraint

Suppose

\[ \theta_1+\theta_2=1. \]

Instead of fitting both independently, write

\[ \theta_2=1-\theta_1. \]

The fitting problem then contains only one independent parameter.

Reparameterizing exact constraints can reduce dimensionality and eliminate unnecessary degrees of freedom.

Stopping Criteria

Numerical fitting algorithms need rules for deciding when to stop.

Common stopping criteria include:

  • small change in objective value;
  • small change in parameter values;
  • small gradient norm;
  • small step size;
  • maximum iteration count.

Stopping is a numerical decision and does not by itself establish model adequacy.

Convergence Diagnostics

After optimization, check:

  • whether the solver reported convergence;
  • whether parameter bounds were active;
  • whether different starting values give similar results;
  • whether gradients are small;
  • whether residuals are sensible;
  • whether the final objective is substantially better than the initial one.

Verification with Synthetic Data

Before fitting experimental data, a useful test is to generate synthetic data from a known parameter vector

\[ \boldsymbol{\theta}_{\text{true}}. \]

Then fit the model back to those generated observations.

If the fitting pipeline cannot recover known parameters under controlled conditions, the implementation should be investigated before real-data conclusions are trusted.

Noise-Free Recovery Test

The strongest initial test uses noise-free synthetic data:

\[ \mathbf{y}_{\text{syn}} = F(\boldsymbol{\theta}_{\text{true}}). \]

Fit

\[ \mathbf{y}_{\text{syn}} \]

using the same forward model.

For an identifiable and correctly implemented problem, the recovered parameter vector should closely match \(\boldsymbol{\theta}_{\text{true}}\).

Noisy Recovery Test

Next add simulated measurement noise:

\[ \mathbf{y}_{\text{syn}} = F(\boldsymbol{\theta}_{\text{true}}) + \boldsymbol{\varepsilon}. \]

Repeated fits show how parameter estimates vary under realistic noise.

This helps assess:

  • bias;
  • variance;
  • practical identifiability;
  • robustness of initialization;
  • coverage of uncertainty intervals.

Fit Quality and Scientific Meaning

A parameter estimate should satisfy more than a numerical criterion.

Ask whether the fitted value:

  • lies in a physically plausible range;
  • is consistent with independent measurements;
  • remains stable across related data sets;
  • supports accurate predictions;
  • has uncertainty appropriate to the available information.

Common Error: Minimizing the Wrong Quantity

A fitting algorithm faithfully minimizes the objective it is given.

If the objective poorly represents the scientific problem, the resulting parameters can be mathematically optimal but scientifically inappropriate.

Objective design is therefore part of modeling.

Common Error: Ignoring Measurement Uncertainty

Suppose one observation has uncertainty \(0.01\) while another has uncertainty \(10\).

Treating the two raw residuals equally may give the noisy measurement far too much influence.

Weighting by uncertainty can better reflect how much information each observation contributes.

Common Error: Overinterpreting the Best-Fit Value

A reported estimate such as

\[ \theta^{*}=2.4173 \]

can create an illusion of precision.

If the data support values from \(1.8\) to \(3.1\) almost equally well, four decimal places are not scientifically meaningful.

Reported precision should reflect parameter uncertainty.

Common Error: Trusting a Single Starting Point

A nonlinear optimizer may converge to a local minimum determined partly by its initial guess.

Repeating the fit from multiple plausible starting points is a simple and valuable diagnostic.

Common Error: Ignoring Residual Structure

A small total objective can hide systematic model failure.

Residual plots may show persistent oscillations, curvature, drift, or condition-specific bias even when the overall error is numerically modest.

Always inspect the residuals themselves.

Common Error: Fitting Parameters That the Data Cannot Distinguish

If two parameters affect the model in nearly identical ways, the optimizer may trade one against the other.

The final predictions can appear excellent while the individual parameter values remain unstable.

Identifiability analysis should therefore precede or accompany fitting.

A Reliable Parameter-Fitting Workflow

  1. Define the forward model and observation operator.
  2. Identify the unknown parameters.
  3. Check structural and practical identifiability.
  4. Define residuals in meaningful units.
  5. Choose an objective function consistent with the error model.
  6. Apply appropriate weighting and scaling.
  7. Set physically justified parameter bounds or constraints.
  8. Choose plausible initial guesses.
  9. Run the optimization.
  10. Repeat from multiple starts when appropriate.
  11. Inspect residuals and convergence diagnostics.
  12. Estimate parameter uncertainty.
  13. Validate predictions on independent or withheld data.
  14. Document preprocessing, assumptions, and solver settings.

What to Remember

Parameter fitting converts model-data mismatch into a numerical estimation problem.

  • Residuals measure the difference between observations and predictions.
  • An objective function summarizes residual disagreement.
  • Least squares minimizes the sum of squared residuals.
  • Weights can represent uncertainty, scaling, or relative importance.
  • Bounds and reparameterizations can enforce physically meaningful values.
  • Nonlinear fitting can contain local minima and depend on initialization.
  • Parameter and residual scaling affect numerical performance.
  • Residual inspection is essential after optimization.
  • A good fit does not prove identifiability or model validity.
  • Synthetic recovery tests are valuable implementation checks.
  • Uncertainty and validation should accompany the best-fit parameter values.

The key principle is:

\[ \boxed{ \text{A fitted parameter is meaningful only when the objective, data, model, and diagnostics support it.} } \]
