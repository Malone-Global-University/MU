Multivariable Relationships

Multivariable mathematics studies quantities that depend on several inputs at once. This sequence extends the ideas of functions, derivatives, integrals, geometry, optimization, and sensitivity from one variable into two, three, and higher dimensions.

Overview

In one-variable calculus, an input \(x\) produces an output \(f(x)\). Multivariable analysis expands this picture to functions such as

\[ z=f(x,y) \]

and

\[ w=f(x,y,z). \]

Once several inputs are allowed to vary, new questions appear:

  • How does the output respond when only one input changes?
  • What happens when several inputs change together?
  • Which direction produces the greatest increase or decrease?
  • How can a surface be approximated locally by a plane?
  • How do we accumulate quantities over regions and solids?
  • How do constraints change optimization?
  • How can several outputs respond to several inputs at once?

The lessons in this sequence develop a unified toolkit for answering these questions.

Learning Sequence

The section is organized so that each lesson extends tools introduced earlier. Begin with functions of several variables, then move through local change, geometry, accumulation, coordinate transformation, optimization, implicit dependence, vector outputs, and sensitivity.

1. Functions of Several Variables

Begin by extending the function concept from one input to several inputs. Learn how multivariable functions are written, evaluated, represented, and interpreted in mathematical and applied settings.

Functions of Several Variables

2. Domains, Ranges, and Level Sets

Determine where multivariable functions are defined, what outputs they can attain, and how fixed-output sets reveal geometry through level curves and level surfaces.

Domains, Ranges, and Level Sets

3. Partial Derivatives

Measure local change with respect to one input while holding the others fixed. Develop first and higher partial derivatives, mixed partials, and coordinate-direction sensitivity.

Partial Derivatives

4. Directional Derivatives

Extend partial derivatives beyond the coordinate axes. Measure the instantaneous rate of change in any chosen unit direction.

Directional Derivatives

5. Gradients

Combine the first partial derivatives into the gradient vector. Use it to identify steepest ascent and descent, maximum directional change, and normals to level curves and surfaces.

Gradients

6. Tangent Planes and Linear Approximation

Extend tangent lines into higher dimensions. Build tangent planes, differentials, and first-order linear approximations for nearby values and small changes.

Tangent Planes and Linear Approximation

7. Multiple Integrals

Extend accumulation from intervals to planar regions and three-dimensional solids. Develop double and triple integrals, iterated integration, mass, volume, average value, probability, and related applications.

Multiple Integrals

8. Coordinate Changes and Jacobians

Transform difficult regions into simpler coordinates and learn how the Jacobian measures local area and volume scaling. Develop polar, cylindrical, spherical, and general change-of-variables methods.

Coordinate Changes and Jacobians

9. Constrained Extrema

Optimize functions when the inputs must satisfy equations or other restrictions. Develop feasible sets, Lagrange multipliers, boundary analysis, and constrained maximum and minimum methods.

Constrained Extrema

10. Implicit Relationships

Study equations that define variables indirectly. Develop implicit differentiation, local solvability, tangent geometry, regular and singular points, and the implicit function theorem.

Implicit Relationships

11. Vector-Valued Functions

Move from scalar outputs to vector outputs. Study parameterized curves, trajectories, tangent vectors, velocity, acceleration, speed, arc length, and motion through several dimensions.

Vector-Valued Functions

12. Multivariable Sensitivity

Bring the section together by studying how outputs respond to input, parameter, and constraint changes. Use gradients, directional derivatives, Jacobians, elasticities, differentials, and uncertainty propagation.

Multivariable Sensitivity

Core Formulas

Several formulas recur throughout the sequence.

Gradient

\[ \boxed{ \nabla f = \langle f_x,f_y\rangle } \]

Directional Derivative

\[ \boxed{ D_{\mathbf{u}}f = \nabla f\cdot\mathbf{u} } \]

Linear Approximation

\[ \boxed{ f(x,y) \approx f(a,b) + f_x(a,b)(x-a) + f_y(a,b)(y-b) } \]

Double Integral

\[ \boxed{ \iint_R f(x,y)\,dA } \]

Change of Variables

\[ \boxed{ dA = \left| \frac{\partial(x,y)}{\partial(u,v)} \right| du\,dv } \]

Lagrange Multipliers

\[ \boxed{ \nabla f = \lambda\nabla g } \]

Implicit Derivative

\[ \boxed{ \frac{dy}{dx} = -\frac{F_x}{F_y} } \]

Vector-Valued Derivative

\[ \boxed{ \mathbf{r}'(t) = \langle x'(t),y'(t),z'(t)\rangle } \]

Multivariable Sensitivity

\[ \boxed{ \Delta\mathbf{F} \approx J_{\mathbf{F}} \Delta\mathbf{x} } \]

What This Section Builds

By the end of this sequence, you should be able to:

  • analyze functions with several inputs;
  • determine domains and interpret level sets;
  • compute and interpret partial and directional derivatives;
  • use gradients to study local direction and magnitude of change;
  • construct tangent planes and local linear models;
  • evaluate double and triple integrals;
  • use polar, cylindrical, spherical, and general coordinate changes;
  • compute and interpret Jacobian determinants;
  • solve constrained optimization problems;
  • differentiate implicit relationships;
  • analyze vector-valued curves and motion;
  • quantify local and normalized sensitivity in multivariable models.

How the Ideas Fit Together

The section begins with the function itself:

\[ \boxed{ \text{several inputs} \longrightarrow \text{one or several outputs} }. \]

Derivatives then describe local change:

\[ \boxed{ \text{partial derivatives} \longrightarrow \text{gradient} \longrightarrow \text{directional change} }. \]

Linearization turns those derivatives into a local model:

\[ \boxed{ \text{gradient} \longrightarrow \text{tangent plane} \longrightarrow \text{first-order approximation} }. \]

Integration accumulates quantities across higher-dimensional regions:

\[ \boxed{ \text{regions and solids} \longrightarrow \text{multiple integrals} \longrightarrow \text{coordinate changes} }. \]

Constraints and implicit relationships describe dependent variables that cannot move freely:

\[ \boxed{ \text{constraints} \longrightarrow \text{implicit geometry} \longrightarrow \text{constrained optimization} }. \]

Finally, vector-valued functions and sensitivity analysis generalize the entire framework to systems, trajectories, and model response.
