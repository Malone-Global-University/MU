Numerical, Graphical, and Symbolic Limits

A limit describes what a function is approaching as its input approaches a particular value. The function does not necessarily have to reach that value, and it may not even be defined there. Limits focus on nearby behavior. Numerical tables, graphs, and symbolic algebra give us three complementary ways to study that behavior.

The Central Idea

Suppose \(f(x)\) gets closer and closer to a number \(L\) as \(x\) gets closer and closer to a number \(a\). We write

\[ \boxed{\lim_{x\to a} f(x)=L}. \]

Read this as: the limit of \(f(x)\) as \(x\) approaches \(a\) is \(L\).

The statement is about what happens near \(x=a\), not necessarily what happens exactly at \(x=a\).

Limits Describe Approach

The arrow in

\[ x\to a \]

means that \(x\) is allowed to move closer and closer to \(a\).

At the same time, we observe what happens to

\[ f(x). \]

If the output values settle toward one number, that number is the limit.

A First Example

Consider the function

\[ f(x)=2x+1. \]

As \(x\) approaches \(3\),

\[ 2x+1 \]

approaches

\[ 2(3)+1=7. \]

Therefore,

\[ \boxed{\lim_{x\to3}(2x+1)=7}. \]

Why Limits Matter

Limits provide the basic language for describing quantities that change continuously or nearly continuously.

They allow us to study:

  • instantaneous rates of change;
  • slopes of tangent lines;
  • areas accumulated from very small pieces;
  • continuity and discontinuity;
  • asymptotic behavior;
  • functions near points where direct substitution fails.

Derivatives and integrals are built from limits.

Three Ways to Study a Limit

We will use three main representations.

  1. Numerical: examine values in a table.
  2. Graphical: inspect the graph near the target input.
  3. Symbolic: use algebraic expressions and known rules.

These approaches should reinforce one another rather than compete with one another.

Numerical Limits

A numerical approach samples function values at inputs increasingly close to the target input.

For example, suppose

\[ f(x)=x^2 \]

and we want

\[ \lim_{x\to2}x^2. \]

We can inspect values near \(x=2\).

Approaching from Below

Choose inputs slightly less than \(2\):

\(x\) \(x^2\)
\(1.9\) \(3.61\)
\(1.99\) \(3.9601\)
\(1.999\) \(3.996001\)

The outputs are moving toward \(4\).

Approaching from Above

Now choose inputs slightly greater than \(2\):

\(x\) \(x^2\)
\(2.1\) \(4.41\)
\(2.01\) \(4.0401\)
\(2.001\) \(4.004001\)

These outputs also move toward \(4\).

So the numerical evidence supports

\[ \boxed{\lim_{x\to2}x^2=4}. \]

Use Values on Both Sides

When estimating a two-sided limit numerically, inspect values on both sides of the target input.

For a target \(a\), useful inputs might look like

\[ a-0.1,\quad a-0.01,\quad a-0.001 \]

and

\[ a+0.1,\quad a+0.01,\quad a+0.001. \]

The key question is whether the corresponding output values approach the same number.

The Function Value Is Not the Same Question

Suppose a function satisfies

\[ f(2)=10, \]

but values near \(x=2\) approach \(4\).

Then

\[ \boxed{\lim_{x\to2}f(x)=4} \]

even though

\[ f(2)=10. \]

A limit and a function value are related concepts, but they are not automatically identical.

A Limit Can Exist When the Function Is Undefined

Consider

\[ f(x)=\frac{x^2-4}{x-2}. \]

Direct substitution at \(x=2\) gives

\[ \frac{0}{0}, \]

so the original expression is undefined there.

But for \(x\neq2\),

\[ \frac{x^2-4}{x-2} = \frac{(x-2)(x+2)}{x-2} = x+2. \]

Therefore, as \(x\) approaches \(2\),

\[ f(x)\to4. \]

Thus,

\[ \boxed{\lim_{x\to2}\frac{x^2-4}{x-2}=4}. \]

Numerical Table for a Removable Hole

The same limit can be estimated numerically.

\(x\) \(\dfrac{x^2-4}{x-2}\)
\(1.9\) \(3.9\)
\(1.99\) \(3.99\)
\(1.999\) \(3.999\)
\(2.001\) \(4.001\)
\(2.01\) \(4.01\)
\(2.1\) \(4.1\)

The values clearly approach \(4\) from both sides.

Graphical Limits

A graph lets us see nearby behavior directly.

To estimate

\[ \lim_{x\to a}f(x), \]

trace the graph toward \(x=a\) from the left and from the right.

If the \(y\)-values approach the same height \(L\) from both sides, then

\[ \lim_{x\to a}f(x)=L. \]

Reading a Graph Near a Hole

A graph may contain an open circle at

\[ (a,L). \]

The open circle indicates that the graph does not include that point.

But if the curve approaches the open circle from both sides, then

\[ \boxed{\lim_{x\to a}f(x)=L}. \]

The missing point does not destroy the limit.

A Filled Point Can Be Somewhere Else

Imagine a graph with:

  • an open circle at \((2,4)\), and
  • a filled point at \((2,7)\).

Then

\[ f(2)=7, \]

but if the surrounding curve approaches \(4\),

\[ \boxed{\lim_{x\to2}f(x)=4}. \]

Again, the function value and the limit answer different questions.

Graphical Limit Checklist

When reading a limit from a graph:

  1. Locate the target input \(x=a\).
  2. Follow the graph toward \(a\) from the left.
  3. Follow the graph toward \(a\) from the right.
  4. Identify the \(y\)-value approached from each side.
  5. Ignore the actual plotted value at \(x=a\) until the limit is settled.
  6. If both sides approach the same value, that value is the limit.

When a Graph Shows No Two-Sided Limit

Suppose the graph approaches \(2\) from the left and \(5\) from the right.

Then there is no single number approached from both directions.

Therefore,

\[ \boxed{\lim_{x\to a}f(x)\text{ does not exist}}. \]

Later we will describe the two directions separately using one-sided limits.

Symbolic Limits

A symbolic approach works directly with the function formula.

For many familiar functions, direct substitution gives the limit immediately.

For example,

\[ \lim_{x\to4}(3x-2) = 3(4)-2 = \boxed{10}. \]

Direct Substitution

If the function behaves regularly at the target input, try substituting the target value.

For example,

\[ \lim_{x\to-1}(x^2+3x+5) \]

becomes

\[ (-1)^2+3(-1)+5 = 1-3+5 = 3. \]

Therefore,

\[ \boxed{\lim_{x\to-1}(x^2+3x+5)=3}. \]

Direct Substitution Is a First Check

Direct substitution is often the fastest first step, but it does not solve every limit.

If substitution gives an ordinary real number, that value is often the limit for the elementary functions studied at this stage.

If substitution produces an undefined or ambiguous expression such as

\[ \frac{0}{0}, \]

more work is needed.

Why \(\frac{0}{0}\) Is Not the Answer

The expression

\[ \frac{0}{0} \]

is not a numerical value.

In a limit problem, it often signals that the original expression can be rewritten so that nearby behavior becomes clearer.

For example,

\[ \lim_{x\to2}\frac{x^2-4}{x-2} \]

gives \(0/0\) by direct substitution, but factoring reveals the actual limit \(4\).

Symbolic Simplification Can Reveal Nearby Behavior

Consider

\[ \lim_{x\to3}\frac{x^2-9}{x-3}. \]

Factor the numerator:

\[ x^2-9=(x-3)(x+3). \]

For \(x\neq3\),

\[ \frac{(x-3)(x+3)}{x-3}=x+3. \]

Therefore,

\[ \boxed{\lim_{x\to3}\frac{x^2-9}{x-3}=6}. \]

Canceling Does Not Redefine the Original Function

In

\[ \frac{(x-3)(x+3)}{x-3}, \]

canceling \(x-3\) is valid only when

\[ x\neq3. \]

That is enough for the limit, because a limit concerns values arbitrarily close to \(3\), not necessarily the value at \(3\) itself.

Numerical, Graphical, and Symbolic Agreement

A well-understood limit often tells the same story in all three representations.

For

\[ \lim_{x\to3}\frac{x^2-9}{x-3}, \]
  • the numerical values approach \(6\);
  • the graph approaches the point \((3,6)\) but has a hole there;
  • the algebra simplifies to \(x+3\) for \(x\neq3\).

All three approaches support

\[ \boxed{6}. \]

Why Use More Than One Representation?

Different representations expose different features.

  • Tables are useful for estimation and numerical evidence.
  • Graphs are useful for visualizing approach and discontinuity.
  • Symbolic expressions can provide exact values and explanations.

When one representation is unclear, another may resolve the ambiguity.

Limits and Nearby Inputs

The word nearby is central.

To study

\[ \lim_{x\to5}f(x), \]

we might examine inputs such as

\[ 4.9,\quad4.99,\quad4.999,\quad5.001,\quad5.01,\quad5.1. \]

We are not limited to those particular numbers. Any sequence of inputs moving toward \(5\) can provide evidence about the same local behavior.

Getting Closer Matters More Than Taking Many Random Samples

A table is most useful when the inputs actually approach the target.

Values such as

\[ 1,\quad2,\quad3,\quad4 \]

do not provide especially strong evidence about a limit at \(x=5\).

Values such as

\[ 4.9,\quad4.99,\quad4.999 \]

are more informative because they reveal what the function is doing increasingly close to the target.

Do Not Confuse Approach with Equality

If

\[ x\to2, \]

we are not saying

\[ x=2. \]

We are saying that \(x\) can be taken as close to \(2\) as needed.

Likewise, if

\[ f(x)\to7, \]

the outputs are approaching \(7\). They do not need to equal \(7\) at every nearby input.

A Limit Is Local Information

A limit near \(x=a\) depends mainly on what the function does near \(a\).

The function can behave very differently far away without changing the limit.

This is why limits are a form of local analysis.

Example: A Piecewise Function

Suppose

\[ f(x)= \begin{cases} x+1, & x\neq2,\\ 100, & x=2. \end{cases} \]

Near \(x=2\), the function follows

\[ x+1. \]

Therefore,

\[ \boxed{\lim_{x\to2}f(x)=3}, \]

even though

\[ f(2)=100. \]

Example: Matching Table and Formula

Consider

\[ f(x)=\frac{x^2-1}{x-1}. \]

For \(x\neq1\),

\[ f(x)=x+1. \]

A table near \(x=1\) gives:

\(x\) \(f(x)\)
\(0.9\) \(1.9\)
\(0.99\) \(1.99\)
\(0.999\) \(1.999\)
\(1.001\) \(2.001\)
\(1.01\) \(2.01\)

Numerically and symbolically,

\[ \boxed{\lim_{x\to1}\frac{x^2-1}{x-1}=2}. \]

Estimating from Rounded Data

Numerical data may be rounded, so a table does not always reveal the exact limit immediately.

Suppose outputs near \(x=4\) are

\[ 8.91,\quad8.991,\quad8.9991 \]

from one side and

\[ 9.0009,\quad9.009,\quad9.09 \]

from the other.

The natural estimate is

\[ \boxed{9}. \]

Numerical Evidence Is Evidence, Not Always Proof

A table can strongly suggest a limit, but finitely many sampled values do not by themselves guarantee what happens at every nearby input.

Symbolic reasoning or a formal limit argument can provide stronger justification.

Numerical estimation remains valuable for developing intuition, checking work, and investigating functions that are difficult to simplify.

Graphical Evidence Also Has Limits

A graph depends on scale, resolution, and the window being viewed.

Two curves can look nearly identical at one scale but behave differently when magnified.

Therefore, use a graph as an analytical tool, but do not assume that a picture alone proves every exact limit.

Symbolic Reasoning Can Also Require Care

Algebraic simplification must respect domain restrictions.

If

\[ \frac{(x-a)g(x)}{x-a} \]

is simplified to

\[ g(x), \]

the simplification is valid only for

\[ x\neq a. \]

That distinction is often exactly what produces a removable discontinuity.

A Practical Workflow

  1. Identify the target input \(a\).
  2. Try direct substitution.
  3. If substitution gives a normal value, record the likely limit.
  4. If substitution fails, inspect nearby numerical values.
  5. Use the graph if one is available.
  6. Look for algebraic simplification.
  7. Compare the three representations.
  8. State the limit only when the evidence supports one common approached value.

Example: Full Three-Representation Workflow

Evaluate

\[ \lim_{x\to4}\frac{x^2-16}{x-4}. \]

Direct substitution gives

\[ \frac{0}{0}. \]

So direct substitution alone does not finish the problem.

Factor:

\[ x^2-16=(x-4)(x+4). \]

For \(x\neq4\),

\[ \frac{x^2-16}{x-4}=x+4. \]

Therefore,

\[ \boxed{\lim_{x\to4}\frac{x^2-16}{x-4}=8}. \]

A table would show outputs approaching \(8\), and the graph would look like the line \(y=x+4\) with a hole at \((4,8)\).

Common Error: Plugging In and Stopping at \(\frac{0}{0}\)

If substitution gives

\[ \frac{0}{0}, \]

do not report \(0\), do not report \(1\), and do not treat \(0/0\) as the final result.

Instead, interpret it as a signal to investigate further.

Common Error: Using Only One Side of a Table

A two-sided limit requires compatible behavior from both sides.

Values approaching \(a\) only from below may not reveal what happens from above.

Always inspect both directions unless the problem specifically asks for a one-sided limit.

Common Error: Reporting the Filled Dot Instead of the Limit

On a graph, the filled point at \(x=a\) tells you

\[ f(a). \]

It does not automatically tell you

\[ \lim_{x\to a}f(x). \]

Trace the nearby graph before reading the function value.

Common Error: Thinking the Function Must Reach the Limit

A function can approach a value without taking that value at the target input.

A removable hole is the standard example.

Limits describe approach, not mandatory arrival.

Common Error: Cancelling an Additive Term

From

\[ \frac{x^2-4}{x-2}, \]

we may factor

\[ x^2-4=(x-2)(x+2) \]

and then cancel the factor \(x-2\).

We may not simply cancel the \(x\) or the \(2\) across addition and subtraction.

Cancellation applies to common multiplicative factors.

Common Error: Assuming Every Limit Exists

Some functions approach different values from different sides.

Others become arbitrarily large in magnitude.

Still others oscillate without settling toward one value.

The later lessons in this section will classify these behaviors more carefully.

What to Remember

A limit describes the value a function approaches:

\[ \boxed{\lim_{x\to a}f(x)=L}. \]
  • Numerically, inspect values increasingly close to the target input.
  • Graphically, trace the curve from both sides.
  • Symbolically, begin with direct substitution and simplify when necessary.
  • The value \(f(a)\) does not automatically determine the limit.
  • A limit can exist even when \(f(a)\) is undefined.
  • A two-sided limit requires compatible behavior from both directions.
  • Tables and graphs provide strong evidence; symbolic reasoning can often give an exact result.

The central habit is to ask: what value are the outputs approaching as the inputs approach the target?
