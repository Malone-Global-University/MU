Properties of Equality

The properties of equality explain why many familiar algebraic moves are valid. They let us transform equations while preserving the relationship between their two sides.

The Central Idea

An equation states that two quantities are equal. If we transform that equation, we must preserve the equality.

Suppose

\[ a=b. \]

If we add the same quantity to both sides, subtract the same quantity from both sides, multiply both sides by the same quantity, or divide both sides by the same nonzero quantity, the resulting equation remains true.

These facts are not arbitrary classroom rules. They are consequences of the basic properties of equality.

The properties of equality provide the logical foundation for solving equations, rearranging formulas, substituting known values, and proving algebraic relationships.

Equality as a Balanced Relationship

A useful first model is a balance scale.

If two sides have equal weight, then adding the same weight to both sides preserves the balance. Removing the same weight from both sides also preserves the balance.

Algebra works similarly.

If

\[ x+3=10, \]

then subtracting \(3\) from both sides gives

\[ x+3-3=10-3, \]

so

\[ x=7. \]

The operation was applied equally to both sides, so the equality was preserved.

The balance model is useful, but the properties of equality extend far beyond physical balancing. They apply to numbers, expressions, functions, vectors, matrices, and many other mathematical objects whenever the relevant operations are defined.

Reflexive Property of Equality

Every mathematical object is equal to itself.

\[ a=a. \]

This is called the reflexive property of equality.

Examples include

\[ 7=7, \] \[ x=x, \]

and

\[ x^2+1=x^2+1. \]

The reflexive property may seem obvious, but it is fundamental. It expresses the idea that equality always relates an object to itself.

Symmetric Property of Equality

If one quantity equals another, then the equality can be read in the opposite direction.

If

\[ a=b, \]

then

\[ b=a. \]

This is the symmetric property of equality.

For example, if

\[ x=12, \]

then we may also write

\[ 12=x. \]

Likewise, if

\[ A=\pi r^2, \]

then

\[ \pi r^2=A. \]

The order of the two sides does not change the equality being asserted.

Transitive Property of Equality

If two quantities are each equal to the same quantity, then they are equal to each other.

If

\[ a=b \]

and

\[ b=c, \]

then

\[ a=c. \]

This is the transitive property of equality.

For example, if

\[ x=y \]

and

\[ y=5, \]

then

\[ x=5. \]

The transitive property is one reason chains of equalities work:

\[ \frac{1}{2}=0.5=\frac{50}{100}. \]

Each link connects quantities that represent the same value.

Addition Property of Equality

If two quantities are equal, adding the same quantity to both sides preserves the equality.

If

\[ a=b, \]

then

\[ a+c=b+c. \]

This is the addition property of equality.

For example, from

\[ x-4=9 \]

we may add \(4\) to both sides:

\[ x-4+4=9+4. \]

Therefore,

\[ x=13. \]

The same quantity was added to both sides, so the original relationship was preserved.

Subtraction Property of Equality

If two quantities are equal, subtracting the same quantity from both sides preserves the equality.

If

\[ a=b, \]

then

\[ a-c=b-c. \]

For example, from

\[ x+6=14 \]

we may subtract \(6\) from both sides:

\[ x+6-6=14-6, \]

giving

\[ x=8. \]

The subtraction property is closely related to the addition property because subtracting \(c\) is equivalent to adding \(-c\).

Multiplication Property of Equality

If two quantities are equal, multiplying both sides by the same quantity preserves the equality.

If

\[ a=b, \]

then

\[ ac=bc. \]

For example, from

\[ \frac{x}{5}=3 \]

we may multiply both sides by \(5\):

\[ 5\left(\frac{x}{5}\right)=5(3), \]

so

\[ x=15. \]

Multiplication by zero also preserves truth:

\[ a=b \quad\Longrightarrow\quad 0a=0b. \]

However, multiplying by zero destroys information because both sides become \(0\). That matters when we want a transformation to be reversible.

Division Property of Equality

If two quantities are equal, dividing both sides by the same nonzero quantity preserves the equality.

If

\[ a=b \]

and

\[ c\ne0, \]

then

\[ \frac{a}{c}=\frac{b}{c}. \]

For example, from

\[ 6x=42 \]

we may divide both sides by \(6\):

\[ \frac{6x}{6}=\frac{42}{6}, \]

so

\[ x=7. \]

The condition \(c\ne0\) is essential because division by zero is undefined.

Substitution Property of Equality

If two quantities are equal, one may replace the other in an expression or equation wherever the replacement is valid.

If

\[ a=b, \]

then an occurrence of \(a\) may be replaced by \(b\), and vice versa.

Suppose

\[ x=4. \]

Then in

\[ 2x+7, \]

we may replace \(x\) with \(4\):

\[ 2x+7=2(4)+7=15. \]

Likewise, if

\[ y=x^2+1, \]

then

\[ 3y=3(x^2+1). \]

The substitution property is the formal version of the replacement principle introduced in the previous lesson.

A Summary of the Core Properties

Property Symbolic Form Meaning
Reflexive \(a=a\) Every object equals itself.
Symmetric If \(a=b\), then \(b=a\). Equality can be reversed.
Transitive If \(a=b\) and \(b=c\), then \(a=c\). Equal quantities can be linked through a common value.
Addition If \(a=b\), then \(a+c=b+c\). Add the same quantity to both sides.
Subtraction If \(a=b\), then \(a-c=b-c\). Subtract the same quantity from both sides.
Multiplication If \(a=b\), then \(ac=bc\). Multiply both sides by the same quantity.
Division If \(a=b\) and \(c\ne0\), then \(\frac{a}{c}=\frac{b}{c}\). Divide both sides by the same nonzero quantity.
Substitution If \(a=b\), either may replace the other where valid. Replace an equal quantity with another representation.

Properties Versus Operations

It is useful to distinguish the operation from the justification.

Consider

\[ x+9=17. \]

We perform the operation of subtracting \(9\):

\[ x+9-9=17-9. \]

The reason this is legitimate is the subtraction property of equality.

Similarly, in

\[ 4x=28, \]

we perform division by \(4\):

\[ \frac{4x}{4}=\frac{28}{4}. \]

The justification is the division property of equality.

This distinction becomes important in formal reasoning. A line of algebra shows what was done; the relevant property explains why it was allowed.

Undoing Operations

Many equation-solving steps are designed to undo operations.

Suppose

\[ 3x+5=20. \]

We first subtract \(5\) from both sides:

\[ 3x=15. \]

Then divide both sides by \(3\):

\[ x=5. \]

The subtraction undoes the addition of \(5\), and the division undoes the multiplication by \(3\).

This works because inverse operations combine with the properties of equality. The operation removes part of the expression, while the property guarantees that doing the same thing to both sides preserves equality.

Working with More Complicated Expressions

The quantities added, subtracted, multiplied, or divided do not have to be simple numbers.

If

\[ a=b, \]

then we may add an entire expression \(f(x)\) to both sides:

\[ a+f(x)=b+f(x). \]

Likewise, we may multiply both sides by another expression:

\[ g(x)a=g(x)b. \]

However, if we later divide by \(g(x)\), we must know that

\[ g(x)\ne0. \]

This is one place where domain restrictions enter algebraic manipulation.

Why the Same Operation Must Be Applied to Both Sides

Suppose

\[ x+2=7. \]

If we subtract \(2\) only from the left side, we would get

\[ x=7, \]

which is not equivalent to the original equation.

The original equation has solution

\[ x=5, \]

while the altered equation has solution

\[ x=7. \]

The equality was not preserved because the transformation changed one side without making the corresponding change to the other.

Equation solving is therefore not about “moving” terms across an equal sign by magic. What appears to be movement is usually shorthand for applying the same legitimate operation to both sides.

What “Move It to the Other Side” Really Means

Students often hear instructions such as “move the \(5\) to the other side and change its sign.” This shortcut can be convenient, but it hides the underlying operation.

From

\[ x+5=12, \]

the mathematically explicit step is

\[ x+5-5=12-5. \]

Then

\[ x=7. \]

The \(5\) did not literally travel across the equal sign. We subtracted \(5\) from both sides using the subtraction property of equality.

Understanding the underlying property makes the shortcut safer and helps prevent sign errors.

Properties of Equality and Functions

The same idea can be expressed more generally using functions.

If

\[ a=b, \]

then applying the same well-defined function \(f\) to both sides gives

\[ f(a)=f(b). \]

For example, if

\[ a=b, \]

then

\[ a^2=b^2. \]

This preserves truth: equal inputs produce equal outputs.

However, the reverse implication may fail. From

\[ a^2=b^2 \]

we cannot always conclude

\[ a=b, \]

because \(a\) and \(b\) could be opposites.

For example,

\[ (-3)^2=3^2, \]

but

\[ -3\ne3. \]

This distinction will matter later when we study reversible steps and solution preservation.

Preserving Truth Is Not Always the Same as Preserving Equivalence

Suppose

\[ x=4. \]

Squaring both sides gives

\[ x^2=16. \]

The new equation is true for every solution of the original equation, so the transformation preserved truth in the forward direction.

But the new equation has an additional solution:

\[ x=-4. \]

Therefore the two equations are not equivalent.

This is an important refinement:

  • A transformation may preserve every original solution.
  • Yet it may still introduce new solutions.
  • To preserve full equivalence, the transformation must preserve the entire solution set.

The elementary properties of equality involving addition, subtraction, multiplication by a nonzero quantity, and division by a nonzero quantity are especially useful because they can be reversed under the same conditions.

Multiplication by Zero: A Special Case

The multiplication property allows us to multiply both sides of a true equation by zero.

If

\[ a=b, \]

then

\[ 0a=0b, \]

so

\[ 0=0. \]

The resulting equality is true, but it no longer tells us what \(a\) and \(b\) were.

For example,

\[ x=7 \]

implies

\[ 0x=0(7), \]

which becomes

\[ 0=0. \]

The new equation is satisfied by every real number, so it is not equivalent to the original equation.

This is a useful reminder that a valid forward operation need not be reversible.

Division Requires Special Care

Division can be especially dangerous when the divisor contains a variable.

Suppose

\[ x(x-2)=0. \]

If we divide both sides by \(x\), we obtain

\[ x-2=0, \]

and therefore

\[ x=2. \]

But the original equation also has the solution

\[ x=0. \]

Dividing by \(x\) silently assumed that

\[ x\ne0. \]

That assumption discarded a legitimate solution.

Whenever dividing by a variable expression, ask whether that expression could equal zero.

Worked Example: Solving with Explicit Justification

Solve

\[ 5x-7=18. \]

Add \(7\) to both sides:

\[ 5x-7+7=18+7. \]

By the addition property of equality,

\[ 5x=25. \]

Divide both sides by \(5\):

\[ \frac{5x}{5}=\frac{25}{5}. \]

By the division property of equality,

\[ x=5. \]

The equation has been transformed step by step without changing its solution set.

Worked Example: Rearranging a Formula

Suppose

\[ A=lw, \]

where \(A\) is area, \(l\) is length, and \(w\) is width.

To solve for \(w\), divide both sides by \(l\), provided \(l\ne0\):

\[ \frac{A}{l}=\frac{lw}{l}. \]

Therefore,

\[ w=\frac{A}{l}. \]

The same properties used in elementary equations also justify rearranging formulas with several variables.

Worked Example: Substitution and Transitivity

Suppose

\[ a=b+2 \]

and

\[ b=5. \]

By substitution, replace \(b\) with \(5\):

\[ a=5+2. \]

Therefore,

\[ a=7. \]

If we separately establish

\[ 5+2=7, \]

then the transitive property links the equalities:

\[ a=5+2=7. \]

Much routine algebra uses several properties of equality at once.

Practice

1. Name the Property

If

\[ m=n, \]

then

\[ n=m. \]

Which property justifies this?

Check Answer

The symmetric property of equality.

2. Solve and Justify

Solve

\[ x-8=15. \]
Check Answer

Add \(8\) to both sides using the addition property of equality:

\[ x-8+8=15+8. \]

Therefore,

\[ x=23. \]

3. Identify the Restriction

From

\[ ax=ay, \]

under what condition may we divide both sides by \(a\) and conclude

\[ x=y? \]
Check Answer \[ a\ne0. \]

If \(a=0\), then the original equation becomes \(0=0\), which gives no information about \(x\) and \(y\).

4. Is the Transformation Reversible?

Starting with

\[ x=3, \]

we cube both sides:

\[ x^3=27. \]

Over the real numbers, does this transformation preserve equivalence?

Check Answer

Yes. The real cube function is one-to-one, so \(x^3=27\) has only the solution \(x=3\). Cubing and taking the real cube root reverse one another.

5. Find the Lost Solution

Consider

\[ x(x+4)=0. \]

A student divides both sides by \(x\) and obtains \(x=-4\). What solution was lost?

Check Answer \[ x=0. \]

Dividing by \(x\) assumes \(x\ne0\), so the step excludes the solution \(x=0\).

Key Ideas

  • The properties of equality justify many standard algebraic transformations.
  • Reflexive, symmetric, and transitive properties describe the basic structure of equality itself.
  • Addition and subtraction of the same quantity on both sides preserve equality.
  • Multiplication by the same quantity preserves equality, but multiplication by zero may destroy information.
  • Division by the same quantity preserves equality only when the divisor is nonzero.
  • Substitution allows one equal quantity or expression to replace another.
  • A valid forward transformation does not automatically guarantee full equivalence.
  • Variable divisors require special attention because they may equal zero for some possible solutions.
  • Formal properties explain the logic behind familiar shortcuts such as “moving a term to the other side.”
