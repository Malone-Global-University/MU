Zeros, Intercepts, and Fixed Points

Some inputs and outputs are especially informative. Zeros show where a function produces zero, intercepts show where its graph meets an axis, and fixed points show where the function returns its own input.

The Central Idea

Consider

\[ f(x)=x^2-4. \]

If we ask when the function equals zero, we solve

\[ f(x)=0. \]

Thus,

\[ x^2-4=0, \] \[ (x-2)(x+2)=0, \]

so

\[ x=2 \]

or

\[ x=-2. \]

These inputs are the zeros of the function.

Graphically, they correspond to the points

\[ (2,0) \]

and

\[ (-2,0), \]

which are the \(x\)-intercepts.

Now ask a different question:

\[ f(x)=x. \]

Then

\[ x^2-4=x. \]

Solutions to this equation are fixed points: inputs that the function sends back to themselves.

What Is a Zero?

A zero of a function \(f\) is an input \(x\) such that

\[ \boxed{f(x)=0}. \]

The zero is the input value itself.

For example, if

\[ f(3)=0, \]

then

\[ 3 \]

is a zero of \(f\).

Zeros Are Also Called Roots

When a function is given by an algebraic expression, zeros are often called roots.

For example, the roots of

\[ x^2-9=0 \]

are

\[ x=\pm3. \]

As a function

\[ f(x)=x^2-9, \]

the same values are zeros of \(f\).

What Is an \(x\)-Intercept?

An \(x\)-intercept is a point where the graph meets the \(x\)-axis.

Every point on the \(x\)-axis has vertical coordinate

\[ 0. \]

So an \(x\)-intercept has the form

\[ (a,0) \]

where

\[ f(a)=0. \]

Zero Versus \(x\)-Intercept

These ideas are closely related but not identical in wording.

If

\[ f(5)=0, \]

then:

  • \(5\) is a zero;
  • \((5,0)\) is an \(x\)-intercept.

A zero is an input value. An intercept is a point on the graph.

What Is a \(y\)-Intercept?

A \(y\)-intercept occurs where the graph meets the \(y\)-axis.

Every point on the \(y\)-axis has input coordinate

\[ x=0. \]

So if \(0\) belongs to the domain, the \(y\)-intercept is

\[ \boxed{(0,f(0))}. \]

Finding a \(y\)-Intercept

Let

\[ f(x)=3x+7. \]

Evaluate at zero:

\[ f(0)=3(0)+7=7. \]

Therefore, the \(y\)-intercept is

\[ \boxed{(0,7)}. \]

A Function May Have No \(y\)-Intercept

Consider

\[ f(x)=\frac{1}{x}. \]

The input

\[ x=0 \]

is not in the domain.

Therefore, the graph has no \(y\)-intercept.

A Function May Have No Zeros

Consider

\[ f(x)=x^2+1 \]

over the real numbers.

Since

\[ x^2\ge0, \]

we have

\[ x^2+1>0. \]

So there are no real zeros.

Therefore, the graph has no real \(x\)-intercepts.

A Function May Have One Zero

Consider

\[ f(x)=(x-4)^2. \]

Then

\[ f(x)=0 \]

only when

\[ x=4. \]

So the function has one distinct real zero:

\[ \boxed{x=4}. \]

A Function May Have Several Zeros

Consider

\[ f(x)=x(x-2)(x+5). \]

Set each factor equal to zero:

\[ x=0, \] \[ x=2, \] \[ x=-5. \]

The function has three real zeros.

Zero as a Special Output

Zeros answer the question:

Which inputs produce output zero?

This is a special case of the more general equation

\[ f(x)=c. \]

Zeros correspond specifically to

\[ c=0. \]

Solving for Zeros

To find zeros algebraically:

  1. write \(f(x)=0\);
  2. solve the resulting equation;
  3. check that each solution belongs to the function's domain.

Linear Zero Example

Let

\[ f(x)=4x-12. \]

Set

\[ 4x-12=0. \]

Then

\[ 4x=12, \] \[ \boxed{x=3}. \]

The \(x\)-intercept is

\[ \boxed{(3,0)}. \]

Quadratic Zero Example

Let

\[ f(x)=x^2-5x+6. \]

Factor:

\[ f(x)=(x-2)(x-3). \]

Set equal to zero:

\[ (x-2)(x-3)=0. \]

Thus,

\[ \boxed{x=2,\quad x=3}. \]

Factored Form Reveals Zeros

If

\[ f(x)=a(x-r_1)(x-r_2)\cdots(x-r_n), \]

then each factor suggests a zero:

\[ x=r_1,\quad x=r_2,\quad\ldots,\quad x=r_n, \]

provided the function is defined there.

Domain Restrictions Still Matter

Consider

\[ f(x)=\frac{(x-2)(x+1)}{x-2}. \]

The original domain excludes

\[ x=2. \]

Although the expression simplifies to

\[ x+1, \]

the original function still does not exist at \(x=2\).

Therefore, \(2\) cannot be an intercept or zero of the original function.

Zeros of Rational Functions

For a rational function

\[ f(x)=\frac{N(x)}{D(x)}, \]

a zero occurs when

\[ N(x)=0 \]

while simultaneously

\[ D(x)\ne0. \]

Numerator zeros that also make the denominator zero require special care.

Rational Example

Let

\[ f(x)=\frac{x-4}{x+2}. \]

The numerator is zero when

\[ x=4. \]

The denominator at \(x=4\) is

\[ 6\ne0. \]

So

\[ \boxed{x=4} \]

is a zero.

Multiplicity of a Zero

A zero may occur more than once as a factor.

For example,

\[ f(x)=(x-2)^3(x+1)^2. \]

The zero

\[ x=2 \]

has multiplicity \(3\), while

\[ x=-1 \]

has multiplicity \(2\).

Multiplicity and Graph Behavior

For polynomial functions:

  • an odd-multiplicity zero usually corresponds to crossing the \(x\)-axis;
  • an even-multiplicity zero usually corresponds to touching the axis and turning around.

This gives a useful connection between algebraic factors and graph shape.

Simple Zero

A zero of multiplicity \(1\) is often called a simple zero.

For

\[ f(x)=(x-3)(x+5), \]

both zeros are simple.

Intercepts from a Table

Suppose a table contains:

\(x\) \(f(x)\)
\(-2\) 5
0 3
4 0

Then:

  • \(x=4\) is a zero;
  • \((4,0)\) is an \(x\)-intercept;
  • \((0,3)\) is the \(y\)-intercept.

Intercepts from a Graph

Graphically:

  • \(x\)-intercepts occur where the graph meets the horizontal axis;
  • the \(y\)-intercept occurs where the graph meets the vertical axis.

These are visual forms of the equations

\[ f(x)=0 \]

and

\[ x=0. \]

Intercepts Can Be Approximate

Some functions do not have zeros that are easy to express exactly.

A graph or numerical method may reveal an approximate zero such as

\[ x\approx1.327. \]

Approximate zeros should be labeled as approximations and can be checked by evaluating the function near the candidate value.

What Is a Fixed Point?

A fixed point of a function \(f\) is an input \(x\) satisfying

\[ \boxed{f(x)=x}. \]

The function sends that input back to itself.

Fixed Point Example

Let

\[ f(x)=\frac{x+6}{2}. \]

Find the fixed points by solving

\[ \frac{x+6}{2}=x. \]

Multiply by \(2\):

\[ x+6=2x. \]

So

\[ \boxed{x=6}. \]

Check:

\[ f(6)=\frac{6+6}{2}=6. \]

Fixed Points Are Self-Mapped Inputs

If

\[ f(a)=a, \]

then \(a\) is fixed under the action of \(f\).

The input and output are numerically the same.

Fixed Points on a Graph

The graph of

\[ y=f(x) \]

contains a fixed point whenever it intersects the line

\[ y=x. \]

Why?

At an intersection,

\[ f(x)=x. \]

Zeros Versus Fixed Points

A zero satisfies

\[ f(x)=0. \]

A fixed point satisfies

\[ f(x)=x. \]

These are different equations.

A zero asks where the output is zero.

A fixed point asks where the output equals the input.

A Value Can Be Both a Zero and a Fixed Point

If

\[ x=0 \]

and

\[ f(0)=0, \]

then \(0\) is both:

  • a zero of \(f\);
  • a fixed point of \(f\).

This happens because both conditions reduce to the same statement at zero.

Fixed Point of a Linear Function

Consider

\[ f(x)=mx+b. \]

A fixed point satisfies

\[ mx+b=x. \]

Rearrange:

\[ (m-1)x=-b. \]

If

\[ m\ne1, \]

then

\[ \boxed{x=\frac{-b}{m-1}=\frac{b}{1-m}}. \]

Special Linear Case: Identity Function

Consider

\[ f(x)=x. \]

Then

\[ f(x)=x \]

for every input.

Every point in the domain is a fixed point.

Special Linear Case: No Fixed Point

Consider

\[ f(x)=x+3. \]

A fixed point would require

\[ x+3=x. \]

This gives

\[ 3=0, \]

which is impossible.

So the function has no fixed points.

Quadratic Fixed Points

Consider

\[ f(x)=x^2. \]

Fixed points satisfy

\[ x^2=x. \]

Factor:

\[ x(x-1)=0. \]

Thus,

\[ \boxed{x=0,\quad x=1}. \]

Another Fixed-Point Example

Let

\[ f(x)=x^2-2. \]

Set

\[ x^2-2=x. \]

Then

\[ x^2-x-2=0. \]

Factor:

\[ (x-2)(x+1)=0. \]

So the fixed points are

\[ \boxed{x=2,\quad x=-1}. \]

Fixed Points Can Be Approximate

Some fixed-point equations cannot be solved easily with elementary algebra.

For example,

\[ \cos x=x. \]

The real solution must generally be approximated numerically.

This is still a fixed-point problem because the defining equation remains

\[ f(x)=x. \]

Fixed Points and Iteration

Suppose we repeatedly apply a function:

\[ x_{n+1}=f(x_n). \]

If the sequence approaches a value \(L\), then under suitable conditions we expect

\[ L=f(L). \]

So limiting values of iterative processes are often fixed points.

Iteration Example

Let

\[ f(x)=\frac{x+6}{2}. \]

Start with

\[ x_0=10. \]

Then

\[ x_1=f(10)=8, \] \[ x_2=f(8)=7, \] \[ x_3=f(7)=6.5, \] \[ x_4=f(6.5)=6.25. \]

The values move toward the fixed point

\[ 6. \]

Not Every Fixed Point Attracts Nearby Inputs

Some fixed points pull nearby iterates toward themselves.

Others push nearby iterates away.

These are often called attracting and repelling fixed points.

A later study of derivatives gives a useful test for this behavior.

Fixed Points Are Broader Than Numbers

A function can act on objects other than numbers.

A fixed point is any object that remains unchanged under the function.

For example, under a geometric transformation, a point may stay in the same location.

That point is fixed by the transformation.

Fixed Points in Geometry

A rotation about a center leaves the center unchanged.

The center of rotation is a fixed point of the transformation.

A reflection leaves every point on its mirror line fixed.

Fixed Points and Identity

The identity function

\[ I(x)=x \]

fixes every point in its domain.

Other functions may fix only some points or none at all.

This gives another way to compare a function with the identity.

Zeros of \(f(x)-x\) Are Fixed Points of \(f\)

The fixed-point equation

\[ f(x)=x \]

can be rewritten as

\[ f(x)-x=0. \]

Therefore, fixed points of \(f\) are exactly the zeros of the function

\[ g(x)=f(x)-x. \]

This connects fixed-point problems directly to zero-finding.

Zeros Are Intersections with \(y=0\)

Solving

\[ f(x)=0 \]

asks where the graph of

\[ y=f(x) \]

intersects the horizontal line

\[ y=0. \]

This line is the \(x\)-axis.

Fixed Points Are Intersections with \(y=x\)

Solving

\[ f(x)=x \]

asks where

\[ y=f(x) \]

intersects

\[ y=x. \]

This graphical viewpoint turns fixed-point problems into intersection problems.

More General Intersection Problems

Suppose we want to solve

\[ f(x)=g(x). \]

This asks where two functions produce the same output at the same input.

Equivalently, solve

\[ f(x)-g(x)=0. \]

Zeros, fixed points, and intersections are all closely connected forms of equation solving.

Intercepts in Context

Intercepts often have practical interpretations.

If

\[ C(q)=5q+100, \]

then

\[ C(0)=100. \]

The \(y\)-intercept

\[ (0,100) \]

can represent a fixed cost before any units are produced.

Zero in Context

Suppose

\[ P(q) \]

represents profit as a function of quantity sold.

A zero of \(P\) satisfies

\[ P(q)=0. \]

Such an input may represent a break-even quantity.

Not Every Intercept Is Meaningful in Context

A formula may have an algebraic intercept outside the practical domain.

For example, a time model may be defined only for

\[ t\ge0. \]

An algebraic zero at

\[ t=-5 \]

would not belong to the practical model.

Domain First

Before reporting zeros, intercepts, or fixed points, check the domain.

An algebraic candidate outside the domain is not a valid feature of the function.

Worked Example: Zeros and Intercepts

Let

\[ f(x)=x^2-6x+8. \]

Factor:

\[ f(x)=(x-2)(x-4). \]

Zeros:

\[ \boxed{x=2,\quad x=4}. \]

\(x\)-intercepts:

\[ \boxed{(2,0),\quad(4,0)}. \]

\(y\)-intercept:

\[ f(0)=8, \]

so

\[ \boxed{(0,8)}. \]

Worked Example: Fixed Points

Using

\[ f(x)=x^2-6x+8, \]

solve

\[ f(x)=x. \]

Then

\[ x^2-6x+8=x. \]

So

\[ x^2-7x+8=0. \]

Using the quadratic formula:

\[ x= \frac{7\pm\sqrt{49-32}}{2} = \frac{7\pm\sqrt{17}}{2}. \]

Thus, the fixed points are

\[ \boxed{x=\frac{7+\sqrt{17}}{2},\quad x=\frac{7-\sqrt{17}}{2}}. \]

Worked Example: Rational Function

Let

\[ f(x)=\frac{x-3}{x+1}. \]

Zero:

\[ x-3=0 \]

gives

\[ \boxed{x=3}. \]

The \(y\)-intercept is

\[ f(0)=\frac{-3}{1}=-3, \]

so

\[ \boxed{(0,-3)}. \]

Worked Example: Fixed Point of a Rational Function

For

\[ f(x)=\frac{x-3}{x+1}, \qquad x\ne-1, \]

solve

\[ \frac{x-3}{x+1}=x. \]

Multiply by \(x+1\):

\[ x-3=x(x+1). \]

Then

\[ x-3=x^2+x. \]

So

\[ x^2+3=0. \]

There are no real fixed points.

Worked Example: Multiplicity

Let

\[ f(x)=(x+2)^2(x-5)^3. \]

The zeros are:

\[ x=-2 \]

with multiplicity \(2\), and

\[ x=5 \]

with multiplicity \(3\).

Graphically, the polynomial typically touches the axis at \(-2\) and crosses at \(5\).

A Reliable Zero-Finding Workflow

  1. Identify the function and its domain.
  2. Set \(f(x)=0\).
  3. Solve using factoring, inverse operations, formulas, graphing, or numerical methods as appropriate.
  4. Reject any candidates outside the domain.
  5. Interpret valid zeros as \(x\)-intercepts \((x,0)\) when graphing.

A Reliable Intercept Workflow

  1. For \(x\)-intercepts, solve \(f(x)=0\).
  2. For the \(y\)-intercept, evaluate \(f(0)\) if \(0\) is in the domain.
  3. Write intercepts as ordered pairs.
  4. Check contextual domain restrictions before interpreting them.

A Reliable Fixed-Point Workflow

  1. Write the equation \(f(x)=x\).
  2. Rearrange to \(f(x)-x=0\) when useful.
  3. Solve the resulting equation.
  4. Check the domain.
  5. Verify each candidate by confirming \(f(x)=x\).
  6. Graphically, compare \(y=f(x)\) with \(y=x\).

Common Errors

Calling an Intercept a Zero

A zero is an input value such as \(x=3\). The corresponding intercept is the point \((3,0)\).

Finding a \(y\)-Intercept by Setting \(f(x)=0\)

The \(y\)-intercept comes from setting the input equal to zero:

\[ x=0. \]

Ignoring the Domain

An excluded input cannot be a valid zero, intercept, or fixed point.

Assuming Every Function Has an \(x\)-Intercept

Some functions never produce zero.

Assuming Every Function Has a \(y\)-Intercept

The function may be undefined at \(x=0\).

Confusing Fixed Points with Zeros

Zeros solve \(f(x)=0\); fixed points solve \(f(x)=x\).

Ignoring Multiplicity

Repeated factors affect how polynomial graphs behave at a zero.

Practice

1. Find the Zero

Let

\[ f(x)=5x-20. \]

Find the zero.

Check Answer \[ 5x-20=0, \] \[ 5x=20, \] \[ \boxed{x=4}. \]

2. Find the Intercepts

Let

\[ f(x)=2x+6. \]

Find the \(x\)- and \(y\)-intercepts.

Check Answer

For the \(x\)-intercept:

\[ 2x+6=0, \] \[ x=-3. \]

So

\[ \boxed{(-3,0)}. \]

For the \(y\)-intercept:

\[ f(0)=6. \]

So

\[ \boxed{(0,6)}. \]

3. Quadratic Zeros

Find the zeros of

\[ f(x)=x^2-9. \]
Check Answer \[ (x-3)(x+3)=0. \]

Thus,

\[ \boxed{x=-3,\quad x=3}. \]

4. Fixed Point

Find the fixed point of

\[ f(x)=\frac{x+8}{2}. \]
Check Answer \[ \frac{x+8}{2}=x. \] \[ x+8=2x. \] \[ \boxed{x=8}. \]

5. Several Fixed Points

Find the fixed points of

\[ f(x)=x^2. \]
Check Answer \[ x^2=x, \] \[ x(x-1)=0. \]

So

\[ \boxed{x=0,\quad x=1}. \]

6. No \(y\)-Intercept

Does

\[ f(x)=\frac{3}{x} \]

have a \(y\)-intercept?

Check Answer

No. The function is undefined at

\[ x=0. \]

7. Multiplicity

For

\[ f(x)=(x-1)^2(x+4), \]

state the zeros and multiplicities.

Check Answer \[ x=1 \]

has multiplicity \(2\), and

\[ x=-4 \]

has multiplicity \(1\).

8. Zero Versus Intercept

If \(x=7\) is a zero, what is the corresponding \(x\)-intercept?

Check Answer \[ \boxed{(7,0)}. \]

Key Ideas

  • A zero is an input \(x\) satisfying \(f(x)=0\).
  • The corresponding \(x\)-intercept is the point \((x,0)\).
  • The \(y\)-intercept is \((0,f(0))\) when \(0\) belongs to the domain.
  • A function may have no zeros, one zero, or many zeros.
  • Domain restrictions must be checked before accepting zeros or intercepts.
  • For rational functions, numerator zeros count only when the denominator is nonzero.
  • Multiplicity describes repeated polynomial zeros and influences graph behavior.
  • A fixed point satisfies \(f(x)=x\).
  • Fixed points are intersections of \(y=f(x)\) with \(y=x\).
  • Fixed points of \(f\) are zeros of \(f(x)-x\).
  • Zeros, fixed points, and general intersections are all forms of equation solving.
  • Fixed points play an important role in iteration, transformations, dynamical systems, and numerical methods.

Where This Leads

Zeros, intercepts, and fixed points provide some of the most useful landmarks of a function.

They lead naturally into polynomial roots, multiplicity, graph behavior, systems of equations, numerical root-finding, inverse problems, iterative methods, dynamical systems, equilibrium models, and calculus-based analysis of how functions cross, touch, or approach important reference lines.
