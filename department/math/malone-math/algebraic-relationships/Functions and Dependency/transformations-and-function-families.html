Transformations and Function Families

Many functions are easier to understand as transformed versions of simpler parent functions. By changing a few parameters, we can shift, reflect, stretch, compress, and otherwise reshape an entire family of related functions.

The Central Idea

Begin with the parent function

\[ f(x)=x^2. \]

Now compare

\[ g(x)=(x-3)^2+2. \]

The rule is still built from squaring, but the graph has moved:

  • right by \(3\);
  • up by \(2\).

So \(g\) belongs to the same general family as \(f\), but its parameters place the parabola differently.

A great deal of graph behavior can be understood through transformations rather than starting from scratch each time.

What Is a Function Family?

A function family is a collection of related functions sharing a common structural form.

For example,

\[ f(x)=ax^2+bx+c \]

describes a family of quadratic functions.

Different values of

\[ a,\quad b,\quad c \]

select different members of the family.

Parent Functions

A parent function is a simple representative used as a reference for a family.

Common examples include:

\[ f(x)=x \]

for linear functions,

\[ f(x)=x^2 \]

for quadratics,

\[ f(x)=|x| \]

for absolute-value functions,

\[ f(x)=\sqrt{x} \]

for square-root functions, and

\[ f(x)=\frac1x \]

for reciprocal functions.

Transformations Build New Functions

Given a parent function

\[ y=f(x), \]

common transformations include:

  • vertical translation;
  • horizontal translation;
  • vertical reflection;
  • horizontal reflection;
  • vertical stretch or compression;
  • horizontal stretch or compression.

Vertical Translation

Consider

\[ g(x)=f(x)+k. \]

Every output changes by the same amount \(k\).

If \(k>0\), the graph moves upward. If \(k<0\), the graph moves downward.

Vertical Translation Example

Start with

\[ f(x)=x^2. \]

Then

\[ g(x)=x^2+4 \]

moves the graph upward by \(4\).

The vertex changes from \((0,0)\) to \((0,4)\).

Horizontal Translation

Consider

\[ g(x)=f(x-h). \]

If \(h>0\), the graph moves right by \(h\). If \(h<0\), it moves left.

The sign appears reversed because the transformation changes the input before the parent function receives it.

Why Horizontal Shifts Look Backward

Suppose an old input is \(u\). In

\[ f(x-3), \]

we need

\[ x-3=u. \]

Therefore,

\[ x=u+3. \]

The corresponding point occurs three units to the right.

Horizontal Translation Examples

For the parent

\[ f(x)=x^2, \]

the function

\[ (x-5)^2 \]

shifts right by \(5\), while

\[ (x+2)^2=(x-(-2))^2 \]

shifts left by \(2\).

Reflection Across the \(x\)-Axis

Consider

\[ g(x)=-f(x). \]

Every output changes sign, so the graph reflects across the \(x\)-axis.

For example,

\[ f(x)=x^2 \]

becomes

\[ g(x)=-x^2. \]

Reflection Across the \(y\)-Axis

Consider

\[ g(x)=f(-x). \]

The input changes sign before entering the function, so the graph reflects across the \(y\)-axis.

For example,

\[ f(x)=\sqrt{x} \]

becomes

\[ g(x)=\sqrt{-x}. \]

Vertical Stretch and Compression

For

\[ g(x)=af(x), \]

the parameter \(a\) scales vertical distances from the \(x\)-axis.

  • If \(|a|>1\), the graph is vertically stretched.
  • If \(0<|a|<1\), the graph is vertically compressed.
  • If \(a<0\), a reflection across the \(x\)-axis is also included.

Vertical Scaling Example

For

\[ f(x)=x^2, \]

the function

\[ g(x)=3x^2 \]

is a vertical stretch by factor \(3\), while

\[ h(x)=\frac12x^2 \]

is a vertical compression by factor \(1/2\).

Horizontal Scaling

For

\[ g(x)=f(bx), \]

the horizontal scale factor is

\[ \boxed{\frac1{|b|}}. \]
  • If \(|b|>1\), the graph is horizontally compressed.
  • If \(0<|b|<1\), the graph is horizontally stretched.
  • If \(b<0\), reflection across the \(y\)-axis is also included.

Why Horizontal Scaling Is Reciprocal

To reproduce an old input \(u\), solve

\[ bx=u. \]

Then

\[ x=\frac{u}{b}. \]

That is why \(f(2x)\) compresses horizontally by factor \(1/2\), while \(f(x/3)\) stretches horizontally by factor \(3\).

The General Transformation Form

A broad transformation pattern is

\[ \boxed{g(x)=a\,f(b(x-h))+k}. \]

The parameters control:

  • \(h\): horizontal translation;
  • \(k\): vertical translation;
  • \(a\): vertical scale and possible reflection across the \(x\)-axis;
  • \(b\): horizontal scale and possible reflection across the \(y\)-axis.

Transformation Summary

Form Effect
\(f(x)+k\)Vertical shift by \(k\)
\(f(x-h)\)Horizontal shift by \(h\)
\(-f(x)\)Reflect across the \(x\)-axis
\(f(-x)\)Reflect across the \(y\)-axis
\(af(x)\)Vertical scale by \(|a|\)
\(f(bx)\)Horizontal scale by \(1/|b|\)

Input Versus Output Transformations

Transformations outside the function act directly on outputs:

\[ af(x)+k. \]

Transformations inside the function act on inputs:

\[ f(b(x-h)). \]

This distinction explains why outside transformations behave directly while inside transformations appear reciprocal.

Point Mapping

Suppose

\[ (u,v) \]

lies on

\[ y=f(x). \]

For

\[ g(x)=a\,f(b(x-h))+k, \]

the corresponding point is

\[ \boxed{ \left(h+\frac{u}{b},\,av+k\right) } \]

when \(b\ne0\).

Point-Mapping Example

Suppose \((2,5)\) lies on \(y=f(x)\), and

\[ g(x)=3f(2(x-4))-1. \]

Here

\[ a=3,\quad b=2,\quad h=4,\quad k=-1. \]

The point becomes

\[ \left(4+\frac22,\,3(5)-1\right) = \boxed{(5,14)}. \]

Transformations and Domain

If

\[ g(x)=f(b(x-h)), \]

then the transformed input must still belong to the original domain:

\[ b(x-h)\in\operatorname{dom}(f). \]

So transformations can shift or rescale domain restrictions.

Square-Root Domain Example

Start with

\[ f(x)=\sqrt{x}, \qquad x\ge0. \]

For

\[ g(x)=\sqrt{x-4}, \]

we require

\[ x-4\ge0. \]

Thus,

\[ \boxed{x\ge4}. \]

Transformations and Range

Vertical transformations act directly on the range.

If an original output is \(y\), then

\[ y\mapsto ay+k. \]

For example,

\[ f(x)=x^2 \]

has range \([0,\infty)\), while

\[ g(x)=-2x^2+5 \]

has range

\[ \boxed{(-\infty,5]}. \]

Quadratic Family

In vertex form,

\[ f(x)=a(x-h)^2+k, \]

the vertex is

\[ (h,k). \]

The parameter \(a\) controls vertical scale and opening direction.

Absolute-Value Family

The transformed absolute-value family is

\[ f(x)=a|x-h|+k. \]

The vertex is

\[ (h,k), \]

and \(a\) controls the steepness and opening direction of the V-shape.

Square-Root Family

A transformed square-root function can be written

\[ f(x)=a\sqrt{b(x-h)}+k. \]

The input transformation changes the starting point and domain, while the output transformation changes vertical placement and scale.

Reciprocal Family

A transformed reciprocal function may be written

\[ f(x)=\frac{a}{x-h}+k. \]

The parent asymptotes

\[ x=0, \qquad y=0 \]

shift to

\[ \boxed{x=h, \qquad y=k}. \]

Exponential Family

A transformed exponential function may be written

\[ f(x)=a\,b^{x-h}+k, \qquad b>0, \qquad b\ne1. \]

The parameter \(k\) shifts the horizontal asymptote, while \(a\) controls vertical scale and possible reflection.

Trigonometric Families

A sinusoidal family can be written

\[ f(x)=A\sin(B(x-h))+k. \]

The parameters can control:

  • amplitude;
  • period;
  • horizontal shift;
  • vertical shift.

Changing an Input Versus Changing a Parameter

Consider the family

\[ f_h(x)=(x-h)^2. \]

For fixed \(h\), changing \(x\) moves along one parabola.

Changing \(h\) selects a different parabola in the family.

This is the difference between varying an independent variable and varying a model parameter.

Transformations as Composition

Transformations can be understood as function composition.

If

\[ S(x)=x-3, \]

then

\[ f(S(x))=f(x-3) \]

applies an input transformation before the parent function.

Output Transformations as Composition

If

\[ T(y)=2y+5, \]

then

\[ T(f(x))=2f(x)+5. \]

The parent function acts first, and then its output is transformed.

Transformation Order Matters

Because composition is generally not commutative, the order of transformations can matter.

This is especially important when translations and scalings are combined.

Factor the Input Before Reading Horizontal Transformations

Consider

\[ f(2x-6). \]

Factor:

\[ 2x-6=2(x-3). \]

So

\[ f(2x-6)=f(2(x-3)). \]

This reveals:

  • a shift right by \(3\);
  • a horizontal compression by factor \(1/2\).

Do Not Read the Inside Constant Too Quickly

In

\[ f(2x-6), \]

the shift is not right by \(6\).

The horizontal structure becomes clear only after factoring:

\[ 2(x-3). \]

Worked Example: Transformed Parabola

Describe

\[ g(x)=-(x-2)^2+5 \]

relative to

\[ f(x)=x^2. \]

Transformations:

  • shift right \(2\);
  • reflect across the \(x\)-axis;
  • shift up \(5\).

The vertex is

\[ \boxed{(2,5)}. \]

Worked Example: Absolute Value

Describe

\[ g(x)=3|x+1|-4 \]

relative to

\[ f(x)=|x|. \]
  • shift left \(1\);
  • vertical stretch by factor \(3\);
  • shift down \(4\).

The vertex is

\[ \boxed{(-1,-4)}. \]

Worked Example: Combined Transformation

Describe

\[ g(x)=-2f(3(x-4))+7. \]

Relative to \(f\):

  • shift right \(4\);
  • horizontal compression by factor \(1/3\);
  • reflect across the \(x\)-axis;
  • vertical stretch by factor \(2\);
  • shift up \(7\).

Transformations and Intercepts

Transformations can move intercepts.

For example, a vertical translation usually changes the zeros because solving

\[ f(x)+k=0 \]

is different from solving

\[ f(x)=0. \]

Transformations and Extrema

A vertical translation shifts maximum and minimum values.

A negative vertical scale reflects the graph, causing maxima and minima to exchange roles.

Transformations and Increasing Behavior

If \(f\) is increasing, then

\[ -f(x) \]

is decreasing on the corresponding interval because all output inequalities reverse.

Transformations and Injectivity

Translations, reflections, and nonzero scalings preserve injectivity when applied to a function with compatible domains.

They change position or scale without forcing two previously distinct function values to become equal.

Transformations Are Often Reversible

A shift right by \(h\) is undone by shifting left by \(h\).

A nonzero scaling by \(a\) is undone by scaling by

\[ \frac1a. \]

A reflection is its own inverse.

Function Families as Reusable Templates

Once a parent function is understood, many related functions can be analyzed through parameter changes.

This reduces memorization and emphasizes structure that can be reused across algebra, geometry, trigonometry, and calculus.

Modeling with Function Families

Suppose data appear approximately quadratic.

Instead of inventing a new model from scratch, we may begin with

\[ f(x)=a(x-h)^2+k. \]

Then choose parameter values that fit the observed location, scale, and orientation.

Parameter Estimation

In applied mathematics and statistics, a model family is often chosen first.

Data are then used to estimate parameter values that best match the observations.

Function families therefore connect algebraic structure with modeling and data analysis.

A Reliable Transformation Workflow

  1. Identify the parent function.
  2. Rewrite the expression in a form resembling \(a\,f(b(x-h))+k\).
  3. Factor the inside expression when necessary.
  4. Identify horizontal shift and scale from \(b(x-h)\).
  5. Identify vertical scale, reflection, and shift from \(a\) and \(k\).
  6. Track domain and range changes.
  7. Use landmark points, intercepts, extrema, or asymptotes to verify the result.

A Reliable Point-Mapping Workflow

  1. Start with a known point \((u,v)\) on the parent graph.
  2. Identify \(a\), \(b\), \(h\), and \(k\).
  3. Apply the coordinate mapping
\[ \boxed{ (u,v) \mapsto \left(h+\frac{u}{b},\,av+k\right) }. \]
  1. Repeat for several landmark points when graphing.
  2. Check restrictions and asymptotes where relevant.

Common Errors

Reading Horizontal Shifts in the Same Direction as the Sign

The expression

\[ f(x-h) \]

shifts right by \(h\).

Using \(b\) as the Horizontal Scale Factor

For

\[ f(bx), \]

the horizontal scale factor is

\[ \frac1{|b|}. \]

Forgetting to Factor the Input

Rewrite

\[ f(2x-6) \]

as

\[ f(2(x-3)) \]

before reading the shift.

Confusing Input and Output Transformations

Inside changes affect inputs; outside changes affect outputs.

Ignoring Hidden Reflections

A negative \(a\) reflects across the \(x\)-axis, and a negative \(b\) reflects across the \(y\)-axis.

Ignoring Domain Changes

Radicals, logarithms, reciprocal functions, and restricted parent functions may acquire shifted or scaled domains.

Treating Family Parameters as the Main Input

Parameters usually select a member of the family; the independent variable then moves through that selected function.

Key Ideas

  • A function family is a collection of functions sharing a common structural form.
  • Parent functions provide simple reference models for larger families.
  • Outside transformations act on outputs; inside transformations act on inputs.
  • \(f(x)+k\) shifts vertically.
  • \(f(x-h)\) shifts horizontally by \(h\).
  • \(-f(x)\) reflects across the \(x\)-axis.
  • \(f(-x)\) reflects across the \(y\)-axis.
  • \(af(x)\) scales vertically by \(|a|\).
  • \(f(bx)\) scales horizontally by \(1/|b|\).
  • The form \(a\,f(b(x-h))+k\) organizes many transformations at once.
  • Factoring inside expressions is often necessary before identifying horizontal changes.
  • Transformations can change domain, range, intercepts, extrema, asymptotes, and monotonicity.
  • Function transformations can be understood as compositions with simpler input and output functions.
  • Parameters generate entire families of related mathematical models.

Where This Leads

Transformations and function families provide a reusable language for understanding graphs without rebuilding every function from the beginning.

These ideas lead naturally into inverse functions, polynomial and rational families, exponential and logarithmic models, trigonometric transformations, conic sections, coordinate transformations, regression, parameter estimation, and the broader study of how changing parameters changes mathematical structure.
