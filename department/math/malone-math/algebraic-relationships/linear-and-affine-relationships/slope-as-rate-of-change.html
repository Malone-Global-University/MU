Slope as Rate of Change

Slope measures how one quantity changes compared with another. On a graph it describes the rise relative to the run; in an equation it measures output change per unit of input; and in an application it may represent speed, cost per item, temperature change per minute, productivity, or any other rate connecting two quantities.

The Central Idea

Suppose a quantity \(y\) changes from

\[ y_1=7 \]

to

\[ y_2=19 \]

while the corresponding input \(x\) changes from

\[ x_1=2 \]

to

\[ x_2=6. \]

The output change is

\[ \Delta y=19-7=12, \]

and the input change is

\[ \Delta x=6-2=4. \]

So the rate of output change relative to input change is

\[ \boxed{ \frac{\Delta y}{\Delta x} = \frac{12}{4} = 3 }. \]

This number is the slope.

It tells us that \(y\) increases by \(3\) units for each increase of \(1\) unit in \(x\).

Slope Compares Two Changes

Slope is not simply the amount that \(y\) changes.

It compares the change in \(y\) with the change in \(x\):

\[ \boxed{ m= \frac{\text{change in output}}{\text{change in input}} }. \]

Using coordinate notation,

\[ \boxed{ m= \frac{y_2-y_1}{x_2-x_1} }, \qquad x_1\ne x_2. \]

The symbol \(m\) is conventionally used for slope.

Delta Notation

The Greek capital letter delta,

\[ \Delta, \]

is commonly used to mean change in.

Thus,

\[ \Delta x=x_2-x_1 \]

and

\[ \Delta y=y_2-y_1. \]

The slope formula can therefore be written compactly as

\[ \boxed{ m=\frac{\Delta y}{\Delta x} }. \]

This notation becomes useful throughout algebra, geometry, science, economics, and calculus.

Rise Over Run

On a coordinate graph, slope is often described as

\[ \boxed{ m= \frac{\text{rise}}{\text{run}} }. \]

The rise is the vertical change:

\[ \text{rise}=\Delta y. \]

The run is the horizontal change:

\[ \text{run}=\Delta x. \]

So “rise over run” and “change in output over change in input” are two ways of describing the same ratio.

Why Slope Is a Rate

A rate compares quantities measured in different roles or units.

Slope does exactly this:

\[ m= \frac{\Delta y}{\Delta x}. \]

If \(y\) is distance and \(x\) is time, then slope may have units

\[ \frac{\text{miles}}{\text{hour}}. \]

If \(y\) is cost and \(x\) is number of items, then slope may have units

\[ \frac{\text{dollars}}{\text{item}}. \]

If \(y\) is temperature and \(x\) is time, then slope may have units

\[ \frac{^\circ\text{C}}{\text{minute}}. \]

The units often reveal the practical meaning of a slope before any further calculation is needed.

Slope Has Direction

The sign of the slope tells us how the output changes as the input increases.

  • If \(m>0\), the output increases as the input increases.
  • If \(m<0\), the output decreases as the input increases.
  • If \(m=0\), the output remains constant.

A vertical line is a separate case because its slope is undefined.

Positive Slope

Consider the points

\[ (1,4) \]

and

\[ (5,12). \]

The slope is

\[ m= \frac{12-4}{5-1} = \frac84 = \boxed{2}. \]

Both the input and output increase.

The graph rises from left to right.

Negative Slope

Consider the points

\[ (2,10) \]

and

\[ (6,2). \]

The slope is

\[ m= \frac{2-10}{6-2} = \frac{-8}{4} = \boxed{-2}. \]

As the input increases by \(1\), the output decreases by \(2\).

The graph falls from left to right.

Zero Slope

Consider

\[ (-3,5) \]

and

\[ (4,5). \]

The slope is

\[ m= \frac{5-5}{4-(-3)} = \frac07 = \boxed{0}. \]

The output does not change.

A horizontal line therefore has slope \(0\).

Undefined Slope

Now consider

\[ (4,1) \]

and

\[ (4,9). \]

The slope calculation would be

\[ m= \frac{9-1}{4-4} = \frac80. \]

Division by zero is undefined, so the slope is undefined.

The two points lie on the vertical line

\[ x=4. \]

A vertical line has undefined slope.

Zero Slope and Undefined Slope Are Different

These cases should not be confused.

For a horizontal line,

\[ \Delta y=0 \]

while

\[ \Delta x\ne0, \]

so

\[ m=\frac0{\Delta x}=0. \]

For a vertical line,

\[ \Delta x=0, \]

so the slope formula requires division by zero and is undefined.

Order Matters, but Consistent Order Gives the Same Slope

Suppose we use the points

\[ (2,5) \]

and

\[ (8,17). \]

Using the first point followed by the second:

\[ m= \frac{17-5}{8-2} = \frac{12}{6} = 2. \]

Reverse both subtraction orders:

\[ m= \frac{5-17}{2-8} = \frac{-12}{-6} = 2. \]

The slope is unchanged.

Do Not Mix the Subtraction Orders

A common error is to calculate

\[ \frac{17-5}{2-8}. \]

This gives

\[ \frac{12}{-6}=-2, \]

which is incorrect for these points.

If the numerator uses

\[ y_2-y_1, \]

the denominator must use

\[ x_2-x_1. \]

Reverse both, or reverse neither.

Slope from a Table

Suppose a table contains:

\(x\) \(y\)
17
313
622

From the first row to the second,

\[ m= \frac{13-7}{3-1} = \frac62 = 3. \]

From the second row to the third,

\[ m= \frac{22-13}{6-3} = \frac93 = 3. \]

The rate is constant.

Unequal Input Steps Require Rates

In the previous table, the input changes were

\[ 2 \]

and

\[ 3. \]

The output changes were therefore different:

\[ 6 \]

and

\[ 9. \]

That does not mean the rate changed.

We compare each output change with its corresponding input change:

\[ \frac62=3, \qquad \frac93=3. \]

When input spacing is unequal, raw first differences are not enough. Use

\[ \frac{\Delta y}{\Delta x}. \]

Constant Slope Characterizes Affine Change

For an affine function

\[ f(x)=mx+b, \]

choose any two distinct inputs \(x_1\) and \(x_2\).

Then

\[ \frac{f(x_2)-f(x_1)}{x_2-x_1} = \frac{(mx_2+b)-(mx_1+b)}{x_2-x_1}. \]

The intercept terms cancel:

\[ = \frac{m(x_2-x_1)}{x_2-x_1} = \boxed{m}. \]

Every pair of distinct points on the same nonvertical affine graph therefore gives the same slope.

The Starting Value Does Not Affect Slope

Compare

\[ f(x)=4x \]

and

\[ g(x)=4x+100. \]

The second graph is shifted upward, but both functions have slope

\[ \boxed{4}. \]

Slope measures the rate of change, not the starting value.

Slope from a Formula

If an affine function is already written as

\[ f(x)=mx+b, \]

then its slope is the coefficient of \(x\):

\[ \boxed{m}. \]

For example,

\[ f(x)=-\frac32x+7 \]

has slope

\[ \boxed{-\frac32}. \]

This means the output decreases by \(3\) units for every increase of \(2\) units in the input.

A Fractional Slope Is Still a Rate

Suppose

\[ m=\frac25. \]

This may be interpreted as:

\[ \Delta y=2 \]

for every

\[ \Delta x=5. \]

It can also be interpreted per one unit of input:

\[ \frac25=0.4. \]

So the output increases by \(0.4\) unit for each increase of \(1\) input unit.

Negative Fractions

If

\[ m=-\frac34, \]

then one convenient movement is:

\[ \Delta x=4, \qquad \Delta y=-3. \]

Move \(4\) units to the right and \(3\) units down.

Equivalently,

\[ \Delta x=-4, \qquad \Delta y=3. \]

Move \(4\) units to the left and \(3\) units up.

Both movements describe the same slope.

Slope Between Any Two Points on an Affine Graph

Suppose a line has slope

\[ m=\frac32. \]

If one point is

\[ (2,5), \]

then increasing \(x\) by \(4\) changes \(y\) by

\[ \Delta y= \frac32(4)=6. \]

So another point on the same line is

\[ (6,11). \]

Checking:

\[ \frac{11-5}{6-2} = \frac64 = \frac32. \]

The Fundamental Difference Relationship

For an affine function with slope \(m\),

\[ \boxed{ \Delta y=m\,\Delta x }. \]

Equivalently,

\[ \boxed{ y_2-y_1=m(x_2-x_1) }. \]

This equation is one of the most useful ways to think about slope.

It says that the change in output equals the slope multiplied by the change in input.

Rate per One Unit

If

\[ \Delta x=1, \]

then

\[ \Delta y=m(1)=m. \]

So slope is the output change associated with one unit of input change.

This is why slope is also a unit rate when the quantities have meaningful units.

Example: Constant Speed

A vehicle's distance increases from \(120\) miles to \(300\) miles while time increases from \(2\) hours to \(5\) hours.

The change in distance is

\[ 300-120=180\text{ miles}. \]

The change in time is

\[ 5-2=3\text{ hours}. \]

The slope is

\[ m= \frac{180\text{ miles}}{3\text{ hours}} = \boxed{60\text{ miles per hour}}. \]

Here slope is literally speed.

Example: Cost per Item

A manufacturer reports that total cost rises from \$2,400 to \$3,150 when production rises from \(200\) units to \(350\) units.

The change in cost is

\[ 3150-2400=750. \]

The change in production is

\[ 350-200=150. \]

So

\[ m= \frac{\$750}{150\text{ units}} = \boxed{\$5\text{ per unit}}. \]

The slope measures the additional cost per additional unit over that interval.

Example: Cooling

A substance cools from \(90^\circ\text{C}\) to \(66^\circ\text{C}\) over \(8\) minutes.

The average rate of temperature change is

\[ m= \frac{66-90}{8-0} = \frac{-24}{8} = \boxed{-3^\circ\text{C per minute}}. \]

The negative sign communicates that the temperature is decreasing.

Example: Elevation

A trail rises from \(620\) meters to \(860\) meters while horizontal distance increases from \(1.2\) kilometers to \(2.0\) kilometers.

The changes are

\[ \Delta y=240\text{ m}, \]

and

\[ \Delta x=0.8\text{ km}. \]

So the slope as a rate is

\[ \frac{240\text{ m}}{0.8\text{ km}} = \boxed{300\text{ m/km}}. \]

Unit conversion may also be used if a dimensionless geometric grade is desired.

Units Must Be Tracked Carefully

Suppose elevation changes by \(30\) meters over a horizontal distance of \(200\) meters.

Then

\[ m= \frac{30\text{ m}}{200\text{ m}} = 0.15. \]

Because the numerator and denominator use the same unit, the units cancel.

This may also be expressed as a \(15\%\) grade:

\[ 0.15(100\%)=15\%. \]

If the horizontal distance had instead been recorded in kilometers, the units would need to be reconciled before making that interpretation.

Slope Is Not the Same as an Output Value

Suppose

\[ f(x)=5x+20. \]

At

\[ x=4, \]

the output is

\[ f(4)=40. \]

But the slope is

\[ \boxed{5}. \]

The value \(40\) tells us where the function is at that input.

The slope \(5\) tells us how rapidly the output changes as the input changes.

Slope Is Not Necessarily a Percentage

A slope of

\[ 0.08 \]

does not automatically mean \(8\%\).

It means

\[ 0.08 \frac{\text{output unit}}{\text{input unit}} \]

unless the context and units justify a percentage interpretation.

Percent change compares a change with a reference amount; slope compares output change with input change.

Average Rate of Change

For any function \(f\), not only an affine function, the average rate of change from \(x=a\) to \(x=b\) is

\[ \boxed{ \frac{f(b)-f(a)}{b-a} }, \qquad a\ne b. \]

This has exactly the same algebraic form as the slope formula.

For an affine function, the result is the same on every interval.

For a nonlinear function, it may change from one interval to another.

Nonlinear Example

Consider

\[ f(x)=x^2. \]

From \(x=0\) to \(x=1\), the average rate of change is

\[ \frac{1^2-0^2}{1-0}=1. \]

From \(x=1\) to \(x=2\), it is

\[ \frac{2^2-1^2}{2-1} = \frac{4-1}{1} = 3. \]

The rate changes, so the function is not affine.

Constant Rate Versus Changing Rate

This gives a useful distinction:

  • Affine behavior: the rate of change is constant.
  • Nonlinear behavior: the rate of change generally varies.

This distinction becomes one of the main bridges from algebra into the later study of curves and calculus.

Slope as the Slope of a Secant Line

For two points on any graph,

\[ (x_1,f(x_1)) \]

and

\[ (x_2,f(x_2)), \]

the quantity

\[ \frac{f(x_2)-f(x_1)}{x_2-x_1} \]

is the slope of the straight line joining those points.

That joining line is called a secant line.

For an affine function, the secant line is the graph itself, so every secant slope is the same.

A Gentle Preview of Local Rate

On a curved graph, the average rate of change depends on which two points are chosen.

If the points are brought closer together, their secant slopes can reveal how rapidly the function is changing near one location.

This idea eventually leads to tangent lines and derivatives.

For now, the important contrast is simple: an affine function has one constant slope everywhere.

Geometric Steepness

For coordinate axes using the same physical scale, a larger value of

\[ |m| \]

corresponds to a steeper nonvertical line.

For example, a line with slope

\[ 5 \]

is steeper than a line with slope

\[ 2. \]

A line with slope

\[ -5 \]

has the same magnitude of steepness as one with slope \(5\), but it falls instead of rises as \(x\) increases.

Graph Appearance Depends on Axis Scale

Visual steepness can be misleading when the horizontal and vertical axes use different scales.

A line may look very steep because one axis is compressed, or nearly flat because one axis is stretched.

The numerical slope

\[ \frac{\Delta y}{\Delta x} \]

depends on the coordinate values and units, not merely on how the graph looks on a screen or page.

Changing Units Changes the Numerical Slope

Suppose a speed is

\[ 60\text{ miles per hour}. \]

The same physical motion expressed in miles per minute has slope

\[ \frac{60}{60} = 1\text{ mile per minute}. \]

The phenomenon has not changed.

The numerical value of the slope changed because the input unit changed.

Changing the Output Unit Also Changes the Number

A slope of

\[ 2\text{ meters per second} \]

is the same rate as

\[ 200\text{ centimeters per second}. \]

Slope should therefore be interpreted together with its units.

Slope from Two Data Points

Suppose measurements give

\[ (10,42) \]

and

\[ (25,87). \]

Then

\[ m= \frac{87-42}{25-10} = \frac{45}{15} = \boxed{3}. \]

If the data are known to follow an affine relationship, this determines the rate for the entire relationship.

If the data come from a potentially nonlinear process, it determines only the average rate between those observations.

Data Do Not Automatically Prove Constant Rate

Two distinct points always determine one nonvertical line when their \(x\)-coordinates differ.

Therefore, any two such data points produce a slope.

But two points alone do not prove that the underlying real-world process has a constant rate everywhere.

Additional observations or a justified model assumption are needed to establish affine behavior.

Checking Several Intervals

Suppose data are:

\(x\) \(y\)
04
210
519
931

Successive rates are

\[ \frac{10-4}{2-0}=3, \] \[ \frac{19-10}{5-2}=3, \]

and

\[ \frac{31-19}{9-5}=3. \]

The data are consistent with a constant slope of \(3\).

Checking Nonadjacent Points

For the same data, compare the first and last points:

\[ m= \frac{31-4}{9-0} = \frac{27}{9} = 3. \]

For truly affine data, every pair of distinct points with different \(x\)-coordinates produces the same slope.

Repeated \(x\)-Values in Data

Suppose a table contains

\[ (3,5) \]

and

\[ (3,11). \]

The two observations have the same input but different outputs.

The slope between them is undefined because

\[ \Delta x=0. \]

If these points are intended to describe a relation \(y=f(x)\), they also violate the function requirement that one input have only one output.

Slope and Direct Proportion

For a direct proportion

\[ y=kx, \]

the constant of proportionality \(k\) is also the slope:

\[ \frac{y}{x}=k \]

for nonzero \(x\), and

\[ \frac{\Delta y}{\Delta x}=k. \]

Thus, in a direct proportional relationship,

\[ \boxed{ \text{slope} = \text{unit rate} = \text{constant of proportionality} }. \]

Slope and Affine Relationships

For

\[ y=mx+b \]

with \(b\ne0\), the slope is still \(m\), but

\[ \frac{y}{x} \]

is generally not constant.

This is why every direct proportion has constant slope, but not every constant-slope relationship is a direct proportion.

Rate and Initial Value Play Different Roles

Consider a delivery service that charges \$8 plus \$3 per mile.

The model is

\[ C(d)=3d+8. \]

The slope

\[ 3\text{ dollars per mile} \]

describes how cost changes with distance.

The value

\[ 8\text{ dollars} \]

is the starting charge.

Slope answers how fast does the output change?, not where does the relationship begin?

Slope from a Change Statement

Suppose a problem says:

“For every additional \(5\) kilograms of material, shipping cost increases by \$12.”

Then

\[ \Delta x=5\text{ kg} \]

and

\[ \Delta y=\$12. \]

So

\[ m= \frac{\$12}{5\text{ kg}} = \boxed{\$2.40\text{ per kg}}. \]

Slope from a Decrease Statement

Suppose a reservoir loses \(18\) million liters over \(6\) days.

If volume is the output and time is the input,

\[ \Delta y=-18 \]

million liters and

\[ \Delta x=6 \]

days.

Therefore,

\[ m= \frac{-18}{6} = \boxed{-3\text{ million liters per day}}. \]

Choosing the Input and Output Matters

Suppose a machine produces \(120\) parts in \(3\) hours at a constant rate.

If parts are output and time is input,

\[ m= \frac{120\text{ parts}}{3\text{ hours}} = 40\text{ parts per hour}. \]

If instead time is treated as output and parts as input, the corresponding rate is

\[ \frac{3\text{ hours}}{120\text{ parts}} = \frac1{40}\text{ hour per part}. \]

The two rates describe reciprocal viewpoints of the same relationship.

Swapping the Axes Reciprocates a Nonzero Slope

If a relationship has nonzero slope

\[ m= \frac{\Delta y}{\Delta x}, \]

then exchanging the roles of \(x\) and \(y\) gives

\[ \frac{\Delta x}{\Delta y} = \frac1m. \]

This is one reason inverse affine relationships have reciprocal slopes when their axes are exchanged.

The zero and vertical cases require separate care because reciprocals involving zero are not defined in the usual way.

Slope as a Difference Quotient

The expression

\[ \frac{f(x_2)-f(x_1)}{x_2-x_1} \]

is called a difference quotient.

It divides a difference in function values by the corresponding difference in inputs.

For affine functions, this quotient always simplifies to the constant slope \(m\).

Difference Quotient Example

Let

\[ f(x)=7x-4. \]

For arbitrary distinct inputs \(a\) and \(b\),

\[ \frac{f(b)-f(a)}{b-a} = \frac{(7b-4)-(7a-4)}{b-a}. \]

Simplify:

\[ = \frac{7b-7a}{b-a} = \frac{7(b-a)}{b-a} = \boxed{7}. \]

The rate does not depend on which two distinct inputs are chosen.

A Useful Algebraic Test for Affine Behavior

If a function satisfies

\[ f(x+h)-f(x)=mh \]

for all appropriate \(x\) and changes \(h\), then its output change depends only on the input change, not on the starting location.

For

\[ f(x)=mx+b, \]

we have

\[ f(x+h)-f(x) = m(x+h)+b-(mx+b) = mh. \]

This is another expression of constant rate of change.

A Reliable Slope Workflow

  1. Identify the input and output quantities.
  2. Choose two distinct observations or points.
  3. Compute the output change \(\Delta y\).
  4. Compute the corresponding input change \(\Delta x\).
  5. Divide: \(m=\Delta y/\Delta x\).
  6. Keep the subtraction order consistent.
  7. Attach and interpret units when the quantities are measured.
  8. Check whether the slope is positive, negative, zero, or undefined.
  9. If testing for affine behavior, compare rates over several intervals.

A Reliable Table Workflow

  1. Do not assume the input steps are equal.
  2. Compute each relevant \(\Delta x\).
  3. Compute the matching \(\Delta y\).
  4. Form \(\Delta y/\Delta x\) for each interval.
  5. If all rates agree, the table is consistent with affine behavior.
  6. If the rates differ, the relationship is not affine across those observations.

A Reliable Interpretation Workflow

  1. State what the numerator measures.
  2. State what the denominator measures.
  3. Read the slope as “output units per input unit.”
  4. Use the sign to describe increase or decrease.
  5. Distinguish the rate from any starting value or current output value.
  6. Check whether a constant-rate interpretation is justified by the model or data.

Common Errors

Using \(y_2-y_1\) Over \(x_1-x_2\)

The subtraction orders must correspond.

Looking Only at \(\Delta y\)

Output differences cannot be compared fairly when input steps differ. Use

\[ \frac{\Delta y}{\Delta x}. \]

Calling a Vertical Line's Slope Zero

A horizontal line has slope \(0\). A vertical line has undefined slope.

Dropping the Sign

A negative slope communicates decrease. Its sign is part of its meaning.

Ignoring Units

In applications, a slope such as \(5\) is incomplete when the meaningful interpretation is \(5\) dollars per item or \(5\) meters per second.

Confusing Slope with an Output

Slope measures change per input change; it is not generally the value of the function.

Assuming Two Points Prove a Linear Process

Two points determine a line, but they do not prove that an underlying process follows that line outside the observed interval.

Judging Slope Only by Appearance

Axis scaling can distort visual steepness. Calculate the numerical slope from coordinate values.

Key Ideas

  • Slope compares output change with input change.
  • \(m=\dfrac{y_2-y_1}{x_2-x_1}=\dfrac{\Delta y}{\Delta x}\).
  • “Rise over run” is the graphical form of the same ratio.
  • Slope is a rate and often has units of output units per input unit.
  • Positive slope indicates increase as \(x\) increases.
  • Negative slope indicates decrease as \(x\) increases.
  • Horizontal lines have slope \(0\).
  • Vertical lines have undefined slope.
  • Subtraction order may be reversed only if it is reversed in both numerator and denominator.
  • Affine functions have the same slope between every pair of distinct points.
  • For affine change, \(\Delta y=m\Delta x\).
  • The intercept or starting value does not affect slope.
  • Direct proportion is a special case in which slope, unit rate, and constant of proportionality coincide.
  • For nonlinear functions, \(\Delta y/\Delta x\) gives an average rate of change over an interval.
  • Two data points determine a slope but do not by themselves prove that an entire real-world process has constant rate.
  • Axis scale and measurement units affect how slope looks or is numerically expressed, so interpretation matters.

Where This Leads

Slope turns the geometric idea of steepness into an algebraic and practical measure of change. It connects coordinate differences, unit rates, proportional relationships, affine functions, tables, formulas, graphs, and real-world models through one reusable quantity.

From here, slope will be combined with intercepts and known points to construct equations of lines, compare line relationships, graph linear and affine equations efficiently, build models from data, study interpolation and trends, and eventually distinguish average rates of change from local rates on curved functions.
