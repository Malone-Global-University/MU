Translations, Reflections, Stretches, and Compressions

Once a familiar graph has been recognized, we rarely need to plot every new version from scratch. A function can often be understood as a transformed version of a parent graph. Translations move a graph, reflections flip it, and stretches or compressions change its scale. Learning to read these changes from a formula creates a direct bridge between algebraic form and graphical structure.

The Central Idea

A transformation changes the position, orientation, or scale of a graph while preserving its basic family structure.

If the parent function is

\[ y=f(x), \]

a large class of transformed functions can be written as

\[ \boxed{g(x)=a\,f\!\bigl(b(x-h)\bigr)+k}. \]

The parameters \(a\), \(b\), \(h\), and \(k\) control the transformation.

Four Basic Transformation Types

  • translation — moves a graph without changing its shape;
  • reflection — flips a graph across a line;
  • stretch — enlarges distances in one direction;
  • compression — reduces distances in one direction.

Transformations Preserve Family Structure

A transformed quadratic function is still quadratic. A transformed absolute-value function is still in the absolute-value family. A transformed square-root function retains the characteristic one-sided shape of the square-root family.

Transformations change the graph's placement or scale, not its underlying function family.

Start with a Parent Graph

A parent function is a simple reference model for a function family. Examples include

\[ f(x)=x, \qquad f(x)=x^2, \qquad f(x)=|x|, \qquad f(x)=\sqrt{x}. \]

Instead of constructing every related graph independently, we can transform known points from the parent graph.

A Point-by-Point View

Suppose the point

\[ (u,v) \]

lies on the graph of \(y=f(x)\). This means

\[ v=f(u). \]

A transformation tells us where that point moves on the new graph.

The General Coordinate Mapping

For

\[ g(x)=a\,f\!\bigl(b(x-h)\bigr)+k, \]

a point \((u,v)\) on \(y=f(x)\) moves to

\[ \boxed{ (u,v) \longmapsto \left(h+\frac{u}{b},\;k+av\right) }. \]

This one rule contains translations, reflections, stretches, and compressions.

Why the Coordinate Rule Works

To make the transformed function use the same parent input \(u\), require

\[ b(x-h)=u. \]

Solving for \(x\) gives

\[ x=h+\frac{u}{b}. \]

Since \(f(u)=v\), the transformed output becomes

\[ y=av+k. \]

Outside Changes Affect Outputs

In

\[ g(x)=a f(x)+k, \]

the changes occur after \(f\) produces an output. They therefore alter the graph vertically.

  • \(a\) scales or reflects output values;
  • \(k\) translates output values vertically.

Inside Changes Affect Inputs

In

\[ g(x)=f\!\bigl(b(x-h)\bigr), \]

the changes occur before \(f\) receives its input. They therefore alter the graph horizontally.

  • \(b\) scales or reflects input positions;
  • \(h\) translates input positions horizontally.

Vertical Translation

Adding a constant outside the function gives

\[ g(x)=f(x)+k. \]

Every output increases by \(k\), so every point moves vertically:

\[ \boxed{(x,y)\longmapsto(x,y+k)}. \]

Up and Down

If \(k>0\), the graph moves upward \(k\) units. If \(k<0\), the graph moves downward \(|k|\) units.

\[ f(x)+4 \quad\text{moves up }4, \] \[ f(x)-3 \quad\text{moves down }3. \]

Example: Vertical Translation of a Parabola

Start with

\[ f(x)=x^2. \]

Then

\[ g(x)=x^2+5 \]

is the parent parabola translated upward \(5\) units. Its vertex moves from \((0,0)\) to

\[ \boxed{(0,5)}. \]

Horizontal Translation

Replacing \(x\) with \(x-h\) gives

\[ g(x)=f(x-h). \]

Parent input \(u\) now occurs when \(x-h=u\), so

\[ x=u+h. \]

Therefore,

\[ \boxed{(x,y)\longmapsto(x+h,y)}. \]

The Horizontal Sign Looks Reversed

The expression

\[ f(x-4) \]

moves the graph right \(4\) units, while

\[ f(x+4)=f(x-(-4)) \]

moves it left \(4\) units.

Why the Horizontal Sign Is Opposite

Suppose a parent feature occurs at input \(u\). In \(f(x-h)\), the same feature occurs when

\[ x-h=u. \]

Thus

\[ x=u+h. \]

The apparent sign reversal comes from solving an input equation, not from an arbitrary convention.

Example: Horizontal Translation of Absolute Value

The parent graph

\[ f(x)=|x| \]

has vertex \((0,0)\). The graph

\[ g(x)=|x-3| \]

is translated right \(3\) units, so its vertex is

\[ \boxed{(3,0)}. \]

Combining Horizontal and Vertical Translation

The form

\[ g(x)=f(x-h)+k \]

translates the graph by the vector

\[ \boxed{\langle h,k\rangle}. \]

Each point moves according to

\[ (x,y)\longmapsto(x+h,y+k). \]

Example: Two-Direction Translation

Starting from \(f(x)=x^2\), consider

\[ g(x)=(x-2)^2-7. \]

The parent parabola moves right \(2\) and down \(7\). Its vertex moves to

\[ \boxed{(2,-7)}. \]

Reflection Across the \(x\)-Axis

Multiplying the entire function by \(-1\) gives

\[ g(x)=-f(x). \]

Every output changes sign:

\[ \boxed{(x,y)\longmapsto(x,-y)}. \]

This is reflection across the \(x\)-axis.

Example: Vertical Reflection

The graph of

\[ y=-x^2 \]

is the reflection of \(y=x^2\) across the \(x\)-axis. The upward-opening parabola becomes downward-opening.

Reflection Across the \(y\)-Axis

Replacing \(x\) with \(-x\) gives

\[ g(x)=f(-x). \]

Every input changes sign:

\[ \boxed{(x,y)\longmapsto(-x,y)}. \]

This reflects the graph across the \(y\)-axis.

Example: Horizontal Reflection

Let

\[ f(x)=\sqrt{x}. \]

Then

\[ g(x)=\sqrt{-x} \]

is the square-root graph reflected across the \(y\)-axis. It extends left from the origin instead of right.

Some Reflections May Be Invisible

If \(f\) is even, then

\[ f(-x)=f(x), \]

so reflection across the \(y\)-axis produces the same graph. For example,

\[ (-x)^2=x^2. \]

Odd Functions and Reflections

If \(f\) is odd, then

\[ f(-x)=-f(x). \]

For an odd function, reflecting across the \(y\)-axis produces the same result as reflecting across the \(x\)-axis.

Two Reflections Produce Origin Symmetry

Reflecting across both coordinate axes sends

\[ (x,y)\longmapsto(-x,-y). \]

This is equivalent to a \(180^\circ\) rotation about the origin.

Vertical Scaling

Multiplying the function by a nonzero constant \(a\) gives

\[ g(x)=a f(x). \]

Each output is multiplied by \(a\):

\[ \boxed{(x,y)\longmapsto(x,ay)}. \]

Vertical Stretch

If

\[ |a|>1, \]

vertical distances from the \(x\)-axis increase by the factor \(|a|\). This is a vertical stretch.

Example: Vertical Stretch

Compare

\[ f(x)=x^2 \]

with

\[ g(x)=3x^2. \]

A parent point such as \((2,4)\) becomes

\[ \boxed{(2,12)}. \]

The parabola appears narrower because its outputs grow three times as far from the \(x\)-axis.

Vertical Compression

If

\[ 0<|a|<1, \]

vertical distances from the \(x\)-axis shrink by the factor \(|a|\). This is a vertical compression.

Example: Vertical Compression

For

\[ g(x)=\frac14 x^2, \]

the point \((2,4)\) on \(y=x^2\) becomes

\[ \boxed{(2,1)}. \]

A Negative Vertical Scale Does Two Things

If \(a<0\), then

\[ g(x)=a f(x) \]

combines a vertical scale by \(|a|\) with a reflection across the \(x\)-axis.

For example,

\[ g(x)=-2f(x) \]

reflects vertically and doubles all vertical distances.

Horizontal Scaling

Replacing \(x\) with \(bx\) gives

\[ g(x)=f(bx). \]

A parent input \(u\) appears at the new input \(u/b\), so

\[ \boxed{(x,y)\longmapsto\left(\frac{x}{b},y\right)}. \]

Horizontal Scaling Uses the Reciprocal

The coefficient inside the function acts reciprocally on horizontal distances.

\[ f(2x) \]

multiplies horizontal coordinates by \(1/2\), while

\[ f\!\left(\frac{x}{2}\right) \]

multiplies horizontal coordinates by \(2\).

Horizontal Compression

If

\[ |b|>1, \]

then the horizontal scale factor is

\[ \frac{1}{|b|}<1. \]

The graph is compressed horizontally.

Example: Horizontal Compression

If \((4,7)\) lies on \(y=f(x)\), then on

\[ y=f(2x) \]

the corresponding point is

\[ \boxed{(2,7)}. \]

Horizontal Stretch

If

\[ 0<|b|<1, \]

then

\[ \frac{1}{|b|}>1, \]

so horizontal distances increase. This is a horizontal stretch.

Example: Horizontal Stretch

For

\[ g(x)=f\!\left(\frac{x}{3}\right), \]

the point \((2,5)\) on the parent graph becomes

\[ \boxed{(6,5)}. \]

A Negative Horizontal Scale Also Reflects

If \(b<0\), then the horizontal coordinate mapping includes a sign change:

\[ x\longmapsto\frac{x}{b}. \]

For the special form \(f(bx)\), this combines horizontal scaling with a reflection across the \(y\)-axis.

Example: Horizontal Scale and Reflection

If \((6,4)\) is on \(y=f(x)\), then on

\[ g(x)=f(-3x) \]

the corresponding point is

\[ \left(\frac{6}{-3},4\right)=\boxed{(-2,4)}. \]

Horizontal and Vertical Scaling Are Different

Compare

\[ 2f(x) \]

and

\[ f(2x). \]

The first doubles outputs. The second halves horizontal coordinates. These transformations are generally not equivalent.

Special Coincidences Can Occur

For certain parent functions, two different-looking transformations may simplify to the same formula. For example, if \(f(x)=x^2\), then

\[ f(2x)=(2x)^2=4x^2=4f(x). \]

This coincidence comes from the algebraic structure of the square function; it is not a general transformation rule.

The Full Transformation Form

Return to

\[ \boxed{g(x)=a\,f\!\bigl(b(x-h)\bigr)+k}. \]

Its effects are summarized by

  • horizontal scale factor \(1/|b|\);
  • horizontal reflection when \(b<0\);
  • horizontal translation by \(h\);
  • vertical scale factor \(|a|\);
  • vertical reflection when \(a<0\);
  • vertical translation by \(k\).

The Safest Point Rule

Rather than memorizing an order of verbal steps, transform a parent point directly:

\[ \boxed{ (u,v) \longmapsto \left(h+\frac{u}{b},\;k+av\right) }. \]

This rule automatically handles signs, reciprocal horizontal scaling, and translations.

Example: Full Coordinate Transformation

Suppose \((6,-2)\) lies on \(y=f(x)\), and define

\[ g(x)=-3f\!\bigl(2(x-4)\bigr)+5. \]

Here

\[ a=-3, \qquad b=2, \qquad h=4, \qquad k=5. \]

Therefore,

\[ x=4+\frac{6}{2}=7, \] \[ y=5+(-3)(-2)=11. \]

The transformed point is

\[ \boxed{(7,11)}. \]

Reading \(h\) Requires Factored Inside Form

The horizontal translation is easiest to read when the inside expression is written as

\[ b(x-h). \]

Do not read \(h\) directly from an unfactored expression such as

\[ 2x-6. \]

Example: Factor Before Reading the Shift

Consider

\[ g(x)=f(2x-6). \]

Factor the inside expression:

\[ 2x-6=2(x-3). \]

Thus

\[ g(x)=f\!\bigl(2(x-3)\bigr). \]

The graph is horizontally compressed by \(1/2\) and translated right \(3\), not right \(6\).

Why \(f(2x-6)\) Is Not \(f(2(x-6))\)

These inputs are different:

\[ 2x-6=2(x-3), \]

while

\[ 2(x-6)=2x-12. \]

Parentheses determine the actual horizontal shift.

Example: Transforming the Quadratic Parent

Let

\[ f(x)=x^2. \]

Consider

\[ g(x)=-2(x-3)^2+4. \]

Relative to the parent graph, this applies a vertical stretch by \(2\), a reflection across the \(x\)-axis, a translation right \(3\), and a translation up \(4\).

The Vertex Moves Predictably

The parent vertex \((0,0)\) transforms under

\[ -2f(x-3)+4 \]

to

\[ \boxed{(3,4)}. \]

The negative coefficient changes the opening direction, but the vertex remains the translated image of the parent vertex.

Example: Transforming Absolute Value

Start with

\[ f(x)=|x|. \]

Then

\[ g(x)=\frac12|x+4|-3 \]

is vertically compressed by \(1/2\), translated left \(4\), and translated down \(3\). Its vertex is

\[ \boxed{(-4,-3)}. \]

Example: Transforming Square Root

Begin with

\[ f(x)=\sqrt{x}. \]

The function

\[ g(x)=-\sqrt{x-5}+2 \]

moves the graph right \(5\), reflects it across the \(x\)-axis, and moves it up \(2\). The parent endpoint \((0,0)\) becomes

\[ \boxed{(5,2)}. \]

Example: Horizontal Scaling of Square Root

Consider

\[ g(x)=\sqrt{4x}. \]

In transformation language, this is \(f(4x)\), a horizontal compression by \(1/4\).

Algebraically,

\[ \sqrt{4x}=2\sqrt{x} \]

for real \(x\ge0\), so this particular parent function also makes the same graph look like a vertical stretch by \(2\).

Equivalent Formulas Can Describe the Same Graph

A single transformed graph may sometimes have several equivalent algebraic descriptions. Transformation language describes how one formula is built from a chosen parent function, but algebraic simplification may reveal an equivalent route.

Example: Cubic Transformation

Let

\[ f(x)=x^3. \]

Then

\[ g(x)=-(x+2)^3+1 \]

reflects the cubic across the \(x\)-axis, translates it left \(2\), and translates it up \(1\). The parent center point \((0,0)\) moves to

\[ \boxed{(-2,1)}. \]

Example: Reciprocal Transformation

From the parent

\[ f(x)=\frac1x, \]

consider

\[ g(x)=\frac{2}{x-3}-4. \]

This is

\[ g(x)=2f(x-3)-4. \]

The graph is vertically stretched by \(2\), shifted right \(3\), and shifted down \(4\).

Distinguished Features Transform Too

Vertices, endpoints, centers, turning points, and other recognizable points move according to the same coordinate rule as every other point.

Identifying a few structural points often makes graphing much faster than constructing a large value table.

Transforming a Table of Points

Suppose a parent graph contains

\[ (-2,4),\qquad(0,0),\qquad(2,4). \]

For

\[ g(x)=3f(x-1)-2, \]

the point rule is

\[ (u,v)\longmapsto(u+1,3v-2). \]

Example: Transforming the Table

The three parent points become

\[ (-2,4)\longmapsto(-1,10), \] \[ (0,0)\longmapsto(1,-2), \] \[ (2,4)\longmapsto(3,10). \]

The transformed points preserve the parent graph's structural relationship while changing location and vertical scale.

Transformations and the Domain

Vertical transformations do not change which input values are allowed. Horizontal transformations generally do.

If the parent domain is a set \(D\), then under

\[ g(x)=a f\!\bigl(b(x-h)\bigr)+k, \]

the new domain is obtained by transforming parent input coordinates:

\[ \boxed{x=h+\frac{u}{b}\quad\text{for }u\in D}. \]

Example: Domain Transformation

The parent square-root function has domain

\[ [0,\infty). \]

For

\[ g(x)=\sqrt{x-5}, \]

the graph shifts right \(5\), so the domain becomes

\[ \boxed{[5,\infty)}. \]

Horizontal Reflection Can Reverse a One-Sided Domain

For

\[ g(x)=\sqrt{-x}, \]

the parent domain \([0,\infty)\) reflects across the \(y\)-axis. The new domain is

\[ \boxed{(-\infty,0]}. \]

Transformations and the Range

Horizontal transformations do not change the set of parent output values by themselves. Vertical transformations generally do.

If the parent range is \(R\), then transformed output values have the form

\[ \boxed{y=k+av\quad\text{for }v\in R}. \]

Example: Range Transformation

The parent quadratic \(f(x)=x^2\) has range

\[ [0,\infty). \]

For

\[ g(x)=-2(x-1)^2+6, \]

the vertical reflection and translation produce the range

\[ \boxed{(-\infty,6]}. \]

Transformations Preserve Open and Closed Features

A transformation moves existing graph points but does not turn an excluded point into an included point merely because it moved. An open endpoint or hole remains excluded after transformation; a closed endpoint remains included.

Transforming a Hole

Suppose a parent relation has a hole at

\[ (2,5). \]

Under

\[ g(x)=-2f(x-3)+1, \]

the hole moves to

\[ (2+3,-2(5)+1)=\boxed{(5,-9)}. \]

It remains a hole.

Translations Do Not Change Shape or Size

A pure translation changes every point by the same displacement. Distances and angles within the graph are preserved.

The graph is relocated, not resized.

Reflections Preserve Size

A reflection reverses orientation but preserves distances. The reflected graph is congruent to the original graph.

Stretches and Compressions Change Scale

Scaling transformations change selected coordinate distances. Vertical scaling changes distances from the \(x\)-axis; horizontal scaling changes distances measured along the \(x\)-direction.

Scaling Relative to a Translated Center

In the full coordinate map

\[ \left(h+\frac{u}{b},\;k+av\right), \]

horizontal coordinates are scaled before being positioned around \(x=h\), while vertical outputs are scaled before being positioned around \(y=k\). This is why a negative \(b\) in the full transformed form reverses horizontal orientation relative to the translated vertical reference line.

Order Matters When Transformations Are Composed

Performing two transformations in different orders can produce different graphs.

For example, starting with an output \(y\), stretching vertically by \(2\) and then shifting up \(3\) gives

\[ 2y+3. \]

Shifting first and then stretching gives

\[ 2(y+3)=2y+6. \]

The Formula Records the Actual Composition

Rather than applying verbal operations in an assumed order, read the algebraic grouping carefully or use the coordinate mapping. Parentheses determine which operations occur together.

Example: Two Different Vertical Compositions

Compare

\[ g(x)=2f(x)+3 \]

with

\[ q(x)=2(f(x)+3)=2f(x)+6. \]

These functions differ by a vertical translation of \(3\) units. The parentheses matter.

Inside Composition Needs Equal Care

Compare

\[ f(2(x-3)) \]

with

\[ f(2x-3). \]

The first contains the horizontal shift \(h=3\). The second rewrites as

\[ f\!\left(2\left(x-\frac32\right)\right), \]

so its shift is \(3/2\).

Transformations Can Be Reversed

If \(a\ne0\) and \(b\ne0\), the coordinate transformation

\[ (u,v)\longmapsto \left(h+\frac{u}{b},k+av\right) \]

is reversible. From a transformed point \((x,y)\), recover the parent coordinates by

\[ \boxed{u=b(x-h),\qquad v=\frac{y-k}{a}}. \]

Why \(a\) and \(b\) Are Usually Nonzero

In the standard transformation model, \(a\ne0\) and \(b\ne0\) are assumed when we want a reversible reshaping of the parent graph.

If \(a=0\), then

\[ g(x)=k, \]

and the parent output structure collapses to a horizontal line.

What Happens If \(b=0\)?

If

\[ g(x)=a f(0)+k, \]

and \(f(0)\) exists, the output is constant for every allowed \(x\). This is not an ordinary horizontal stretch; the parent input variation has collapsed to one value.

Transforming Relations, Not Only Functions

Coordinate transformations can also be applied to graphs that are relations but not functions. Each point moves according to the specified coordinate rule.

For example, reflecting a circle across the \(y\)-axis still produces a circle, even though the full circle is not a function of \(x\).

Translation of an Implicit Relation

The circle

\[ x^2+y^2=9 \]

translated right \(4\) and up \(2\) becomes

\[ \boxed{(x-4)^2+(y-2)^2=9}. \]

The center moves from \((0,0)\) to \((4,2)\).

Transformations and Symmetry

A transformation may move a graph's symmetry away from the coordinate axes. For example, \(y=x^2\) is symmetric about the \(y\)-axis, but

\[ y=(x-5)^2 \]

is symmetric about

\[ \boxed{x=5}. \]

Family Symmetry Can Move with the Graph

A transformed graph can preserve the structural symmetry of its parent family without remaining even or odd relative to the origin. Coordinate-axis symmetry and family structure are related but not identical ideas.

Graph Shape Versus Graph Position

Translations primarily change position. Reflections change orientation. Stretches and compressions change scale. These distinctions help describe what changed without confusing the graph's family with its location.

Recognizing Transformations from a Graph

When comparing a transformed graph with a known parent, look for structural landmarks such as:

  • vertices;
  • endpoints;
  • centers;
  • turning points;
  • symmetry lines;
  • distances between recognizable points.

Use More Than One Point to Detect Scale

A translation can often be inferred from one distinguished point. A scale factor usually requires comparison of additional points or distances.

Several transformed graphs can share the same vertex but have different vertical or horizontal scales.

Example: Same Vertex, Different Scale

All three functions

\[ (x-2)^2+1, \qquad 3(x-2)^2+1, \qquad \frac14(x-2)^2+1 \]

have vertex \((2,1)\), but their vertical scales differ.

Do Not Use Visual Width Alone

A graph may look narrow or wide because of axis scale, window dimensions, or aspect ratio. Identify a stretch or compression by coordinates and algebraic structure, not merely by appearance on a screen.

Graphing Windows Can Distort Perception

If one grid unit horizontally occupies a different physical length from one grid unit vertically, angles and apparent steepness can be distorted. The transformation should be interpreted using coordinate values rather than the physical shape of the display alone.

Transformation Language Is Relative

A graph is transformed relative to a chosen reference graph. The same final function may be described in different ways if a different reference function is chosen.

Example: Choosing the Reference Matters

The function

\[ g(x)=4x^2 \]

is a vertical stretch by \(4\) of \(f(x)=x^2\). It can also be viewed as a horizontal compression by \(1/2\) because

\[ (2x)^2=4x^2. \]

Both descriptions are valid relative to the same quadratic parent, but they arise from different equivalent algebraic forms.

Equivalent Descriptions Are Not Always Available

For a general function \(f\), there is no reason to expect

\[ f(2x)=4f(x). \]

Transformation equivalences that work for one family should not be assumed for another.

Transformations and Zeros

Suppose \(u\) is a zero of the parent function, so \(f(u)=0\). Under a purely horizontal transformation

\[ g(x)=f\!\bigl(b(x-h)\bigr), \]

that zero moves to

\[ \boxed{x=h+\frac{u}{b}}. \]

Vertical Translation Can Change Zeros

If \(k\ne0\), a parent zero does not generally remain an \(x\)-intercept, because the transformed output is

\[ av+k, \]

which equals \(k\) when \(v=0\).

Transformations and the \(y\)-Intercept

The transformed \(y\)-intercept must be evaluated at \(x=0\):

\[ g(0)=a f(-bh)+k. \]

It does not generally come from simply translating the parent \(y\)-intercept, because horizontal transformations may move that parent point away from the \(y\)-axis.

Example: A Parent \(y\)-Intercept Moves Off the Axis

The parent parabola \(y=x^2\) has \(y\)-intercept \((0,0)\). Under

\[ y=(x-3)^2, \]

that particular parent point moves to \((3,0)\), which is no longer on the \(y\)-axis. The new \(y\)-intercept is instead

\[ (0,9). \]

Transformations and Extreme Points

A local or absolute extreme point of a parent graph moves with the coordinate transformation, provided the transformation is reversible. A negative vertical scale reverses high and low behavior, so maxima and minima exchange roles.

Example: Minimum Becomes Maximum

The parent parabola \(y=x^2\) has an absolute minimum at \((0,0)\). The graph

\[ y=-x^2+5 \]

reflects vertically and shifts upward. The transformed point \((0,5)\) is an absolute maximum.

Transformations of Increasing and Decreasing Behavior

A negative vertical scale reverses increasing and decreasing behavior. A negative horizontal scale also reverses left-to-right orientation. Positive scale factors preserve orientation in their respective directions.

Transforming Piecewise Graphs

The same transformation rule applies to every point of a piecewise graph. Endpoints, open circles, closed circles, and each piece move together.

However, domain conditions written algebraically must also be transformed consistently.

Example: Moving an Endpoint

Suppose a parent piece begins at the included endpoint \((1,2)\). Under

\[ g(x)=2f(x+3)-5, \]

the coordinate rule gives

\[ (1,2)\longmapsto(-2,-1). \]

The endpoint remains included.

Transformations of Discrete Graphs

Discrete points transform exactly as continuous graphs do. If the original relation consists only of selected points, the transformed relation also consists only of their images. Do not connect them unless the context says to do so.

Example: Transforming a Discrete Point

Under

\[ g(x)=-f\!\left(\frac{x-2}{4}\right)+3, \]

we can write

\[ b=\frac14, \qquad h=2, \qquad a=-1, \qquad k=3. \]

Thus a parent point \((3,5)\) maps to

\[ \left(2+\frac{3}{1/4},3-5\right)=\boxed{(14,-2)}. \]

A Reliable Procedure: Reading a Transformation

  1. Identify the parent function \(f\).
  2. Rewrite the formula in the form \(a f(b(x-h))+k\) when possible.
  3. Factor the inside expression before reading \(b\) and \(h\).
  4. Record \(a\), \(b\), \(h\), and \(k\).
  5. Use horizontal scale factor \(1/|b|\).
  6. Use vertical scale factor \(|a|\).
  7. Check signs for horizontal or vertical reflections.
  8. Apply translations by \(h\) and \(k\).
  9. Verify important points using the coordinate rule.

A Reliable Procedure: Transforming Known Points

  1. Choose useful parent points \((u,v)\).
  2. Compute \(x=h+u/b\).
  3. Compute \(y=k+av\).
  4. Plot the transformed points.
  5. Preserve open or closed endpoint status.
  6. Connect points only when the parent relation is continuous there.
  7. Use family structure to complete the graph.

A Reliable Procedure: Recovering the Parent Point

If a point \((x,y)\) is known on the transformed graph and \(a,b\ne0\), use

\[ \boxed{u=b(x-h)}, \] \[ \boxed{v=\frac{y-k}{a}}. \]

Then \((u,v)\) is the corresponding point on the parent graph.

Common Error: Reversing the Vertical Shift

In

\[ f(x)+5, \]

the \(+5\) moves the graph upward, not downward. Outside additions act directly on outputs.

Common Error: Reading the Horizontal Shift Directly

In

\[ f(x-5), \]

the graph moves right \(5\), not left \(5\). Solve \(x-5=u\) to see why.

Common Error: Forgetting the Reciprocal Horizontal Scale

The graph of

\[ f(4x) \]

is horizontally compressed by a factor of \(1/4\), not stretched by a factor of \(4\).

Common Error: Treating \(2f(x)\) and \(f(2x)\) as the Same

The first scales outputs; the second rescales inputs. They are different transformations unless the particular function happens to make the formulas equivalent.

Common Error: Ignoring a Negative Inside Coefficient

In

\[ f(-2x), \]

the magnitude \(2\) causes horizontal compression, while the negative sign causes horizontal reflection.

Common Error: Ignoring a Negative Outside Coefficient

In

\[ -3f(x), \]

the magnitude \(3\) produces a vertical stretch, while the negative sign reflects the graph across the \(x\)-axis.

Common Error: Reading \(h\) Before Factoring

From

\[ f(3x+12), \]

first write

\[ f\!\bigl(3(x+4)\bigr) = f\!\bigl(3(x-(-4))\bigr). \]

The horizontal shift is left \(4\), not left \(12\).

Common Error: Moving Only a Special Point

A transformation acts on the entire graph. Moving the vertex correctly but leaving other points unchanged does not produce the transformed function.

Common Error: Connecting Discrete Images

Transforming a discrete relation relocates its points; it does not make the relation continuous. Preserve the original connectivity structure.

Common Error: Losing Endpoint Status

An open circle represents an excluded point. A geometric transformation moves that excluded location but does not fill it in. Likewise, an included endpoint remains included.

Common Error: Trusting Appearance Over Coordinates

A graphing window can make a vertical stretch appear like a horizontal compression or vice versa. Use numerical scale, known points, and the formula to identify transformations precisely.

Common Error: Assuming Every Formula Is Already in Transformation Form

Expressions often need algebraic rewriting before their transformations are clear. Factor inside coefficients and identify the parent function before assigning transformation parameters.

Checking a Transformation Algebraically

After describing a transformation, substitute the parent formula into the transformation expression and simplify. The result should match the proposed transformed formula.

Example: Algebraic Check

Let \(f(x)=x^2\). A vertical stretch by \(3\), shift right \(2\), and shift down \(1\) gives

\[ g(x)=3f(x-2)-1. \]

Substituting the parent rule gives

\[ \boxed{g(x)=3(x-2)^2-1}. \]

Checking a Transformation with a Point

If \((1,1)\) lies on \(y=x^2\), then under

\[ g(x)=3(x-2)^2-1 \]

the coordinate rule predicts

\[ (1,1)\longmapsto(3,2). \]

Check directly:

\[ g(3)=3(1)^2-1=2. \]

Checking Several Points Is Stronger

One matching point can occur by accident. Checking several structural points provides stronger evidence that the intended transformation has been read correctly.

Transformation Notation as a Toolbox

The general form

\[ a f\!\bigl(b(x-h)\bigr)+k \]

is not a new function family. It is a reusable language for describing how a known graph changes.

One Transformation at a Time

When a complicated formula feels difficult, isolate the parameters and study one effect at a time. For example, from \(f(x)\) compare successively with

\[ f(2x), \qquad f(2(x-3)), \qquad -f(2(x-3)), \qquad -f(2(x-3))+4. \]

Each step adds one visible change.

Then Recombine with the Coordinate Rule

Once individual effects are understood, the point mapping

\[ \left(h+\frac{u}{b},k+av\right) \]

provides a compact way to apply them together without losing track of signs or scale factors.

Practice 1

The graph is translated down \(7\) units:

\[ (x,y)\longmapsto(x,y-7). \]

Since

\[ f(x+5)=f(x-(-5)), \]

the graph is translated left \(5\) units.

The factor \(-4\) causes a vertical stretch by \(4\) and a reflection across the \(x\)-axis.

\[ 4x+12=4(x+3)=4(x-(-3)). \]

Factor the inside expression:

\[ \boxed{g(x)=f\!\bigl(2(x-4)\bigr)}. \]

What to Remember

For

\[ \boxed{g(x)=a\,f\!\bigl(b(x-h)\bigr)+k}, \]
  • \(h\) translates horizontally;
  • \(k\) translates vertically;
  • \(|a|\) is the vertical scale factor;
  • \(a<0\) reflects vertically;
  • \(1/|b|\) is the horizontal scale factor;
  • \(b<0\) reverses horizontal orientation;
  • inside coefficients act reciprocally on horizontal coordinates;
  • factor the inside expression before reading the horizontal shift;
  • open, closed, continuous, and discrete features transform with the graph.

The most reliable point rule is

\[ \boxed{ (u,v) \longmapsto \left(h+\frac{u}{b},\;k+av\right) }. \]
