Intercepts

Intercepts identify where a graph meets the coordinate axes. In linear and affine relationships, they give immediate geometric and practical information: the \(y\)-intercept often represents an initial value, while the \(x\)-intercept often marks where an output reaches zero.

The Central Idea

Consider the affine function

\[ f(x)=2x-6. \]

Two points on its graph are especially useful.

First, set the input equal to zero:

\[ f(0)=2(0)-6=-6. \]

So the graph meets the \(y\)-axis at

\[ \boxed{(0,-6)}. \]

Next, ask when the output equals zero:

\[ 2x-6=0. \]

Solving gives

\[ x=3. \]

So the graph meets the \(x\)-axis at

\[ \boxed{(3,0)}. \]

These two axis-crossing points are the intercepts.

What Is an Intercept?

An intercept is a point where a graph intersects one of the coordinate axes.

In the Cartesian plane:

  • an \(x\)-intercept lies on the \(x\)-axis;
  • a \(y\)-intercept lies on the \(y\)-axis.

Because every point on the \(x\)-axis has \(y=0\), an \(x\)-intercept has the form

\[ \boxed{(a,0)}. \]

Because every point on the \(y\)-axis has \(x=0\), a \(y\)-intercept has the form

\[ \boxed{(0,b)}. \]

The \(y\)-Intercept

For a function

\[ y=f(x), \]

the \(y\)-intercept is found by setting

\[ \boxed{x=0}. \]

If \(0\) is in the domain, the resulting point is

\[ \boxed{(0,f(0))}. \]

So the \(y\)-intercept is directly connected to the function value at zero.

The \(x\)-Intercept

An \(x\)-intercept occurs where the graph has output

\[ \boxed{y=0}. \]

For a function \(y=f(x)\), we therefore solve

\[ \boxed{f(x)=0}. \]

If \(x=a\) is a solution, then the corresponding \(x\)-intercept is

\[ \boxed{(a,0)}. \]

Zeros and \(x\)-Intercepts

A zero of a function is an input value \(a\) such that

\[ f(a)=0. \]

The zero itself is the number

\[ a. \]

The corresponding \(x\)-intercept is the point

\[ (a,0). \]

These ideas are closely related, but they are not literally the same object.

Do Not Confuse a Zero with an Intercept Point

Suppose

\[ f(5)=0. \]

Then

\[ \boxed{5} \]

is a zero of the function, while

\[ \boxed{(5,0)} \]

is the corresponding \(x\)-intercept.

The zero is an input value. The intercept is a coordinate point.

Intercepts of an Affine Function

Consider

\[ f(x)=mx+b. \]

The \(y\)-intercept is immediate:

\[ f(0)=m(0)+b=b. \]

Therefore,

\[ \boxed{\text{\(y\)-intercept}=(0,b)}. \]

If \(m\ne0\), the \(x\)-intercept comes from

\[ mx+b=0. \]

Solving gives

\[ x=-\frac{b}{m}. \]

Therefore,

\[ \boxed{ \text{\(x\)-intercept} = \left(-\frac{b}{m},0\right) }. \]

The Intercept \(b\) in \(y=mx+b\)

In the familiar affine form

\[ y=mx+b, \]

the parameter \(b\) is the \(y\)-coordinate of the \(y\)-intercept.

The graph contains

\[ \boxed{(0,b)}. \]

This is why the form \(y=mx+b\) is commonly called slope-intercept form.

A later lesson will study that form in greater detail.

Example: Find Both Intercepts

Find the intercepts of

\[ y=3x-12. \]

For the \(y\)-intercept, set \(x=0\):

\[ y=3(0)-12=-12. \]

So

\[ \boxed{(0,-12)} \]

is the \(y\)-intercept.

For the \(x\)-intercept, set \(y=0\):

\[ 0=3x-12. \]

Then

\[ 3x=12, \]

so

\[ x=4. \]

Therefore, the \(x\)-intercept is

\[ \boxed{(4,0)}. \]

Why Setting \(x=0\) Finds the \(y\)-Intercept

Every point on the \(y\)-axis has horizontal coordinate

\[ x=0. \]

So any graph point lying on the \(y\)-axis must satisfy that condition.

Setting \(x=0\) is therefore not a memorized trick. It is simply the coordinate definition of the \(y\)-axis.

Why Setting \(y=0\) Finds the \(x\)-Intercept

Every point on the \(x\)-axis has vertical coordinate

\[ y=0. \]

So any graph point lying on the \(x\)-axis must satisfy that condition.

Again, the procedure comes directly from coordinate geometry.

Intercepts and the Origin

The origin is

\[ \boxed{(0,0)}. \]

It lies on both coordinate axes.

Therefore, if a graph passes through the origin, the same point is both an \(x\)-intercept and a \(y\)-intercept.

Linear Functions Pass Through the Origin

In the structural sense used in Malone Math, a linear function has the form

\[ f(x)=mx. \]

Then

\[ f(0)=0. \]

So every such linear function contains

\[ \boxed{(0,0)}. \]

For \(m\ne0\), the origin is its unique \(x\)-intercept and its unique \(y\)-intercept.

The Zero Function Is a Special Case

The zero function is

\[ f(x)=0. \]

Its graph is the entire \(x\)-axis.

Therefore, every point on its graph is an \(x\)-intercept in the geometric sense, and every input in its domain is a zero.

Its \(y\)-intercept is

\[ \boxed{(0,0)}. \]

Nonzero Constant Functions

Consider

\[ f(x)=5. \]

The graph is the horizontal line

\[ y=5. \]

It meets the \(y\)-axis at

\[ \boxed{(0,5)}. \]

But it never reaches

\[ y=0. \]

So it has no \(x\)-intercept and no zeros.

Vertical Lines

A vertical line has an equation such as

\[ x=4. \]

It intersects the \(x\)-axis at

\[ \boxed{(4,0)}. \]

Unless the line is the \(y\)-axis itself, it has no \(y\)-intercept.

A vertical line is not a function \(y=f(x)\), but it still has geometric intercepts.

The \(y\)-Axis Is a Special Vertical Line

The \(y\)-axis has equation

\[ x=0. \]

Every point on it lies on the \(y\)-axis, so the usual idea of one isolated \(y\)-intercept no longer applies.

It also crosses the \(x\)-axis at

\[ \boxed{(0,0)}. \]

This is a useful reminder that intercept language is simplest when the graph is not itself one of the coordinate axes.

Can a Nonvertical Line Have No \(x\)-Intercept?

Yes.

A nonzero constant function such as

\[ y=7 \]

is a horizontal line parallel to the \(x\)-axis.

Because it never reaches \(y=0\), it has no \(x\)-intercept.

Can an Affine Function Have No \(y\)-Intercept?

If an affine function

\[ f(x)=mx+b \]

has domain \(\mathbb{R}\), then \(x=0\) is allowed and it always has the \(y\)-intercept

\[ (0,b). \]

However, a restricted-domain function may exclude \(x=0\).

In that case, the graph may have no \(y\)-intercept even if its formula resembles \(mx+b\).

Domain Restrictions Matter

Suppose

\[ f(x)=2x+3, \qquad x>1. \]

If we substitute \(x=0\), the formula gives \(3\), but \(0\) is not in the domain.

Therefore,

\[ (0,3) \]

is not actually part of the graph.

The restricted function has no \(y\)-intercept.

Intercepts from a Table

Suppose a table contains:

\(x\) \(y\)
\(-2\)\(-9\)
0\(-5\)
2\(-1\)
31

The row with

\[ x=0 \]

reveals the \(y\)-intercept:

\[ \boxed{(0,-5)}. \]

No listed row has \(y=0\), so the table does not directly display an \(x\)-intercept.

A Table May Not List the Intercept Exactly

Suppose the same table is known to come from an affine relationship.

Its slope is

\[ m= \frac{-1-(-5)}{2-0} = \frac42 = 2. \]

So the function is

\[ y=2x-5. \]

Set \(y=0\):

\[ 0=2x-5. \]

Then

\[ x=\frac52. \]

Thus the \(x\)-intercept is

\[ \boxed{\left(\frac52,0\right)}. \]

The intercept can exist between sampled table values.

Finding an Intercept from Two Points

Suppose an affine graph passes through

\[ (1,5) \]

and

\[ (4,14). \]

First find the slope:

\[ m= \frac{14-5}{4-1} = \frac93 = 3. \]

Use the point \((1,5)\):

\[ 5=3(1)+b. \]

So

\[ b=2. \]

The function is

\[ y=3x+2. \]

Therefore, the \(y\)-intercept is

\[ \boxed{(0,2)}. \]

For the \(x\)-intercept:

\[ 0=3x+2, \]

so

\[ x=-\frac23. \]

Thus,

\[ \boxed{\left(-\frac23,0\right)} \]

is the \(x\)-intercept.

Intercepts from Standard Form

A line may be written

\[ Ax+By=C. \]

To find the \(x\)-intercept, set

\[ y=0. \]

Then

\[ Ax=C. \]

If \(A\ne0\),

\[ x=\frac{C}{A}. \]

So the \(x\)-intercept is

\[ \boxed{\left(\frac{C}{A},0\right)}. \]

To find the \(y\)-intercept, set

\[ x=0. \]

Then

\[ By=C. \]

If \(B\ne0\),

\[ y=\frac{C}{B}. \]

So the \(y\)-intercept is

\[ \boxed{\left(0,\frac{C}{B}\right)}. \]

Example from Standard Form

Find the intercepts of

\[ 3x+4y=24. \]

For the \(x\)-intercept, set \(y=0\):

\[ 3x=24, \]

so

\[ x=8. \]

Therefore,

\[ \boxed{(8,0)}. \]

For the \(y\)-intercept, set \(x=0\):

\[ 4y=24, \]

so

\[ y=6. \]

Therefore,

\[ \boxed{(0,6)}. \]

Two Intercepts Can Determine a Line

Suppose a nonvertical, nonhorizontal line has intercepts

\[ (a,0) \]

and

\[ (0,b), \]

with

\[ a\ne0, \qquad b\ne0. \]

These are two distinct points.

Because two distinct points determine a unique line, the two intercepts are enough to determine the line completely.

Slope from the Intercepts

Using the points

\[ (a,0) \]

and

\[ (0,b), \]

the slope is

\[ m= \frac{b-0}{0-a} = -\frac{b}{a}. \]

Therefore,

\[ \boxed{m=-\frac{b}{a}}. \]

This connects intercept geometry directly with slope.

Intercept Form Preview

If a line has nonzero \(x\)-intercept \(a\) and nonzero \(y\)-intercept \(b\), it can be written as

\[ \boxed{ \frac{x}{a} + \frac{y}{b} = 1 }. \]

This is called intercept form.

Indeed, setting \(y=0\) gives \(x=a\), and setting \(x=0\) gives \(y=b\).

Intercept Form Example

Suppose a line has \(x\)-intercept

\[ (6,0) \]

and \(y\)-intercept

\[ (0,4). \]

Its intercept form is

\[ \frac{x}{6} + \frac{y}{4} = 1. \]

Multiplying by \(12\) gives

\[ 2x+3y=12. \]

Both equations describe the same line.

Intercept Form Has Limitations

The form

\[ \frac{x}{a}+\frac{y}{b}=1 \]

requires

\[ a\ne0 \]

and

\[ b\ne0. \]

It is therefore not suitable for a line whose intercept is the origin, nor for a horizontal or vertical line lacking one of the required finite nonzero intercepts.

Intercepts and Sign

For

\[ y=mx+b, \qquad m\ne0, \]

the \(x\)-intercept is

\[ x=-\frac{b}{m}. \]

The signs of \(m\) and \(b\) therefore determine whether the \(x\)-intercept lies to the left or right of the origin.

If \(m\) and \(b\) have opposite signs, then

\[ -\frac{b}{m}>0, \]

so the \(x\)-intercept is positive.

If they have the same sign, the \(x\)-intercept is negative.

Example: Predict the Side of the \(x\)-Intercept

Consider

\[ y=5x+10. \]

Both \(m\) and \(b\) are positive, so the \(x\)-intercept should be negative.

Check:

\[ 0=5x+10, \] \[ x=-2. \]

Thus,

\[ \boxed{(-2,0)}. \]

Intercepts and Translation

Compare

\[ f(x)=2x \]

and

\[ g(x)=2x+6. \]

The second graph is a vertical translation of the first.

The slope remains

\[ 2, \]

but the \(y\)-intercept moves from

\[ (0,0) \]

to

\[ (0,6). \]

The \(x\)-intercept also changes, from

\[ (0,0) \]

to

\[ (-3,0). \]

Translations can move intercepts even when slope remains unchanged.

Intercepts and Horizontal Translation

Consider

\[ f(x)=2x \]

and

\[ g(x)=2(x-4). \]

The second graph is shifted right by \(4\).

Its \(x\)-intercept is found from

\[ 2(x-4)=0. \]

Thus,

\[ x=4. \]

The graph crosses the \(x\)-axis at

\[ \boxed{(4,0)}. \]

Its \(y\)-intercept is

\[ g(0)=2(0-4)=-8, \]

so

\[ \boxed{(0,-8)}. \]

Intercepts Are Coordinate-Dependent

Intercepts depend on the chosen coordinate axes.

If the origin or axes are translated, the same geometric line may have different coordinate intercepts.

This is different from intrinsic geometric properties such as whether two lines are parallel.

Intercepts are therefore especially useful when the coordinate system itself has meaningful reference values.

Practical Meaning of a \(y\)-Intercept

In an applied model

\[ y=mx+b, \]

the \(y\)-intercept often represents the output when the input is zero.

Depending on context, \(b\) may represent:

  • a starting balance;
  • an initial population;
  • a fixed fee;
  • an initial distance;
  • a baseline measurement;
  • a starting temperature.

The interpretation should always be tied to the units and meaning of the variables.

Example: Fixed Fee

A service charges a \$25 enrollment fee plus \$8 per month.

If \(m\) is the number of months and \(C\) is cost,

\[ C(m)=8m+25. \]

The \(y\)-intercept is

\[ \boxed{(0,25)}. \]

In context, it means the cost is already \$25 when zero months of monthly usage have accumulated.

Practical Meaning of an \(x\)-Intercept

An \(x\)-intercept occurs when the output reaches zero.

Depending on context, it may represent:

  • the time when a balance is exhausted;
  • the break-even input level;
  • the time when a height reaches ground level;
  • the quantity at which a remaining amount becomes zero;
  • the input at which a temperature difference disappears.

Whether the intercept has practical meaning depends on whether it lies in the realistic domain of the model.

Example: Depleting Inventory

A warehouse begins with \(500\) units and ships \(40\) units per day.

The remaining inventory after \(d\) days is modeled by

\[ I(d)=500-40d. \]

The \(y\)-intercept is

\[ \boxed{(0,500)}, \]

representing the initial inventory.

For the \(x\)-intercept:

\[ 500-40d=0. \]

Then

\[ 40d=500, \] \[ d=12.5. \]

So the model reaches zero inventory at

\[ \boxed{(12.5,0)}. \]

An Algebraic Intercept May Be Outside the Practical Domain

Suppose a model is valid only for

\[ 0\le t\le10, \]

but solving \(f(t)=0\) gives

\[ t=18. \]

The formula has an algebraic zero at \(18\), but that value lies outside the stated model domain.

It should not be interpreted as an observed or predicted event within the valid model interval.

Example: Temperature Conversion

The Celsius-to-Fahrenheit relationship is

\[ F(C)=\frac95C+32. \]

The \(F\)-axis intercept occurs at

\[ C=0. \]

Thus,

\[ F(0)=32, \]

giving

\[ \boxed{(0,32)}. \]

The horizontal intercept occurs when

\[ F=0. \]

So

\[ 0=\frac95C+32. \]

Solving gives

\[ C=-\frac{160}{9}\approx -17.78. \]

Thus the intercept encodes the familiar equivalence

\[ 0^\circ\text{F}\approx -17.78^\circ\text{C}. \]

Changing Which Quantity Is on Which Axis Changes the Intercepts

When one variable is placed on the horizontal axis and another on the vertical axis, the intercepts answer questions relative to that choice.

If the axes are swapped, the same relationship is represented differently.

An \(x\)-intercept in one orientation may correspond to a \(y\)-intercept in the reversed orientation.

Always identify what each axis represents before interpreting an intercept.

Intercepts Need Not Be Integers

Consider

\[ y=4x-7. \]

The \(y\)-intercept is

\[ \boxed{(0,-7)}. \]

For the \(x\)-intercept:

\[ 0=4x-7. \]

So

\[ x=\frac74. \]

Therefore,

\[ \boxed{\left(\frac74,0\right)}. \]

Fractional and irrational intercepts are completely valid.

An Affine Function with Nonzero Slope Has Exactly One \(x\)-Intercept

Let

\[ f(x)=mx+b, \qquad m\ne0. \]

The equation

\[ mx+b=0 \]

has the unique solution

\[ x=-\frac{b}{m}. \]

Therefore, every real affine function with nonzero slope has exactly one real zero and exactly one \(x\)-intercept.

Why There Can Be Only One

A nonhorizontal, nonvertical straight line cannot cross the same coordinate axis at two distinct points without becoming that axis.

Algebraically, an affine function with \(m\ne0\) is one-to-one, so it cannot produce the output

\[ 0 \]

for two different inputs.

The geometric and function-theoretic viewpoints agree.

Nonlinear Functions May Have Several \(x\)-Intercepts

The relationship between zeros and \(x\)-intercepts extends beyond affine functions.

For example,

\[ f(x)=x^2-4 \]

satisfies

\[ x^2-4=0. \]

Factoring gives

\[ (x-2)(x+2)=0. \]

So the function has zeros

\[ x=-2 \]

and

\[ x=2, \]

with \(x\)-intercepts

\[ \boxed{(-2,0)} \]

and

\[ \boxed{(2,0)}. \]

Affine functions are simpler because a nonconstant affine function has only one.

A Function May Have No Real \(x\)-Intercept

Consider

\[ f(x)=x^2+1. \]

For every real \(x\),

\[ x^2+1>0. \]

So the graph never reaches the \(x\)-axis.

It has no real zeros and no real \(x\)-intercepts.

This broader perspective will become useful when studying polynomial and other function families.

A Function May Have More Than One \(y\)-Axis Intersection Only If It Is Not a Function of \(x\)

For a genuine function \(y=f(x)\), the input

\[ x=0 \]

can correspond to at most one output.

Therefore, a function can have at most one \(y\)-intercept.

A more general relation, however, may intersect the \(y\)-axis multiple times.

Intercepts as Boundary Information

Intercepts often identify natural boundaries in a model.

For example, if

\[ P(q)=20q-400, \]

represents profit as a function of quantity \(q\), then the \(x\)-intercept satisfies

\[ 20q-400=0. \]

Thus,

\[ q=20. \]

At that quantity, profit is zero.

In a simplified model, this is a break-even point.

Example: Break-Even Interpretation

Suppose

\[ P(q)=15q-600. \]

The \(y\)-intercept is

\[ P(0)=-600. \]

So

\[ \boxed{(0,-600)} \]

represents a \$600 loss before any units are sold.

The \(x\)-intercept is found from

\[ 15q-600=0. \]

Thus,

\[ q=40. \]

So

\[ \boxed{(40,0)} \]

represents the break-even quantity in this model.

Intercepts and Units

Coordinates should retain the units of their axes.

If \(x\) is measured in hours and \(y\) in gallons, an \(x\)-intercept such as

\[ (5,0) \]

means \(5\) hours and \(0\) gallons.

A \(y\)-intercept such as

\[ (0,120) \]

means \(0\) hours and \(120\) gallons.

The numerical point is incomplete as an applied interpretation unless the axis meanings are known.

Finding Intercepts Without Solving the Entire Problem

Intercepts can often be extracted quickly because each one sets one coordinate equal to zero.

For an equation such as

\[ 7x-2y=28, \]

we do not need to rewrite the whole equation into another form first.

Set \(y=0\):

\[ 7x=28, \]

giving

\[ x=4. \]

Set \(x=0\):

\[ -2y=28, \]

giving

\[ y=-14. \]

So the intercepts are

\[ \boxed{(4,0)} \]

and

\[ \boxed{(0,-14)}. \]

Intercepts as a Graphing Check

If an equation predicts the intercepts

\[ (4,0) \]

and

\[ (0,-14), \]

a correct graph should pass through both points.

Intercepts therefore provide convenient checkpoints when verifying a hand-drawn or computer-generated graph.

Using Intercepts to Check a Formula

Suppose a line is claimed to have equation

\[ y=-2x+8 \]

and \(x\)-intercept

\[ (5,0). \]

Check the claimed point:

\[ 0\stackrel{?}{=}-2(5)+8=-2. \]

The equation is not satisfied.

So \((5,0)\) is not an intercept of that line.

The actual \(x\)-intercept comes from

\[ 0=-2x+8, \]

giving

\[ \boxed{(4,0)}. \]

Recovering the Slope from Two Intercepts

Suppose the intercepts are

\[ (-3,0) \]

and

\[ (0,6). \]

Then

\[ m= \frac{6-0}{0-(-3)} = \frac63 = \boxed{2}. \]

Knowing both intercepts gives both position and rate information.

Recovering an Equation from Two Intercepts

Using the same intercepts,

\[ (-3,0) \]

and

\[ (0,6), \]

we already found

\[ m=2. \]

Because the \(y\)-intercept is \(6\),

\[ b=6. \]

So the affine equation is

\[ \boxed{y=2x+6}. \]

One Intercept Alone Does Not Usually Determine a Line

Knowing only that a line passes through

\[ (0,4) \]

does not determine a unique line.

Infinitely many lines share that \(y\)-intercept:

\[ y=x+4, \] \[ y=2x+4, \] \[ y=-5x+4, \]

and many others.

Another independent condition, such as slope or a second point, is needed.

An Intercept and a Slope Determine a Nonvertical Line

If a line has slope

\[ m=-3 \]

and \(y\)-intercept

\[ (0,7), \]

then its equation is immediately

\[ \boxed{y=-3x+7}. \]

This observation leads directly into slope-intercept form.

An \(x\)-Intercept and a Slope Also Determine a Line

Suppose the slope is

\[ m=4 \]

and the \(x\)-intercept is

\[ (3,0). \]

Using the change relationship from the previous lesson,

\[ y-0=4(x-3). \]

So

\[ y=4x-12. \]

The \(y\)-intercept is therefore

\[ \boxed{(0,-12)}. \]

Intercepts and Sign Changes

For a continuous affine function with nonzero slope, crossing the \(x\)-axis changes the sign of the output.

For example,

\[ f(x)=2x-6 \]

has zero

\[ x=3. \]

If \(x<3\), then

\[ f(x)<0. \]

If \(x>3\), then

\[ f(x)>0. \]

The \(x\)-intercept separates negative and positive output regions.

Decreasing Example

Consider

\[ f(x)=-4x+8. \]

The \(x\)-intercept is

\[ 0=-4x+8, \]

so

\[ x=2. \]

For \(x<2\),

\[ f(x)>0, \]

while for \(x>2\),

\[ f(x)<0. \]

The direction reverses because the slope is negative.

Intercepts Can Reveal Whether a Model Is Plausible

Suppose a model for the number of employees at a company is

\[ E(t)=50t-200. \]

Its \(y\)-intercept is

\[ (0,-200). \]

A negative employee count is not physically meaningful.

This does not automatically make the algebra wrong. It may indicate that \(t=0\) lies outside the model's intended domain or that the model is only a local approximation.

Intercepts can therefore expose assumptions that need interpretation.

Measured Data and Estimated Intercepts

In real data, points may not lie exactly on one line.

A fitted affine model may still have intercepts even when no observed data point lies on either axis.

Those intercepts are properties of the model, not necessarily directly observed measurements.

This distinction becomes important later in regression and trend analysis.

A Reliable \(y\)-Intercept Workflow

  1. Identify the horizontal input variable.
  2. Set that variable equal to \(0\).
  3. Solve for the vertical coordinate.
  4. Write the result as a point \((0,b)\).
  5. Check that \(0\) belongs to the domain.
  6. Interpret the value in context when units are present.

A Reliable \(x\)-Intercept Workflow

  1. Set the vertical output equal to \(0\).
  2. Solve for the horizontal variable.
  3. Write the result as a point \((a,0)\).
  4. Check that the solution belongs to the domain.
  5. If working with a function, distinguish the zero \(a\) from the intercept point \((a,0)\).
  6. Interpret the zero-output condition in context.

A Reliable Intercept Check

  1. Substitute the proposed \(x\)-intercept into the original equation and verify that \(y=0\).
  2. Substitute \(x=0\) for the proposed \(y\)-intercept and verify its \(y\)-value.
  3. Check signs and units.
  4. Check domain restrictions.
  5. Confirm that the point lies on the correct axis.

Common Errors

Setting the Wrong Variable Equal to Zero

For the \(x\)-intercept, set \(y=0\). For the \(y\)-intercept, set \(x=0\).

Giving Only a Number When a Point Is Requested

If \(x=4\) is a zero, the \(x\)-intercept is

\[ (4,0). \]

Confusing the \(y\)-Intercept with the Slope

In

\[ y=mx+b, \]

\(m\) is slope and \(b\) is the \(y\)-intercept value.

Assuming Every Line Has Two Ordinary Intercepts

Horizontal and vertical lines may lack one of the usual intercepts, and the coordinate axes themselves are special cases.

Ignoring the Domain

An algebraic value is not part of a graph if the corresponding input is excluded from the domain.

Assuming an \(x\)-Intercept Is Always Practically Meaningful

A calculated zero may lie outside the valid range of a real-world model.

Forgetting That \(x=0\) Means the \(y\)-Axis

The coordinate condition is the reason the \(y\)-intercept procedure works.

Forgetting That \(y=0\) Means the \(x\)-Axis

The intercept procedure should follow from coordinate meaning, not memorization alone.

For the \(y\)-intercept:

\[ y=5(0)-20=-20. \]

So

\[ \boxed{(0,-20)}. \]

For the \(x\)-intercept:

\[ 0=5x-20, \] \[ x=4. \]

So

\[ \boxed{(4,0)}. \]

2. Fractional Intercept

Find the \(x\)-intercept of

\[ y=6x+5. \]
Check Answer \[ 0=6x+5, \] \[ 6x=-5, \] \[ x=-\frac56. \]

Therefore,

\[ \boxed{\left(-\frac56,0\right)}. \]

3. Standard Form

Find both intercepts of

\[ 2x+5y=30. \]
Check Answer

Set \(y=0\):

\[ 2x=30, \] \[ x=15. \]

So the \(x\)-intercept is

\[ \boxed{(15,0)}. \]

Set \(x=0\):

\[ 5y=30, \] \[ y=6. \]

So the \(y\)-intercept is

\[ \boxed{(0,6)}. \]

4. Zero Versus Intercept

If

\[ f(-3)=0, \]

state the zero and the corresponding \(x\)-intercept.

Check Answer

The zero is

\[ \boxed{-3}. \]

The \(x\)-intercept is

\[ \boxed{(-3,0)}. \]

5. Constant Function

Find the intercepts of

\[ f(x)=-7. \]
Check Answer

The \(y\)-intercept is

\[ \boxed{(0,-7)}. \]

There is no \(x\)-intercept because the function never equals \(0\).

6. Linear Function

Find the intercepts of

\[ f(x)=-9x. \]
Check Answer

The graph passes through the origin:

\[ \boxed{(0,0)}. \]

For this nonzero-slope linear function, the origin is both the \(x\)-intercept and the \(y\)-intercept.

7. Vertical Line

Find the intercepts of

\[ x=-4. \]
Check Answer

The line crosses the \(x\)-axis at

\[ \boxed{(-4,0)}. \]

It has no \(y\)-intercept because it never reaches \(x=0\).

8. Interpret an Initial Value

A rental company models total cost by

\[ C(d)=45d+120, \]

where \(d\) is the number of rental days. Find and interpret the \(y\)-intercept.

Check Answer \[ C(0)=120. \]

So the \(y\)-intercept is

\[ \boxed{(0,120)}. \]

It represents a \$120 initial or fixed charge before daily charges accumulate.

9. Interpret a Zero

A tank contains

\[ V(t)=360-30t \]

liters after \(t\) minutes. Find and interpret the \(x\)-intercept.

Check Answer \[ 0=360-30t, \] \[ 30t=360, \] \[ t=12. \]

So the \(x\)-intercept is

\[ \boxed{(12,0)}. \]

According to the model, the tank reaches zero liters after \(12\) minutes.

10. Recover the Slope from Intercepts

A line has intercepts

\[ (8,0) \]

and

\[ (0,6). \]

Find its slope.

Check Answer \[ m= \frac{6-0}{0-8} = \frac6{-8} = \boxed{-\frac34}. \]

11. Recover the Equation

A line has \(x\)-intercept

\[ (-2,0) \]

and \(y\)-intercept

\[ (0,5). \]

Find its affine equation.

Check Answer

The slope is

\[ m= \frac{5-0}{0-(-2)} = \frac52. \]

Since \(b=5\),

\[ \boxed{ y=\frac52x+5 }. \]

12. Restricted Domain

Consider

\[ f(x)=3x-6, \qquad x>4. \]

Does this restricted function have an \(x\)-intercept?

Check Answer

The unrestricted formula has zero

\[ 3x-6=0, \] \[ x=2. \]

But

\[ 2\not>4. \]

So \((2,0)\) is excluded from the graph.

The restricted function has

\[ \boxed{\text{no \(x\)-intercept}}. \]

Key Ideas

  • An intercept is a point where a graph meets a coordinate axis.
  • An \(x\)-intercept has the form \((a,0)\).
  • A \(y\)-intercept has the form \((0,b)\).
  • To find an \(x\)-intercept, set \(y=0\) or solve \(f(x)=0\).
  • To find a \(y\)-intercept, set \(x=0\).
  • A zero is an input value \(a\); the corresponding \(x\)-intercept is the point \((a,0)\).
  • For \(f(x)=mx+b\), the \(y\)-intercept is \((0,b)\).
  • For \(f(x)=mx+b\) with \(m\ne0\), the \(x\)-intercept is \(\left(-\frac{b}{m},0\right)\).
  • A structural linear function \(f(x)=mx\) passes through the origin.
  • A nonzero constant function has a \(y\)-intercept but no \(x\)-intercept.
  • A vertical line may have an \(x\)-intercept even though it is not a function of \(x\).
  • Domain restrictions can remove an intercept suggested by an unrestricted formula.
  • Two distinct intercepts determine a unique line.
  • Intercepts often represent initial values, zero-output conditions, thresholds, or break-even points in applications.
  • Calculated intercepts must be interpreted within the units and valid domain of a model.

Where This Leads

Intercepts provide fixed reference points that connect algebraic equations with coordinate geometry. Together with slope, they give enough information to describe, construct, interpret, and verify many linear and affine relationships.

From here, slope and the \(y\)-intercept can be combined directly in slope-intercept form. The same ideas will then support point-slope form, standard form, graphing lines, constructing equations from conditions and data, solving linear equations and inequalities, and interpreting where models cross meaningful thresholds.
