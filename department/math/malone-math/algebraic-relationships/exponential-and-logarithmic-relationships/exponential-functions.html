Exponential Functions

An exponential function describes a quantity that changes by repeated multiplication. Instead of adding the same amount during each step, an exponential relationship repeatedly multiplies by the same factor. This simple change in perspective produces some of the fastest-growing and fastest-decaying relationships in mathematics.

The Central Idea

A basic exponential function has the form

\[ \boxed{f(x)=ab^x}, \]

where \(a\) and \(b\) are constants and the variable \(x\) appears in the exponent.

The defining feature is not simply the presence of an exponent. It is the fact that the variable is in the exponent.

For example,

\[ f(x)=3(2)^x \]

is exponential because \(x\) is an exponent.

By contrast,

\[ g(x)=3x^2 \]

is a power or polynomial function because the exponent is constant and the variable is the base.

Repeated Multiplication

Exponentiation provides a compact way to describe repeated multiplication.

For positive integer exponents,

\[ 2^4=2\cdot2\cdot2\cdot2=16. \]

An exponential function allows the number of repetitions to vary.

In

\[ f(x)=2^x, \]

changing \(x\) changes how many factors of \(2\) are represented.

This repeated multiplication is the structural idea behind exponential change.

The Basic Exponential Form

In

\[ \boxed{f(x)=ab^x}, \]

the pieces have different roles.

  • \(a\) is the initial value or initial scale factor.
  • \(b\) is the base or repeated multiplication factor.
  • \(x\) is the independent variable.
  • \(f(x)\) is the resulting dependent value.

Later lessons will interpret \(b\) more specifically as a growth factor or decay factor.

The Variable Is in the Exponent

Compare

\[ f(x)=2^x \]

with

\[ g(x)=x^2. \]

These expressions may look similar, but their structures are fundamentally different.

In \(2^x\), the base is fixed and the exponent changes.

In \(x^2\), the exponent is fixed and the base changes.

Therefore,

\[ \boxed{2^x\text{ is exponential, while }x^2\text{ is not.}} \]

Evaluating an Exponential Function

Suppose

\[ f(x)=3(2)^x. \]

To find \(f(4)\), substitute \(4\) for \(x\):

\[ f(4)=3(2)^4. \]

Since

\[ 2^4=16, \]

we obtain

\[ \boxed{f(4)=48}. \]

The Value at \(x=0\)

The value \(x=0\) plays an especially important role.

For

\[ f(x)=ab^x, \]

substitute \(x=0\):

\[ f(0)=ab^0. \]

Because

\[ b^0=1, \]

we obtain

\[ \boxed{f(0)=a}. \]

This is why \(a\) is called the initial value.

The \(y\)-Intercept

The \(y\)-intercept of a function occurs when \(x=0\).

Since

\[ f(0)=a, \]

the basic exponential function

\[ f(x)=ab^x \]

has \(y\)-intercept

\[ \boxed{(0,a)}. \]

For example,

\[ f(x)=5(3)^x \]

has \(y\)-intercept

\[ \boxed{(0,5)}. \]

Building a Table of Values

Consider

\[ f(x)=2^x. \]

Evaluate the function at several integer values:

\[ \begin{array}{c|c} x & 2^x\\ \hline -3 & \frac18\\ -2 & \frac14\\ -1 & \frac12\\ 0 & 1\\ 1 & 2\\ 2 & 4\\ 3 & 8 \end{array} \]

Moving one unit to the right multiplies the output by \(2\).

That constant multiplicative change is the signature of an exponential relationship.

Each Step Multiplies by the Base

If

\[ f(x)=ab^x, \]

compare two consecutive outputs:

\[ f(x)=ab^x \]

and

\[ f(x+1)=ab^{x+1}. \]

Since

\[ b^{x+1}=b^x\cdot b, \]

we have

\[ f(x+1)=b\,f(x). \]

Therefore,

\[ \boxed{\frac{f(x+1)}{f(x)}=b} \]

whenever the quotient is defined.

Additive Change versus Multiplicative Change

Linear and exponential relationships change in different ways.

A linear function such as

\[ f(x)=3x+2 \]

adds the same amount when \(x\) increases by \(1\).

An exponential function such as

\[ g(x)=2(3)^x \]

multiplies by the same factor when \(x\) increases by \(1\).

A useful first distinction is therefore:

\[ \boxed{ \text{linear}\longrightarrow\text{constant difference} } \] \[ \boxed{ \text{exponential}\longrightarrow\text{constant ratio} }. \]

Recognizing Exponential Change from a Table

Suppose a table contains

\[ \begin{array}{c|c} x & y\\ \hline 0 & 5\\ 1 & 10\\ 2 & 20\\ 3 & 40\\ 4 & 80 \end{array} \]

The differences are

\[ 5,\quad10,\quad20,\quad40, \]

so the differences are not constant.

But the ratios are

\[ \frac{10}{5} = \frac{20}{10} = \frac{40}{20} = \frac{80}{40} = 2. \]

The constant ratio indicates an exponential relationship.

Since the initial value is \(5\), the function is

\[ \boxed{y=5(2)^x}. \]

Restrictions on the Base

For the standard real-valued exponential function

\[ f(x)=ab^x, \]

the base is usually required to satisfy

\[ \boxed{b>0,\qquad b\ne1}. \]

These restrictions give the familiar exponential function defined for every real value of \(x\).

Why the Base Is Positive

A negative base behaves normally for many integer exponents but creates difficulties when arbitrary real exponents are allowed.

For example,

\[ (-2)^2=4 \]

and

\[ (-2)^3=-8 \]

are real numbers.

But an expression such as

\[ (-2)^{1/2} \]

is not a real number.

Requiring \(b>0\) allows \(b^x\) to behave consistently as a real-valued function for all real \(x\).

Why \(b=1\) Is Excluded

If the base were \(1\), then

\[ f(x)=a(1)^x. \]

But

\[ 1^x=1 \]

for every real \(x\).

Therefore,

\[ f(x)=a. \]

This is a constant function rather than a genuinely changing exponential relationship.

Exponential Growth

When

\[ b>1, \]

the basic function

\[ f(x)=b^x \]

increases as \(x\) increases.

For example,

\[ f(x)=2^x \]

produces

\[ 1,\quad2,\quad4,\quad8,\quad16,\quad32,\ldots \]

as \(x\) moves through \(0,1,2,3,4,5,\ldots\).

This behavior is called exponential growth.

Exponential Decay

When

\[ 0 the basic function decreases as \(x\) increases.

For example,

\[ f(x)=\left(\frac12\right)^x \]

produces

\[ 1,\quad\frac12,\quad\frac14,\quad\frac18,\quad\frac1{16},\ldots \]

as \(x\) moves through \(0,1,2,3,4,\ldots\).

This behavior is called exponential decay.

Growth and Decay Are Both Multiplicative

Growth and decay may appear to move in opposite directions, but the underlying structure is the same.

For

\[ f(x)=2^x, \]

every one-unit increase in \(x\) multiplies the output by \(2\).

For

\[ g(x)=\left(\frac12\right)^x, \]

every one-unit increase in \(x\) multiplies the output by \(\frac12\).

Both relationships are exponential because both repeatedly multiply by a constant factor.

Negative Inputs

Exponential functions are not restricted to positive exponents.

Recall that

\[ b^{-n}=\frac{1}{b^n}. \]

For example,

\[ 2^{-3} = \frac{1}{2^3} = \frac18. \]

Therefore,

\[ \boxed{2^{-3}=\frac18}. \]

Negative inputs extend the exponential graph naturally to the left.

Fractional Inputs

Fractional exponents connect exponentiation with radicals.

For example,

\[ 4^{1/2}=\sqrt4=2. \]

Thus the exponential function

\[ f(x)=4^x \]

can be evaluated at

\[ x=\frac12: \] \[ f\left(\frac12\right)=4^{1/2}=2. \]

This is one reason positive bases are especially important: they permit a continuous real-valued exponential function.

The Domain of an Exponential Function

For a standard exponential function

\[ f(x)=ab^x, \]

with \(b>0\), the exponent \(x\) may be any real number.

Therefore, its domain is

\[ \boxed{(-\infty,\infty)}. \]

In other words, a basic exponential function accepts every real input.

The Range When \(a>0\)

A positive base raised to a real power is always positive:

\[ b^x>0. \]

Therefore, if

\[ a>0, \]

then

\[ ab^x>0. \]

The range is consequently

\[ \boxed{(0,\infty)}. \]

The Range When \(a<0\)

If

\[ a<0, \]

then the positive quantity \(b^x\) is multiplied by a negative number.

Therefore,

\[ ab^x<0 \]

for every real \(x\).

The range becomes

\[ \boxed{(-\infty,0)}. \]

The Basic Horizontal Asymptote

Consider

\[ f(x)=2^x. \]

As \(x\) becomes increasingly negative,

\[ 2^x \]

becomes increasingly small:

\[ 2^{-1}=\frac12,\qquad 2^{-2}=\frac14,\qquad 2^{-3}=\frac18,\qquad 2^{-4}=\frac1{16}. \]

The values approach \(0\) without becoming \(0\).

Therefore, the basic exponential function has horizontal asymptote

\[ \boxed{y=0}. \]

Approaching Zero Is Not Reaching Zero

The graph of

\[ f(x)=2^x \]

can become arbitrarily close to the \(x\)-axis, but

\[ 2^x>0 \]

for every real \(x\).

Therefore, the graph never actually touches the horizontal asymptote

\[ y=0. \]

This distinction between approaching a value and attaining a value will become increasingly important in later analysis.

The Graph of \(y=2^x\)

A few important points are

\[ (-2,\tfrac14),\qquad (-1,\tfrac12),\qquad (0,1),\qquad (1,2),\qquad (2,4). \]

The graph passes through

\[ \boxed{(0,1)} \]

and rises increasingly rapidly as \(x\) moves to the right.

To the left, it approaches the \(x\)-axis.

The Graph of \(y=\left(\frac12\right)^x\)

Consider

\[ f(x)=\left(\frac12\right)^x. \]

Some points are

\[ (-2,4),\qquad (-1,2),\qquad (0,1),\qquad (1,\tfrac12),\qquad (2,\tfrac14). \]

The graph again passes through

\[ (0,1), \]

but now it decreases from left to right.

Reciprocal Bases Reverse the Direction

Notice that

\[ \left(\frac12\right)^x=2^{-x}. \]

Therefore, the graph of

\[ y=\left(\frac12\right)^x \]

can also be written as

\[ y=2^{-x}. \]

Replacing \(x\) by \(-x\) reflects the graph of \(y=2^x\) across the \(y\)-axis.

This connects exponential functions with the transformation language developed earlier in Malone Math.

The Effect of the Initial Value

Compare

\[ f(x)=2^x \]

and

\[ g(x)=5(2)^x. \]

The second function has every output multiplied by \(5\).

For example,

\[ f(0)=1,\qquad g(0)=5, \] \[ f(1)=2,\qquad g(1)=10, \] \[ f(2)=4,\qquad g(2)=20. \]

The base controls the repeated multiplicative change, while \(a\) sets the initial scale.

Vertical Scaling

Starting with

\[ y=b^x, \]

multiplying by \(a\) gives

\[ y=ab^x. \]

When \(a>1\), the graph is vertically stretched relative to \(b^x\).

When

\[ 0 the graph is vertically compressed.

Regardless of the scale, the multiplicative factor associated with a one-unit increase in \(x\) remains \(b\).

Reflection across the \(x\)-Axis

If \(a\) is negative, then

\[ f(x)=ab^x \]

is the corresponding positive exponential graph reflected across the \(x\)-axis.

For example,

\[ y=-2^x \]

means

\[ y=-(2^x). \]

Some values are

\[ -1,\quad-2,\quad-4,\quad-8,\ldots \]

for \(x=0,1,2,3,\ldots\).

Horizontal Shifts

A transformed exponential function may contain

\[ b^{x-h}. \]

For example,

\[ f(x)=2^{x-3}. \]

Replacing \(x\) by \(x-3\) shifts the graph of

\[ y=2^x \]

three units to the right.

Similarly,

\[ y=2^{x+3} \]

shifts the graph three units to the left.

Vertical Shifts

Adding a constant outside the exponential expression shifts the entire graph vertically.

For example,

\[ f(x)=2^x+4 \]

shifts the graph of \(2^x\) upward by \(4\) units.

The horizontal asymptote moves from

\[ y=0 \]

to

\[ \boxed{y=4}. \]

A More General Exponential Form

A useful transformed form is

\[ \boxed{f(x)=ab^{x-h}+k}. \]

In this form:

  • \(a\) controls vertical scale and possible reflection;
  • \(b\) controls exponential growth or decay;
  • \(h\) produces a horizontal shift;
  • \(k\) produces a vertical shift.

The horizontal asymptote is

\[ \boxed{y=k}. \]

Example: Reading a Transformed Function

Consider

\[ f(x)=3(2)^{x-1}+5. \]

From the structure we can identify:

  • vertical scale factor \(3\);
  • exponential base \(2\);
  • horizontal shift \(1\) unit right;
  • vertical shift \(5\) units upward;
  • horizontal asymptote \(y=5\).

The structure of the formula tells us a great deal before any points are plotted.

Exponential Functions Are Continuous

For \(b>0\), the exponential function

\[ f(x)=b^x \]

is defined not only at integers but throughout the real number line.

There are meaningful values between

\[ b^1 \]

and

\[ b^2. \]

The graph therefore forms a continuous curve rather than isolated points.

Exponential Functions Change at a Changing Rate

Consider

\[ f(x)=2^x. \]

Consecutive outputs are

\[ 1,\quad2,\quad4,\quad8,\quad16. \]

The corresponding differences are

\[ 1,\quad2,\quad4,\quad8. \]

The amount added is not constant.

Instead, the size of the increase itself grows.

This is why exponential growth eventually becomes extremely rapid.

A Constant Percentage Can Produce Exponential Change

Suppose a quantity increases by \(10\%\) during every time period.

After one period, the new value is

\[ 100\%+10\%=110\% \]

of the previous value.

As a multiplier,

\[ 110\%=1.10. \]

Therefore, every step multiplies the current quantity by

\[ 1.10. \]

Repeated percentage change is consequently modeled by exponential functions.

Repeated Percentage Change Acts on the Current Value

Suppose an initial quantity is \(100\) and grows by \(10\%\) per period.

After one period,

\[ 100(1.10)=110. \]

After two periods,

\[ 110(1.10)=121. \]

Equivalently,

\[ 100(1.10)^2=121. \]

The second increase is larger than the first because the same percentage is applied to a larger current value.

Example: A Simple Growth Model

Suppose a population begins at \(800\) and increases by a factor of \(1.05\) each year.

A simple exponential model is

\[ P(t)=800(1.05)^t. \]

After \(3\) years,

\[ P(3)=800(1.05)^3. \]

Since

\[ (1.05)^3=1.157625, \]

we obtain

\[ P(3)=926.1. \]

Thus the model predicts approximately

\[ \boxed{926} \]

individuals after three years.

Example: A Simple Decay Model

Suppose a quantity begins at \(500\) and retains \(80\%\) of its current value during each period.

The repeated factor is

\[ 0.80. \]

Therefore,

\[ Q(t)=500(0.80)^t. \]

After three periods,

\[ Q(3)=500(0.80)^3 \] \[ =500(0.512) \] \[ =256. \]

Thus,

\[ \boxed{Q(3)=256}. \]

Exponential Functions and Sequences

Exponential functions are closely connected to geometric sequences.

Consider

\[ f(x)=3(2)^x. \]

At integer inputs,

\[ x=0,1,2,3,\ldots, \]

the outputs are

\[ 3,\quad6,\quad12,\quad24,\ldots \]

These outputs form a geometric sequence with common ratio \(2\).

The exponential function extends the same multiplicative pattern beyond integer indices to real inputs.

Exponential Functions and Geometric Change

The relationship

\[ f(x+1)=bf(x) \]

is the function version of the geometric-sequence rule

\[ a_{n+1}=ra_n. \]

In both cases, one value is obtained from the preceding value through multiplication by a constant factor.

This is an important bridge between discrete sequences and continuous function models.

Comparing \(2^x\) and \(x^2\)

It is useful to compare exponential and polynomial growth.

\[ \begin{array}{c|c|c} x & x^2 & 2^x\\ \hline 1 & 1 & 2\\ 2 & 4 & 4\\ 3 & 9 & 8\\ 4 & 16 & 16\\ 5 & 25 & 32\\ 6 & 36 & 64\\ 10 & 100 & 1024 \end{array} \]

At first, the values can be similar, and \(x^2\) can even be larger for some inputs.

But eventually \(2^x\) overtakes \(x^2\) and grows much more rapidly.

Exponential Growth Can Be Deceptively Slow at First

Because an exponential function may begin with relatively modest values, its long-term growth can be underestimated.

Repeated doubling illustrates this:

\[ 1,\quad2,\quad4,\quad8,\quad16,\quad32,\quad64,\quad128,\ldots \]

The early values are small, but the increases become progressively larger.

Understanding this compounding effect is essential when interpreting exponential models.

Exponential Models Describe Many Processes

Exponential relationships occur whenever change is naturally proportional to, or based upon, the amount currently present.

Common applications include:

  • compound interest;
  • population growth;
  • radioactive decay;
  • depreciation;
  • spread processes;
  • cooling and attenuation models under appropriate assumptions;
  • repeated percentage changes;
  • doubling and half-life relationships.

The mathematical structure is reusable even though the interpretation changes from one application to another.

Not Every Increasing Function Is Exponential

A graph rising rapidly does not by itself prove that a relationship is exponential.

For example,

\[ f(x)=x^3 \]

increases rapidly for positive \(x\), but it is not exponential.

To identify exponential structure, look for repeated multiplication or a constant ratio over equal increments of the independent variable.

Not Every Expression with an Exponent Is Exponential

Consider

\[ x^5,\qquad 3x^2,\qquad (x+1)^4. \]

All contain exponents, but none is an exponential function in \(x\).

Their variables occur in the base.

By contrast,

\[ 5^x,\qquad 3(1.2)^x,\qquad 7^{x-4} \]

contain the variable in the exponent and therefore have exponential structure.

Common Error: Confusing \(2x\) with \(2^x\)

The expression

\[ 2x \]

means

\[ 2\cdot x. \]

The expression

\[ 2^x \]

means that \(2\) is raised to the variable exponent \(x\).

These operations are fundamentally different.

For example, at \(x=4\),

\[ 2x=8 \]

while

\[ 2^x=16. \]

Common Error: Treating Exponential Change as Constant Addition

Suppose a quantity doubles each period.

Starting with \(5\), the values are

\[ 5,\quad10,\quad20,\quad40,\quad80,\ldots \]

The amount added is not always \(5\).

Instead, every new value is twice the preceding value.

Exponential relationships are built from repeated multiplication, not repeated addition.

Common Error: Thinking a Decay Factor Must Be Negative

Exponential decay usually uses a positive base between \(0\) and \(1\).

For example,

\[ f(x)=100(0.7)^x \]

is an exponential decay function.

The factor \(0.7\) means that each new value is \(70\%\) of the preceding value.

A decay factor is smaller than \(1\); it does not need to be negative.

Common Error: Confusing a Decay Factor with a Decay Rate

If a quantity loses \(20\%\) during each period, the amount remaining is

\[ 100\%-20\%=80\%. \]

Therefore, the repeated multiplication factor is

\[ 0.80, \]

not \(0.20\).

Thus a model with initial value \(500\) is

\[ \boxed{500(0.80)^t}, \]

not

\[ 500(0.20)^t. \]

Common Error: Assuming the Initial Value Is the Base

In

\[ f(x)=300(1.04)^x, \]

the initial value is

\[ 300, \]

while the exponential base is

\[ 1.04. \]

They perform different jobs.

The initial value establishes where the process begins, while the base determines the repeated multiplicative change.

Common Error: Forgetting That \(b^0=1\)

Suppose

\[ f(x)=7(3)^x. \]

Then

\[ f(0)=7(3)^0. \]

Since

\[ 3^0=1, \]

we obtain

\[ \boxed{f(0)=7}. \]

The exponent \(0\) does not make the entire expression zero.

A Reliable Procedure for Reading \(ab^x\)

  1. Identify the initial value \(a\).
  2. Identify the exponential base \(b\).
  3. Verify that the variable occurs in the exponent.
  4. Determine whether \(b>1\) or \(0
  5. Use \(b>1\) to recognize growth.
  6. Use \(0
  7. Use \(f(0)=a\) to identify the initial value and \(y\)-intercept.
  8. Look for a constant ratio over equal input intervals.
  9. Evaluate by substituting the desired input into the exponent.

Example: Reading an Exponential Function

Consider

\[ f(x)=250(1.06)^x. \]

The initial value is

\[ \boxed{250}. \]

The repeated multiplication factor is

\[ \boxed{1.06}. \]

Since

\[ 1.06>1, \]

the function represents exponential growth.

Its \(y\)-intercept is

\[ \boxed{(0,250)}. \]

Example: Reading a Decay Function

Consider

\[ Q(t)=900(0.85)^t. \]

The initial value is

\[ 900. \]

The repeated factor is

\[ 0.85. \]

Because

\[ 0<0.85<1, \]

the function represents exponential decay.

Each period retains \(85\%\) of the previous quantity.

Example: Find a Function from a Table

Suppose

\[ \begin{array}{c|c} x & f(x)\\ \hline 0 & 4\\ 1 & 12\\ 2 & 36\\ 3 & 108 \end{array} \]

The initial value is

\[ f(0)=4. \]

The ratio of consecutive outputs is

\[ \frac{12}{4} = \frac{36}{12} = \frac{108}{36} = 3. \]

Therefore,

\[ \boxed{f(x)=4(3)^x}. \]

Example: Extend an Exponential Pattern

Suppose the values are

\[ 160,\quad80,\quad40,\quad20,\ldots \]

Each term is obtained by multiplying the preceding term by

\[ \frac12. \]

Therefore, the next two values are

\[ 20\left(\frac12\right)=10 \]

and

\[ 10\left(\frac12\right)=5. \]

The extended pattern is

\[ \boxed{160,\ 80,\ 40,\ 20,\ 10,\ 5,\ldots} \]

What to Remember

The basic exponential function is

\[ \boxed{f(x)=ab^x}. \]
  • The variable appears in the exponent.
  • \(a\) is the initial value.
  • \(b\) is the repeated multiplication factor.
  • \(f(0)=a\).
  • If \(b>1\), the basic relationship represents exponential growth.
  • If \(0
  • Equal increases in \(x\) produce constant multiplicative ratios.
  • The domain of a standard exponential function is all real numbers.
  • The basic horizontal asymptote is \(y=0\).
  • A vertical shift changes the horizontal asymptote.

The defining habit is to think multiplicatively: exponential change repeatedly multiplies the current value by the same factor.
