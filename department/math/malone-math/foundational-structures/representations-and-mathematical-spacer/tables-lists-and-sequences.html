Tables, Lists, and Sequences

Mathematical information is often organized rather than written as one long formula. Lists preserve order, tables align related values, and sequences turn ordered values into mathematical objects that can follow patterns, rules, or recursive processes.

Organizing Mathematical Information

Suppose we record the first five square numbers:

\[ 1,\ 4,\ 9,\ 16,\ 25. \]

That simple line is already more than a collection of numbers. The order matters.

We can place the same information into a table:

Position \(n\) Value \(a_n\)
\(1\)\(1\)
\(2\)\(4\)
\(3\)\(9\)
\(4\)\(16\)
\(5\)\(25\)

Or we can describe the pattern symbolically:

\[ a_n=n^2. \]

These are different representations of one ordered mathematical structure.

Lists

A list is an ordered collection of entries.

For example,

\[ 3,\ 7,\ 7,\ 10 \]

is a list of four entries.

Two features matter:

  • the position of each entry,
  • and the possibility of repetition.

The list

\[ 3,\ 7,\ 7,\ 10 \]

is not the same ordered list as

\[ 10,\ 7,\ 7,\ 3. \]

The entries are the same, but their order is different.

Sets versus Lists

A set and a list may contain the same visible entries but represent different structures.

For a set,

\[ \{1,2,3\} = \{3,2,1\}. \]

Order does not matter.

Also,

\[ \{1,1,2,3\} = \{1,2,3\}. \]

Repeated set elements do not create new elements.

But in a list,

\[ (1,1,2,3) \]

contains four positions, and the repeated \(1\) matters.

A Useful Distinction

\[ \boxed{ \text{set: membership matters} \qquad \text{list: membership and position matter} } \]

This distinction becomes important in coordinates, vectors, matrices, sequences, data records, and algorithms.

Tables

A table organizes information into rows and columns.

Tables are especially useful when two or more quantities are associated.

For example:

Hours \(h\) Distance \(d\)
\(0\)\(0\)
\(1\)\(60\)
\(2\)\(120\)
\(3\)\(180\)

The table shows a relationship between time and distance.

Each row connects one input value with one output value.

Tables as Ordered Pairs

A two-column table can usually be read as a list of ordered pairs.

The table

\(x\) \(y\)
\(1\)\(4\)
\(2\)\(7\)
\(3\)\(10\)

corresponds to

\[ (1,4),\ (2,7),\ (3,10). \]

If each first component has exactly one second component, the table may represent a function.

This gives a direct connection:

\[ \boxed{ \text{table row} \longleftrightarrow \text{ordered pair} } \]

Sequences

A sequence is an ordered collection of terms, usually indexed by integers.

For example,

\[ 2,\ 4,\ 6,\ 8,\ 10,\ldots \]

is the sequence of positive even integers.

We may name the terms

\[ a_1,a_2,a_3,\ldots \]

so that

\[ a_1=2,\quad a_2=4,\quad a_3=6. \]

The subscript tells us the position of the term.

Indices and Terms

In the notation

\[ a_n, \]

the symbol \(a\) names the sequence and \(n\) identifies the term position.

If

\[ a_n=3n+1, \]

then

\[ a_1=3(1)+1=4, \] \[ a_2=3(2)+1=7, \]

and

\[ a_5=3(5)+1=16. \]

Indexing Need Not Always Begin at \(1\)

Some sequences begin at

\[ n=0. \]

For example,

\[ a_n=2^n, \qquad n=0,1,2,\ldots \]

gives

\[ 1,2,4,8,16,\ldots \]

The starting index is part of the definition and should not be assumed.

Explicit Sequence Rules

An explicit rule gives a term directly from its index.

For example,

\[ a_n=5n-2. \]

To find the tenth term,

\[ a_{10}=5(10)-2=48. \]

No earlier terms are required.

Example: Squares

\[ a_n=n^2 \]

produces

\[ 1,4,9,16,25,\ldots \]

when \(n=1,2,3,\ldots\).

Recursive Sequence Rules

A recursive rule defines terms using earlier terms.

For example,

\[ a_1=3, \] \[ a_n=a_{n-1}+4 \qquad (n\geq2) \]

produces

\[ 3,7,11,15,19,\ldots \]

Each term depends on the previous one.

Initial Information Matters

The recurrence

\[ a_n=a_{n-1}+4 \]

does not determine a unique sequence by itself.

We also need a starting value such as

\[ a_1=3. \]

The recursive rule tells us how to continue; the initial condition tells us where to begin.

Finite and Infinite Sequences

A finite sequence has a last term.

For example,

\[ 2,4,6,8,10 \]

is a finite sequence of five terms.

An infinite sequence continues without a final term:

\[ 2,4,6,8,10,\ldots \]

The ellipsis

\[ \ldots \]

indicates continuation according to the intended pattern or rule.

An Ellipsis Needs Context

The list

\[ 1,2,3,\ldots \]

is usually clear.

But

\[ 1,2,4,\ldots \]

could continue in many different ways.

A pattern should not be assumed unless the rule or context makes it sufficiently clear.

Sequences as Functions

A sequence can be viewed as a function whose domain is an ordered set of indices, usually positive integers or nonnegative integers.

For example,

\[ a_n=n^2 \]

can be viewed as the function

\[ a:\mathbb{N}\to\mathbb{R} \]

defined by

\[ a(n)=n^2. \]

The sequence terms are the outputs:

\[ a(1)=1,\quad a(2)=4,\quad a(3)=9,\ldots \]

This connection is important:

\[ \boxed{ \text{sequence} = \text{function on an indexed discrete domain} } \]

It explains why sequences can be tabulated, graphed, composed, transformed, and analyzed using many of the same tools as functions.

Recognizing Patterns

Lists and tables often make patterns easier to notice.

Constant Difference

Consider

\[ 5,8,11,14,17,\ldots \]

The difference between consecutive terms is always

\[ 3. \]

This suggests an arithmetic pattern.

Constant Ratio

Consider

\[ 2,6,18,54,\ldots \]

Each term is obtained by multiplying the previous term by

\[ 3. \]

This suggests a geometric pattern.

Second Differences

Consider

\[ 1,4,9,16,25,\ldots \]

The first differences are

\[ 3,5,7,9,\ldots \]

and the second differences are constant:

\[ 2,2,2,\ldots \]

This is a useful signal of quadratic behavior.

Practical Applications

Time-Series Data

Daily temperatures, monthly revenue, yearly population, and sensor readings can be represented as sequences indexed by time.

Spreadsheets

Rows and columns organize related values into tables. Formulas can then turn those tables into calculated sequences or functions.

Computer Science

Arrays and lists are ordered data structures. Index position matters, and repeated entries are allowed.

Finance

Account balances over successive months can form a sequence:

\[ B_0,B_1,B_2,\ldots \]

A recursive rule may describe how each balance is computed from the previous one.

Scientific Experiments

Measurements collected in sequence can reveal trends, cycles, noise, or recurring structure that might be difficult to see from isolated values.

Worked Examples

Example 1: List versus Set

Compare

\[ (2,2,5,7) \]

with

\[ \{2,2,5,7\}. \]

The list has four positions.

The set simplifies to

\[ \{2,5,7\}, \]

which has cardinality \(3\).

Example 2: Table to Ordered Pairs

\(x\) \(y\)
\(0\)\(2\)
\(1\)\(5\)
\(2\)\(8\)

The ordered pairs are

\[ \boxed{ (0,2),(1,5),(2,8) }. \]

Example 3: Evaluate a Sequence Term

Let

\[ a_n=4n+1. \]

Find \(a_7\).

\[ a_7=4(7)+1=29. \] \[ \boxed{a_7=29}. \]

Example 4: Generate a Recursive Sequence

Given

\[ a_1=2 \]

and

\[ a_n=2a_{n-1}+1, \]

find the first four terms.

\[ a_1=2, \] \[ a_2=2(2)+1=5, \] \[ a_3=2(5)+1=11, \] \[ a_4=2(11)+1=23. \]

So the sequence begins

\[ \boxed{ 2,5,11,23,\ldots }. \]

Example 5: Find a Simple Rule

Consider

\[ 4,7,10,13,\ldots \]

The common difference is \(3\).

With indexing beginning at \(n=1\), one explicit rule is

\[ \boxed{ a_n=3n+1 }. \]

Example 6: Sequence as a Function

Let

\[ a_n=2^n, \qquad n=0,1,2,\ldots \]

Then

\[ a:\{0,1,2,\ldots\}\to\mathbb{R} \]

is a function whose outputs are

\[ 1,2,4,8,16,\ldots \]

Common Errors

1. Treating a List Like a Set

Lists preserve order and repetition. Sets do not.

2. Confusing an Index with a Term Value

In

\[ a_5=17, \]

the \(5\) is the position and \(17\) is the value.

3. Assuming Every Sequence Begins at \(1\)

A sequence may begin at \(0\), \(1\), or another specified index.

4. Assuming an Ellipsis Determines a Unique Pattern

A few terms may fit many possible rules.

5. Using a Recursive Rule without an Initial Value

A recurrence usually needs starting information to determine a unique sequence.

6. Assuming a Table Determines a Unique Formula

A finite table may be consistent with many different rules.

The Deeper Idea

Tables, lists, and sequences all organize information by position or association.

A list introduces order.

A table aligns related entries.

A sequence adds indexing and often a rule.

\[ \boxed{ \text{ordered entries} \longrightarrow \text{indexed structure} \longrightarrow \text{function-like behavior} } \]

This is why these simple representations lead naturally into coordinates, vectors, matrices, time series, algorithms, and discrete mathematics.

The underlying lesson is broader than sequences: once position matters, mathematical structure becomes richer than ordinary set membership.

Summary

  • A list is an ordered collection and may contain repeated entries.
  • A set ignores order and repeated copies of the same element.
  • A table organizes related values into rows and columns.
  • A two-column table can be interpreted as ordered pairs.
  • A sequence is an ordered collection of indexed terms.
  • The notation \[ a_n \] identifies the term at index \(n\).
  • An explicit rule gives a term directly from its index.
  • A recursive rule defines terms from earlier terms and usually requires initial information.
  • Sequences may be finite or infinite.
  • A sequence can be viewed as a function on a discrete indexed domain.
  • Constant differences, constant ratios, and difference tables can reveal patterns.
  • Tables, lists, and sequences are foundational representations for data, functions, algorithms, and later mathematical spaces.

The key idea is organization. Once values are arranged by position, association, or index, we can study not only what the values are but how they relate across the structure.
