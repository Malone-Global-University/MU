Networks, Graphs, and Trees

Some mathematical structures are best represented by connections rather than coordinates. Networks model relationships, graphs turn those relationships into vertices and edges, and trees organize connections without cycles.

Representing Relationships

Suppose four cities are connected by roads.

We could list every road in words, but a diagram can reveal the structure much faster:

  • cities become points,
  • roads become connections between points.

The actual geographic positions may not matter. What matters is which objects are connected.

This leads to a new kind of representation:

\[ \boxed{ \text{objects} + \text{connections} = \text{network structure} } \]

Graph theory makes that structure precise.

Networks

A network is a collection of objects connected by relationships or links.

Examples include:

  • roads connecting cities,
  • air routes connecting airports,
  • people connected by communication,
  • computers connected by cables or wireless links,
  • web pages connected by hyperlinks,
  • tasks connected by dependencies.

The word network often emphasizes the real system being modeled.

A graph is the mathematical structure commonly used to represent that network.

Graphs

A graph consists of a set of vertices and a collection of edges connecting them.

A common notation is

\[ \boxed{ G=(V,E) } \]

where:

  • \(V\) is the set of vertices,
  • \(E\) is the set of edges.

For example, let

\[ V=\{A,B,C,D\} \]

and

\[ E= \{\{A,B\},\{A,C\},\{B,C\},\{C,D\}\}. \]

This graph has four vertices and four undirected edges.

Graph-Theory Graphs versus Coordinate Graphs

The word graph is used in more than one mathematical sense.

Coordinate Graph

A set of points plotted in a coordinate space, such as the graph of \[ y=x^2. \]

Graph-Theory Graph

A structure made of vertices and edges that represent relationships.

These ideas are related through representation, but they are not the same object.

In this lesson, graph usually means the graph-theory object

\[ G=(V,E). \]

Vertices and Edges

A vertex represents an object in the network.

An edge represents a relationship between two vertices.

If an edge joins \(u\) and \(v\), we say that \(u\) and \(v\) are adjacent.

The edge is incident to both vertices.

Undirected Edge

When the relationship has no direction, an edge may be written

\[ \{u,v\}. \]

The order does not matter:

\[ \{u,v\}=\{v,u\}. \]

A two-way road is a natural example.

Directed Graphs

Some relationships have direction.

A directed graph, or digraph, uses directed edges called arcs.

A directed edge from \(u\) to \(v\) may be written

\[ (u,v). \]

Now order matters:

\[ (u,v)\neq(v,u) \]

in general.

Examples include:

  • one-way roads,
  • web links,
  • task dependencies,
  • follower relationships,
  • state transitions.

Weighted Graphs

An edge can carry a numerical value called a weight.

A weight might represent:

  • distance,
  • travel time,
  • cost,
  • capacity,
  • risk,
  • similarity.

Degree

In an undirected graph, the degree of a vertex is the number of edges incident to it.

It is commonly written

\[ \deg(v). \]

In the graph

\[ E= \{\{A,B\},\{A,C\},\{B,C\},\{C,D\}\}, \]

the degrees are

\[ \deg(A)=2, \] \[ \deg(B)=2, \] \[ \deg(C)=3, \] \[ \deg(D)=1. \]

Directed Degree

For directed graphs, we distinguish:

  • indegree: number of arrows entering a vertex,
  • outdegree: number of arrows leaving a vertex.

Walks, Paths, and Cycles

A graph lets us study routes through a network.

Walk

A walk is a sequence of adjacent vertices. Vertices or edges may repeat.

Path

A path is a route through the graph that does not repeat vertices.

For example,

\[ A\to C\to D \]

is a path in the earlier graph.

Cycle

A cycle begins and ends at the same vertex while otherwise avoiding repeated vertices.

For example,

\[ A\to B\to C\to A \]

forms a cycle.

Cycles will become especially important when we define trees.

Connectivity

An undirected graph is connected if every pair of vertices can be joined by a path.

If some vertices cannot be reached from others, the graph is disconnected.

The disconnected pieces are called connected components.

Connectivity is often more important than the physical placement of vertices in a drawing.

We can redraw a graph dramatically while preserving exactly the same connectivity.

Trees

A tree is a connected undirected graph with no cycles.

\[ \boxed{ \text{tree} = \text{connected} + \text{acyclic} } \]

A Useful Finite-Tree Property

A finite tree with

\[ n \]

vertices has exactly

\[ \boxed{n-1} \]

edges.

The six-vertex tree above therefore has five edges.

Rooted Trees

A tree becomes a rooted tree when one vertex is chosen as the root.

That choice creates hierarchical language:

  • parent,
  • child,
  • ancestor,
  • descendant,
  • leaf,
  • level or depth.

Rooted trees are useful for representing:

  • folder structures,
  • decision processes,
  • organizational hierarchies,
  • expression trees,
  • search procedures.

Leaves

A leaf is a vertex with no children in the rooted-tree interpretation.

The same underlying undirected tree can have different parent-child relationships if a different root is chosen.

Representing the Same Graph

A graph need not be stored or communicated only as a picture.

The same graph can be represented using:

  • a diagram,
  • a vertex set and edge set,
  • an adjacency list,
  • an adjacency matrix.

This makes graphs another example of the central theme of this section:

\[ \boxed{ \text{same mathematical object} \longleftrightarrow \text{multiple representations} } \]

Adjacency Lists

An adjacency list records the neighbors of each vertex.

For the graph with

\[ E= \{\{A,B\},\{A,C\},\{B,C\},\{C,D\}\}, \]

an adjacency-list representation is:

Vertex Adjacent Vertices
\(A\)\(B,C\)
\(B\)\(A,C\)
\(C\)\(A,B,D\)
\(D\)\(C\)

Adjacency lists are often compact when a graph has relatively few edges compared with the number of possible connections.

Adjacency Matrices

A graph with vertices

\[ A,B,C,D \]

can also be represented by a matrix.

For a simple undirected graph, put a \(1\) where two vertices are adjacent and a \(0\) where they are not:

\[ \boxed{ \begin{array}{c|cccc} & A&B&C&D\\ \hline A&0&1&1&0\\ B&1&0&1&0\\ C&1&1&0&1\\ D&0&0&1&0 \end{array} } \]

This is the graph's adjacency matrix.

Symmetry

For a simple undirected graph, the adjacency matrix is symmetric across the main diagonal because

\[ A\text{ adjacent to }B \]

means the same thing as

\[ B\text{ adjacent to }A. \]

Directed graphs need not produce symmetric adjacency matrices.

Practical Applications

Transportation

Vertices can represent cities or stations; edges can represent roads, rail lines, or flights; weights can represent distance or travel time.

Computer Networks

Devices become vertices and communication links become edges.

Project Planning

Directed edges can represent task dependencies:

\[ A\to B \]

may mean task \(A\) must occur before task \(B\).

Social Networks

Vertices can represent people or accounts, while edges represent friendship, communication, following, or other relationships.

Web and Search

Web pages form vertices and hyperlinks form directed edges.

Computer Science

Trees organize file systems, parse expressions, support searching, and model hierarchical data.

Biology

Networks can represent food webs, molecular interactions, neural connections, and evolutionary relationships.

Worked Examples

Example 1: Build a Graph from Connections

Suppose

\[ V=\{P,Q,R,S\} \]

and the connections are

\[ P-Q,\quad Q-R,\quad R-S. \]

Then one edge-set representation is

\[ \boxed{ E= \{\{P,Q\},\{Q,R\},\{R,S\}\} }. \]

The resulting graph is connected and has no cycles, so it is a tree.

Example 2: Find Degree

For

\[ E= \{\{A,B\},\{A,C\},\{A,D\},\{C,D\}\}, \]

the vertex \(A\) touches three edges.

\[ \boxed{\deg(A)=3}. \]

Example 3: Identify a Path

Suppose the graph has edges

\[ \{A,B\}, \quad \{B,C\}, \quad \{C,D\}. \]

Then

\[ \boxed{A\to B\to C\to D} \]

is a path from \(A\) to \(D\).

Example 4: Identify a Cycle

If the graph contains

\[ \{A,B\}, \quad \{B,C\}, \quad \{C,A\}, \]

then

\[ \boxed{A\to B\to C\to A} \]

is a cycle.

Example 5: Is It a Tree?

A graph has \(5\) vertices, is connected, and has no cycles.

Therefore it is a tree, and it must have

\[ 5-1=\boxed4 \]

edges.

Example 6: Read an Adjacency Matrix

Suppose

\[ M= \begin{bmatrix} 0&1&0\\ 1&0&1\\ 0&1&0 \end{bmatrix}. \]

Using vertex order \(A,B,C\), the \(1\) in row \(A\), column \(B\) shows that \(A\) is adjacent to \(B\), while the \(0\) in row \(A\), column \(C\) shows that \(A\) is not adjacent to \(C\).

Common Errors

1. Confusing a Graph-Theory Graph with a Coordinate Graph

A graph-theory graph represents connections among vertices. A coordinate graph represents points in a coordinate space.

2. Thinking the Drawing Determines the Graph

Moving vertices around does not change the graph as long as the same connections remain.

3. Ignoring Direction

In a directed graph,

\[ u\to v \]

does not automatically imply

\[ v\to u. \]

4. Ignoring Weights

Two routes may use the same number of edges while having very different total cost, distance, or time.

5. Calling Every Connected Graph a Tree

A tree must be connected and contain no cycles.

6. Treating an Adjacency Matrix as Ordinary Numerical Data Only

Its row-column positions encode relationships among vertices.

Practice

Degree

A vertex is incident to four edges. What is its degree?

Check Answer \[ \boxed4. \]

Directed Relationship

If a digraph contains

\[ A\to B, \]

must it also contain \(B\to A\)?

Check Answer

No. Direction matters.

Tree Test

A connected graph contains a cycle. Can it be a tree?

Check Answer

No. Trees are connected and acyclic.

Finite Tree Edge Count

How many edges does a tree with \(12\) vertices have?

Check Answer \[ 12-1=\boxed{11}. \]

Adjacency

For

\[ E= \{\{A,B\},\{B,C\},\{C,D\}\}, \]

which vertices are adjacent to \(B\)?

Check Answer \[ \boxed{A\text{ and }C}. \]

The Deeper Idea

Coordinates represent objects by position.

Graphs represent objects by relationship.

That is a major change in viewpoint.

\[ \boxed{ \text{coordinate space asks: where?} } \] \[ \boxed{ \text{graph structure asks: connected to what?} } \]

A network can often be redrawn in many ways while preserving the same underlying graph. The invariant is the pattern of relationships.

This makes graphs ideal for systems whose structure matters more than physical location.

Later, graph theory will deepen these ideas through connectivity, shortest paths, spanning trees, coloring, traversal, combinatorics, probability, algorithms, and network optimization.

Summary

  • A network is a collection of objects connected by relationships.
  • A graph is commonly written \[ G=(V,E), \] where \(V\) is the vertex set and \(E\) is the edge collection.
  • Vertices represent objects; edges represent relationships.
  • Undirected edges have no direction.
  • Directed graphs use arrows whose orientation matters.
  • Weighted graphs attach numerical information to edges.
  • The degree of a vertex counts its incident edges in an undirected graph.
  • Walks, paths, and cycles describe routes through a graph.
  • A connected graph allows a path between every pair of vertices.
  • A tree is a connected graph with no cycles.
  • A finite tree with \(n\) vertices has \[ n-1 \] edges.
  • A rooted tree adds hierarchical parent-child structure.
  • The same graph can be represented by a diagram, edge set, adjacency list, or adjacency matrix.
  • Graph-theory graphs represent connectivity rather than coordinate position.

Networks, graphs, and trees give mathematics a language for relationships. They let us ignore irrelevant geometric placement and focus directly on connections, routes, hierarchy, and structure.
