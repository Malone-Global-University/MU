Multiple Representations

Mathematics becomes easier to understand when we can look at the same object in more than one way. A number can be a point, a measurement, or a symbol; a function can be a formula, table, graph, or mapping; and a geometric object can be described with coordinates, equations, or a picture.

The Object Is Not the Representation

Suppose we write

\[ \frac12. \]

We might also write

\[ 0.5 \]

or

\[ 50\%. \]

These expressions look different, but they represent the same numerical value.

That distinction is fundamental:

\[ \boxed{ \text{mathematical object} \neq \text{particular representation of that object} } \]

A representation is a way of displaying, encoding, describing, or working with an object.

Different representations make different features easier to see.

Why Use Multiple Representations?

A single representation rarely shows everything we care about.

For example, a formula may be best for exact calculation, while a graph may be best for seeing shape and trend.

A table may make selected values easy to compare, while a verbal description may make the real-world meaning clearer.

Symbolic

Good for exact rules, identities, manipulation, and proof.

Numerical

Good for concrete values, approximation, and computation.

Graphical

Good for shape, trend, position, and visual comparison.

Tabular

Good for selected data, patterns, and organized comparison.

Verbal

Good for meaning, interpretation, and communication.

Structural

Good for showing relationships among objects, such as mappings, sets, and networks.

Learning mathematics therefore involves more than learning symbols. It also means learning how to move among representations.

Common Forms of Representation

Across mathematics, the same object may be represented in several recurring ways.

Verbal Representation

A description in ordinary language:

“The output is twice the input plus one.”

Symbolic Representation

\[ f(x)=2x+1. \]

Numerical Representation

\[ f(3)=7. \]

Ordered Pairs

\[ (0,1),(1,3),(2,5),(3,7). \]

Table

\(x\) \(f(x)\)
\(0\)\(1\)
\(1\)\(3\)
\(2\)\(5\)
\(3\)\(7\)

Graphical Representation

Plot the ordered pairs in a coordinate plane.

Diagrammatic Representation

Use arrows, Venn diagrams, trees, matrices, networks, or other diagrams to show relationships and structure.

Equivalent Representations

Two representations are equivalent when they describe the same mathematical object or value under the conventions being used.

For example,

\[ \frac34=0.75=75\%. \]

These are different notations for the same number.

Likewise, the equation

\[ y=2x+1 \]

and the set

\[ \{(x,y)\in\mathbb{R}^2\mid y=2x+1\} \]

describe the same line when the ambient coordinate space is \(\mathbb{R}^2\).

Equivalent Does Not Mean Visually Identical

The representations may look completely different.

The important question is whether they preserve the same underlying mathematical information.

Translating between Representations

A useful mathematical habit is to ask:

How would this same object look in another representation?

Words to Symbols

“Three more than twice \(x\)” becomes

\[ 2x+3. \]

Symbols to Table

Given

\[ f(x)=2x+3, \]

evaluate selected inputs.

Table to Graph

Treat each row as an ordered pair and plot it.

Graph to Words

Describe visible behavior:

  • increasing,
  • decreasing,
  • constant,
  • curved,
  • periodic,
  • bounded,
  • or discontinuous.

Equation to Set

The equation

\[ x^2+y^2=25 \]

can be written as the set

\[ C= \{(x,y)\in\mathbb{R}^2\mid x^2+y^2=25\}. \]

This explicitly identifies the circle as a set of points.

What Stays the Same?

When the representation changes, some features remain invariant.

For equivalent numerical representations,

\[ \frac12,\quad 0.5,\quad 50\% \]

all have the same value.

For a function represented by a formula, table, or graph, the same input-output pairs remain part of the function.

For a line described geometrically or algebraically, the same collection of points is being described.

This idea of an invariant—something preserved while the representation changes—will become increasingly important later.

\[ \boxed{ \text{change the representation} \quad\text{without changing the object} } \]

Example: One Number, Many Forms

Consider the number

\[ \frac14. \]

It can be represented as:

  • a fraction: \[ \frac14, \]
  • a decimal: \[ 0.25, \]
  • a percent: \[ 25\%, \]
  • a ratio: \[ 1:4, \] when the intended comparison is appropriate,
  • a point on the number line,
  • or a measurement such as \[ 0.25\text{ meter}. \]

Different representations may make different tasks easier.

For example, \(25\%\) may be useful in finance, while \(\frac14\) may make exact arithmetic easier.

Consider

\[ f(x)=x+2. \]

The same function may be represented verbally:

As ordered pairs:

\[ (0,2),(1,3),(2,4),(3,5). \]

As a table:

\(0\)\(2\)
\(1\)\(3\)
\(2\)\(4\)
\(3\)\(5\)

And as a graph:

Each form shows the same function but emphasizes different features.

Example: One Set, Many Forms

Consider the even integers.

We can describe them verbally:

“All integers divisible by \(2\).”

With set-builder notation:

\[ E=\{n\in\mathbb{Z}\mid 2\mid n\}. \]

Or parametrically:

\[ E=\{2k\mid k\in\mathbb{Z}\}. \]

Or partially by roster notation:

\[ E=\{\ldots,-4,-2,0,2,4,\ldots\}. \]

These are different representations of the same infinite set.

Choosing the Best Representation

The best representation depends on what you want to do.

Goal Often Useful Representation
Exact algebraic manipulation Symbolic formula
Compare selected values Table
See global behavior Graph
Explain meaning Words
Show set relationships Venn or mapping diagram
Show location or motion Coordinate or geometric representation
Compute efficiently Numerical or algorithmic representation

A skilled problem solver changes representation when the current one makes the problem harder than it needs to be.

What Representations Can Hide

A representation may emphasize some information while hiding other information.

A Finite Table Hides Unlisted Values

A table showing five function values does not automatically tell us what the function does everywhere else.

A Graph May Hide Exact Values

A graph can show shape clearly while making an exact value difficult to read.

A Decimal May Hide Exact Structure

The decimal

\[ 0.333333\ldots \]

may be less convenient than the exact fraction

\[ \frac13. \]

A Formula May Hide Meaning

The expression

\[ C(q)=50+12q \]

is compact, but without context we do not know whether \(q\) represents hours, products, miles, or something else.

This is why mathematical communication often uses several representations together.

A Preview of Mathematical Spaces

Representations often place objects inside a mathematical space.

A real number may be represented as a point on

\[ \mathbb{R}. \]

An ordered pair may be represented as a point in

\[ \mathbb{R}^2. \]

An ordered triple may be represented in

\[ \mathbb{R}^3. \]

A function may be represented by a graph consisting of points in a coordinate space.

Later, we will expand this idea beyond familiar physical geometry. Vectors, matrices, sequences, functions, and other mathematical objects can also be organized into spaces with their own structures and rules.

For now, the key idea is simple:

\[ \boxed{ \text{a representation places an object into a form where useful relationships become visible} } \]

Practical Applications

Engineering

A physical system may be represented with a diagram, a formula, a data table, and a graph. Each helps answer a different engineering question.

Business

Revenue may appear as raw transaction data, a spreadsheet table, a formula, or a chart. The business quantity is the same, but the representation changes with the task.

Computer Science

The same data can be represented as text, numbers, arrays, matrices, graphs, trees, or encoded binary structures.

Science

Experimental measurements may begin as numerical data, become a graph, and then be summarized by a mathematical model.

Communication

A good representation can make a difficult idea accessible. A poor one can hide a simple relationship.

Worked Examples

Example 1: Fraction, Decimal, Percent

Convert

\[ \frac38 \]

to decimal and percent form.

\[ \frac38=0.375. \]

Then

\[ 0.375=37.5\%. \]

So

\[ \boxed{ \frac38=0.375=37.5\% } \]

represents the same value in three forms.

Example 2: Words to Formula

“A quantity is five more than three times \(x\).”

The symbolic representation is

\[ \boxed{3x+5}. \]

Example 3: Formula to Ordered Pairs

Let

\[ f(x)=2x-1. \]

For \(x=0,1,2\):

\[ f(0)=-1, \qquad f(1)=1, \qquad f(2)=3. \]

So selected ordered pairs are

\[ \boxed{ (0,-1),(1,1),(2,3) }. \]

Example 4: Equation to Geometric Meaning

Consider

\[ y=4. \]

This equation represents all points whose vertical coordinate equals \(4\):

\[ \{(x,4)\mid x\in\mathbb{R}\}. \]

Geometrically, this is a horizontal line.

Example 5: Set-Builder to Roster Form

Let

\[ A=\{n\in\mathbb{Z}\mid -2\leq n\leq2\}. \]

Then

\[ \boxed{ A=\{-2,-1,0,1,2\} }. \]

Example 6: Choose a Better Representation

Suppose we want to know whether a function has a maximum over a given interval.

A symbolic formula may help calculate the maximum exactly, but a graph may make the existence and approximate location of the maximum immediately visible.

Using both representations may be more effective than using either one alone.

Common Errors

1. Confusing the Object with Its Notation

The symbol is a representation of the mathematical object, not the object itself.

2. Assuming Different-Looking Forms Must Represent Different Objects

Expressions such as

\[ \frac12,\quad0.5,\quad50\% \]

look different but can represent the same value.

3. Assuming a Small Table Completely Determines a Function

Many different rules can agree on a finite set of data points.

4. Assuming a Graph Always Shows Exact Values

Graphs are often excellent for structure but weaker for exact numerical reading.

5. Choosing a Representation That Hides the Important Feature

If a symbolic expression is difficult to interpret, switching to a graph, table, diagram, or verbal description may reveal the structure.

6. Changing the Object While Changing the Representation

A valid translation must preserve the mathematical information intended to stay the same.

Choose a Representation

Which representation would usually be best for seeing whether a function is increasing, decreasing, or changing direction over an interval?

Check Answer

A graph is usually especially useful because the overall shape and direction are visible at once.

The Deeper Idea

A major part of mathematical maturity is learning to recognize one structure across many appearances.

The same object may look symbolic in one problem, geometric in another, numerical in a third, and algorithmic in a fourth.

The representation changes, but the underlying relationships can remain the same.

\[ \boxed{ \text{representation changes} \quad\text{while}\quad \text{structure is preserved} } \]

This is why Malone Math repeatedly moves among numbers, number lines, coordinate planes, sets, mappings, graphs, and later higher-dimensional spaces. Each representation becomes another tool for seeing the same mathematics from a useful angle.

Summary

  • A mathematical object is not the same thing as its representation.
  • One object may have verbal, symbolic, numerical, tabular, graphical, geometric, or diagrammatic representations.
  • Equivalent representations preserve the same underlying mathematical information.
  • Different representations make different features easier to see.
  • Translating between representations is a core problem-solving skill.
  • Important features that remain unchanged across representations are examples of invariants.
  • Numbers, functions, sets, and geometric objects can all be represented in multiple ways.
  • A finite table may hide unlisted behavior, while a graph may hide exact values.
  • The best representation depends on the question being asked.
  • Mathematical spaces provide environments in which representations such as points, vectors, and functions can be organized and compared.

The goal is not to memorize many separate forms. It is to recognize the same mathematical structure when it appears in different forms and to choose the representation that makes the next step easier.
