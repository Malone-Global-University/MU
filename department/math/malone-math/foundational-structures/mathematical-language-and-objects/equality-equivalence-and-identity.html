Equality, Equivalence, and Identity

Three ways mathematics makes “the same” precise—without pretending that every kind of sameness is identical.

The Big Idea

In ordinary conversation, we use the word same rather freely. Two shirts may be the same color, two songs may use the same melody, and two routes may take the same amount of time. We do not mean the shirts, songs, or routes are literally one object. We mean they match according to a feature that matters.

Mathematics separates several kinds of sameness:

  • Equality says that two expressions, names, or representations refer to the same mathematical value or object.
  • Equivalence says that two objects match according to a stated relationship or criterion, even when they are not literally equal.
  • Identity commonly refers either to an equality that holds for every permitted value or to an object or operation that leaves other objects unchanged.

The words overlap, but they are not interchangeable. The question is always: same in what sense?

Equality Means the Same Mathematical Object or Value

The equality sign \(=\) states that the expression on its left and the expression on its right represent the same mathematical object or value.

\[ 3+4=7 \]

does not say the visible expression \(3+4\) looks like the visible numeral \(7\). It says both representations have the same value.

One number can have many equal representations:

\[ \frac12=\frac24=0.5=50\%. \]

The notation changes, but each expression represents the same rational number.

Equality Depends on the Kind of Object

“Equal” always uses the equality rule appropriate for the objects being compared.

Equality for several kinds of mathematical objects
Object type What equality requires Example
Numbers The same numerical value \(\frac34=0.75\)
Ordered pairs Equal components in corresponding positions \((a,b)=(c,d)\) when \(a=c\) and \(b=d\)
Sets Exactly the same members \(\{1,2,3\}=\{3,2,1\}\)
Matrices The same dimensions and equal corresponding entries \(A=B\) entry by entry
Functions The same domain and the same output for every input; some definitions also require the same codomain \(f(x)=g(x)\) for every input in that domain

Order does not matter when listing the members of a set, but it matters in an ordered pair. Thus \(\{1,2\}=\{2,1\}\), while \((1,2)\ne(2,1)\). You must identify the kind of object before deciding what equality means.

Equality Behaves Reliably

Equality has three basic relationship properties:

  1. Reflexive: Every object equals itself, so \(a=a\).
  2. Symmetric: If \(a=b\), then \(b=a\).
  3. Transitive: If \(a=b\) and \(b=c\), then \(a=c\).

Equality also supports substitution. If \(a=b\), one may replace \(a\) with \(b\) in a valid expression without changing the represented value. If \(x=5\), then

\[ 2x+1=2(5)+1=11. \]

This replacement principle is one reason equality is so useful. Once two representations are known to be equal, either may stand in for the other wherever the substitution is defined.

Solving Preserves Equality

An equation asks when two expressions are equal. We solve it by applying operations that preserve the equality and, ideally, preserve the same solution set.

Start with

\[ 3x+5=17. \]

Subtract 5 from both sides:

\[ 3x=12. \]

Divide both sides by 3:

\[ x=4. \]

The familiar “do the same thing to both sides” method works because valid operations applied under the same conditions preserve equality. We are not moving terms across a decorative symbol; we are creating a sequence of equations with the same solution.

Equivalence Means the Same for a Chosen Purpose

Two objects are equivalent when they are related according to a rule that treats them as the same for a particular purpose. They may remain distinct objects in other respects.

For example, the integers \(17\) and \(5\) are not equal. However, they leave the same remainder when divided by \(12\). We express this modular equivalence as

\[ 17\equiv5\pmod{12}. \]

In clock arithmetic, both numbers point to the same clock position. They are equivalent modulo 12 without being equal as ordinary integers.

Equivalence lets mathematics ignore differences that do not matter to the current question while preserving the features that do.

Common Kinds of Equivalence

Context Objects are equivalent when… Example
Algebraic expressions They produce the same value for every permitted input \(2(x+3)\) and \(2x+6\)
Fractions They represent the same rational number \(\frac12\) and \(\frac24\)
Geometry They have the same chosen geometric structure Congruent figures have the same size and shape
Logical statements They have the same truth value in every allowed case “If \(P\), then \(Q\)” and its contrapositive
Modular arithmetic Their difference is divisible by the modulus \(17\equiv5\pmod{12}\)

Sometimes equivalent representations are also said to represent the same underlying object, as with equivalent fractions. In other contexts, equivalence deliberately groups distinct objects, as with different integers that share a remainder. The equivalence rule tells us what is being preserved.

An Equivalence Relation Has Three Properties

A relationship qualifies as an equivalence relation when it is reflexive, symmetric, and transitive:

  1. Reflexive: Every object is equivalent to itself.
  2. Symmetric: If \(a\) is equivalent to \(b\), then \(b\) is equivalent to \(a\).
  3. Transitive: If \(a\) is equivalent to \(b\), and \(b\) is equivalent to \(c\), then \(a\) is equivalent to \(c\).

“Has the same remainder when divided by 3” satisfies all three properties. “Is less than” does not: if \(a\lt b\), it is not also true that \(b\lt a\). Therefore less-than is a useful relation, but it is not an equivalence relation.

Equivalence Relations Create Classes

An equivalence relation sorts a collection into nonoverlapping equivalence classes. Every object belongs with all objects equivalent to it.

Under equivalence modulo 3, the integers separate into three classes:

  • Remainder 0: \(\{\ldots,-6,-3,0,3,6,\ldots\}\)
  • Remainder 1: \(\{\ldots,-5,-2,1,4,7,\ldots\}\)
  • Remainder 2: \(\{\ldots,-4,-1,2,5,8,\ldots\}\)

Within modular arithmetic, we can work with the three classes rather than carrying every integer separately. Equivalence turns a large collection into an organized set of meaningful categories.

Equal Objects Are More Than Merely Equivalent

Equality is the strongest ordinary form of sameness: the two sides refer to the same object or value. Equivalence usually preserves only the features chosen by an equivalence relation.

If two objects are equal, they will often be equivalent under many broader criteria. The reverse need not hold. Two triangles may be similar because they have the same shape, but they may have different sizes and therefore need not be congruent or equal as geometric objects.

A useful reading habit is:

  • When you see \(=\), ask what makes the two sides the same object or value.
  • When you see an equivalence relation, ask which feature is being preserved and which differences are being ignored.

An Identity Is an Equality That Holds Throughout a Domain

An identity is an equation true for every permitted value of its variables. The distributive identity

\[ a(b+c)=ab+ac \]

does not ask us to solve for special values of \(a\), \(b\), and \(c\). It states a relationship that holds whenever the operations are defined in the number system being used.

Other identities include:

  • \(x+0=x\)
  • \(x\cdot1=x\)
  • \((x+y)^2=x^2+2xy+y^2\)
  • \(\sin^2\theta+\cos^2\theta=1\)

An identity differs from a conditional equation such as \(x+3=8\), which is true only when \(x=5\).

Identities Still Have Domains

“True for every value” means every value for which the expressions are defined. Consider

\[ \frac{x^2-1}{x-1}=x+1. \]

Factoring the numerator shows why the equality holds:

\[ \frac{(x-1)(x+1)}{x-1}=x+1. \]

The cancellation is valid only when \(x\ne1\). The equality is therefore an identity on its permitted domain, not at \(x=1\), where the original left side is undefined.

Domain restrictions are part of the claim. An identity does not override undefined operations.

Identity Elements Leave Objects Unchanged

The word identity also names an object that leaves other objects unchanged under a particular operation.

Common identity elements and identity objects
Setting Identity Unchanged relationship
Addition \(0\) \(a+0=0+a=a\)
Multiplication \(1\) \(a\cdot1=1\cdot a=a\)
Matrix multiplication Identity matrix \(I\) \(AI=IA=A\), when dimensions permit
Function composition Identity function \(\operatorname{id}\) \(\operatorname{id}(x)=x\)
Geometric transformation Identity transformation Every point remains in its original position

Identity elements depend on the operation. Zero is the additive identity, but it is not the multiplicative identity. The identity matrix for a \(2\times2\) matrix is not the same array as the identity matrix for a \(3\times3\) matrix, though both perform the same structural role.

Inverses Return Us to an Identity

An inverse is defined relative to an operation and its identity. Additive inverses combine to produce the additive identity:

\[ a+(-a)=0. \]

Multiplicative inverses combine to produce the multiplicative identity:

\[ a\cdot\frac1a=1, \qquad a\ne0. \]

A function and its inverse compose to the identity function when the required domain conditions are met:

\[ f^{-1}\circ f=\operatorname{id}. \]

This connection explains why identities appear throughout algebra: they are the unchanged states to which inverse operations return us.

The Symbols \(=\), \(\equiv\), \(\approx\), and \(:=\)

Different symbols help signal different relationships, but conventions vary.

Symbol Common use Example
\(=\) Equality \(2+3=5\)
\(\equiv\) Identity, congruence, or another defined equivalence \(17\equiv5\pmod{12}\)
\(\approx\) Approximate equality \(\pi\approx3.14159\)
\(:=\) or \(\coloneqq\) Definition or assignment \(f(x):=x^2+1\)
\(\ne\) Not equal \(2\ne3\)

The symbol \(\equiv\) is especially overloaded. It may mark an identity in algebra, congruence in modular arithmetic, or a defined equivalence relation elsewhere. Read the source's definitions rather than assuming the symbol has one universal use.

Not Every Transformation Is Reversible

Two equations are equivalent when they have the same solution set. Some operations preserve that equivalence in both directions; others produce only a one-way implication.

If

\[ x=2, \]

then squaring gives

\[ x^2=4. \]

Every solution of \(x=2\) satisfies \(x^2=4\), but \(x^2=4\) also has the solution \(x=-2\). Squaring has introduced an extra possibility, so the two equations are not equivalent.

This is why solutions should be checked after operations such as squaring, multiplying by an expression that might be zero, or removing denominators and radicals. A valid implication may help us find candidates without guaranteeing that every candidate solves the original equation.

Testing Is Not the Same as Proving an Identity

Substituting several values can reveal a false identity quickly. If one permitted value makes the two sides unequal, the proposed identity is disproved.

Successful tests, however, do not prove that an equality works for every value. To establish an identity, transform one side into the other using definitions and valid identities, or show that both sides follow from the same established structure.

For example,

\[ (x+2)^2 =(x+2)(x+2) =x^2+4x+4. \]

The distributive property establishes the identity for every value in the permitted number system. We have explained why it works, not merely observed that it works in a few cases.

Common Equality Mistakes

Using \(=\) to mean “and then I did the next step”

Every equals sign claims both sides have the same value. The chain \(3+4=7\times2=14\) is false because it also claims \(7=14\). Separate unrelated calculations or explain the operation in words.

Replacing exact equality with a rounded decimal

If a value has been rounded, use \(\approx\). For example, \(\frac13\approx0.333\), not \(\frac13=0.333\).

Assuming equivalent means literally equal

Equivalent objects match under a stated criterion. Congruent integers modulo 12 may share a remainder without being equal as integers.

Ignoring a domain restriction in an identity

An identity holds for every permitted value, not for values at which an expression is undefined. Cancellation cannot make division by zero valid.

A Friendly Sameness-Checking Routine

When two mathematical objects are said to be “the same,” ask:

  1. What kind of objects are being compared? Numbers, sets, functions, figures, matrices, or statements?
  2. Does the claim use equality or an equivalence relation?
  3. If it is equality, what definition of equality applies to these objects?
  4. If it is equivalence, which feature is preserved?
  5. Is the relation reflexive, symmetric, and transitive?
  6. Is the equation conditional or an identity? Does it hold for selected values or every permitted value?
  7. What domain restrictions apply?
  8. Are the transformations reversible? Check for extra or lost solutions.
  9. Is the value exact, approximate, or defined by convention? Choose the symbol that communicates that relationship honestly.

Working Summary

Equality identifies the same mathematical object or value. Equivalence treats objects as the same under a stated relationship. An identity is either an equality valid throughout its domain or an object that leaves others unchanged under an operation.

These ideas form the backbone of symbolic reasoning. They tell us when substitution is valid, when equations preserve their solutions, when different forms express the same structure, and why inverse operations return objects to an unchanged identity state.

Check Your Understanding

Why can two different-looking expressions be equal?

Equality concerns the represented object or value, not visual appearance. The expressions \(\frac12\), \(0.5\), and \(50\%\) look different but represent the same number.

What makes equivalence different from equality?

Equality identifies one mathematical object or value. Equivalence groups objects that match under a chosen criterion, even if they remain distinct in other respects.

Why is \(0\) called the additive identity?

Adding \(0\) leaves every permitted number unchanged: \(a+0=0+a=a\).

Is \(\frac{x}{x}=1\) an identity for every real number?

It is an identity only on the domain \(x\ne0\). The original expression is undefined at \(x=0\).

Why can squaring both sides introduce an extra solution?

Opposite numbers have the same square. Squaring loses sign information, so the new equation may allow values that did not satisfy the original equation.
