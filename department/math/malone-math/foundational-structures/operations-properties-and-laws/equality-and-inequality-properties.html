Equality and Inequality Properties

Preserving equal values, comparing unequal values, and transforming relationships without losing what they mean.

The Big Idea

Equality and inequality are relationships between mathematical objects. Their properties tell us which transformations preserve those relationships.

Equality and inequality at a glance
Relationship Meaning Central transformation rule
\(a=b\) \(a\) and \(b\) have the same value or denote the same object Apply the same valid operation or function to both sides
\(a<b\) or \(a>b\) One ordered value is less than or greater than another Preserve direction under increasing transformations; reverse it under decreasing ones

The most famous difference appears when multiplying or dividing by a negative number: equality remains equality, but an inequality reverses direction.

The Symbols Describe Relationships

An equals sign does not mean “the answer comes next.” It states that the expressions on its two sides have the same value. An inequality sign compares values within an ordered system.

Basic comparison symbols
Symbol Read as Example
\(=\) is equal to \(3+4=7\)
\(\ne\) is not equal to \(2^3\ne3^2\)
\(<\) is less than \(-2<5\)
\(>\) is greater than \(9>6\)
\(\le\) is less than or equal to \(x\le10\)
\(\ge\) is greater than or equal to \(y\ge0\)

Foundational Properties of Equality

Equality behaves consistently through several foundational properties.

Core equality properties
Property Pattern Meaning
Reflexive \(a=a\) Every object is equal to itself
Symmetric If \(a=b\), then \(b=a\) An equality can be read in either direction
Transitive If \(a=b\) and \(b=c\), then \(a=c\) Equal objects linked through a common value are equal to one another
Substitution If \(a=b\), either may replace the other in a valid context Equal quantities are interchangeable without changing value

These properties make equality an equivalence relation. They support algebraic replacement, proof, definition, and classification.

The Substitution Property of Equality

If two expressions are equal, one may replace the other wherever the replacement is defined and type-appropriate. If

\[ x=4, \]

then \(x\) may be replaced by \(4\) in \(3x+2\):

\[ 3x+2=3(4)+2=14. \]

Substitution also works with complete expressions. If \(u=v+1\), then

\[ u^2=(v+1)^2. \]

Parentheses preserve the replacement as one object.

Operations That Preserve Equality

Applying the same valid operation to equal quantities produces equal results.

Operational properties of equality
Property If \(a=b\), then Restriction
Addition \(a+c=b+c\) \(c\) must be compatible with both sides
Subtraction \(a-c=b-c\) \(c\) must be compatible with both sides
Multiplication \(ac=bc\) No sign reversal occurs
Division \(\dfrac ac=\dfrac bc\) \(c\ne0\)

“Do the same thing to both sides” is a useful beginning, provided the operation is defined and does not discard information needed for an equivalent equation.

The Balance Model

An equation can be pictured as a balanced scale. Adding the same mass to both sides, removing the same mass from both sides, or multiplying both loads by the same factor preserves balance.

The model helps explain equations such as

\[ x+7=19. \]

Subtract \(7\) from both sides:

\[ x+7-7=19-7, \qquad x=12. \]

The balance image is helpful, but algebra extends beyond physical weights. Domains, functions, matrices, and transformations require the more general principle of preserving a relationship through valid operations.

Solving a Linear Equation

Solve

\[ 4x-5=23. \]

Add \(5\) to both sides, then divide both sides by \(4\):

\[ \begin{aligned} 4x-5+5&=23+5\\ 4x&=28\\ \frac{4x}{4}&=\frac{28}{4}\\ x&=7. \end{aligned} \]

Check by substitution in the original equation:

\[ 4(7)-5=28-5=23. \]

Equivalent Equations Preserve the Solution Set

Two equations are equivalent when they have the same solutions. Adding or subtracting the same expression on both sides preserves equivalence. Multiplying or dividing both sides by the same nonzero quantity also preserves equivalence.

Some same-operation transformations preserve truth in one direction but can introduce extra candidates. Squaring both sides illustrates the distinction:

\[ x=3\quad\Longrightarrow\quad x^2=9. \]

The reverse implication is not unique:

\[ x^2=9\quad\Longrightarrow\quad x=3\ \text{or}\ x=-3. \]

Squaring can enlarge the candidate set. That is why solutions produced after nonreversible steps must be checked in the original equation.

Applying a Function to Both Sides

If \(a=b\) and a function \(f\) is defined at that value, then

\[ f(a)=f(b). \]

However, recovering \(a=b\) from \(f(a)=f(b)\) requires \(f\) to be one-to-one on the relevant domain. For example,

\[ (-2)^2=2^2 \]

even though \(-2\ne2\). Applying the same function preserves an existing equality, but a non-injective function may lose information.

Inequalities Require an Ordered System

The symbols \(<\), \(>\), \(\le\), and \(\ge\) require a meaningful order. Real numbers have such an order. Ordinary complex numbers do not have a compatible “less than” order of the same kind.

For any real numbers \(a\) and \(b\), exactly one of the following is true:

\[ a<b,\qquad a=b,\qquad a>b. \]

This is the trichotomy property. It partitions each comparison into less than, equal to, or greater than.

Transitivity of Inequality

Ordered comparisons can be chained. If

\[ a<b \quad\text{and}\quad b<c, \]

then

\[ a<c. \]

For example, \(-4<2\) and \(2<9\), so \(-4<9\). The same structure works with \(>\), and compatible mixtures of strict and inclusive inequalities can also be combined carefully.

Addition and Subtraction Preserve Direction

Adding the same real number to both sides of an inequality preserves its direction:

\[ a<b\quad\Longrightarrow\quad a+c<b+c. \]

Subtraction does the same because subtracting \(c\) is adding \(-c\):

\[ a<b\quad\Longrightarrow\quad a-c<b-c. \]

If \(3<8\), then adding \(-10\) gives

\[ -7<-2. \]

Both numbers shift the same distance along the number line, so their left-to-right order remains unchanged.

Positive Multiplication Preserves Direction

Multiplying both sides by a positive real number preserves an inequality:

\[ a<b,\ c>0 \quad\Longrightarrow\quad ac<bc. \]

If \(2<5\), multiplying by \(3\) gives \(6<15\). Positive scaling stretches or compresses distances without reflecting the number line.

Division by a positive number also preserves direction:

\[ a<b,\ c>0 \quad\Longrightarrow\quad \frac ac<\frac bc. \]

Negative Multiplication Reverses Direction

Multiplying both sides by a negative real number reverses the inequality:

\[ a<b,\ c<0 \quad\Longrightarrow\quad ac>bc. \]

Starting with \(2<5\) and multiplying by \(-3\) gives

\[ -6>-15. \]

Multiplication by a negative number reflects values across zero. The value that was farther right becomes farther left, so the comparison reverses.

Division by a negative number reverses direction for the same reason.

Why Equality Does Not Reverse

If \(a=b\), multiplying both sides by \(-1\) gives \(-a=-b\). The sides remain equal because reflecting the same location produces the same reflected location.

If \(a<b\), the two values occupy different locations. Reflection swaps their left-to-right order:

\[ a<b \quad\Longrightarrow\quad -a>-b. \]

The “flip the sign” rule is therefore not a memorized exception. It expresses how an order-reversing transformation acts on the number line.

The Sign of the Multiplier Controls the Result

Multiplying or dividing an inequality by \(c\)
Condition on \(c\) Effect on direction Reason
\(c>0\) Direction stays the same Positive scaling preserves order
\(c<0\) Direction reverses Negative scaling reflects order
\(c=0\) A strict inequality is destroyed Both sides become \(0\); division is undefined
Sign of \(c\) unknown No single conclusion is justified The cases \(c>0\), \(c<0\), and sometimes \(c=0\) must be separated

Solving a Linear Inequality

Solve

\[ -3x+4\le19. \]

Subtract \(4\) from both sides:

\[ -3x\le15. \]

Divide by \(-3\) and reverse the inequality:

\[ x\ge-5. \]

A quick check uses one solution and one nonsolution. The value \(x=0\) satisfies \(4\le19\). The value \(x=-6\) produces \(22\le19\), which is false. This matches \(x\ge-5\).

Variables on Both Sides

Solve

\[ 5x-2>2x+10. \]

Subtract \(2x\) and add \(2\):

\[ 3x>12. \]

Divide by positive \(3\), so the direction stays the same:

\[ x>4. \]

Collecting variable terms on either side is valid. Choosing a route that leaves a positive coefficient often reduces sign errors.

Compound Inequalities

A chain such as

\[ 2<x\le8 \]

means \(2<x\) and \(x\le8\). The same valid addition or subtraction may be applied to all three parts:

\[ 2<x\le8 \quad\Longrightarrow\quad 5<x+3\le11. \]

If all parts are multiplied by a negative number, both comparison symbols reverse:

\[ 2<x\le8 \quad\Longrightarrow\quad -2>-x\ge-8. \]

Reordering the chain from least to greatest gives \(-8\le-x<-2\).

From Inequalities to Interval Notation

Inequalities can describe sets of real numbers. Interval notation packages the same information.

Equivalent inequality and interval forms
Inequality Interval Endpoint meaning
\(x<4\) \((-\infty,4)\) \(4\) is excluded
\(x\le4\) \((-\infty,4]\) \(4\) is included
\(2<x<8\) \((2,8)\) Both endpoints are excluded
\(2<x\le8\) \((2,8]\) \(2\) is excluded and \(8\) is included
\(x\ge-3\) \([-3,\infty)\) \(-3\) is included

Infinity is not an endpoint that can be included, so interval notation always uses a parenthesis beside \(\infty\) or \(-\infty\).

All Real Numbers or No Solution

Simplification may eliminate the variable. The remaining statement tells us whether every permitted value works or none do.

For

\[ 2(x+3)<2x+7, \]

distribution gives \(2x+6<2x+7\), then \(6<7\). This is always true, so every real \(x\) is a solution.

For

\[ 2(x+3)>2x+7, \]

simplification gives \(6>7\), which is false. There is no solution.

Reciprocals and Order

Taking reciprocals reverses order when two nonzero real numbers have the same sign. For positive values,

\[ 0<a<b \quad\Longrightarrow\quad \frac1a>\frac1b. \]

For example, \(2<5\), but \(1/2>1/5\).

Do not apply this rule blindly across zero. Although \(-2<3\), it is also true that \(-1/2<1/3\). The reciprocal function is decreasing on each interval \((-\infty,0)\) and \((0,\infty)\), but its discontinuity at zero separates those intervals.

Squaring Does Not Preserve Every Inequality

The squaring function is increasing on nonnegative numbers but not across all real numbers. From

\[ -3<2, \]

we obtain

\[ 9>4 \]

after squaring. The direction did not stay the same.

If \(0\le a<b\), then \(a^2<b^2\). If both numbers are negative, squaring reverses their order. When signs are unknown, split into cases or use a method that tracks the domain carefully.

Increasing and Decreasing Functions Generalize the Rule

If \(f\) is increasing on a relevant interval, then

\[ a<b\quad\Longrightarrow\quad f(a)<f(b). \]

If \(f\) is decreasing, then

\[ a<b\quad\Longrightarrow\quad f(a)>f(b). \]

Multiplication by a positive constant is increasing. Multiplication by a negative constant is decreasing. The familiar sign-reversal rule is therefore one instance of a larger principle about order-preserving and order-reversing functions.

Absolute-Value Inequalities

Absolute value measures distance from zero. For \(r>0\),

\[ |x|<r \quad\Longleftrightarrow\quad -r<x<r. \]

The values lie within \(r\) units of zero. By contrast,

\[ |x|>r \quad\Longleftrightarrow\quad x<-r\ \text{or}\ x>r. \]

Those values lie more than \(r\) units from zero. Inclusive versions use \(\le\) or \(\ge\) and include the boundary points.

Domain Restrictions Come Before Algebraic Cancellation

A transformation may simplify an expression while leaving an original restriction in place:

\[ \frac{x^2-1}{x-1} =\frac{(x-1)(x+1)}{x-1} =x+1, \qquad x\ne1. \]

The simplified formula \(x+1\) is defined at \(x=1\), but the original fraction is not. Equality of formulas on a restricted domain does not erase the restriction.

Similar care is required when multiplying inequalities by expressions whose sign may vary or denominators that may be zero.

Inequalities Model Practical Constraints

Suppose a delivery service charges a fixed fee of \(\$12\) plus \(\$3\) per package, and a customer can spend at most \(\$60\). If \(p\) is the number of packages,

\[ 12+3p\le60. \]

Solving gives

\[ 3p\le48, \qquad p\le16. \]

The context also requires \(p\) to be a nonnegative whole number. Algebra supplies the numerical bound; the model supplies the meaningful domain.

Exact Relations and Measured Values

Equality can be exact, defined, or approximate. A measured length reported as \(8.2\text{ cm}\) usually represents a range determined by instrument precision, not a perfectly exact mathematical value.

Use \(=\) for exact equality and \(\approx\) for approximation:

\[ \frac13=0.\overline3, \qquad \frac13\approx0.333. \]

Rounding during a multi-step inequality calculation can move a value across a boundary. Retain exact values or sufficient precision until the final decision whenever the endpoint matters.

Write Chains That Remain True

Every link in a chain must support the relation written between it and the next expression:

\[ 2+3=5<8<10. \]

This chain is valid: \(2+3=5\), \(5<8\), and \(8<10\).

Avoid using equals signs merely to mean “then I did another step.” For example,

\[ 3+4=7\times2=14 \]

falsely claims \(7=14\). A calculation must preserve the stated relationship at every link.

Checking Equations and Inequalities

An equation solution can usually be checked by direct substitution. An inequality solution is a set, so use three checks:

  1. Interior check: test a value claimed to be in the solution set.
  2. Exterior check: test a nearby value claimed to be outside it.
  3. Boundary check: determine whether each endpoint should be included.

These checks catch direction reversals, arithmetic errors, and incorrect open or closed endpoints.

A Reliable Transformation Routine

  1. Identify the relationship. Is it equality, strict inequality, inclusive inequality, or approximation?
  2. Record the domain. Note zero restrictions, sign conditions, units, and permitted object types.
  3. Simplify each expression carefully. Use valid operation and distribution rules.
  4. Apply the same valid transformation. For inequalities, determine whether it preserves or reverses order.
  5. Keep the solution set in view. Watch for lost solutions, extraneous candidates, and excluded endpoints.
  6. Translate the result. Use words, interval notation, a graph, or contextual restrictions as appropriate.
  7. Check against the original relation.

Common Confusions

Does the equals sign mean “calculate”?

No. It states that the objects or values on its two sides are equal.

Why can equal expressions replace one another?

The substitution property of equality permits one equal object to replace another in any context where the replacement is defined and appropriate.

Does multiplying an equation by a negative number reverse equality?

No. Equal values remain equal. Only an ordered inequality reverses direction under negative scaling.

When must an inequality sign reverse?

Reverse it when multiplying or dividing both sides by a negative quantity, or more generally when applying a decreasing function under valid domain conditions.

Can I multiply an inequality by a variable?

Only after determining its sign. A positive multiplier preserves direction, a negative multiplier reverses it, and zero can destroy a strict comparison.

Does squaring both sides produce an equivalent equation?

Not always. Squaring preserves an existing equality but may introduce extra candidates because opposite numbers have the same square.

What is the difference between \(x<4\) and \(x\le4\)?

The first excludes \(4\); the second includes it.

Can infinity be included as an interval endpoint?

No. Infinity is not a real endpoint, so it always receives a parenthesis in interval notation.

Can cancellation remove an original domain restriction?

No. A simplified expression must retain restrictions inherited from the original expression.

How can I quickly check an inequality solution?

Test an interior point, an exterior point, and each boundary. This checks direction and endpoint inclusion.

Working Summary

Equality preserves sameness; inequality preserves or reverses order according to the transformation used. Reflexivity, symmetry, transitivity, and substitution provide the logical foundation of equality.

Adding or subtracting the same real number preserves an inequality. Multiplication or division by a positive number preserves direction, while multiplication or division by a negative number reverses it. An unknown sign requires cases.

Equivalent transformations must preserve the solution set and respect the domain. Squaring, reciprocals, cancellation, rounding, and other nonlinear steps demand additional care. Check equations in the original statement and check inequality sets with interior, exterior, and boundary values.
