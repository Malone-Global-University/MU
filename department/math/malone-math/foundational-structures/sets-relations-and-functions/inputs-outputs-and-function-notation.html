Inputs, Outputs, and Function Notation

Function notation gives us a compact way to describe what a function does to an input and which output it produces. Once the notation becomes comfortable, formulas, tables, graphs, and mappings begin to speak the same language.

Reading a Function as an Input-Output Rule

Suppose

\[ f(x)=2x+3. \]

The symbol \(x\) represents an input. The expression \(2x+3\) tells us how the function produces its output.

If the input is \(4\), then

\[ f(4)=2(4)+3=11. \]

So the mapping is

\[ 4\mapsto11. \]

The ordered pair

\[ (4,11) \]

belongs to the function.

These are three ways of describing the same relationship:

\[ \boxed{ f(4)=11 \quad\Longleftrightarrow\quad 4\mapsto11 \quad\Longleftrightarrow\quad (4,11)\in f } \]

Inputs and Outputs

A function maps each allowed input to exactly one output.

\[ \text{input} \longmapsto \text{output} \]

If

\[ f(5)=12, \]

then \(5\) is the input and \(12\) is the output.

The notation tells us that the function named \(f\) sends \(5\) to \(12\).

Inputs Come from the Domain

Only values in the function's domain are valid inputs.

If the domain is

\[ [0,\infty), \]

then a negative input such as \(-3\) is not allowed.

Outputs Form the Range

As valid inputs are evaluated, the outputs that actually occur form the function's range.

Thus the input-output picture is set-theoretic:

\[ \boxed{ \text{domain} \longrightarrow \text{function} \longrightarrow \text{range} } \]

Reading Function Notation

The notation

\[ f(x) \]

is read as

“\(f\) of \(x\).”

It means the output of function \(f\) when the input is \(x\).

If

\[ f(x)=3x-1, \]

then the right-hand side gives the rule for producing the output.

\(f(x)\) Is Not Multiplication

The expression

\[ f(x) \]

does not mean

\[ f\cdot x. \]

The letter \(f\) names the function, while the parentheses indicate the input being supplied to that function.

Functions Can Have Other Names

There is nothing special about the letter \(f\).

We might write

\[ g(x),\qquad h(t),\qquad P(n),\qquad C(q). \]

The function name and input variable should match the meaning of the problem whenever practical.

Evaluating Numerical Inputs

To evaluate a function, replace the input variable everywhere it appears in the rule.

Suppose

\[ f(x)=4x+7. \]

To find \(f(3)\), substitute \(3\) for \(x\):

\[ f(3)=4(3)+7. \] \[ f(3)=12+7. \] \[ \boxed{f(3)=19}. \]

The notation has changed from \(f(x)\) to \(f(3)\) because the general input \(x\) has been replaced by the specific input \(3\).

Negative Inputs

Negative inputs require careful substitution, especially when powers are involved.

Suppose

\[ g(x)=x^2+2x-5. \]

Find \(g(-3)\).

Substitute \(-3\) everywhere \(x\) appears:

\[ g(-3) = (-3)^2+2(-3)-5. \] \[ g(-3)=9-6-5. \] \[ \boxed{g(-3)=-2}. \]

Use Parentheses

Writing

\[ (-3)^2 \]

makes clear that the entire negative number is being squared.

This is safer than mentally replacing \(x\) without preserving the original grouping.

Evaluating Expression Inputs

An input does not have to be a single number.

A function can be evaluated at an expression.

Suppose

\[ f(x)=2x^2-3. \]

Then

\[ f(t+1) \]

means substitute the entire expression \(t+1\) for \(x\):

\[ f(t+1) = 2(t+1)^2-3. \]

Expand:

\[ f(t+1) = 2(t^2+2t+1)-3. \] \[ f(t+1) = 2t^2+4t+2-3. \] \[ \boxed{f(t+1)=2t^2+4t-1}. \]

The Whole Input Replaces the Variable

This is one of the most important habits in function work:

\[ \boxed{ x \longrightarrow \text{entire supplied input} } \]

If the input is \(a-2\), every occurrence of \(x\) becomes \(a-2\).

The Input Variable Is a Placeholder

The variable inside a function rule is a placeholder for an input.

For example,

\[ f(x)=x^2+1 \]

and

\[ f(t)=t^2+1 \]

describe the same rule if the domain and mapping are otherwise the same.

The letters \(x\) and \(t\) are not what make the function what it is.

The important structure is

\[ \text{input}\mapsto\text{input}^2+1. \]

Why This Matters

Later, functions will be composed, transformed, differentiated, and applied to expressions. Seeing the input variable as a placeholder keeps the notation flexible rather than tying the function to one particular letter.

Function Notation from Tables

A function table gives input-output pairs directly.

\(x\) \(f(x)\)
\(-2\) \(5\)
\(0\) \(1\)
\(3\) \(7\)
\(4\) \(9\)

From the table, we can read

\[ f(-2)=5, \] \[ f(0)=1, \] \[ f(3)=7, \]

and

\[ f(4)=9. \]

No formula is required. Function notation describes the mapping itself, not only formulas.

Function Notation from Ordered Pairs

Suppose

\[ f=\{(1,4),(2,7),(5,7),(8,10)\}. \]

Each ordered pair

\[ (x,y) \]

can be read as

\[ f(x)=y. \]

Therefore,

\[ f(1)=4, \] \[ f(2)=7, \] \[ f(5)=7, \]

and

\[ f(8)=10. \]

Notice that

\[ f(2)=f(5)=7. \]

That is allowed. Different inputs may share an output.

Working Backward from an Output

Sometimes the output is known and the input must be found.

Suppose

\[ f(x)=3x+2 \]

and we are told

\[ f(x)=20. \]

Since

\[ f(x)=3x+2, \]

set

\[ 3x+2=20. \]

Then

\[ 3x=18 \]

and

\[ \boxed{x=6}. \]

One Output May Correspond to More Than One Input

Suppose

\[ g(x)=x^2 \]

and

\[ g(x)=9. \]

Then

\[ x^2=9, \]

so

\[ x=3 \quad\text{or}\quad x=-3. \]

This does not violate the function definition. Each input still has exactly one output.

It simply means that two different inputs produce the same output.

Functions with More Than One Input

Functions are not limited to one input variable.

For example,

\[ A(\ell,w)=\ell w \]

could give the area of a rectangle from its length and width.

The input is now an ordered pair:

\[ (\ell,w). \]

For example,

\[ A(5,8)=5\cdot8=40. \]

So

\[ (5,8)\mapsto40. \]

This extends the same mapping idea:

\[ \text{input object} \longmapsto \text{exactly one output}. \]

Later, functions of several variables will become important in geometry, statistics, economics, physics, and multivariable analysis.

Interpreting Function Notation in Context

Function notation becomes especially useful when the letters describe real quantities.

Cost

Suppose

\[ C(q)=12q+50, \]

where \(q\) is the number of units produced and \(C(q)\) is total cost in dollars.

Then

\[ C(100)=1250 \]

means:

The cost of producing \(100\) units is \$1,250.

Distance

Suppose

\[ d(t)=60t, \]

where \(t\) is time in hours and \(d(t)\) is distance in miles.

Then

\[ d(2.5)=150 \]

means that after \(2.5\) hours, the distance traveled is \(150\) miles.

Temperature

Suppose

\[ F(C)=\frac95C+32. \]

Then

\[ F(0)=32 \]

means that \(0^\circ\text{C}\) corresponds to \(32^\circ\text{F}\).

Good function notation keeps track not only of numbers but of what those numbers mean.

Worked Examples

Example 1: Direct Evaluation

Let

\[ f(x)=5x-4. \]

Find \(f(6)\).

\[ f(6)=5(6)-4=30-4=26. \] \[ \boxed{f(6)=26}. \]

Example 2: Negative Input

Let

\[ g(x)=x^2-2x+1. \]

Find \(g(-2)\).

\[ g(-2)=(-2)^2-2(-2)+1. \] \[ g(-2)=4+4+1=9. \] \[ \boxed{g(-2)=9}. \]

Example 3: Expression Input

Let

\[ h(x)=x+4. \]

Find \(h(2t)\).

\[ h(2t)=2t+4. \]

Example 4: More Complicated Expression Input

Let

\[ p(x)=x^2+2x. \]

Find \(p(a-1)\).

\[ p(a-1) = (a-1)^2+2(a-1). \] \[ p(a-1) = a^2-2a+1+2a-2. \] \[ \boxed{p(a-1)=a^2-1}. \]

Example 5: Solve for the Input

Let

\[ f(x)=7x-3. \]

Find \(x\) if

\[ f(x)=32. \] \[ 7x-3=32. \] \[ 7x=35. \] \[ \boxed{x=5}. \]

Example 6: Read from Ordered Pairs

Let

\[ f=\{(2,8),(4,10),(6,8)\}. \]

Then

\[ f(2)=8, \qquad f(4)=10, \qquad f(6)=8. \]

Two different inputs, \(2\) and \(6\), share the same output.

Common Errors

1. Treating \(f(x)\) as Multiplication

The notation

\[ f(x) \]

means the output of function \(f\) at input \(x\).

2. Substituting into Only One Occurrence of the Variable

Every occurrence of the input variable must be replaced.

If

\[ f(x)=x^2+3x, \]

then

\[ f(2)=2^2+3(2), \]

not \(2^2+3x\).

3. Dropping Parentheses around Negative Inputs

For

\[ f(x)=x^2, \]

the correct substitution is

\[ f(-3)=(-3)^2=9. \]

4. Replacing Only Part of an Expression Input

If the input is \(t+1\), then the entire quantity \(t+1\) replaces every \(x\).

5. Assuming One Output Means One Input

A function may send several inputs to the same output.

For

\[ f(x)=x^2, \]

both

\[ f(3)=9 \]

and

\[ f(-3)=9. \]

6. Ignoring Units or Meaning

In applied functions, an expression such as

\[ C(20)=350 \]

should be interpreted in context, including units.

Practice

Evaluate the Function

Let

\[ f(x)=3x^2-2x+1. \]

Find:

  1. \(f(0)\)
  2. \(f(2)\)
  3. \(f(-1)\)
Check Answers
  1. \[ f(0)=1. \]
  2. \[ f(2)=3(4)-4+1=9. \]
  3. \[ f(-1)=3(1)+2+1=6. \]

Expression Input

Let

\[ g(x)=2x+5. \]

Find \(g(t-3)\).

Check Answer \[ g(t-3)=2(t-3)+5. \] \[ g(t-3)=2t-6+5. \] \[ \boxed{g(t-3)=2t-1}. \]

Read the Table

\(x\) \(h(x)\)
\(1\) \(4\)
\(3\) \(8\)
\(5\) \(12\)

Find:

  1. \(h(1)\)
  2. \(h(3)\)
  3. \(h(5)\)
Check Answers \[ h(1)=4, \qquad h(3)=8, \qquad h(5)=12. \]

Work Backward

Let

\[ p(x)=4x+1. \]

Find \(x\) if

\[ p(x)=29. \]
Check Answer \[ 4x+1=29. \] \[ 4x=28. \] \[ \boxed{x=7}. \]

Interpret the Meaning

Suppose

\[ R(t)=75t \]

gives revenue in dollars after selling \(t\) tickets.

Interpret

\[ R(40)=3000. \]
Check Answer

Selling \(40\) tickets produces revenue of

\[ \boxed{\$3{,}000}. \]

The Deeper Idea

Function notation compresses several mathematical ideas into one expression.

When we write

\[ f(a)=b, \]

we are saying all of the following:

  • \(a\) is an allowed input,
  • \(b\) is the unique output assigned to \(a\),
  • \((a,b)\) belongs to the function as a relation,
  • and \(a\mapsto b\) describes the corresponding mapping.

So function notation links the earlier set-theoretic language directly to algebra:

\[ \boxed{ (a,b) \longleftrightarrow a\mapsto b \longleftrightarrow f(a)=b } \]

Once these forms feel interchangeable, later work with composition, inverses, transformations, sequences, and multivariable functions becomes much easier.

Summary

  • A function maps each allowed input to exactly one output.
  • The notation \[ f(x) \] means the output of function \(f\) at input \(x\).
  • The statement \[ f(a)=b \] is equivalent to the mapping \[ a\mapsto b. \]
  • It also corresponds to the ordered pair \[ (a,b) \] belonging to the function.
  • To evaluate a function, substitute the entire supplied input for every occurrence of the input variable.
  • Use parentheses carefully with negative or compound inputs.
  • The input variable is a placeholder and can often be renamed without changing the underlying rule.
  • Function notation can be read from formulas, tables, ordered pairs, mappings, and graphs.
  • Working backward from an output means solving an equation such as \[ f(x)=k. \]
  • Several inputs may produce the same output.
  • Functions can also accept ordered pairs or other structured objects as inputs.
  • In practical applications, function notation should be interpreted together with the meaning and units of the variables.

Function notation is compact because it carries a great deal of structure. Once you can move comfortably among \(f(a)=b\), \(a\mapsto b\), and \((a,b)\), the language of functions becomes much more natural.
