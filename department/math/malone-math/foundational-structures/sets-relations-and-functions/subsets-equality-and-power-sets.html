Subsets, Equality, and Power Sets

Once we know which objects belong to a set, the next question is how entire sets relate to one another. Subsets give us the language for one collection being contained inside another.

From Elements to Collections

In the previous lesson, we asked questions such as

\[ 3\in A. \]

That compares an object with a set.

Now suppose

\[ A=\{1,2,3,4,5\} \]

and

\[ B=\{2,4\}. \]

Every element of \(B\) is also an element of \(A\). We therefore say that \(B\) is a subset of \(A\).

\[ B\subseteq A. \]

This introduces a new kind of relationship:

\[ \boxed{\text{set compared with set}} \]

That distinction matters. Membership and subset relationships are closely related, but they do different jobs.

What Is a Subset?

Let \(A\) and \(B\) be sets.

We say that \(A\) is a subset of \(B\) when every element of \(A\) is also an element of \(B\).

\[ A\subseteq B. \]

This can be stated precisely as:

\[ A\subseteq B \quad\text{if every }x\in A\text{ also satisfies }x\in B. \]

For example, let

\[ A=\{1,3\} \]

and

\[ B=\{1,2,3,4\}. \]

The elements of \(A\) are \(1\) and \(3\). Both occur in \(B\). Therefore,

\[ A\subseteq B. \]

A Simple Subset Test

To determine whether

\[ A\subseteq B, \]

ask:

Can I find any element of \(A\) that is missing from \(B\)?

If the answer is no, then \(A\subseteq B\).

If even one element of \(A\) is absent from \(B\), then \(A\) is not a subset of \(B\).

For example,

\[ \{1,5\}\nsubseteq\{1,2,3,4\} \]

because \(5\) belongs to the first set but not the second.

Membership versus Subset

This is one of the most important notation distinctions in elementary set theory.

Let

\[ A=\{1,2,3\}. \]

Then

\[ 2\in A \]

because the number \(2\) is an element of \(A\).

But

\[ \{2\}\subseteq A \]

because every element of the set \(\{2\}\) is also an element of \(A\).

Compare the two:

\[ 2\in A \]

means

“The object \(2\) belongs to \(A\).”

while

\[ \{2\}\subseteq A \]

means

“The set \(\{2\}\) is contained within \(A\).”

A useful mental check is:

\[ \boxed{\in\text{ compares an element with a set}} \] \[ \boxed{\subseteq\text{ compares a set with a set}} \]

Nested Sets Can Change the Answer

Suppose instead that

\[ B=\{1,\{2\},3\}. \]

Now

\[ \{2\}\in B. \]

The set \(\{2\}\) itself appears as an element of \(B\).

But

\[ 2\notin B. \]

The braces matter because they tell us what the actual mathematical object is.

Set Equality

Two sets are equal when they contain exactly the same elements.

If

\[ A=\{1,2,3\} \]

and

\[ B=\{3,1,2\}, \]

then

\[ A=B. \]

Order does not matter in a set.

Likewise,

\[ \{1,1,2,3,3\}=\{1,2,3\}. \]

Repeating an element does not change the set.

Equality through Subsets

There is a powerful way to characterize set equality:

\[ A=B \]

exactly when

\[ A\subseteq B \]

and

\[ B\subseteq A. \]

In words, if every element of \(A\) belongs to \(B\), and every element of \(B\) belongs to \(A\), then the two sets must contain exactly the same elements.

\[ \boxed{ A=B \iff A\subseteq B \text{ and } B\subseteq A } \]

The symbol \(\iff\) means “if and only if.”

We will encounter this style of reasoning repeatedly in mathematics: instead of comparing complicated objects all at once, we prove that each one is contained in the other.

Proper Subsets

Sometimes one set is contained inside another but is not equal to it.

For example,

\[ A=\{1,2\} \]

and

\[ B=\{1,2,3\}. \]

We have

\[ A\subseteq B, \]

but

\[ A\neq B. \]

In this case, \(A\) is called a proper subset of \(B\). We will write

\[ A\subsetneq B. \]

The notation \(\subsetneq\) tells us both that

\[ A\subseteq B \]

and that

\[ A\neq B. \]

Why Use \(\subsetneq\)?

Some textbooks use \(\subset\) for proper subset, while others use it more loosely for subset. To avoid ambiguity, Malone Math will use

\[ \subseteq \]

for ordinary subset and

\[ \subsetneq \]

when we specifically mean a proper subset.

The Empty Set as a Subset

The empty set,

\[ \varnothing, \]

contains no elements.

An important result is:

\[ \boxed{\varnothing\subseteq A} \]

for every set \(A\).

At first this can feel strange. How can a set containing nothing be inside every set?

Remember the definition of subset:

Every element of the first set must also belong to the second set.

But the empty set has no elements that can violate this condition. There is nothing in \(\varnothing\) that fails to belong to \(A\).

Therefore,

\[ \varnothing\subseteq A \]

for every possible set \(A\).

A Logical View

This is an early example of what is sometimes called vacuous truth.

The statement

“Every element of the empty set belongs to \(A\)”

is true because there are no counterexamples.

We do not need to explore formal logic deeply yet, but this connection will be useful later.

Every Set Is a Subset of Itself

For any set \(A\),

\[ A\subseteq A. \]

Why?

Because every element of \(A\) is certainly an element of \(A\).

Therefore, for any set \(A\), we automatically know two subsets:

\[ \varnothing \]

and

\[ A. \]

These are sometimes called the improper subsets of \(A\), while the remaining subsets are proper subsets.

Power Sets

Now we can take a major conceptual step.

Instead of asking whether one particular set is a subset of another, we can collect all possible subsets of a set into a new set.

This new collection is called the power set.

The power set of \(A\) is written

\[ \mathcal{P}(A). \]

Let

\[ A=\{a,b\}. \]

The subsets of \(A\) are

\[ \varnothing, \qquad \{a\}, \qquad \{b\}, \qquad \{a,b\}. \]

Therefore,

\[ \mathcal{P}(A) = \{ \varnothing, \{a\}, \{b\}, \{a,b\} \}. \]

Notice the Levels of Braces

The elements of \(\mathcal{P}(A)\) are themselves sets.

For example,

\[ \{a\}\in\mathcal{P}(A). \]

That statement is true because \(\{a\}\) is one of the subsets of \(A\).

At the same time,

\[ a\notin\mathcal{P}(A) \]

because \(a\) itself is not a subset of \(A\). The set \(\{a\}\) is.

Power sets are an excellent place to practice distinguishing membership from subset relationships.

Counting Subsets

Suppose a set contains \(n\) elements.

For every element, we have exactly two choices when building a subset:

  • include the element, or
  • do not include the element.

If the set contains one element, there are

\[ 2 \]

possible subsets.

If it contains two elements, there are

\[ 2\cdot2=2^2=4 \]

possible subsets.

If it contains three elements, there are

\[ 2\cdot2\cdot2=2^3=8. \]

In general, if

\[ |A|=n, \]

then

\[ \boxed{|\mathcal{P}(A)|=2^n}. \]

Here \(|A|\) means the cardinality of \(A\): the number of elements in the set.

Example

Let

\[ A=\{a,b,c\}. \]

Because

\[ |A|=3, \]

the number of subsets is

\[ 2^3=8. \]

Indeed,

\[ \mathcal{P}(A) = \{ \varnothing, \{a\}, \{b\}, \{c\}, \{a,b\}, \{a,c\}, \{b,c\}, \{a,b,c\} \}. \]

The Binary Connection

There is a useful connection hiding inside the formula \(2^n\).

For each element, we make a yes-or-no decision:

\[ \text{include}=1, \qquad \text{exclude}=0. \]

For the set

\[ \{a,b,c\}, \]

a choice such as

\[ 101 \]

could mean:

  • include \(a\),
  • exclude \(b\),
  • include \(c\).

That binary pattern corresponds to the subset

\[ \{a,c\}. \]

So power sets connect naturally with binary strings, combinatorics, digital logic, and computer science.

Why Subsets Matter

Subsets are not merely an exercise in arranging braces. They model a very common question:

Which selections can be made from a larger collection?

Permissions

Suppose a software system has three optional permissions:

\[ P=\{\text{read},\text{write},\text{delete}\}. \]

Any particular user's permission package is a subset of \(P\).

The power set \(\mathcal{P}(P)\) describes every possible combination of permissions.

Feature Selection

If a product has optional features

\[ F=\{\text{GPS},\text{camera},\text{Bluetooth}\}, \]

each possible configuration corresponds to a subset of \(F\).

There are

\[ 2^3=8 \]

possible feature combinations.

Probability

If a sample space is

\[ \Omega=\{1,2,3,4,5,6\}, \]

then an event such as

\[ E=\{2,4,6\} \]

is a subset of the sample space.

\[ E\subseteq\Omega. \]

Probability theory therefore uses subsets constantly: events are collections of possible outcomes.

Solutions and Domains

A solution set is normally a subset of some larger number system. For example,

\[ S=\{-2,2\} \]

is a subset of the real numbers:

\[ S\subseteq\mathbb{R}. \]

Likewise, the domain of a function may be a particular subset of \(\mathbb{R}\), \(\mathbb{Z}\), or some other set.

Worked Examples

Example 1: Testing a Subset

Let

\[ A=\{2,4\} \]

and

\[ B=\{1,2,3,4,5\}. \]

Every element of \(A\) appears in \(B\), so

\[ A\subseteq B. \]

Because \(A\neq B\), we can say more specifically

\[ A\subsetneq B. \]

Example 2: Finding a Failed Subset

Let

\[ C=\{1,3,6\} \]

and

\[ D=\{1,2,3,4,5\}. \]

The number \(6\) belongs to \(C\), but

\[ 6\notin D. \]

Therefore,

\[ C\nsubseteq D. \]

Only one missing element is needed to show that a subset relationship fails.

Example 3: Proving Equality

Suppose

\[ A=\{x\in\mathbb{Z}\mid 1\leq x\leq3\} \]

and

\[ B=\{1,2,3\}. \]

Every member of \(A\) belongs to \(B\), so

\[ A\subseteq B. \]

Every member of \(B\) also satisfies the rule defining \(A\), so

\[ B\subseteq A. \]

Therefore,

\[ A=B. \]

Example 4: Constructing a Power Set

Let

\[ A=\{x,y\}. \]

Start with the empty selection:

\[ \varnothing. \]

Add the one-element selections:

\[ \{x\}, \qquad \{y\}. \]

Add the selection containing both elements:

\[ \{x,y\}. \]

Therefore,

\[ \mathcal{P}(A) = \{ \varnothing, \{x\}, \{y\}, \{x,y\} \}. \]

Example 5: Counting without Listing

A set contains \(7\) elements. How many subsets does it have?

Use

\[ |\mathcal{P}(A)|=2^{|A|}. \]

Therefore,

\[ 2^7=128. \]

The set has

\[ \boxed{128} \]

different subsets.

Common Errors

1. Confusing \(\in\) with \(\subseteq\)

If

\[ A=\{1,2,3\}, \]

then

\[ 2\in A \]

but

\[ \{2\}\subseteq A. \]

The first compares an element with a set. The second compares two sets.

2. Forgetting the Empty Set

When listing all subsets of a set, always include

\[ \varnothing. \]

The empty set is a subset of every set.

3. Forgetting the Whole Set

Every set is a subset of itself:

\[ A\subseteq A. \]

Therefore \(A\) itself must appear in \(\mathcal{P}(A)\).

4. Confusing a Power Set with the Original Set

If

\[ A=\{1,2\}, \]

then

\[ \mathcal{P}(A) = \{ \varnothing, \{1\}, \{2\}, \{1,2\} \}. \]

The power set contains sets as its elements.

5. Assuming a Proper Subset Can Equal the Original Set

If

\[ A\subsetneq B, \]

then necessarily

\[ A\neq B. \]

If the sets are equal, the relationship is a subset relationship but not a proper-subset relationship.

Practice

Let

\[ A=\{1,2,3,4\}. \]

Determine whether each statement is true or false.

  1. \(\{1,3\}\subseteq A\)
  2. \(\{1,5\}\subseteq A\)
  3. \(2\in A\)
  4. \(\{2\}\in A\)
  5. \(\varnothing\subseteq A\)
  6. \(A\subseteq A\)
  7. \(\{1,2\}\subsetneq A\)
Check Answers
  1. True: \[ \{1,3\}\subseteq A. \]
  2. False, because \[ 5\notin A. \]
  3. True: \[ 2\in A. \]
  4. False. The number \(2\) is an element of \(A\), but the set \(\{2\}\) is not an element of \(A\).
  5. True. The empty set is a subset of every set.
  6. True. Every set is a subset of itself.
  7. True. Both \(1\) and \(2\) belong to \(A\), and \[ \{1,2\}\neq A. \]

Power Set Practice

Find the power set of

\[ B=\{a,b,c\}. \]
Check Answer \[ \mathcal{P}(B) = \{ \varnothing, \{a\}, \{b\}, \{c\}, \{a,b\}, \{a,c\}, \{b,c\}, \{a,b,c\} \}. \]

There are

\[ 2^3=8 \]

subsets, as expected.

Counting Practice

A system has \(10\) independently selectable options. If every combination of selected options is allowed, how many different selections are possible?

Check Answer

Each option has two possibilities: selected or not selected.

\[ 2^{10}=1024. \]

Therefore there are

\[ \boxed{1024} \]

possible selections.

The Deeper Idea

Membership lets us ask whether an object belongs to a collection.

\[ x\in A \]

Subset language moves one level higher and asks whether an entire collection fits inside another collection.

\[ A\subseteq B. \]

The power set moves one level higher again by collecting all those possible subsets into a new set:

\[ \mathcal{P}(A). \]

So there is a natural progression:

\[ \boxed{ \text{elements} \longrightarrow \text{sets} \longrightarrow \text{sets of subsets} } \]

This ability to organize mathematical objects into layers of structure will become important when we study relations, functions, probability, combinatorics, and more advanced mathematics.

Summary

  • \(A\subseteq B\) means every element of \(A\) is also an element of \(B\).
  • \(A\nsubseteq B\) means at least one element of \(A\) does not belong to \(B\).
  • Membership, \[ x\in A, \] compares an element with a set.
  • Subset notation, \[ A\subseteq B, \] compares one set with another.
  • Two sets are equal exactly when they contain the same elements: \[ A=B \iff A\subseteq B \text{ and } B\subseteq A. \]
  • A proper subset satisfies \[ A\subsetneq B, \] meaning \(A\subseteq B\) but \(A\neq B\).
  • The empty set is a subset of every set: \[ \varnothing\subseteq A. \]
  • Every set is a subset of itself: \[ A\subseteq A. \]
  • The power set \[ \mathcal{P}(A) \] is the set containing every subset of \(A\).
  • If \[ |A|=n, \] then \[ |\mathcal{P}(A)|=2^n. \]

Subsets give us a systematic way to talk about selecting, containing, and organizing mathematical objects. That language will become especially important as we begin building relations and functions from sets.
