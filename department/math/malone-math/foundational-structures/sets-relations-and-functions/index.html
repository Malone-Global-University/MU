1.6 Sets, Relations, and Functions

Organizing mathematical objects into collections, describing relationships among them, and developing functions as structured mappings between sets.

Organizing Mathematical Relationships

Sets provide one of mathematics' most general ways to organize objects. A set may contain numbers, points, functions, geometric figures, outcomes, matrices, or almost any other mathematical objects. Once collections have been defined, we can compare them, combine them, count them, and study relationships among their elements.

Relations extend this organizational structure by specifying which objects are connected to which others. Functions form an especially important class of relations because they associate every allowable input with exactly one output. This simple requirement becomes one of the central organizing ideas of mathematics.

This section develops sets, relations, and functions as connected structures. Students begin with membership and set operations, build ordered pairs and Cartesian products, examine general relations, and then develop functions, function notation, mappings, inverses, composition, and multiple representations.

Sets as Collections of Mathematical Objects

A set is determined by its members. The elements of a set may be simple objects such as integers or much more complicated objects such as functions, matrices, graphs, or geometric figures.

Set notation gives mathematics a compact way to describe membership and containment. Once sets are available, we can ask whether one collection is contained inside another, whether two sets contain exactly the same elements, or how several sets overlap.

These ideas appear throughout mathematics. Solution sets collect values that satisfy equations, domains collect allowable inputs, probability spaces collect possible outcomes, and geometric sets collect points satisfying specified conditions.

Set Operations Describe Combination and Overlap

Union, intersection, difference, and complement provide standard ways to construct new sets from existing ones. Union gathers elements belonging to one set or another, while intersection keeps only elements shared by both.

Difference removes elements belonging to another set, and complement describes elements outside a specified set relative to an understood universe.

These operations mirror logical ideas introduced earlier. Intersection corresponds closely to satisfying two conditions simultaneously, while union often corresponds to satisfying one condition or another. This connection between set structure and logic will be used repeatedly in inequalities, probability, functions, and solution sets.

Cardinality Measures the Size of Sets

For finite sets, cardinality simply counts the number of elements. Infinite sets require a more structural interpretation because ordinary finite counting never reaches an endpoint.

Two sets can be compared by asking whether their elements can be paired without omission or duplication. This leads to the important idea that infinite sets can sometimes have the same cardinality even when one appears to be contained inside another.

The treatment here is introductory, but it establishes cardinality as a general measure of set size and prepares for later work involving counting, probability, combinatorics, and infinite mathematical structures.

Cartesian Products Create Ordered Structure

A Cartesian product combines two sets by forming every allowable ordered pair whose first coordinate comes from one set and whose second coordinate comes from the other.

Order matters. The pair \((a,b)\) is generally different from \((b,a)\). That distinction makes ordered pairs useful for representing position, input-output relationships, and directed associations.

The Cartesian product therefore provides the structural bridge from sets to coordinate geometry and relations. The Cartesian plane itself can be understood as the product of the real numbers with themselves.

Relations Connect Objects

A relation specifies which objects are associated with which others. In a relation between two sets, the relationship can be represented as a set of ordered pairs.

Relations can describe equality, comparison, divisibility, geometric incidence, family connections, network links, or almost any other meaningful association. Some relations have additional structural properties such as reflexivity, symmetry, antisymmetry, or transitivity.

Studying those properties allows relations to be classified and compared rather than treated merely as arbitrary collections of pairs.

Equivalence Relations Create Classes

An equivalence relation captures a generalized notion of sameness. It is reflexive, symmetric, and transitive, allowing objects to be grouped according to a shared criterion.

Objects within the same equivalence class need not be literally identical. They are treated as equivalent according to the particular relationship being studied. For example, integers may be grouped according to the same remainder modulo a fixed number.

This idea becomes important throughout mathematics because classification often depends on deciding which differences matter and which can be ignored under a chosen notion of equivalence.

Functions Are Special Relations

A function is a relation with a specific assignment rule: every input in its domain must correspond to exactly one output. Different inputs may sometimes produce the same output, but a single input cannot produce two different outputs within the same function.

This definition makes functions much broader than algebraic formulas. A function may be represented by a table, graph, mapping diagram, algorithm, verbal rule, or other process, provided the input-output requirement is satisfied.

Thinking of functions as mappings establishes a foundation that will later support linear, polynomial, exponential, trigonometric, discrete, stochastic, and multivariable functions.

Domain and Range Describe Input and Output Sets

The domain specifies which inputs are allowed. The range identifies which outputs are actually produced.

These sets are part of the definition and interpretation of a relation or function. A formula alone may not completely specify a function if different domains are possible.

Domain restrictions can arise from algebraic structure, physical context, or explicit definition. A denominator cannot be zero, some real radicals require nonnegative inputs, and an applied model may restrict time or distance to values that make sense in context.

Function Notation Records Dependency

Notation such as \(f(x)\) identifies a function and records the output associated with an input \(x\). The notation does not mean multiplication of \(f\) and \(x\); it describes evaluation of a named mapping.

Function notation allows several relationships to be discussed simultaneously without ambiguity. It also makes substitution, composition, inverse relationships, and transformations much easier to express.

Once this notation is familiar, functions can be treated as mathematical objects that can themselves be combined, transformed, compared, and analyzed.

Injective, Surjective, and Bijective Behavior

Functions can be classified according to how their inputs and outputs correspond. An injective function does not send two different inputs to the same output. A surjective function reaches every element of its stated codomain.

A bijective function has both properties. Every input corresponds to one output, every intended output is reached, and no output is shared by distinct inputs.

Bijectivity is especially important because it supports complete reversal. A bijective function has an inverse mapping that returns each output to its unique original input.

Identity, Inverse, and Composition

The identity function maps each allowable object to itself. It is the functional analogue of an identity operation: applying it leaves the input unchanged.

An inverse function reverses a suitable mapping, while composition connects functions sequentially so that the output of one becomes the input of another. These ideas extend the earlier themes of identity, inverses, and composition from arithmetic operations into the language of mappings.

The same structural ideas will later appear in matrices, transformations, algorithms, permutations, and generalized algebra.

Functions Have Many Representations

A function is not the same thing as its formula. The same functional relationship may be represented through a table of values, a graph, a mapping diagram, an equation, a verbal description, or an algorithm.

Each form emphasizes different information. Tables make individual input-output pairs visible, graphs reveal global behavior, formulas support symbolic manipulation, and algorithms show how outputs are generated procedurally.

Learning to move among these representations prepares students for later sections where choosing the most efficient representation becomes an important part of problem solving.

A Foundation for Mathematical Structure

Sets, relations, and functions provide a common organizational language used throughout Malone Math. Sets describe collections, relations describe associations, and functions describe controlled dependencies between inputs and outputs.

These ideas will reappear in nearly every later branch. Algebra studies functions and solution sets, geometry studies sets of points and transformations, discrete mathematics studies relations and mappings on finite structures, probability uses sets of events, and analysis studies functions with increasingly sophisticated forms of behavior.

The purpose of this section is therefore not merely to introduce set notation or function vocabulary. It establishes a structural framework that allows many apparently different mathematical topics to be understood through the same underlying ideas.
