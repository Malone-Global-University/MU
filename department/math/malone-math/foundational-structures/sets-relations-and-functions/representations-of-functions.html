Representations of Functions

A function can be described with words, ordered pairs, a table, a mapping diagram, a formula, or a graph. The representation may change, but the underlying input-output relationship remains the same.

One Function, Many Views

Suppose a function doubles an input and then adds \(1\).

We can describe that function in words:

“Multiply the input by \(2\), then add \(1\).”

We can write a formula:

\[ f(x)=2x+1. \]

We can list ordered pairs:

\[ \{(0,1),(1,3),(2,5),(3,7)\}. \]

We can make a table, draw arrows, or plot points on a graph.

These are not different functions just because they look different. They are different representations of the same mapping.

A major mathematical skill is learning to move comfortably among these forms:

\[ \boxed{ \text{words} \longleftrightarrow \text{pairs} \longleftrightarrow \text{table} \longleftrightarrow \text{mapping} \longleftrightarrow \text{formula} \longleftrightarrow \text{graph} } \]

Verbal Descriptions

A function can be described entirely in words.

For example:

“Take the input, multiply by \(3\), then subtract \(4\).”

This verbal rule corresponds to

\[ f(x)=3x-4. \]

Why Verbal Descriptions Matter

Real problems often begin in language rather than notation.

A business problem may say:

“The company charges a \$25 service fee plus \$8 per hour.”

That statement can be translated into

\[ C(h)=25+8h. \]

The ability to recognize the mathematical structure inside ordinary language is part of modeling.

Ordered Pairs

A function can be represented as a set of ordered pairs.

For example,

\[ f=\{(0,1),(1,3),(2,5),(3,7)\}. \]

Each pair

\[ (x,y) \]

means

\[ f(x)=y. \]

So from the set above,

\[ f(0)=1, \qquad f(1)=3, \qquad f(2)=5, \qquad f(3)=7. \]

Function Condition

A set of ordered pairs represents a function only if no first component is paired with two different second components.

For example,

\[ \{(1,4),(1,7),(2,9)\} \]

does not represent a function because input \(1\) has two different outputs.

Tables

A table organizes ordered pairs into columns.

\(x\) \(f(x)\)
\(0\) \(1\)
\(1\) \(3\)
\(2\) \(5\)
\(3\) \(7\)

Each row is an ordered pair:

\[ (0,1), \quad (1,3), \quad (2,5), \quad (3,7). \]

Patterns Are Easy to See in Tables

Here the input increases by \(1\) each row while the output increases by \(2\).

That suggests a linear rule with slope \(2\).

Since

\[ f(0)=1, \]

the vertical intercept is \(1\), leading to

\[ f(x)=2x+1. \]

Tables are especially useful for detecting numerical patterns.

Mapping Diagrams

A mapping diagram emphasizes the assignment structure between a domain and a codomain.

Mapping diagrams are especially good for seeing

  • whether each input has exactly one output,
  • whether outputs are shared,
  • whether every codomain element is reached,
  • and whether a function is injective, surjective, or bijective.

Formulas and Rules

A formula describes how to compute the output from an input.

For example,

\[ f(x)=2x+1. \]

This compact rule represents infinitely many ordered pairs if the domain is infinite.

For every permitted input \(x\), the corresponding ordered pair is

\[ (x,2x+1). \]

Formulas Are Powerful but Not Always Complete

A formula should be interpreted together with its domain.

For example,

\[ f(x)=x^2 \]

on \(\mathbb{R}\) is not the same mapping as

\[ g(x)=x^2 \]

on \([0,\infty)\).

The rule is identical, but the allowed inputs differ.

Graphs

A graph plots the ordered pairs belonging to a function in the coordinate plane.

For the rule

\[ f(x)=2x+1, \]

the graph is a straight line.

Graphs Reveal Shape and Behavior

A graph can make features immediately visible:

  • increasing or decreasing behavior,
  • intercepts,
  • turning points,
  • gaps or discontinuities,
  • bounded or unbounded behavior,
  • and overall geometric shape.

A graph is especially useful when the global behavior matters more than a single output value.

Translating between Representations

The goal is not merely to recognize each representation separately. The stronger skill is moving from one representation to another.

Formula to Table

Given

\[ f(x)=3x-2, \]

choose input values and evaluate.

\(x\) \(f(x)\)
\(0\) \(-2\)
\(1\) \(1\)
\(2\) \(4\)

Table to Ordered Pairs

Read each row as a pair:

\[ \{(0,-2),(1,1),(2,4)\}. \]

Ordered Pairs to Graph

Plot each ordered pair as a coordinate point.

Words to Formula

“Multiply the input by \(5\), then subtract \(3\)” becomes

\[ f(x)=5x-3. \]

Graph to Table

Read selected points from the graph and record their coordinates.

The information is the same, but each representation makes different features easier to see.

What Each Representation Shows Best

No single representation is always best.

Representation Especially Useful For
Words Meaning, context, and real-world interpretation
Ordered pairs Exact input-output assignments
Table Numerical patterns and selected values
Mapping diagram Function structure, injectivity, surjectivity, and codomain use
Formula Calculation, symbolic manipulation, and general rules
Graph Overall shape, trends, extrema, and geometric behavior

A strong mathematical model often uses several representations together.

For example, a formula may be best for calculation while a graph is best for seeing trends and a verbal description is best for explaining what the quantities mean.

Discrete and Continuous Functions

Some functions are naturally discrete.

Suppose \(C(n)\) gives the cost of purchasing \(n\) whole notebooks.

If fractional notebooks are not allowed, then the practical domain may be

\[ n\in\{0,1,2,3,\ldots\}. \]

A graph of this function should show separate points rather than a continuous line through every real input.

Continuous Example

If \(d(t)\) gives the distance traveled after \(t\) hours, then time may vary continuously:

\[ t\in[0,5]. \]

The graph may contain every point along a curve.

Representation Should Match the Domain

Connecting discrete data points with an unbroken line can falsely suggest that intermediate inputs are allowed.

The visual representation should respect the actual domain of the function.

Reading Domain and Range from Representations

Different representations reveal domain and range in different ways.

Ordered Pairs

Domain comes from first components; range comes from second components.

Tables

The input column gives the domain values shown. The output column gives the range values shown.

Mapping Diagrams

The domain is the source set, while the outputs actually receiving arrows form the range.

Graphs

Read the domain horizontally and the range vertically.

Formulas

Domain and range may require algebraic analysis rather than direct reading.

For example,

\[ f(x)=\frac{1}{x-2} \]

excludes

\[ x=2 \]

from its real domain.

The range similarly excludes

\[ y=0. \]

Practical Applications

Business Forecasting

A revenue function may be presented as a formula for calculation, a table for monthly reporting, and a graph for trend analysis.

Each representation serves a different operational purpose.

Scientific Measurement

Experimental data often begins as a table of measurements.

A graph may reveal a pattern, and a formula may then be fitted to model the relationship.

Software Systems

A lookup function may be represented by key-value pairs, a table, or a programming rule.

The underlying mapping remains the same.

Geometry

A geometric curve may be represented

  • by an equation,
  • as a set of ordered pairs,
  • or visually as a graph.

These representations describe one geometric object from different perspectives.

Communication

A technically correct formula may still be a poor communication tool for a general audience.

Choosing a useful representation is part of mathematical judgment.

Worked Examples

Example 1: Formula to Ordered Pairs

Let

\[ f(x)=x+2. \]

For inputs \(0,1,2,3\):

\[ f(0)=2, \qquad f(1)=3, \qquad f(2)=4, \qquad f(3)=5. \]

So the ordered-pair representation is

\[ \boxed{ \{(0,2),(1,3),(2,4),(3,5)\} }. \]

Example 2: Table to Formula

\(x\) \(f(x)\)
\(0\) \(4\)
\(1\) \(7\)
\(2\) \(10\)
\(3\) \(13\)

The output increases by \(3\) whenever the input increases by \(1\), so the slope is \(3\).

Since

\[ f(0)=4, \]

the intercept is \(4\).

Therefore,

\[ \boxed{ f(x)=3x+4 }. \]

Example 3: Words to Formula

A gym charges a \$30 monthly membership fee plus \$5 per class attended.

Let \(c\) be the number of classes.

The total monthly cost is

\[ \boxed{ C(c)=30+5c }. \]

Example 4: Formula to Verbal Description

Suppose

\[ T(x)=\frac{x}{4}+6. \]

One verbal description is:

“Divide the input by \(4\), then add \(6\).”

Example 5: Determine Whether a Pair Set Is a Function

Consider

\[ R=\{(1,2),(2,5),(3,5),(4,8)\}. \]

Every first component appears with exactly one second component.

Therefore, \(R\) represents a function.

The repeated output \(5\) is allowed.

Example 6: Discrete or Continuous?

Suppose \(P(n)\) gives the number of pages printed after \(n\) complete print jobs.

If \(n\) counts completed jobs,

\[ n\in\{0,1,2,\ldots\}. \]

The domain is discrete, so a point-based representation is usually more appropriate than drawing a continuous curve through every real value.

Common Errors

1. Treating Different Representations as Different Functions

A table, graph, formula, and mapping diagram may all describe the same underlying mapping.

2. Assuming Every Table Determines a Unique Formula

A finite table can often fit many different formulas.

Additional information or assumptions may be needed to determine a unique rule.

3. Assuming a Formula Alone Tells the Entire Function

The domain and mapping context matter.

4. Connecting Discrete Points Automatically

A line between plotted points suggests that intermediate inputs are allowed.

That may be false for a discrete domain.

5. Reading a Table Backward

The input column and output column have different roles.

Reversing them changes the relation.

6. Ignoring Units and Context

A formula such as

\[ C(h)=25+8h \]

is more useful when we remember what \(h\) and \(C(h)\) represent.

Practice

Formula to Table

Let

\[ f(x)=2x-1. \]

Complete the table for \(x=0,1,2,3\).

Check Answer
\(x\) \(f(x)\)
\(0\) \(-1\)
\(1\) \(1\)
\(2\) \(3\)
\(3\) \(5\)

Table to Ordered Pairs

\(x\) \(g(x)\)
\(-1\) \(2\)
\(0\) \(4\)
\(2\) \(8\)

Write the function as a set of ordered pairs.

Check Answer \[ \boxed{ \{(-1,2),(0,4),(2,8)\} }. \]

Words to Formula

A delivery service charges \$12 plus \$3 per mile. Let \(m\) be the number of miles.

Write a function for total cost.

Check Answer \[ \boxed{ C(m)=12+3m }. \]

Function or Not?

Does

\[ \{(1,a),(2,b),(2,c),(3,d)\} \]

represent a function?

Check Answer

No.

The input \(2\) is paired with both \(b\) and \(c\), so the function rule is violated.

Choose a Representation

Which representation would be especially useful for showing whether every codomain element is reached by a finite function?

Check Answer

A mapping diagram is especially useful because the codomain elements and incoming arrows are visible directly.

The Deeper Idea

Mathematics becomes more powerful when the same object can be viewed from several perspectives.

A function may be understood as

  • a set of ordered pairs,
  • a mapping between sets,
  • a computational rule,
  • a numerical table,
  • a geometric graph,
  • or a relationship described in words.

Each representation preserves the same underlying structure while making different features easier to inspect.

This ability to change representation is a major mathematical skill:

\[ \boxed{ \text{same object} + \text{different representation} = \text{different insight} } \]

Later lessons will repeatedly move among symbolic, numerical, graphical, and algorithmic views of functions. The stronger these translations become, the easier it is to recognize structure rather than memorize isolated procedures.

Summary

  • Functions can be represented verbally, by ordered pairs, tables, mapping diagrams, formulas, and graphs.
  • Different representations can describe the same underlying function.
  • Ordered pairs show exact input-output assignments.
  • Tables organize selected values and often reveal numerical patterns.
  • Mapping diagrams emphasize the relationship between domain and codomain.
  • Formulas give compact general rules for calculating outputs.
  • Graphs display the geometric shape and overall behavior of a function.
  • A finite table does not necessarily determine a unique formula.
  • A formula should be interpreted together with its domain.
  • Discrete and continuous domains should be graphed differently.
  • Domain and range can be read differently depending on the representation.
  • Choosing the right representation is part of mathematical modeling and communication.

The goal is not to prefer one representation over all others. The goal is to move among them fluently and choose the representation that makes the important structure easiest to see.
