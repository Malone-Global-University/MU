## Lesson 6: Installing and Removing Apps

You need a program to open a particular document, study a new subject, or join an approved online meeting. A website offers a large **Download** button. A second page offers a similar program at a lower price. Another message says your computer needs an urgent installer. Which action is appropriate? And when you no longer need a program, how do you remove it without accidentally deleting your work?

This lesson develops a practical, safety-first method for managing [[app|applications (apps)]] on everyday computers. You will learn what it means to [[install|install]] or [[uninstall|uninstall]] software, how to distinguish a legitimate application from a shortcut or website, and how to evaluate a source before agreeing to a download. Windows 11 is the primary demonstration environment, with comparisons to macOS, ChromeOS, Android, and iOS. The instruction does **not** require you to install, purchase, or remove anything: the exercises include supervised and observation-only alternatives.

**Level:** Beginner · **Estimated study time:** 85–115 minutes · **Prerequisites:** Operating System Basics Lessons 1–5 recommended · **Practice equipment:** Windows 11 computer preferred; Mac, Chromebook, phone, or paper-based practice alternatives provided · **Safety:** No actual downloads, purchases, account changes, administrator approvals, or removals are required

> **Essential idea:** **Install** means make software available for use on a device; **uninstall** means remove software through an appropriate removal procedure. A trustworthy decision involves the **purpose of the app**, the **source and publisher**, the **permissions and cost**, the **device's rules**, and the **effect on saved work**. You should be able to examine these matters **before** clicking an installation or removal confirmation.

### Learning objectives

After completing this lesson, you should be able to:

1. Distinguish downloading, installing, opening, updating, uninstalling, and deleting an app shortcut.
1. Identify common sources of apps, including Microsoft Store and a software publisher's official website.
1. Examine an app listing for its publisher, name, purpose, price, device requirements, and requested access.
1. Describe the basic Microsoft Store installation workflow without needing to complete a real installation.
1. Recognize executable installers and understand why Windows may display a security or administrator prompt.
1. Identify misleading download buttons, unsolicited installer requests, and suspicious permission requests.
1. Locate **Settings → Apps → Installed apps** in Windows 11 and explain the uninstallation workflow.
1. Explain why uninstalling an app, deleting its files, and cancelling a subscription are different actions.
1. Identify conditions under which a device owner, teacher, employer, or administrator must approve changes.
1. Compare app management on a Mac, Chromebook, and smartphone at an introductory level.
1. Use a practical decision checklist to determine whether to install, keep, update, or remove an application.

## 1. What do installing and removing apps mean?

An [[app|application]] is a software program designed to help someone perform tasks. Examples include a text editor, calculator, browser, photo editor, classroom application, and video-meeting program. The [[operating-system|operating system]] provides the underlying environment in which these programs run. Apps differ in purpose, price, capabilities, source, and device compatibility. The familiar icon represents a way of reaching an app, but the icon is not necessarily the application itself.

To [[download|download]] something is to transfer information from another computer or service onto your device. To **install** software is to place or register the required program components so the operating system can offer and run the application. These actions often occur together in an app store, but they are not the same. Downloading a software installer might leave a file in Downloads; installation does not occur until the appropriate installation process completes. Some software can run without a conventional installation, and some web applications work primarily in the browser. The label on a button is only one clue to what will happen.

Uninstalling is the intended procedure for removing an installed application. It may delete program components and related settings, but **it does not universally remove all user files, cloud-stored data, or account records**. Effects vary by app, publisher, and selected removal options. A person should identify important work and account arrangements before uninstalling anything.

### Six actions that beginners should not confuse

| Action | Plain-language meaning | Typical example | Important distinction |
| --- | --- | --- | --- |
| **Download** | Transfer a file or package to your device | Save a publisher's installation package | Having the file is not necessarily the same as installing the program |
| **Install** | Set up the app so it can run | Complete an approved Store installation | May involve files, settings, storage, and permissions |
| **Launch** | Open the installed or available app | Open Calculator from Start | Usually does not download or install new software |
| **Update** | Replace or add newer software components | Install an approved app update | Usually preserves the app, but may change features or requirements |
| **Uninstall** | Remove an installed app by its supported process | Use Settings → Apps → Installed apps | May affect associated data and other programs |
| **Unpin / remove shortcut** | Remove a convenient link to an app | Unpin an app from Start | Normally does not uninstall the underlying application |

Suppose a learner unpins a text editor from the taskbar. The program can still be present in the Windows app list. Suppose the learner removes a downloaded installer file after successful setup. The installed app may still work, although deleting an installer should not be done without understanding whether it is still needed. Conversely, manually deleting an installed program's folder is not a proper substitute for uninstalling; it may leave entries, services, dependencies, and settings behind.

### Installed apps, web apps, and portable programs

Most beginner courses concentrate on installed applications, but not every program works in the same way. A [[web-app|web app]] may run in a browser and store information on a remote service. Certain browsers can add an app-like shortcut or install a progressive web application. A [[portable-app|portable app]] may be designed to operate from a folder without a traditional installer. Some Microsoft Store items are conventional desktop programs, while others use different packaging and installation arrangements.

Do not conclude that every icon is evidence of a conventional installation. If a website icon opens a browser tab, it may merely be a shortcut. If an app requires signing in, its data may be associated with an online [[account|account]] rather than stored solely on your computer. These differences matter when deciding how to remove an app or recover its data.

### The lifecycle of an application

A useful lifecycle is **select → verify → obtain → install → launch → use → maintain → remove when appropriate**. Not every application follows every stage. For a preinstalled app, for instance, the manufacturer has already performed the installation. For a web service, there may be no traditional installation step. For a workplace app, an administrator may manage selection, updates, and removal centrally.

The sequence teaches an important operating principle: **the first step is deciding whether you need a program at all**. Sometimes an existing built-in tool is sufficient. Before installing another calculator, for example, check whether your computer already has one. Fewer unnecessary apps can mean fewer confusing icons, fewer permissions to evaluate, and fewer software maintenance tasks.

### Who may install or remove software?

Permissions depend on the device and the software. On a personal computer you own, you may have authority to install approved programs, subject to the operating system's safeguards. On a shared, library, school, or workplace computer, you may have only ordinary [[standard-user|standard-user]] privileges. Some activities require an [[administrator|administrator]] or are prohibited by a [[device-policy|device policy]]. An administrator prompt is not a signal to guess a password or request someone else's credentials. It means the operation is requesting elevated authority and deserves scrutiny.

> **Beginner rule:** If the computer does not belong to you, or you are unsure whether you are authorized, use the observation-only steps in this lesson. Do not install or remove a program to complete an exercise.

## 2. How do you decide whether an app is safe and appropriate?

A good decision begins with the job you want to accomplish. If the task is writing simple notes, a built-in text editor may be sufficient. If a course requires specialized software, the instructor should identify the appropriate program, source, and version. The goal is not to collect apps; it is to choose the smallest suitable tool from a trustworthy source and use it responsibly.

Software can cost money, request access to personal information, consume storage, create background activity, or require a subscription. A product's popularity does not settle all of these questions. Nor does the word **free** necessarily mean free of advertisements, optional purchases, data collection, or ongoing charges. Students should learn to evaluate the entire installation decision rather than looking only at the Download button.

### Five questions before installing

1. **Purpose:** What job does this app perform, and do I already have a suitable app?
1. **Source:** Is it offered through the operating system's recognized store or the publisher's verified official site?
1. **Publisher:** Who maintains it, and does the name match the application I intended to obtain?
1. **Terms and access:** Does it request a payment, subscription, sign-in, or permission I understand and accept?
1. **Fit and authority:** Does it support my operating system and device, and am I permitted to install it here?

The answers may lead to “do not install,” “ask for approval,” “research further,” or “proceed only when authorized.” A cautious decision is a successful outcome, not a failure to learn.

### Recognize the source of the software

A [[digital-store|digital app store]] provides a central place to find and obtain software. Microsoft Store is a prominent source on Windows 11. Apple's App Store serves Macs and Apple mobile devices. Google Play supports compatible Android devices and many Chromebooks. Software publishers may also offer official downloads directly from their websites. The existence of a store listing provides a meaningful distribution channel but **does not mean every product is automatically suitable, private, secure, or free**.

A [[publisher|publisher]] is the person or organization distributing and maintaining software. In a store, inspect the publisher or developer information. On a website, compare the address and organization carefully with a verified source. Search advertisements and copied product pages can imitate real products. An address beginning with `https://` indicates an encrypted connection under normal conditions; it does not by itself prove that the site's content or seller is trustworthy.

| Source or offer | Typical advantage | Checks still needed | Beginner recommendation |
| --- | --- | --- | --- |
| Recognized app store | Central listing, installation flow, and updates for supported items | Publisher, purpose, cost, permissions, device compatibility | Often an appropriate first place to investigate |
| Official publisher website | Direct access to some desktop programs unavailable in a store | Exact site, installer, signature or publisher details, payment terms | Use only when you have verified the source and have authorization |
| Link in an unexpected message | Convenient-looking access | Message authenticity, source, destination, urgency claims | Do not start installation from an unsolicited link |
| Third-party download mirror | May display a familiar product name | Bundled extras, outdated versions, altered downloads | Avoid when a verified official source exists |
| Advertisement marked “Download” | Easy to notice | Whether it advertises a different product | Do not assume it is the desired application's button |

**Independent verification** means navigating to an official vendor or institutional page through a trusted route instead of relying on an unexpected link. A teacher may provide a course-specific official download page; an employer may publish an approved software catalog. Following those institutional routes generally provides better control over version and authorization.

### Check cost, licensing, and account requirements

An app's price may be a one-time purchase, a recurring [[subscription|subscription]], a free trial, an in-app purchase system, or a free license with limitations. A **trial** may require payment details and later renew automatically under its terms. A “free download” can lead to a paid account. Some software is free for individual use but requires a separate business license. Do not assume that the ability to install something grants the right to use it for every purpose.

Before installation, determine whether you are expected to provide a credit card, personal information, or organizational credentials. If the cost or renewal terms are unclear, stop. Students should never be required to create a paid account or submit payment information for this lesson. An approved application can also have optional paid upgrades that the student does not need.

### Understand what an app may access

An app may request access to files, photos, cameras, microphones, location data, contacts, or other capabilities. A legitimate video-meeting app may need a microphone during a call, but an unrelated calculator should not need broad access to your documents merely to perform basic arithmetic. Some permissions are required for a specific feature, while others can be refused or changed through settings. The permission prompts differ across app types and operating systems.

Ask whether a permission is **necessary for the job at hand**. Treat especially broad or unexpected access as a reason to review the app and its publisher. Do not approve a prompt simply because you want the window to close. During supervised installation, read prompts in order and request guidance when you cannot explain the change being requested.

### Compatibility and storage requirements

A program designed for Windows may not work on macOS or ChromeOS. A 64-bit application may require a compatible processor and operating system. Some programs need a newer operating-system version, additional storage, or a network connection. Check the developer's published **system requirements** instead of guessing from the appearance of a screenshot. A device with limited storage may not have room for a large application even if the installer file is small.

A program's total [[storage-space|storage space]] can include the app itself, downloaded supporting files, user projects, and temporary data. App listings may not predict the exact amount needed after months of use. If space is tight, identify large files and apps carefully before removing anything; do not delete unknown system files or other people's documents to make room.

### A simple decision example

A student wants to read a PDF document. The computer's existing browser already opens the document. Installing an unfamiliar “PDF speed booster” is unnecessary for that task. The student can use the existing program and avoid granting additional permissions. If an instructor requires a separate accessible PDF reader, the student can verify its official source and availability before requesting installation approval. Both outcomes show successful software selection.

> **Safety checkpoint:** A genuine need does not make an unsafe installer acceptable. If you cannot verify the source, publisher, cost, permissions, or authorization, stop and ask a knowledgeable person through an independent trusted channel.

## 3. How do you install apps from Microsoft Store?

On Windows 11, **[[microsoft-store|Microsoft Store]]** is one common route for finding and installing applications. It presents product pages with information that may include descriptions, screenshots, the developer or publisher, ratings, cost, supported devices, and other conditions. The exact arrangement and button names can change as Microsoft updates the application, so **follow the meaning of the controls rather than memorizing one screenshot**.

This section is a guided explanation, **not an instruction to install a real app**. You may examine the store or use the sample listing later in the practice section. Do not select an actual installation, purchase, sign-in, or permission button on a shared or managed device without authorization.

### The standard Windows 11 Store workflow

1. **Begin with a specific need.** Decide which kind of software you require and whether a suitable program is already installed.
1. **Open Microsoft Store.** On an authorized Windows 11 device, use Start and search for *Microsoft Store*, then open the app if it is available. Managed devices may restrict access.
1. **Search by the intended app name.** Enter the correct product name and inspect the results; similar titles are not proof that two listings are from the same company.
1. **Open the listing.** Check its product title, publisher, description, compatibility, price, and any relevant age, privacy, or access information.
1. **Decide whether to proceed.** For a genuine installation, read the button and any further prompts. A free app may display **Get** or **Install**, and an item that is already available may show **Open** or another management action. Paid products show relevant purchasing controls.
1. **Complete only an authorized installation.** The Store may download and register the application automatically. Some software may have separate publisher, account, or installation conditions; treat any additional prompts as new decisions.
1. **Verify the result.** Locate the app through Start, inspect its name, and launch it only when appropriate. Do not interpret a search suggestion as proof that the app is installed.
1. **Know how to manage it.** The app may be listed under **Settings → Apps → Installed apps**, and supported Store apps may receive updates through the Store.

The app store does not eliminate the need to read. Some listings provide a free trial or in-app purchases rather than a completely free product. Others require a subscription after installation. A familiar brand name or polished screenshot is not a substitute for confirming the publisher.

### Buttons can represent different commitments

| Possible Store label | What it often means | What to check before selecting |
| --- | --- | --- |
| **Get** | Obtain or begin installing a free or previously entitled item | Publisher, requirements, permissions, account prompts |
| **Install** | Start the software installation or reinstallation | Whether this is the intended application and device |
| **Open** | Launch an app already available to the device | Whether you intended to launch it and allow its access |
| Price or **Buy** | Purchase may be required | Amount, payment account, terms, refund rules |
| **Free trial** | Temporary access under stated terms | Trial length, payment requirement, automatic renewal |
| **Update** | Obtain a newer version of the application | Publisher and any updated requirements or permissions |

These are illustrative labels, not a guarantee that every app uses the same controls. If the display is different, identify the operation and stop before accepting unclear terms.

### Search results are not an installed-app inventory

A search for an app in Microsoft Store can return products that **are not installed**. The result is an offer to view or obtain software, not evidence that it already lives on your computer. Likewise, Windows Search may show online results as well as locally installed apps. To check installed programs, use **Start → Settings → Apps → Installed apps** or another supported inventory route. This distinction connects directly to the previous Start-menu lesson.

### Accounts and purchase records

Certain Store operations require a Microsoft account or other authentication. The account may be associated with purchases, licenses, or reinstall rights. A school or organization may manage licenses differently. **Never sign into a personal account on a shared computer merely to perform a classroom practice exercise.** If the Store asks for an account, select the observation-only exercise instead. Do not infer that uninstalling a purchased app automatically cancels a license, subscription, or recurring charge.

### After installation: verify without unnecessary changes

A successful installation should produce a usable app entry, but the visible result depends on the software. An app may appear in Start, in Installed apps, on the desktop, or in a Store library. Not all programs create taskbar icons, desktop shortcuts, or automatic start-up entries. To confirm the result safely, find the named application, inspect the publisher where supported, open it if permitted, and avoid entering confidential information during testing.

An app may ask to sign in or request a permission at first launch. These requests are **additional decisions**, separate from installation. Installing a video-conferencing app does not mean you must immediately grant camera access; use the app's legitimate feature only if it is needed and authorized.

### If the Store is unavailable

A managed school computer may hide the Store, restrict installation, or present a message that an administrator controls the feature. A user may also be offline or may not have an account required for a particular item. These conditions do not mean you should bypass policies or find a random installer elsewhere. Record the message, check connectivity only through approved methods, and ask the owner or administrator for the appropriate installation route.

## 4. What about installers from websites?

Some legitimate desktop applications are supplied directly by their publishers rather than solely through an app store. These programs may be distributed as downloadable [[installer|installer]] files. The operating system may inspect the file, verify certain information, and request permission before it can make changes. The ability to run an installer is powerful; it deserves more scrutiny than opening a harmless document.

You should understand the process even if you never perform it independently. The lesson's purpose is to teach how to **recognize a trustworthy workflow**, not to encourage unsupervised installation from websites.

### Understand common Windows installation files

| Common file type | General role | Beginner caution |
| --- | --- | --- |
| `.exe` | Executable program; sometimes an installer | Running it can start software and request system changes |
| `.msi` | Windows Installer package | Can install or alter Windows applications |
| `.msix` / `.msixbundle` | Packaged Windows application format | Still requires an appropriate trusted source and authorization |
| `.zip` | Compressed archive, possibly containing an installer | Extracting is not the same as verifying or safely installing contents |
| `.pdf` / `.txt` | Usually document or text formats | Not normally program installers, although any untrusted file should be treated carefully |

A filename extension provides a clue, not a complete safety guarantee. File names may be misleading; some systems hide known extensions by default. Do not make an installer seem trustworthy merely by renaming it. A file downloaded from an official-looking page may still need verification. More advanced installation technologies exist, but beginners do not need to memorize them to use computers safely.

### A careful, authorized publisher-site workflow

1. **Identify the official publisher and product.** Use a known course, institution, or official vendor page as your source.
1. **Review the relevant product documentation.** Confirm Windows compatibility, hardware requirements, license type, and whether a Store option exists.
1. **Check the website carefully.** Look for the precise company and product; do not assume a paid advertisement or visually similar URL is the official source.
1. **Review the download offer.** Confirm what file is being offered and whether it matches the expected operating system and product.
1. **Obtain explicit authorization.** On any shared, school, or employer device, follow local policy and use the approved service or IT team.
1. **Inspect security information.** If a permitted installation is carried out, pay attention to Windows warnings, the displayed publisher, and the program's requested changes.
1. **Read installer options.** Some setup programs offer optional extras or change default applications; do not agree without understanding the implications.
1. **Verify completion.** Confirm that the correct program appears in the installed inventory and behaves as expected, without disclosing sensitive information.

This is a decision model, not a requirement to launch an installer. If the publisher cannot be verified, the application appears to be an imitation, or the prompts are confusing, **cancel rather than proceed**.

### What does a User Account Control prompt mean?

Windows may show a [[uac|User Account Control (UAC)]] prompt when a program requests permission to make changes requiring elevated privileges. You might see the application name, a [[verified-publisher|publisher]] identity where available, and a request to approve the operation. A verified publisher can provide useful identity information, but it does not guarantee that software is appropriate or harmless. An unknown or unexpected name deserves additional scrutiny.

**Do not click Yes automatically.** Consider whether you deliberately started this specific approved installation and whether you trust the program and the requested change. Do not provide administrator credentials that do not belong to you. If you did not initiate the installation, cancel and investigate through a trusted route. Some installers do not require elevation at all, so the absence of a UAC prompt does not itself establish safety.

### Windows reputation and malware defenses

Windows has protections such as [[smartscreen|Microsoft Defender SmartScreen]], reputation checks, antivirus scanning, and—in supported configurations—Smart App Control. These features may warn about a known or suspicious download or app. A warning is a reason to **pause and verify**, not an obstacle to bypass for the sake of finishing a lesson. An apparently harmless installation can cause trouble if the file is altered, bundled with unwanted extras, or disguised as another product.

Do not disable antivirus, SmartScreen, Smart App Control, or organizational protections to install a program. A website that tells you to turn off security tools or paste unknown commands into PowerShell or a terminal should be treated with particular suspicion. Requiring a script, command, or administrator override is beyond this beginner lesson and needs informed, authorized review.

### Windows 11 in S mode and other restrictions

Some Windows 11 systems operate in [[s-mode|S mode]], which restricts installations to eligible software from Microsoft Store. Switching out of S mode is a separate device-level decision and is not a routine troubleshooting step. Microsoft states that leaving S mode is permanent. **Do not switch out of S mode merely to complete a practice exercise.** A workplace or school may apply its own installation policies whether or not S mode is in use.

| Situation | Possible explanation | Appropriate learner response |
| --- | --- | --- |
| “Administrator approval required” | Installation needs higher privileges or policy approval | Cancel or stop; contact the authorized administrator |
| “App not from Microsoft Store” | Device has app-source restrictions or recommendation settings | Review policy; do not change safeguards without permission |
| “App can't run on this PC” | Incompatible version, hardware, or architecture | Verify official system requirements |
| Browser warns about a download | Reputation or security check has concerns | Do not bypass; verify using a trusted route |
| Installer offers an unrelated toolbar or extra app | Optional bundled software may be present | Decline unwanted extras or cancel installation |
| Website insists on urgent “codec,” “cleaner,” or “security fix” | May be deceptive pressure or scareware | Close the page; consult official support or security staff |

### Recognize social engineering before running software

A common deception begins with a frightening message: “Your computer is infected—download this tool immediately.” Another page offers several green Download buttons, only one of which may be connected to the intended product. A fake support agent may ask you to install a remote-access utility or disclose a password. A browser notification can imitate a system warning. **Urgency, professional artwork, or a familiar logo does not establish authenticity.**

Ask: Did I intend to install this software? Do I know the publisher? Did I reach the page independently? Is the requested action necessary for my specific task? If the answer is unclear, do not proceed. If you believe something was accidentally installed, inform the device owner or administrator promptly rather than attempting random cleanup steps that might make the problem worse.

## 5. How do you uninstall an app in Windows?

Sometimes removing software is reasonable: a program is no longer needed, a device is short of storage, a trial has ended, or an administrator has replaced a tool with an approved alternative. At other times removal would be a mistake. A program may be required for school assignments, workplace processes, device drivers, accessibility, printing, backups, security, or opening particular file types. **Uninstalling should be a deliberate change, not a reaction to an unfamiliar name.**

Windows 11 provides an ordinary app-management route under **Settings → Apps → Installed apps**. Microsoft also documents removal options from Start for supported apps and, for some desktop programs, through Control Panel. The exact steps and options may differ according to app type and system configuration.

### Inspect without removing: Windows 11

1. Open **Start** and then **Settings**, or press **Windows key + I**.
1. Select **Apps**, then **Installed apps**. The page contains a list of programs Windows recognizes as installed.
1. Review the list. Search, sort, or filter options may help locate an app; available controls vary by version.
1. Identify a familiar nonessential app *only for the exercise*. Do not select **Uninstall** during observation-only practice.
1. Note the app's displayed name and any available publisher, size, or version information. These fields are not equally detailed for every app.
1. Return to the previous screen or close Settings when finished.

This safe observation exercise is enough to demonstrate where an uninstall would begin. It does not modify the computer.

### If a removal is genuinely authorized

1. **Verify identity.** Confirm the exact app, who installed it, what work depends on it, and whether you have permission to remove it.
1. **Protect important data.** Check where the app stores documents, projects, saved settings, downloaded files, and cloud information. Back up material you may need later.
1. **Check account and billing effects.** If a paid subscription or online account exists, review cancellation and data-retention procedures separately.
1. **Close work safely.** Save current documents; close the program and dependent tasks when appropriate.
1. **Open Installed apps.** Navigate to **Settings → Apps → Installed apps** and locate the exact application.
1. **Choose the app's menu.** For a supported item, use the **More options (… )** menu and choose **Uninstall**. Some items may have another removal interface or a disabled uninstall option.
1. **Read confirmation screens.** Check the name, whether related data will be removed, and whether administrator approval is required. Cancel if unexpected.
1. **Follow the supported removal process.** Some traditional desktop applications open their own uninstaller, which may have more options.
1. **Verify afterward.** Check whether the app still appears in the installed list, whether important documents remain available, and whether dependent programs work.

Students should **not** perform this removal as part of the lesson. These steps explain the ordinary workflow for later authorized use. If a program is essential, belongs to another user, or is unfamiliar, leave it alone.

### Start-menu and Control Panel alternatives

Certain apps can be removed by right-clicking a Start-menu entry and selecting **Uninstall**. On some Windows 11 versions, the Start menu has a different layout or app list, and the command may lead to another management interface. Some traditional applications are also managed through **Control Panel → Programs → Programs and Features**. Not every program appears in every interface, and not every option is available for built-in Windows components.

If a program refuses removal, do not delete random folders or registry entries in an attempt to force it. The publisher may supply a supported uninstaller or Microsoft may offer an official troubleshooting route. A device administrator can evaluate complications. Beginners should treat a failed removal as a support matter, not a challenge to remove as much software as possible.

### Uninstalling is not the same as deleting your work

An app can store information in several places: user documents, its own data folders, a browser profile, an online account, or a synchronized cloud service. Some uninstallers preserve files; others may delete app-specific data or ask whether to remove settings. **There is no reliable universal rule that uninstalling always preserves all personal information—or that it always deletes everything.** Read the particular product's documentation and prompts.

| Item or relationship | What uninstalling might do | Safe preliminary action |
| --- | --- | --- |
| App's program files | Often removes installed program components | Confirm the correct app |
| Documents you created | May remain, but location and app behavior vary | Locate and back up necessary files |
| App preferences and cache | May be retained, reset, or removed | Review the app's removal options |
| Files synced to a cloud account | May remain online; some services have special sync or deletion behavior | Review sync and account settings before removal |
| Paid license or subscription | Usually managed separately from local removal | Check vendor or store billing settings independently |
| Browser-based account | Often remains after local removal | Decide separately whether the account should stay active |
| Shared components or device drivers | May affect connected hardware or other apps | Ask the owner or administrator before removing |

Imagine a student using an image editor for a project. They save their edited image in Documents but also keep a partially completed project in the app's own working folder. Removing the editor without checking both locations could make the project difficult or impossible to recover. Saving an exported image may not preserve all editable layers or project settings. Students should locate what matters **before** uninstalling.

### Uninstalling does not cancel a subscription

Deleting a software app is not normally an instruction to its billing provider to stop charging. A paid account may continue even if the program is no longer on the device. A subscription purchased through Microsoft, Apple, Google, or directly from a publisher may have a different cancellation mechanism. Do not assume that clicking **Uninstall**, removing an icon, or signing out cancels charges. Verify billing separately through the original authorized provider. This lesson does not require opening payment accounts or sharing financial details.

### Clean up carefully rather than aggressively

Deleting a shortcut from the desktop is not the same as removing the program. Deleting an installer in Downloads is not equivalent to uninstalling. Removing a browser extension differs from uninstalling the whole browser. Nor should you remove a driver or security application just because its name is unfamiliar. On shared computers, consult the responsible person before changing installed software. If you are uncertain what an item does, **do not remove it**.

A computer with many apps is not necessarily broken or insecure; the issue is whether software is appropriate, supported, maintained, and needed. Responsible app management may include leaving essential components alone, using approved updates, removing clearly obsolete software through normal processes, and documenting changes where an institution requires it.

## 6. How do other systems and common problems compare?

Every major operating system provides a way to obtain and remove software, but not every platform calls the same thing an “app,” treats installation the same way, or stores user information in the same place. Beginners should recognize the family resemblance: **identify → verify → authorize → install/use → maintain → remove carefully**. The specifics are platform-dependent.

### macOS: App Store, publisher downloads, and application removal

On a Mac, many applications are obtained through the built-in **App Store**. Some publishers distribute apps directly through their official websites; a downloaded package may use formats such as `.dmg` or `.pkg`. Installation procedures differ by application. The Mac may ask for authorization or warn about an unfamiliar developer. Use the same source-verification and permission principles you learned for Windows.

For removal, Apple explains that some third-party apps include a dedicated uninstaller, which can be important when the app installs extra supporting components. Other apps can be removed through Finder or another supported macOS interface. Built-in applications required by the system cannot always be deleted. Moving an app to Trash does not necessarily remove associated user data or online accounts. **Do not use another platform's Windows instructions on a Mac.**

### ChromeOS: Google Play, web apps, and managed devices

A compatible Chromebook may install Android applications from **Google Play**, and ChromeOS also supports web apps and certain browser-based features. The Chromebook **Launcher** helps find installed or available app entries. Google documents uninstalling supported items from the Launcher by opening the app's context menu and selecting **Uninstall** or **Remove from Chrome**, as appropriate. Availability varies by Chromebook, app type, and organizational policy. Some Chromebooks do not support particular Android apps, and some school-managed devices block app changes.

A [[browser-extension|browser extension]] modifies browser functionality. It is not the same as a full operating-system application, although it can still request extensive permissions or affect your browsing. If something was added as a browser extension, its removal may occur through browser management rather than the ordinary app inventory. Do not install unknown extensions as an alternative to a blocked application.

### Smartphones: app stores and device permissions

Android devices commonly use Google Play or another authorized distributor supported by the device. iPhones use Apple's App Store and the platform's supported app-distribution routes. A person typically selects an app, reviews its developer and terms, chooses the appropriate obtain/install action, and may later remove the app through an app-management interface. **Removing a home-screen icon is not always the same as uninstalling**, particularly where an operating system offers an option to remove an icon while keeping the app in an app library.

On phones, pay attention to permissions for location, photos, microphone, camera, notifications, and account sign-in. Removing a phone app can erase data stored only within that app even when cloud-stored records remain. Before a removal, check whether the app provides an export, backup, or account-data procedure.

### Comparison at a glance

| Platform | Common route to obtain software | Common place to find/remove it | Important caution |
| --- | --- | --- | --- |
| Windows 11 | Microsoft Store or verified official publisher | Start and Settings → Apps → Installed apps; certain desktop apps use their own uninstaller | Policies, UAC, S mode, and app-data effects vary |
| macOS | Mac App Store or verified publisher | Applications/Finder and publisher's supported removal method | An uninstaller may be needed for apps with supporting components |
| ChromeOS | Supported Google Play apps, web apps, and other authorized routes | Launcher or appropriate app/browser management | Device support and school policies can restrict options |
| Android | Google Play or authorized device-specific routes | Settings or app-management interface | App-specific local data and subscriptions may persist differently |
| iOS | App Store or other supported distribution under applicable platform rules | Home Screen, App Library, or Settings | Removing an icon may not delete the app; data and subscriptions require separate review |

### Troubleshooting by diagnosing, not guessing

If an app does not appear after installation, first check whether installation actually completed. Search for the correct app name and review the installed-app list. A page advertising an app, a downloaded file, or a pinned shortcut does not automatically mean a usable program was installed. If a program will not launch, note any error message and avoid repeated installation attempts from unknown sources.

If an app seems incompatible, check the publisher's minimum requirements, supported operating systems, and relevant system updates. If a device says the administrator has blocked it, follow organizational policy. If a Store app has installation problems, consult the Store's official troubleshooting documentation or institutional help desk rather than bypassing security controls.

| What you observe | Likely question | Conservative next step |
| --- | --- | --- |
| App is absent from Start | Did installation finish or is the name different? | Check Installed apps and the original approved source |
| Store asks for sign-in | Is an authorized account needed? | Do not use personal credentials on an unmanaged/shared device without permission |
| Installer requires admin approval | Is the change authorized and expected? | Stop and request authorized help |
| “Not compatible” message | Is the OS or device supported? | Check official requirements, not third-party “fixers” |
| App is installed but will not open | Is there a documented app error or update? | Record the message and use publisher/official support |
| Uninstall option is unavailable | Is it a protected, managed, or system component? | Leave it installed; ask the owner or IT support |
| Storage is low | Are there unnecessary approved files or apps? | Inventory carefully; protect projects and backups |
| Unexpected software appears | Was a program installed without your knowledge? | Inform the owner/IT and consult built-in security guidance |
| Charges continue after removing an app | Was a subscription separately cancelled? | Check the original billing provider through a trusted route |

### Accessibility and different ways to complete the task

Students may use touch, a keyboard, speech input, screen readers, magnification, or assistive controls. On Windows, **Windows key + I** opens Settings, and the Windows key opens Start. Keyboard users can navigate familiar controls with Tab, arrow keys, and Enter where supported, but the exact sequence differs by app. Screen readers can announce buttons, menus, and dialogs so that a learner can distinguish **Open**, **Install**, and **Uninstall** before taking action.

For the purposes of this lesson, a learner may complete every activity with a description, screenshot provided by an instructor, or a paper-based scenario. No one must risk changing device software to demonstrate that they understand the workflow. In fact, recognizing when **not** to install is a major learning outcome.

## 7. Guided practice: Evaluate and manage apps

These five activities are designed for a beginner using Windows 11, but each has a paper-based, Mac, or Chromebook alternative. **The default is observation-only:** do not download a file, purchase a product, sign in, enter a password, grant a permission, run an installer, change app-source rules, or uninstall anything. On school or workplace equipment, comply with the responsible organization's instructions even if a control appears available.

**Objective:** Show that you can find programs that are installed without confusing them with web results or shortcuts.

## 8. Common misconceptions

### “Downloading an installer means the app is already installed.”

Not necessarily. Downloading generally transfers a file to the device. Installation is a distinct setup action, although some stores combine the two steps. A downloaded installer may remain unused in the Downloads folder.

### “If Microsoft Store offers an app, it must be safe and perfect for me.”

Not necessarily. A recognized store offers distribution and review mechanisms, but you still need to verify the product's identity, publisher, purpose, price, compatibility, and requested permissions.

### “Any website showing HTTPS and a padlock is the official publisher.”

No. An encrypted connection does not prove the vendor or site content is legitimate. Carefully verify the organization's identity and domain through a trusted route.

### “A free download always means the app will never cost money.”

No. Free downloads may include trials, in-app purchases, advertising, subscriptions, or feature limitations. Read the terms before agreeing.

### “A Windows warning is an inconvenience that I should bypass.”

No. Security and reputation warnings are designed to prompt scrutiny. Do not override them or disable protection to complete an exercise.

### “If Windows requests administrator permission, I should enter any password available.”

No. Elevated access belongs to authorized administrators. Do not guess, borrow, or disclose credentials. If you did not deliberately initiate an approved change, cancel and ask for help.

### “Pinning, unpinning, installing, and uninstalling are interchangeable.”

No. Pinning and unpinning normally affect shortcuts. Installing adds software; uninstalling removes software using a supported process. Opening the program is different again.

### “I can uninstall unfamiliar items to make the computer faster.”

Unfamiliar components may be necessary drivers, shared software, accessibility tools, or security features. Removing them without research or approval can cause problems. Inventory and identify before taking action.

### “Deleting a program folder is the proper way to uninstall software.”

Not generally. Program components may be registered in multiple locations, including services and shared settings. Use the program's supported uninstall method.

### “Uninstalling an app automatically erases my subscription and online account.”

No. Local software removal, online data deletion, account closure, and subscription cancellation are separate matters. Check each through the original provider.

### “Uninstalling always leaves my documents untouched.”

Not guaranteed. Many programs leave ordinary documents in place, but app-specific data, local projects, and settings can be removed depending on the software and selected options. Back up important work first.

### “I must leave Windows S mode to complete this lesson.”

No. S mode restrictions may be intentional. The lesson can be completed entirely through reading and observation. Changing device-level restrictions is beyond the practice activities.

### “A browser extension is always less risky than a full app.”

No. Extensions can request access to websites and browsing activity. The relevant permissions and source still require review. Use the appropriate browser management controls for extensions.

### “If a program cannot be uninstalled, I should keep clicking or force it.”

No. It may be protected by Windows or organizational policy, or it may require a supported uninstall tool. Record the message and seek official support instead of deleting system files or registry entries.

## 9. Essential vocabulary

Words marked with a dotted underline earlier in the lesson can be selected to display a brief explanation. The summary below is designed for first-time learners; more detailed MGU Encyclopedia links are provided where a relevant entry is established.

- **Application (app):** Software used to complete a user task, such as writing, communication, or image editing.
- **Operating system (OS):** The foundational software layer that manages computer resources and enables applications.
- **Download:** The transfer of data or a file to your device from another system.
- **Install / installation:** Set up software so a device can use it in the intended way.
- **Uninstall / removal:** Remove an installed application through a supported process.
- **Launch:** Start or bring an application into use.
- **Update:** A newer set of program components or changes installed to maintain or improve software.
- **Installer:** Software or package used to perform an installation procedure.
- **Microsoft Store:** Microsoft's app-distribution service and app-store application on Windows.
- **App listing:** A product page describing a software offering, including its publisher and terms.
- **Publisher / developer:** The organization or person distributing or maintaining the software.
- **Official website:** A site operated or authorized by the actual organization responsible for a product.
- **Digital app store:** A platform that presents and distributes apps to compatible devices.
- **Executable:** A file or program capable of executing instructions, rather than simply presenting text.
- **Installation package:** An arranged collection of program components and setup information.
- **User Account Control (UAC):** A Windows mechanism that requests confirmation or authorization for certain system changes.
- **Administrator:** A user or role with authority to perform selected elevated system operations.
- **Standard user:** An account with fewer permissions than an administrator.
- **Device policy:** Rules controlling software and other actions on a computer, often established by its owner or institution.
- **Permission:** Authorized access to a function, piece of information, or operating-system capability.
- **Microsoft Defender SmartScreen:** A Microsoft reputation- and threat-related protection feature for certain sites, downloads, and apps.
- **Smart App Control:** A Windows security feature that may block untrusted or suspicious apps in supported configurations.
- **S mode:** A Windows operating mode with app-installation restrictions and other design constraints.
- **App compatibility:** Whether a particular program is supported by an operating system and device.
- **System requirements:** Published conditions, such as operating-system version, processor, or storage needs.
- **Storage space:** Device capacity used to keep programs and files.
- **Subscription:** An ongoing arrangement that may involve recurring payments for access to a product or service.
- **Free trial:** Temporary access provided under specified conditions, possibly with later charges.
- **License:** Terms determining the permitted use of software.
- **App data:** Information maintained by an application, including certain preferences, caches, and user content.
- **Cloud storage:** Data saved on remote services and accessed through a network when available.
- **Backup:** An additional copy of valuable information for recovery if something is lost or damaged.
- **Uninstaller:** Software or a system function designed to remove an installed program.
- **Pinned app:** A convenient launcher entry attached to Start, taskbar, Dock, or another interface.
- **Shortcut:** A link that opens a program, file, or destination without containing the whole program.
- **Portable app:** Software designed to run without an ordinary system-wide installation process.
- **Web app:** A software service accessed through a browser or a web-app interface.
- **Browser extension:** An add-on that changes or extends a browser's behavior.
- **Verified publisher:** A publisher identity supported by a digital signing or verification mechanism; not a guarantee of safety.
- **Digital signature:** Cryptographic information that can help verify a software publisher or file integrity where supported.
- **Malware:** Software designed to harm, compromise, or misuse a device or its information.
- **Scareware:** Deceptive messaging or software that uses fear to pressure a person into unsafe action.
- **Bundled software:** An additional product offered or installed with another program.
- **Account:** An identity used to access a device, app, store, or online service.
- **Reinstall:** Install a program again, sometimes to recover a missing or damaged installation.
- **App source restriction:** A device rule that controls where software may be obtained.
- **Troubleshooting:** A systematic effort to identify and resolve the cause of a problem.
- **Verification:** Checking important information through an independent or otherwise reliable method.
