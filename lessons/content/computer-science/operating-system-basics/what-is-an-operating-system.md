Basic Computer Skills / Operating System Basics

## Lesson 1: What Is an Operating System?

Every time you open an app, save a photograph, connect to Wi-Fi, or adjust the volume, your device relies on software working in the background. The most important part of that foundation is its **operating system**. This lesson explains what an operating system does, how it works with hardware and apps, and how to identify the system running on a computer, tablet, or phone. No programming knowledge is required.

**Level:** Beginner · **Estimated study time:** 50–70 minutes · **Prerequisites:** Computer Basics recommended; no technical experience required · **Practice equipment:** A Windows computer, Mac, Chromebook, Android device, iPhone, or iPad (optional)

> **Essential idea:** An **operating system (OS)** is the main [[system-software|system software]] that manages a device's hardware, provides a working environment for [[application-software|apps]], and helps people use the device. You use the OS whenever you interact with the device—even when you do not notice it.

### Learning objectives

After completing this lesson, you should be able to:

1. Define an operating system in plain language and explain why it is important.
1. Distinguish hardware, an operating system, and application software.
1. Describe at least five jobs performed by an operating system.
1. Recognize common desktop and mobile operating systems.
1. Explain how an operating system differs from an app, a web browser, and the internet.
1. Find the name and version of the OS on a familiar device without changing its settings.
1. Identify safe habits for using a device and keeping its software current.

## 1. What is an operating system?

An [[operating-system|operating system]], often shortened to **OS**, is the foundational software that manages a computer's resources and makes it practical to run other programs. It coordinates the physical parts of the device, supports apps, manages stored files, and provides ways for a person to interact with the computer.

Think about opening a notes app. You select an icon. The app appears on the screen. You type a sentence, and the words become visible. If you save the note, you can usually open it later. Many parts work together to make this ordinary action possible. The operating system coordinates several of them.

An operating system is not necessarily something you open like a calculator. It normally starts when the device starts and continues working while you use the device. Windows, macOS, Linux, ChromeOS, Android, iOS, and iPadOS are examples of operating systems or operating-system families.

> **Remember:** The **device** is the physical computer; the **operating system** manages its basic operation; an **app** helps you perform a particular task.

### Why does a computer need one?

A modern general-purpose computer may have several programs running, a keyboard or touchscreen receiving input, a network connection exchanging information, and a storage device holding files. These activities need coordination. The operating system supplies common services so that each program does not need to manage every part of the machine on its own.

For example, a word processor should not have to know every technical detail of every printer model. The OS and appropriate supporting software help connect the program's request to the printer. Similarly, an app can ask to save a file without directly controlling the storage hardware's electrical operations.

Most personal computers and smartphones use an operating system. Some simpler electronic devices rely on specialized embedded software instead of a general-purpose operating system. The key point for beginners is that **the OS is the basic working environment on ordinary computers and mobile devices**.

### A helpful comparison—and its limit

You can picture a busy office building:

- **Hardware** is the building and its equipment.
- **The operating system** coordinates shared services, access, and use of resources.
- **Apps** are the individual activities taking place, such as writing, calculating, and communicating.
- **The user** is the person choosing what needs to be done.

This comparison helps you remember the different roles. But an OS is actual software executing instructions, not a person making independent decisions. It follows programmed rules and permissions.

### What you already know

From Computer Basics, you may remember that **hardware** is physical equipment and **software** is instructions and programs. An OS is a particularly important type of software, not a separate physical component. It can be stored on a drive or built-in flash storage, but the storage device itself is hardware.

## 2. How do hardware, operating systems, and apps work together?

A useful beginner model has three main layers: **hardware**, **operating system**, and **applications**. The person using the device interacts with the applications and the OS's controls.

| Layer | What it means | Examples | What it contributes |
| --- | --- | --- | --- |
| Hardware | Physical equipment | Processor, memory, screen, keyboard, storage | Performs the physical work and holds information |
| Operating system | Foundational system software | Windows, macOS, Android | Coordinates resources and provides services and controls |
| Application software | Programs for particular tasks | Notes, spreadsheet, camera, web browser | Helps the user create, calculate, communicate, or browse |

These are **roles**, not completely isolated boxes. Some apps are included with the operating system. The OS may also include tools that look like normal apps, such as Settings or a file manager. What matters is **what each piece of software does**.

### Walk through a simple task: Open and save a note

Imagine using a Windows laptop. The same broad sequence applies on other operating systems, although the screens and controls may look different.

1. **You choose the task.** You select a notes or text-editing app.
1. **The OS helps launch the app.** It locates the program and provides the environment it needs to run.
1. **The hardware carries out instructions.** The [[cpu|processor]] executes instructions, and [[memory|memory]] supports the active work.
1. **You enter information.** The keyboard or touchscreen sends input that the operating system and app handle.
1. **You see the result.** The app displays your text through the screen and supporting display software.
1. **You save your work.** The app requests that information be written to an appropriate file location, and the OS helps manage that request.
1. **You close the app.** The OS releases resources as the application finishes.

You do not normally see the many technical steps behind each action. That is one reason operating systems are useful: they make complex computer operations available through manageable controls.

### The operating system is not the application

A **web browser** such as Microsoft Edge, Safari, Chrome, or Firefox is an app. It opens websites and web-based services. It is **not** the whole operating system. A Windows computer can run a browser, a calculator, and a photo editor because Windows supplies underlying services for them. A Mac does the same through macOS.

The distinction also applies to mobile devices. **Android** is an operating system; an Android messaging app is an application. **iOS** is an operating system; the iPhone's camera app is an application. The camera hardware, camera app, and OS are different parts of one working system.

### Supporting software behind the scenes

Some software works even closer to hardware. A [[device-driver|device driver]] enables an operating system to communicate with particular hardware. [[firmware|Firmware]] is lower-level software built into many devices or components; it may help initialize hardware before the main OS starts. Beginners do not need to install or modify either of these to complete this course.

> **Check your understanding:** If you can replace one app without replacing the whole operating system, they are not the same thing. If you remove or replace the operating system, the effect on the device is much more significant and may affect whether its installed apps can run.

## 3. What jobs does an operating system perform?

Operating systems carry out many jobs. You do not need to memorize their technical mechanisms. Learn to recognize **the problem each job solves**.

### Job 1: Run and coordinate programs

The OS helps start apps, keeps track of running programs, and allows you to switch between them. This is part of [[process|process management]]. When you listen to music while writing a document, the operating system helps both activities share computing resources. This general ability to handle multiple active tasks is called [[multitasking|multitasking]].

Multitasking does not mean the device has unlimited speed. Too many demanding tasks can slow it down. The OS coordinates available resources, but it cannot create additional physical memory or processor capacity.

### Job 2: Manage memory

Programs need working space while they run. The operating system helps allocate [[memory|RAM]] to active applications and protects one program's memory from unintended access by another. If you open many large apps, your device may have less memory available. The result can be slower performance or an app that cannot start properly.

**Working memory is not the same as saved storage.** Saving a document stores it for later use; simply seeing text on screen does not guarantee that it has been saved.

### Job 3: Organize files and storage

The OS provides tools for creating, locating, opening, moving, renaming, and deleting saved [[file|files]]. On a Windows computer, a common file-management tool is **File Explorer**. On a Mac, it is **Finder**. Phones and tablets may provide a Files app or another file-management interface.

The OS also manages the underlying [[file-system|file system]]—the method used to organize and track stored information. In this beginner course, the important skill is knowing that files live in particular locations, whether on the device or in an online storage service. You will practice more detailed file organization in a later module.

### Job 4: Coordinate devices and input/output

The OS helps the computer receive input from keyboards, touchscreens, microphones, and other equipment. It also supports output through displays, speakers, printers, and similar devices. Depending on the hardware, it may work with a driver or other specialized software.

For example, when you change a device's volume, you are using a system control that affects audio output. When you connect a compatible printer, the OS may recognize it and make it available to applications.

### Job 5: Provide a way to control the computer

An OS supplies ways to use the device, such as a desktop, menus, settings screens, windows, app launchers, and touch gestures. These controls are part of the [[user-interface|user interface]]. Not every operating system uses exactly the same arrangement. Desktop computer systems commonly have movable windows; phones often open apps full screen.

The OS may provide accessibility tools such as text enlargement, screen readers, keyboard assistance, voice controls, or display adjustments. These features support different ways of using the same computing environment.

### Job 6: Manage user accounts and permissions

The operating system can provide separate [[user-account|user accounts]], sign-in methods, and [[permission|permissions]]. Permissions help determine which user or app can view information or perform particular actions. A shared computer might have different accounts for family members or employees. An employer may restrict some system settings to an administrator.

Not every protection is absolute, and security also depends on good decisions. However, OS accounts and permissions are important parts of the device's normal security system.

### Job 7: Support networking and connectivity

An OS usually includes settings and services for connecting to Wi-Fi or other networks, communicating with nearby devices, and accessing online resources through compatible apps. The OS helps manage the connection; it is **not the internet itself**. You can often write notes, edit local files, or use a calculator even without an internet connection.

### Job 8: Maintain the system

An OS supports software updates, error reporting, power management, and other system-maintenance tasks. Updates can improve reliability and fix security problems. Some updates require a restart, and available features vary by operating system and version. You will learn safe update and restart procedures in Lesson 7 of this course.

### Review: Match each OS job to an everyday action

| Everyday action | Operating-system job involved |
| --- | --- |
| Switch from a document to a music app | Coordinating programs |
| Keep several programs active | Managing processes and memory |
| Save a document in a folder | Managing files and storage |
| Select a printer | Coordinating hardware devices |
| Increase text size | Providing interface and accessibility settings |
| Sign in to a personal account | Managing users and permissions |
| Join a Wi-Fi network | Supporting connectivity |
| Install a system security update | Maintaining the system |

These jobs often overlap. Saving a file, for example, also uses memory, processing, and the storage hardware.

## 4. How do people interact with an operating system?

Most beginners work with a [[graphical-user-interface|graphical user interface (GUI)]]. A GUI presents visual elements—icons, buttons, menus, windows, and settings—so you can control the device without typing special technical commands.

### On a desktop or laptop

Common parts of a graphical desktop environment include:

- **Desktop:** The main workspace or background area where windows and sometimes shortcuts appear.
- **Taskbar or dock:** A location for launching, viewing, or switching between frequently used and running apps. Windows commonly calls its main bar the **taskbar**; macOS uses the **Dock** for many of these purposes.
- **App launcher or menu:** A place to find and open apps. Windows has the **Start** menu; a Mac has several ways to launch apps.
- **Windows:** Rectangular app areas that may be moved, resized, minimized, or closed, depending on the OS and app.
- **Settings:** Screens where you can view or adjust system preferences such as display, sound, network, or accessibility options.
- **Notifications:** Messages from the system or apps about events, reminders, or needed attention.

These names and designs can change with OS releases. The next lesson will teach **Desktop and Taskbar Basics** in more detail.

### On a phone or tablet

A mobile operating system is typically designed around touch input. You may use a **Home screen** to find apps, swipe to switch between screens, tap an icon to launch an app, or open a settings app. Some tablets also support keyboards, pointing devices, and overlapping windows.

The lack of a traditional Windows-style taskbar does **not** mean a phone lacks an operating system. Android, iOS, and iPadOS all manage apps, memory, hardware, connectivity, storage, and security.

### Not every interface looks graphical

Some systems also provide a [[command-line-interface|command-line interface (CLI)]], where a user types commands. Windows includes command-line tools, and macOS and Linux systems include terminal tools. They are useful in some settings, but **you do not need to use a command line for this lesson**. A graphical interface and a command line are different ways of interacting with the system, not different definitions of an OS.

### Accessibility matters from the beginning

An OS may be usable through a mouse, keyboard, touch, voice, screen reader, switch device, or other assistive technology. The goal is to complete the task, not to use one particular input method. If a step says “click,” a learner using a touchscreen may tap instead; a learner using a keyboard or screen reader may use the equivalent control.

> **Try this mentally:** When you select the Wi-Fi icon or open Settings, are you interacting with the device's operating-system controls or an ordinary website? You are using **OS controls**. A website may provide information about Wi-Fi, but it does not itself manage the computer's physical connection.

## 5. Which operating systems are common?

There is no single operating system used by every device. Different systems are designed for different kinds of equipment, users, and organizations. You may recognize the following names:

| Operating system | Common device category | Useful point to remember |
| --- | --- | --- |
| **Windows** | Many desktop and laptop PCs | Windows 11 is a Windows release; its Start menu and taskbar are common controls |
| **macOS** | Apple Mac desktops and laptops | Uses features such as Finder, the Apple menu, and Dock |
| **Linux** | Computers, servers, and specialized devices | A family of systems; desktop distributions may have different interfaces |
| **ChromeOS** | Many Chromebooks | Built around a streamlined computing environment with browser and app support |
| **Android** | Many smartphones and tablets | A mobile OS available across devices from multiple manufacturers |
| **iOS** | Apple iPhone | Apple's operating system for iPhones |
| **iPadOS** | Apple iPad | Apple's operating system designed for iPads |

These are examples, not a complete list. Some specialized computers, appliances, vehicles, and industrial equipment run other operating systems or embedded control software.

### Different operating systems may do the same basic work

Someone can write a document on Windows, macOS, Linux, ChromeOS, Android, iOS, or iPadOS if suitable software is available. However, the app may have a different name, layout, features, or file format on each system. A program designed for Windows does not automatically run on a Mac or iPhone. Software **compatibility** depends on the app, platform, hardware, and sometimes the OS version.

### Operating system, company, and device are not identical terms

A **Mac** is a computer made by Apple. **macOS** is the operating system normally used on that computer. An **iPhone** is a phone made by Apple. **iOS** is its operating system. A **Chromebook** is a type of computer that commonly runs **ChromeOS**; **Google Chrome** is a browser app, not another name for ChromeOS.

Likewise, a PC manufacturer such as Dell, HP, or Lenovo makes computers that may run Windows or another supported operating system. The name on the outside of the machine does not always tell you exactly which version of software is installed.

### Operating-system names and versions

An **OS family** is the broader product or category, such as Windows. A **version** is a particular release within that family, such as Windows 11. Some systems also show an **edition**, **build**, or **security update level**. You usually do not need to memorize these details, but they are useful when checking whether an app will work or asking for technical support.

A version number is **not** a performance rating. A higher number does not automatically mean every device will be faster, and a version number by itself cannot tell you whether your computer is safe or fully updated.

### Why recognizing your OS is useful

Knowing the OS helps you:

1. Follow the correct instructions for your device.
1. Choose apps designed to work with it.
1. Identify appropriate accessibility options.
1. Locate the right system settings.
1. Describe a technical problem accurately when requesting assistance.

> **Example:** If instructions tell you to use the Windows Start menu but your computer is a Mac, the steps may not match. Knowing that your device runs macOS helps you look for the Apple menu, Finder, or the equivalent Mac instructions instead.

## 6. What happens when a device starts or stops?

Your operating system is active during ordinary computer use, but the device also has important stages when it starts, rests, or shuts down.

### Starting up

When you turn on a typical computer, low-level hardware and [[firmware|firmware]] first help prepare the machine. The operating system then loads so that sign-in, the home or desktop environment, and applications can become available. This process is called [[boot|booting]] or startup.

You do not need to interact with boot settings to use a computer. On a shared or managed device, you may be asked to sign in before opening personal files or applications.

### Sleep, restart, and shut down are different

| Action | What usually happens | When it can be useful |
| --- | --- | --- |
| **Sleep** | Device enters a low-power state and can usually resume your session quickly | A short break when the device supports sleep |
| **Restart** | The operating system closes its session and starts again | Completing some updates or resolving certain temporary problems |
| **Shut down** | The device ends the running session and powers off under normal conditions | When you are finished and need the computer off |
| **Lock** | The session remains available but requires authentication to return | Stepping away from a shared or public workspace |

The exact behavior can differ by hardware and OS configuration. Some phones do not offer a traditional desktop-computer sleep command; instead, their screen locks and the system manages background activity.

**Save important work before a restart or shutdown.** Some apps can recover unsaved work, but you should not rely on automatic recovery. When a device seems unresponsive, avoid repeated forced power-offs as a first solution; seek approved help if you are unsure.

### Updates support reliability and security

OS developers release [[system-update|updates]] to fix defects, address security weaknesses, improve compatibility, and sometimes add features. An [[security-update|security update]] is specifically intended to address a security concern. Your device might download updates automatically or request permission or a restart.

For now, recognize the purpose of updates. Detailed update decisions, scheduling, and restart procedures belong to **Lesson 7: Updates and Restarts**. Never install a supposed “system update” merely because a strange website or pop-up demands it. Use the device's own update controls and trusted vendor instructions.

### Your files and accounts deserve protection

A computer that starts successfully is not automatically free from risk. Protect passwords and private information, lock shared devices when appropriate, and save important files in approved locations. A software update does not replace safe browsing, careful handling of attachments, or making backups of valuable information.

> **Safety note:** This course teaches you to *recognize* system controls before changing them. Do not reset a device, remove apps, change administrator settings, disable security tools, or share account details as part of these beginner activities.

## 7. Guided practice: Identify your operating system

These activities use ordinary, read-only system screens. You may perform them on a device you own or are authorized to use. **Do not change settings, install software, or share serial numbers, product keys, passwords, device IDs, or screenshots containing private account information.** If the device is managed by an employer or school, follow its policies. If no device is available, work from the examples instead.

### Activity 1: Find the OS name (about 5–10 minutes)

Choose the instructions for your device. Menu names can differ slightly by model, update, or accessibility mode.

**Windows 11 computer**

1. Open **Start** and choose **Settings**, or press **Windows key + I**.
1. Open **System** and select **About**.
1. Find **Windows specifications**. Look for the Windows **edition** and **version**.
1. Record the name and version on your worksheet, *not* a serial number or device identifier.
1. Close Settings when finished.

**Mac**

1. Open the **Apple menu** in the upper-left portion of the screen.
1. Choose **About This Mac**.
1. Look for the macOS name and version.
1. Record only the OS name and version, then close the window.

**Android phone or tablet**

1. Open **Settings**.
1. Look for **About phone**, **About tablet**, or a similarly named section.
1. Find **Android version** (sometimes under an additional **Software information** screen).
1. Record the OS name and version only.

**iPhone or iPad**

1. Open **Settings**.
1. Open **General**, then **About**.
1. Find the **iOS Version** or **iPadOS Version** entry, as available on the device.
1. Record the operating-system name and version only.

**Chromebook**

1. Open **Settings** from the system interface.
1. Find **About ChromeOS**, often near the bottom of the navigation area.
1. Read the ChromeOS version information without selecting update or reset controls.

**Linux computer**

1. Open your desktop environment's **Settings** or **System Information** tool.
1. Look for a section such as **About**, **System**, or **OS information**.
1. Record the distribution name and version if shown. Layouts vary widely, so use your distribution's help resources if the control is not obvious.

If your device does not match any set of steps, or the menu is unavailable, you may **skip that step** and describe which operating-system family you believe it uses. No activity requires administrator access.

### Activity 4: Follow one task through the system (about 5–10 minutes)

Imagine—or safely perform—the following task: **Open a notes app, type “The operating system helps my computer work,” and save or close the note without affecting an existing file.** If you cannot save in a suitable place, use a paper-only example.

1. Name the **app** used to enter the sentence.
1. Name the **input hardware** used to type or dictate it.

## 8. Common misconceptions

### “The operating system is the computer itself.”

No. The computer is the physical device. The operating system is software that runs on the device and coordinates its operation.

### “Windows is the same thing as Microsoft Word.”

No. Windows is an operating system. Microsoft Word is an application that can run in supported environments. Different apps can operate within the same OS.

### “Chrome is the same thing as ChromeOS.”

No. Chrome is a web browser. ChromeOS is an operating system used on many Chromebooks. Their names are related, but their functions differ.

### “The internet is an operating system.”

No. The internet is a global network of connected networks. An operating system may help a device connect to it, but many local activities do not require internet access.

### “Every operating system looks the same.”

No. Windows, macOS, Linux desktops, Android, iOS, and iPadOS can provide different menus, gestures, and settings. Even different versions of one OS may look different.

### “If the screen goes dark, the computer has shut down.”

Not necessarily. The screen may be off, the device may be locked or asleep, or the system may still be running. The visible screen alone does not prove a complete shutdown.

### “Installing a new version is always the right first step.”

No. Compatibility, organizational policy, backup readiness, device support, and official update guidance matter. Beginners should use trusted update channels and ask for help when uncertain.

### “An operating system makes every app safe.”

No. OS security features can help, but unsafe downloads, deceptive websites, account compromises, and user mistakes can still cause harm. Good security habits remain necessary.

### “You need to learn technical commands before using an OS.”

No. Everyday computer use can begin with a graphical or touch interface. Technical commands are an optional advanced method, not a prerequisite.

### “A newer OS version means I must purchase a new computer.”

Not automatically. Some systems can receive updates on supported hardware. Others have compatibility restrictions. The appropriate decision depends on the specific device, installed software, manufacturer support, and update requirements.

## 9. Essential vocabulary

Terms with a dotted underline earlier in the lesson can be selected for short explanations. Some tooltips also link to an MGU Encyclopedia article for deeper reading. Learn the meaning of the following terms rather than memorizing technical details.

- **Operating system (OS):** Core software that manages device resources, supports applications, and provides a working environment. [MGU Encyclopedia: Operating Systems](/library/encyclopedia/computer-science/software-systems/operating-systems).
- **System software:** Software that supports the basic operation and management of a computer. [System Software](/library/encyclopedia/computer-science/software-systems/system-software).
- **Hardware:** Physical computer equipment, including processors, screens, keyboards, and storage devices.
- **Software:** Programs and instructions used by computers. [Software Overview](/library/encyclopedia/computer-science/software-systems/software-overview).
- **Application software (app):** Software intended to help a user perform a specific activity, such as writing or browsing. [Application Software](/library/encyclopedia/computer-science/software-systems/application-software).
- **Processor (CPU):** Hardware that executes program instructions and carries out much of a computer's processing work.
- **Memory (RAM):** Working memory used to support programs and data while the device operates.
- **Process:** An instance of a program running on a device.
- **Multitasking:** The ability of a system to manage multiple active tasks or programs.
- **File:** A named unit of stored information, such as a document, image, or audio recording.
- **File system:** A method by which an operating system organizes and tracks stored files.
- **User interface:** The controls and presentation through which a person interacts with software.
- **Graphical user interface (GUI):** A visual interface with elements such as icons, menus, and windows.
- **Command-line interface (CLI):** An interface that accepts typed commands.
- **Device driver:** Software that helps an OS communicate with specific hardware. [Device Drivers](/library/encyclopedia/computer-science/software-systems/device-drivers).
- **Firmware:** Low-level software embedded in hardware that helps it perform fundamental functions. [Firmware](/library/encyclopedia/computer-science/software-systems/firmware).
- **User account:** A profile or identity used to access a device or its services.
- **Permission:** An authorization to access information or perform an action.
- **Boot / startup:** The process of starting a computer and preparing the OS for use.
- **Restart:** Ending the current OS session and starting the system again.
- **Sleep:** A power-saving state from which a device can generally resume more quickly than from a full shutdown.
- **OS version:** A particular release of an operating system.
- **System update:** An authorized change to system software intended to maintain or improve it.
- **Security update:** An update designed to address security issues.
