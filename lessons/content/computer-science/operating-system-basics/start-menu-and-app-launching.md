## Lesson 3: Start Menu and App Launching

The [[start-menu|Start menu]] is one of the main places to begin a task on a Windows computer. It can help you find a program, open a familiar tool, locate a document, or reach important system options without searching through desktop folders. A person learning to use a computer may know what they want to accomplish—write a note, calculate a total, or open a browser—without knowing where the program is located. The Start menu provides several routes from that intention to a useful app.

In this lesson, you will work with a Windows 11 Start menu and learn the difference between **finding**, **opening**, **pinning**, and **installing** applications. You will practice launching a harmless app, using search carefully, and recognizing when a search result is an installed program rather than a website or download suggestion. You will also learn equivalent methods on Macs and Chromebooks. This lesson builds on Lesson 2's desktop and taskbar skills without requiring you to change your computer's settings.

**Level:** Beginner · **Estimated study time:** 65–90 minutes · **Prerequisites:** Lessons 1–2, *What Is an Operating System?* and *Desktop and Taskbar Basics*, recommended · **Practice equipment:** A Windows 11 computer preferred; Mac, Chromebook, or paper-based alternatives provided · **Safety:** No downloads, purchases, account changes, or administrator access required

> **Essential idea:** The **[[start-menu|Start menu]]** is a convenient starting point for applications and system destinations. **[[search|Search]]** helps locate a program by name; a **[[pinned-app|pinned app]]** is a convenient shortcut, not a guarantee that the app is running; and **[[launch|launching]]** an app means starting or bringing it into use. **An installed app is not the same thing as a web search result or a Store suggestion.**

### Learning objectives

After completing this lesson, you should be able to:

1. Open and close the Windows 11 Start menu using a mouse, touchpad, or keyboard.
1. Recognize Search, pinned items, the app list, recommendations, and selected account or power controls when present.
1. Locate a commonly installed application by browsing or searching without downloading anything.
1. Launch a practice application and identify the window that appears.
1. Distinguish a program, its shortcut, an open window, a saved file, and a website or Store result.
1. Explain how pinning and unpinning change a convenient launcher without normally installing or uninstalling software.
1. Use basic keyboard and accessibility methods to navigate to an app.
1. Respond safely when a program is missing, has the wrong name, requires permission, or appears only as an online suggestion.
1. Compare the Start menu with the macOS Dock or app launcher and the Chromebook Launcher.

## 1. What is the Start menu for?

The Start menu is a part of the Windows [[graphical-user-interface|graphical user interface (GUI)]]. It gives you a recognizable place to reach programs and some commonly used computer functions. You do not need to memorize the physical location of every application file on the computer. Instead, you can open Start, choose a visible entry, or type part of the program's name. The operating system then helps you reach the item.

Think about a workplace supply cabinet with labeled drawers. You want a stapler; you do not need to know which factory made it or where each individual part is stored. You look for the right label and retrieve the tool. Start serves a similar organizing purpose for software, although the labels and available items depend on the computer.

When you want to do something with a computer, identify the **task** first. For example, “I need to add three prices” suggests a calculator; “I need to write a short reminder” suggests a note or text-editing program; “I need to visit a public website” suggests a browser. After identifying the task, you can choose an appropriate app. A useful habit is **task → suitable app → launch → verify the window → work**.

### Start is a launcher, not the entire operating system

The Start menu is not the same thing as Windows itself. Windows is the [[operating-system|operating system]]: it manages many resources and supports running software. The Start menu is one user-facing part of that system. It can open tools that affect the computer, but simply opening Start normally makes no change to your files or settings.

You may also launch an app through the taskbar, a desktop shortcut, File Explorer, or another application. Start is a useful primary route, not the only route. If you understand both the Start menu and the taskbar, you can recover when a particular shortcut is missing. You can also choose a method that is easiest for your input device or accessibility needs.

### What does “launch” mean?

To **[[launch|launch]]** an application means to open or start using it. For a typical app with a visible window, launching it usually makes a window appear. However, what happens depends on the program: if the program is already running, selecting its launcher may bring an existing window forward; some apps open a new window or a specific document; certain background utilities may not display an ordinary window at all.

A launch action is therefore different from the idea that a new copy of the program **must** start every time. When in doubt, check the screen for a window, a taskbar button, or a message asking you to sign in or choose an option. Do not repeatedly activate the same launcher just because you did not immediately see a result; a slow app may take a moment to appear.

### Simple examples: From intention to application

| Your intention | Possible application | What a successful launch may look like | What to avoid during beginner practice |
| --- | --- | --- | --- |
| Add up expenses | Calculator | A calculator window with number buttons | Entering real financial-account details |
| Write a harmless note | Notepad or another text editor | A blank text-editing window | Overwriting an existing document |
| Open a local folder | File Explorer | A window showing folders and files | Moving or deleting shared files |
| Browse the internet | A web browser, such as Edge | A browser window or new tab | Treating a suspicious website as trusted |
| Check a built-in feature | Settings | A window with categories of system options | Changing unfamiliar settings without a reason |

These apps are examples, not a requirement that every computer contain them. Windows 11 computers typically provide familiar built-in tools, but an organization may remove or restrict particular apps. App names can differ by language, version, or device policy. This lesson never requires installing a missing tool just to complete an activity.

### One app can be reached through several paths

Imagine that Calculator has a pinned Start icon, a taskbar icon, and an entry in the app list. Those are three ways to reach the same program. They do not normally represent three separate installations. If you can open Calculator through Search even when its pin is absent, you have learned an important troubleshooting skill: **a missing launcher is not necessarily a missing application**.

> **Remember:** Ask “What do I need to do?” and then “Which installed app can do it?” The Start menu helps with the second question. A search suggestion that would require a new download is not proof that the software is already on your computer.

## 2. What do you see when Start opens?

On a typical Windows 11 computer, select the **[[start-button|Start button]]** on the [[taskbar|taskbar]], or press the **Windows logo key** once. You should see a menu containing familiar app entries and ways to search or browse. To dismiss it without selecting anything, press **Esc** or select a neutral area outside the menu. The exact position of the Start button can vary: it is often near the center of the taskbar, but users may align taskbar items differently.

There is no single Start menu image that will match all computers. Windows 11 updates, company policies, accessibility preferences, and personalization can change the appearance and arrangement. On some Windows 11 versions, app sections appear together in a scrolling layout; on others, you use a separate **All apps** control. The essential functions—finding apps, launching them, and accessing selected system destinations—remain more important than any one screenshot.

### Recognize the main areas

| Area or label | Typical purpose | Important note |
| --- | --- | --- |
| Search field or search entry | Find apps, settings, files, and sometimes online results | Verify the type and source of a result before opening |
| Pinned | Shows chosen shortcuts for frequent use | A pin does not mean an app is open or newly installed |
| All or All apps | Browses applications available in the computer's app list | Layout can be a list, category, or grid, depending on version |
| Recommended or recent items | Surfaces recently used or suggested items where enabled | These entries can include documents as well as apps |
| Account/profile area | Provides some account-related actions | Do not switch or sign out of someone else's account |
| Power controls | Offers options such as Sleep, Shut down, or Restart | Do not use these controls during launch practice |

Some sections can be hidden or minimized. For example, Recommended entries may not appear if their providers or display options have been disabled. The All section may show apps in a format other than a traditional alphabetized list. Treat the labels above as functions to recognize, not a promise that every screen has exactly the same arrangement. Microsoft documents these variations in its current [Start menu guide](https://support.microsoft.com/en-us/windows/experience/personalization/customize-the-windows-start-menu).

### What is a pinned item?

A **[[pinned-app|pinned app]]** is a frequently used app or other shortcut kept in a convenient position. The Start menu's Pins area is like a small set of bookmarks for your software. A device might show Calculator, a browser, Settings, or apps provided by its manufacturer. Which icons you see does not prove which apps are currently running.

To open a pinned application, select its labeled icon once using a mouse or touchpad, or move keyboard focus to it and press Enter. A computer with touch input may allow a tap. Be sure you recognize the application you choose. If you are using a shared or institutional computer, avoid opening an app that exposes another person's documents or messages.

### What is the app list?

**All** or **All apps** provides a way to browse available installed applications without remembering their names exactly. Depending on the Windows 11 build, you may see an alphabetical list or categories and selectable views. Scrolling through the list is useful if you know the kind of app but cannot remember whether the name begins with “Note,” “Text,” or “Write.”

An **[[application|application]]** is a program intended to help you perform tasks. Examples include calculators, text editors, media players, and browsers. A full app can contain smaller features, tools, and tabs; a single app name may be different from the name of a file you open inside it. Also, some system services do not appear as launchable apps in the Start list.

### What does Recommended mean?

The **Recommended** area may show recently opened files, recently installed apps, or suggestions. It can be a useful convenience, but it is not a complete history of everything done on the computer. A recommendation may be based on activity or settings and may be hidden by policy. A suggested document is **not** the application that opens it. Select only items you own or are authorized to use.

For instance, suppose the Start menu recommends `meeting-notes.txt`. That text file contains information; it is not the text editor itself. Selecting the file may cause an associated application to open it. Later in this lesson you will distinguish opening a *document* from launching a *program*.

### Account and power are not for this exercise

A Start menu may also contain a profile image or account name and a power symbol. They serve different functions from the app list. The account area may lead to actions such as locking or signing out; the power area may include sleeping, restarting, or shutting down the device. They are important controls, but operating them can interrupt work. You will learn more about safe restarting in Lesson 7. For now, **identify these areas by sight without activating them**.

### When Start does not open where you expect

Check three simple possibilities: (1) the Start button may be positioned differently, (2) the taskbar may be hidden or your computer may be in a full-screen app, or (3) a different application may have focus. Pressing the Windows logo key is a useful alternative on many Windows keyboards. If the keyboard has no Windows logo key, use the visible Start control, an approved alternative input method, or ask a responsible support person. On managed or shared systems, do not edit the registry, install menu replacements, or disable security controls to change the layout.

## 3. How do you find and launch an app?

There are three practical beginner methods: select an existing pin, browse the app list, or search by name. Start with whichever needs the fewest steps on your device. The outcome should be the same: a recognized, authorized application is ready for use. The following examples use **Calculator** or **Notepad**, which commonly appear on Windows 11, but any harmless approved app is acceptable.

### Method A: Open a pinned app

1. If you have an unsaved document open, save it appropriately or leave it open; do not close it for this exercise.
1. Select **Start** or press the Windows logo key.
1. Look at the **Pinned** area, if your layout displays one.
1. Identify a familiar safe app, such as Calculator or Notepad. Do not select an unfamiliar financial, messaging, or administrative application.
1. Select the app once. Allow it time to start.
1. Look for the app window, taskbar indication, or other normal opening behavior.
1. If you see the right app, the launch succeeded. Close only your practice window after checking that it contains no unsaved work.

**If there is no pin:** This is not an error. Move to the app list or Search. Some computers have no pins, a different set of pins, or a recommended layout instead.

### Method B: Browse installed apps

1. Open the Start menu.
1. Find the **All**, **All apps**, or equivalent app-list area; on some Windows 11 versions this area is already shown in the scrolling menu.
1. Browse or scroll to the desired program. Some layouts allow you to switch between list, grid, or category views.
1. Read the app's name carefully. Similar icons can represent different tools.
1. Select the installed program to launch it.
1. Confirm that its window or another expected interface appears.

Browsing works especially well for recognition. You may not know what “Calculator” is called in a particular language, but you might recognize the icon or group after scrolling. If the device is managed by a school or employer, some applications may appear with organization-specific names.

### Method C: Search by name

1. Press the Windows logo key, or open Start and move to Search.
1. Type the name of a safe program, such as `Calculator` or `Notepad`.
1. Pause to inspect the results rather than selecting the first matching word automatically.
1. Look for a result identified as an **App**, or otherwise clearly identified as an application already installed on the device.
1. Select that app result, or use Enter if the correct result is currently selected.
1. Confirm that the app opens as expected.

If the search instead shows a website, Store suggestion, or article about a program, do not assume that the program is installed. You can leave the search without opening the result. Search is a finding tool; **the label on the result matters more than the similarity of the words**.

### How do you know the app launched?

Look for a change that makes sense: a calculator's number pad, a text editor's blank page, a browser's address bar, or a File Explorer window with folders. If you see a sign-in request, permission prompt, error, or installation offer instead, read it before responding. Many apps can function without opening a large conventional window, so for beginner activities select a tool with an obvious interface.

If an app's window is behind another window, use the taskbar or **Alt + Tab** to bring it into view, as practiced in Lesson 2. Do not repeatedly launch a slow app unless you are sure it has failed. Repeated launches might create several windows, start duplicate tasks, or make the screen confusing.

### Program, window, file, and shortcut: four distinct things

These words often appear together, but they describe different parts of an activity:

| Item | Plain-language meaning | Example | If you open it... |
| --- | --- | --- | --- |
| Program or app | Software designed to perform work | Notepad | The app may show a window |
| Window | A visible area controlled by a program | A Notepad editing window | You work within the app interface |
| File or document | Saved information | `practice-note.txt` | A suitable app may open it |
| Shortcut or pin | A convenient reference to something else | A pinned Notepad icon | The target app or destination is reached |

Suppose you launch Notepad and then create a practice note. The app is Notepad, the open editing space is its window, the saved `practice-note.txt` is a file, and a Start-menu pin is a way to reach Notepad again. Closing the window is not necessarily the same as deleting the file; removing a pin is not the same as uninstalling Notepad. These distinctions are essential for safe everyday work.

### What if you open a file rather than an app?

Windows associates many file types with applications. A `.txt` file commonly opens in a text-editing app; a `.pdf` may open in a document reader or browser; an image file may open in a picture-viewing app. Selecting a recent file therefore may **launch an app and open that particular document** in one operation. That can be convenient, but you should check the file name and whether you are authorized to see it.

A document can also open through an unexpected program because of a changed file association. If you see a prompt asking “How do you want to open this file?” or something similar, do not make systemwide changes while practicing. Close the prompt or ask a responsible person for assistance. Default app settings belong to a later, more advanced discussion.

### Launching is different from installing

**[[installation|Installing]]** software adds software components to a device. **Launching** runs an app that is already available. If a result is labeled **Get**, **Install**, **Download**, or **Open in Store**, the program may not be installed, or the link may lead to optional content. It is not necessary to proceed. Installing or removing apps has security and permission implications and is taught separately in Lesson 6.

> **Practice rule:** For this lesson, use applications that are already present and approved. Never enter payment information, grant administrative privileges, or download something to make a demonstration work.

## 4. How do you use Search without confusion?

Windows Search helps find more than installed apps. Depending on the device, it may show files, settings, web pages, support material, Microsoft Store suggestions, or information from supported connected services. This broad scope can save time, but it also creates a risk of selecting the wrong result. A careful beginner should search **by task or name** and then check **what type of result** has appeared.

### What kinds of results could appear?

| Result type | What you may be looking at | Appropriate beginner response |
| --- | --- | --- |
| Installed app | Program available on this computer | Open it if recognized and authorized |
| File | Document saved on a location you can access | Open only if it belongs to you or you have permission |
| Setting | Control that can change computer behavior | Identify it, but do not change unfamiliar settings |
| Web result | Online information or website | Check the URL and relevance before visiting |
| Store suggestion | Offer to view, obtain, or install software | Do not install during this lesson |
| Connected or organizational result | Content from a linked account or workplace system | Follow the account's access and privacy policies |

A result label such as “App,” “Settings,” “Web,” or “Microsoft Store” can be more informative than an icon alone. Current Windows 11 updates may show the source or type with varying emphasis. Read the text that is available; the layout can change between Windows versions.

### Search for an exact app name first

For a familiar program, type a clear name: `Calculator`, `Notepad`, or `File Explorer`. Avoid searching for broad words such as `money`, `video`, or `work` during the first exercise; those terms can produce numerous web pages, files, or product suggestions. A clear app name narrows the task and reduces mistakes.

If you cannot find an exact name, try an ordinary spelling variation or check the app list. The application might have a different name on your computer, the device might use another language, the organization may have restricted it, or the software might genuinely not be present. It is not necessary to “fix” this by downloading something.

### Search without opening anything

You can use Search as an observation tool. Enter a program name, study the list, and then press Esc to dismiss it. This is a good skill when learning an unfamiliar device. No app has to be launched, and no file has to be opened. You can practice classifying results—app, file, settings page, or website—even if you prefer not to run anything.

### How to avoid common mistakes

- **Do not confuse a familiar app name with a familiar-looking advertisement or Store entry.** A matching word does not guarantee the result is the locally installed program.
- **Do not trust a result solely because it appears near the top.** Ranking and suggestions vary.
- **Do not open unexpected private files.** A shared computer may show documents that are not yours.
- **Do not act on security warnings mechanically.** Read what the message asks and stop if it involves permissions or unfamiliar software.
- **Do not enter passwords into arbitrary search results or unfamiliar websites.** Use the appropriate approved sign-in process for the app or service.
- **Do not copy commands from the internet into Run, PowerShell, or a terminal as a substitute for opening a known app.** This lesson does not require command execution.

### Search from Start versus a browser

Typing in the Windows Start menu's Search area is different from typing in a web browser's address bar. The first may find local applications and system destinations; the second usually navigates to or searches the web. Windows Search can also include online results, so it is possible for the two activities to overlap. **Where you entered the words and how the result is labeled** help you decide what will happen when you select it.

For example, typing `Notepad` into Start may reveal an installed Notepad app. Typing `Notepad` into a browser's search box generally finds webpages describing or offering text editors. A webpage is not automatically an installed program. A web application can still be useful, but it operates through a browser and may require an account or internet connection.

### What if the installed app does not appear?

Pause and check what you know. Did you spell the name correctly? Are you looking under the correct user account? Has the application been renamed or grouped differently? Could the computer have organization-specific restrictions? Can you find the item by browsing the app list rather than Search? If not, select a different approved practice app or complete the paper-based exercise. **No lesson activity requires changing permissions, performing a repair, or installing software.**

### Keyboard search shortcuts

Pressing the **Windows logo key** commonly opens Start, after which typing an app name can begin a search. **Windows logo key + S** opens Windows Search directly. These shortcuts are helpful if the taskbar icon is hard to reach. **Esc** usually dismisses the active menu or search surface. The **Enter** key activates a selected result, so always verify that the correct item has keyboard focus before pressing it.

Windows logo key + R opens the **Run** dialog, but this lesson does **not** require it. Run accepts names and commands and can lead to advanced system tools. Beginners should learn ordinary Start, Search, and app-list navigation first. An application missing from Search is not a reason to try instructions from an unknown website in Run.

## 5. How do pins and shortcuts help you?

A **[[shortcut|shortcut]]** is a reference that provides access to a program, file, folder, or other destination. A Start-menu pin is a convenient launcher that can make a frequent task easier to reach. The main purpose of pinning is **organization**, not installation. You can use an app without pinning it, and you can unpin a launcher while the app itself remains installed.

### Pinned versus installed versus running

| Status | What it answers | Example | What it does **not** prove |
| --- | --- | --- | --- |
| Installed | Is the software available on this computer? | Calculator is installed | That it is currently running |
| Pinned | Is a convenient launcher saved in a particular place? | Calculator appears in Start Pins | That it was installed by the pinning action |
| Running | Is the app currently active or executing? | Calculator has an open window | That it is pinned for future use |
| Open file | Is a particular document in use? | A note is open in Notepad | That the document is the application itself |

An installed app can be pinned or unpinned. A running app can be pinned or unpinned. A pinned app can be closed. These properties describe different things. Learn to say “I opened Calculator,” “I pinned Calculator to Start,” or “I saved a document” rather than using the phrase “I put the app on my computer” for all three actions.

### Pin to Start: What it means

On many Windows 11 computers, you can search for an installed app, right-click its result, and choose **Pin to Start**. The shortcut can then appear in a Pins section. A keyboard user may use the context-menu key or **Shift + F10** when supported, then navigate the available menu. A touch user may press and hold on certain items. Exact options vary by app and device policy.

**Changing pins is optional for this lesson.** On a personally managed device, you may practice with an ordinary app and restore the prior arrangement afterward. On a school, library, workplace, or shared computer, do not reorganize someone else's launcher without permission. The core lesson can be completed by simply explaining what **Pin to Start** would do.

### Unpin from Start: What it does and does not do

A context menu may provide **Unpin from Start**. That removes the pin from that Start-menu location. It does **not normally uninstall the application** or delete its saved documents. You may still find the program by typing its name or browsing the installed-app list. **Uninstall** is a separate action; do not confuse the two words. The difference matters because one is a navigation preference while the other changes what software is present on the computer.

If you are studying on a shared PC, avoid using any option labeled Uninstall, Remove, Delete, or a similarly consequential action simply to see what it does. Some operating systems and apps use “Remove” for different purposes; read the full context rather than assuming it is harmless.

### Pin to taskbar versus pin to Start

Both operations create convenient access points, but they appear in different places. A Start pin is inside the Start menu; a taskbar pin remains on the taskbar so you can reach an app without opening Start. An app can be pinned to one place, both places, or neither. Lesson 2 explained taskbar basics; the present lesson focuses on using Start as a gateway.

### Organize by frequency and purpose

An effective launcher puts frequently used tools within easy reach without filling the screen with unnecessary icons. Imagine someone who regularly writes, calculates, and studies. Their frequent-app set might contain a browser, a text editor, and a calculator. Another person doing media work might prioritize a photo editor and audio player. There is no universal “correct” group of pins. The goal is to reduce the number of steps required to reach familiar, authorized tools.

The placement or grouping options available in Windows 11 depend on the version. Some allow rearranging or grouping pins; newer variants can show different views and collapsed sections. Follow the interface displayed on your device rather than using old screenshots as exact instructions. Organizing a pin is generally reversible, but the safest approach on a device you do not own is to leave the layout unchanged.

### Shortcuts do not guarantee permission

An icon may lead to a shared network resource, paid software, or an account-protected application. Seeing the icon does not grant permission to use that resource. If a program asks for credentials, a subscription, or elevated privileges, stop and consult the device owner, administrator, or course instructor. No practice activity requires working around restrictions.

### A practical decision path

When you want to open an app, ask these questions in order:

1. **Is the app visible in a known Start pin?** If yes, select it and confirm its window.
1. **If not, can I find it under All or All apps?** Browse the locally available apps.
1. **If not, does Search clearly identify an installed application?** Select only that type of result.
1. **If Search shows a web or Store suggestion instead, do I really need this app?** For this lesson, choose a different approved app rather than downloading software.
1. **If the app does not open, what safe next step is available?** Check the taskbar for an existing window, wait briefly, or ask for assistance.

This decision path is intentionally simple. As you gain experience, you will learn installation, updates, permission handling, and troubleshooting in later lessons. For now, successful app launching means reaching a known program **without risking files, accounts, or system configuration**.

## 6. What if your computer looks different?

Operating systems solve similar problems with different visual arrangements. Mac computers do not use a Windows Start menu, and Chromebooks use a Launcher instead of Windows Start. The purpose remains familiar: locate an application, activate it, and see its interface. Windows versions and device-managed environments can also vary from one another. Understanding the **function** helps you transfer your skills to a different machine.

### Windows 11 may have more than one Start layout

One Windows 11 device may display a visible **All apps** button, while another shows **All** as a scrolling area in the Start menu. Pinned and Recommended sections may appear expanded, collapsed, or not visible. Some installations emphasize categories, lists, or grids. These differences arise from software updates and settings; they do not mean the student is using the computer incorrectly.

Microsoft's current Start instructions describe Search, pins, app browsing, recommendations, account controls, and power controls. They also describe options for hiding or reorganizing sections. The safest approach in this lesson is to **identify the function from labels and descriptions**, not to insist on a fixed number of columns or screen coordinates.

### macOS: Dock, Spotlight, and the apps view

On a Mac, the **[[dock|Dock]]** provides quick app access. A user can also open an app by searching with **[[spotlight|Spotlight]]**, typically through **Command + Space** or the Spotlight control, then typing the app's name and pressing Return once the correct result is selected. Macs also have an Applications folder. Newer macOS versions provide an apps view or launcher interface; older instruction books may refer to Launchpad. You do not need any one launcher screen to understand the main task: find the installed app and open it.

For example, to launch a Mac calculator, use Spotlight to find **Calculator**, verify that the application is the chosen result, and activate it. The Mac's menu bar, Dock, and app windows look different from Windows, but there is still a clear distinction between launching software and opening a saved document. An app can run without a visible app window, and choosing an icon from the Dock may bring an already running app to the front.

### ChromeOS: Launcher and shelf

On a Chromebook, the **[[launcher|Launcher]]** helps find applications, files, and some settings. You can typically select the Launcher control or press the keyboard's **Search/Launcher key**, if available. Type an app's name or browse the available list, then select it. The **[[shelf|shelf]]** is the taskbar-like strip used for commonly available or active apps. Apps may be pinned to the shelf for convenience; that is an organizational action, not the same as installing them.

Some Chromebook applications run as web apps, while others are installed or provided through supported app services. This is another reason to check how a result is labeled. Not every Chromebook has access to every app, and school-managed devices may restrict choices.

### Phones and tablets: Home screen and app library

Smartphones and tablets often use a **[[home-screen|Home screen]]**, app drawer, or app library instead of a desktop-style Start menu. A tap may launch an app; swiping or search can find additional apps. Some icons lead to web links or shortcuts rather than separate installed applications. The same distinction among finding, launching, and installing still applies.

### Compare the app-launching approaches

| Device family | Common place to find apps | Typical search method | Quick-access area |
| --- | --- | --- | --- |
| Windows 11 PC | Start menu and All/All apps | Start Search or Windows logo key + S | Start pins or taskbar |
| Mac | Applications folder or apps view | Spotlight, often Command + Space | Dock |
| Chromebook | Launcher | Search/Launcher key | Shelf |
| Smartphone/tablet | Home screen or app library/drawer | Device app search | Home-screen icons or dock-like area |

The table summarizes general patterns. Exact names and key combinations depend on the hardware, operating-system version, assistive technology, and personalization.

### Accessibility: You do not need a mouse

Windows includes keyboard access to Start and Search. Press the Windows logo key; use Search or available arrow-key and Tab navigation; read the focused item's name; activate the intended result with Enter. **Tab**, arrow keys, and other navigation controls may behave differently depending on the current menu section, so pause to confirm focus rather than pressing Enter reflexively.

A **[[screen-reader|screen reader]]** can announce controls, result categories, and selection state. **[[keyboard-focus|Keyboard focus]]** identifies the element that will receive your next keyboard action. Users may also enlarge text, use magnification, activate voice access, or rely on alternative pointer devices. Many Windows accessibility features can be reached from keyboard commands or the Settings application, but changing them is not required to complete this lesson. Lesson 8 covers accessibility settings in detail.

If the Windows logo key does not work, use the mouse, touchpad, accessible Start button, or an approved alternate control. If you use a screen reader, follow its current navigation guidance; shortcuts can depend on screen-reader mode. The objective is to **find and identify the correct app**, not to use a particular body movement or input device.

### Shared, school, and workplace computers

On a managed computer, the organization may limit access to apps, hide sections, customize the Start menu, and require sign-in for certain software. You should follow those policies, use your own account, and leave another person's layout unchanged. Do not attempt to get around restrictions by changing accounts, using unauthorized portable apps, or launching system tools with elevated permissions.

### What to do when an app does not start

First, consider ordinary explanations: perhaps the program is already open behind another window, perhaps it is taking time to load, or perhaps the computer is temporarily busy. Check the taskbar or use an approved window-switching method. If a warning or error appears, read and record the non-sensitive text, without sharing passwords or private identifiers. Do not repeatedly dismiss security prompts or enter administrator credentials that do not belong to you. If the failure persists, ask the responsible support person and continue the practice with another available app.

> **Transferable skill:** Regardless of operating system, identify a trustworthy launcher, verify the application you intend to use, activate it, and confirm that the right app is available. Avoid installing anything or changing permissions simply because one route fails.

## 7. Guided practice: Find and open apps

Complete these activities on an approved computer if one is available. A Windows 11 PC is best for the detailed controls, but Mac and Chromebook students may adapt the activities using the methods in Section 6. You may also complete the paper-based alternatives without touching a computer. **You do not need to install anything, change any settings, create an account, enter sensitive information, or open private documents.**

Choose a harmless app such as Calculator, Notepad, or a familiar browser already present on the computer. If you are using a shared or managed machine, follow its rules and do not modify another user's pins. A practice demonstration is successful when you understand the process; there is no requirement that a specific app name appear on every device.

### Activity 1: Map the Start menu (about 7–10 minutes)

**Purpose:** Recognize the main functions of Start without opening applications.

1. Press the Windows logo key, or select the Start button on the taskbar.
1. Identify any visible Search area or indication that typing can begin a search.
1. Look for **Pinned** items or another area containing convenient application icons.
1. Find a way to browse all available apps. The label may be **All**, **All apps**, or a similar entry, and the view may be built into the Start menu.
1. Look for Recommended or recent items, if enabled. Do **not** open any files shown there.
1. Find the profile and power controls **by sight only**. Do not select them.
1. Press Esc to close Start, then open it again using a different available input method if possible.
1. Complete the worksheet below, leaving “not shown” if a particular section is hidden.

| Item to locate | What you observed | What the area is for |
| --- | --- | --- |

**Reflect:** Was your Start menu arranged like an illustration in a textbook? If not, which functions could you still identify? A different arrangement is normal when the important controls are present in another location.

A successful response identifies available search, app-launching, and app-browsing functions, even if one or more sections are hidden. The Start button may be centered or left-aligned. ### Activity 2: Launch a familiar app two ways (about 8–12 minutes)

**Purpose:** Demonstrate that an application can have more than one launcher.

1. Choose a familiar, harmless installed app, preferably Calculator or Notepad. On a Mac, choose Calculator; on a Chromebook, choose an approved built-in app.
1. Open Start and look for the app in Pins or the available app list. If it is not there, skip to Step 3.
1. If you can see the correct installed app, select it and confirm that the expected window or interface opens.
1. Return to Start, or close only your own empty practice window when it is safe to do so.
1. Use Search to enter the same app's name.
1. Read the result type. Select the installed application, **not** an offered download, website, or document with the same name.
1. Confirm that the appropriate app is available again. If the existing window becomes active instead of a new window opening, that is also an acceptable outcome.
1. Record the two routes you tried and what appeared.

**Example:** “I opened Calculator from the Start app list. Later I searched for Calculator, chose the result labeled App, and saw a calculator window. I did not need to install Calculator.”

If the app is not available, use another installed app or write how these steps would work. Do not install missing software simply to complete the activity.

:::answer Show Activity 2 explanation
The two routes are different paths to the same installed application. Choosing a pin or browsing the app list is one route; Search is another. Launching the app may create a window or bring its existing window forward. Neither action requires an installation. If only a Store or web result appears, the student should stop or select another approved app.

### Activity 4: Explain pinning without changing the system (about 7–10 minutes)

**Purpose:** Learn the difference between organization and installation.

**Statement A:** Pinning an app installs a second copy of that software.  **True / False**

:::answer Show Activity 4 answers

### Activity 5: Choose the safest launch method (about 10–12 minutes)

**Purpose:** Apply the lesson to situations encountered at school, at work, or at home.

**Scenario C — Existing window:** You select a browser from Start and nothing seems to happen, but you see its taskbar icon and a different app covering the screen. What might you try?

:::answer Show Activity 5 suggested responses
**A:** Browse All/All apps or search for Calculator as an installed app. The missing pin alone does not prove uninstallation.

**B:** Choose another approved program already on the computer, or complete the paper alternative. Do not install software for the practice exercise.

**C:** Use the taskbar or an approved window-switching method such as Alt + Tab to locate an existing browser window; allow extra loading time if needed.

**D:** No. A recommendation is not permission to read someone else's document.

**E:** No. Stop, leave the app unchanged, and ask the device owner or support staff. Administrator credentials and security controls are not obstacles to bypass for an introductory lesson.

## 8. Common misconceptions

### “The Start menu is the same thing as Windows.”

No. Start is a user-interface feature within Windows. The operating system performs many functions even when the Start menu is closed. Start is one convenient gateway to system functions and installed applications.

### “If an app is not pinned, it is no longer on the computer.”

Not necessarily. Pinning affects how conveniently you reach something, not whether the app is installed. Search or browse the app list before assuming a missing pin means missing software.

### “Everything in Start is an installed app.”

No. Start can display files, settings, system options, shortcuts, recommendations, and sometimes other destinations. Search can also show online material or Store suggestions. Identify the result type before selecting it.

### “The first search result is always the correct one.”

No. Search may prioritize a webpage, file, suggestion, or another app with a similar name. Verify the label, source, and purpose of the result before opening it.

### “Opening an app always opens a brand-new window.”

Not always. Selecting an already running program may bring an existing window forward. Some apps launch into the background or have different window behavior. Use the taskbar or a window switcher to check.

### “A shortcut is the complete program.”

Usually not. A shortcut is a reference used to open another item. Removing an ordinary launcher shortcut normally does not remove the program or its data.

### “Unpin and Uninstall are two names for the same action.”

No. Unpin generally removes a convenient entry from a launcher location. Uninstall removes installed software components. These operations have very different consequences.

### “A Recommended document is available for anyone to read.”

No. A file appearing on a screen is not permission to open it. Follow privacy, ownership, and account-access rules on shared computers.

### “You must have internet access to start any app.”

No. Many local applications can launch and do useful work without an internet connection, although some apps and features may require one. A downloaded or installed program is different from a website that only operates online.

### “If I see a Store link, the program is already installed.”

Not necessarily. Store links may offer software that is not installed. Do not treat “Get” or “Install” as the same action as “Open.”

### “Every Windows 11 Start menu looks exactly alike.”

No. Microsoft changes layouts across updates, and people or organizations can configure what is shown. Learn to identify Search, pins, the app list, and result labels rather than relying on one fixed screenshot.

### “Opening Start automatically changes the computer.”

No. Simply viewing Start or a result list does not ordinarily install software, change settings, or alter files. Choosing certain commands can cause changes, which is why you should identify what an option will do before activating it.

### “The Run dialog is a better beginner alternative to Start.”

Not for routine practice. Run can open commands and advanced tools; typing a command found on an unfamiliar website creates unnecessary risk. Start, Search, and the installed-app list are more appropriate for a first lesson in launching apps.

### “If an app asks for administrator permission, I should keep trying until it opens.”

No. Administrative access is a security control. Do not attempt to bypass it or use credentials that are not your own. Stop and request authorized assistance.

### “Keyboard users cannot navigate the Start menu.”

Not true. Windows supports keyboard input and accessible navigation. The Windows logo key, Search, Tab, arrow keys, Enter, and screen-reader features can assist with app selection, depending on the user interface and focus.

### “A Mac or Chromebook cannot teach me app-launching skills because it has no Start menu.”

The names differ, but the workflow is transferable: find the appropriate app in a launcher or app list, verify what it is, activate it, and confirm that it opened. Macs and Chromebooks offer their own launchers and search tools.

## 9. Essential vocabulary

Words with a dotted underline earlier in the lesson can be selected to open a short definition. Where a verified MGU Encyclopedia article exists, the tooltip also links to a longer explanation. Use this section for review; you do not need to memorize every term before practicing.

- **Start menu:** Windows interface for reaching applications, selected files, settings, and system actions.
- **Start button:** Taskbar control that opens the Windows Start menu.
- **Graphical user interface (GUI):** Visual environment using controls, icons, menus, and windows to interact with software.
- **Operating system (OS):** Foundational software that manages resources and supports applications.
- **Application (app):** A program used for a task, such as calculating, writing, or browsing.
- **Launch:** Start or bring an application into use.
- **Search:** A tool for finding items by their names or other information.
- **Search result:** A matching item shown in response to a search query.
- **Pinned app:** An app or destination with a convenient launcher entry in Start, the taskbar, or another location.
- **All / All apps:** Windows Start area used to browse locally available applications.
- **Recommended:** A Start area that may show recently used items or other suggestions, when enabled.
- **Shortcut:** A reference that opens another program, item, or location.
- **Taskbar:** Windows navigation strip containing app controls and selected system indicators.
- **App window:** A visible workspace controlled by an application.
- **Installed app:** Software made available on the device through an installation or system-provisioning process.
- **Installation:** The process of adding software components so a program can be used.
- **Uninstall:** Remove installed application components from a computer through an approved process.
- **Unpin:** Remove a launcher entry from a location such as Start without ordinarily uninstalling its software.
- **Context menu:** A menu of actions for a selected item, often opened by right-clicking or an accessible equivalent.
- **File:** A saved collection of information, such as a text document or photograph.
- **File association:** A relationship between a file type and the application that ordinarily opens it.
- **Web result:** An online page or destination found during a search.
- **Store suggestion:** A result offering software or content through an app distribution service; it may not be installed locally.
- **Keyboard shortcut:** A key or key combination that performs a common action quickly.
- **Keyboard focus:** The current control or item that will receive keyboard actions.
- **Screen reader:** Assistive software that announces interface content and controls through speech or another output format.
- **Dock:** A macOS area used to reach apps and certain other destinations.
- **Spotlight:** macOS search interface used to find apps, files, and information.
- **Launcher:** An interface that helps users find and open applications; particularly the app-finding interface on Chromebooks.
- **Shelf:** ChromeOS app and navigation strip, roughly comparable to a Windows taskbar.
- **Home screen:** App-launching workspace commonly found on phones and tablets.
