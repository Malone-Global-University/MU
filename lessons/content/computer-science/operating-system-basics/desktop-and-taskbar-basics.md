Basic Computer Skills / Operating System Basics

## Lesson 2: Desktop and Taskbar Basics

When a Windows computer is ready to use, you usually see a background, icons, and a strip of controls called the **taskbar**. As you open apps, rectangular areas called **windows** appear on the screen. Learning to recognize these parts is one of the most useful first steps toward operating a computer independently. You will learn to identify desktop elements, use the taskbar to move among open programs, manage windows without losing your work, and keep a workspace organized. The lesson uses Windows 11 for hands-on examples and explains comparable controls on other systems.

**Level:** Beginner · **Estimated study time:** 60–85 minutes · **Prerequisites:** Lesson 1, *What Is an Operating System?*, recommended · **Practice equipment:** A Windows 11 desktop or laptop preferred; Mac or Chromebook for observation; paper-based alternatives provided

> **Essential idea:** The **[[desktop|desktop]]** is a visual workspace. The **[[taskbar|taskbar]]** helps you reach apps, see which ones are running, and switch between tasks. An **[[app-window|app window]]** is a movable area in which you work. Learning the difference between *showing*, *minimizing*, *switching*, and *closing* windows helps you use a computer safely and efficiently.

### Learning objectives

After completing this lesson, you should be able to:

1. Identify the desktop, wallpaper, icons, taskbar, and open app windows on a typical Windows 11 screen.
1. Explain the difference between a desktop icon, a shortcut, a file, an app, and a taskbar button.
1. Recognize the Start, Search, app, status, and clock areas of the taskbar without needing to change system settings.
1. Distinguish a pinned app from an app that is currently running.
1. Minimize, restore, maximize, move, and close a practice window while protecting unsaved work.
1. Switch between two open windows using the taskbar or a keyboard shortcut.
1. Use at least one safe method to display the desktop or arrange windows side by side.
1. Describe basic desktop and taskbar equivalents on a Mac or Chromebook.
1. Practice accessible, privacy-conscious habits when working on shared or unfamiliar computers.

## 1. What is the desktop workspace?

On a typical Windows computer, the **[[desktop|desktop]]** is the main graphical work area displayed after you sign in. It may show a background photograph or color, a few icons, and the taskbar. It is not a physical desk, and it is not the same thing as a *desktop computer*. A laptop and an all-in-one computer can display the same kind of Windows desktop.

The operating system provides the desktop as part of a **[[graphical-user-interface|graphical user interface (GUI)]]**. A GUI lets people interact with software through visual elements such as icons, windows, buttons, and menus. You can typically use a mouse, touchpad, touchscreen, keyboard, or accessible input device to operate these controls.

Imagine a student preparing an assignment. The student might keep a document open in one window, use a web browser in another, and switch between the two using the taskbar. The desktop is the workspace underneath those windows; it does not disappear simply because a program covers it.

### A typical Windows 11 desktop at a glance

| Visible element | Usual location or appearance | Main purpose |
| --- | --- | --- |
| Desktop background | Image or solid color behind app windows | Helps distinguish the workspace visually |
| Desktop icons | Small images with text labels, often at one side | Represent items such as shortcuts, files, folders, or Recycle Bin |
| Taskbar | Strip usually along the bottom edge | Provides access to Start, apps, and system information |
| App window | Rectangular work area above the desktop | Displays a running program, document, or other activity |
| Pointer | Movable arrow or other cursor | Shows where a mouse or touchpad action will take place |
| Clock and status area | Usually near the right end of the taskbar | Shows time and selected device status information |

These are **typical Windows 11 arrangements**, not a guarantee that every computer looks identical. Organizations may control the desktop layout, a person may customize the display, and Windows updates may adjust the appearance of individual controls. On touch devices and multi-monitor setups, locations and behaviors can differ.

### The desktop is not the whole computer

A desktop is a way of interacting with an [[operating-system|operating system]], not a physical hardware component. Windows can still run tasks when a window hides the desktop. Likewise, a program may continue playing audio after you minimize its window.

The word *desktop* also has a second common meaning: a **desktop computer**, which is a kind of physical computer usually intended to stay at a desk. The context tells you whether someone is talking about the device or its on-screen workspace.

### What happens after sign-in?

Depending on the computer and its configuration, you may encounter a sign-in screen first. After the user signs in, Windows loads a personal workspace. You might see familiar icons and a taskbar, but the exact items depend on the signed-in account. Shared computers can have different desktop arrangements for different users.

> **Remember:** The desktop is the **work area**, a window is a **place where an app appears**, and the taskbar is a **navigation strip**. They work together, but they are not interchangeable.

### A brief note on the mouse and touchpad

- **Point:** Move the mouse or slide a finger across the touchpad so the pointer rests on an item.
- **Click:** Press and release the primary mouse button, or perform the touchpad's primary click, to select or activate a control.
- **Double-click:** Click twice quickly when opening many desktop files or shortcuts; some systems use different activation preferences.
- **Right-click:** Open a contextual menu of available actions, often using the secondary mouse button or a two-finger touchpad gesture.
- **Drag:** Hold down a pointer button while moving an item, then release. Dragging can move windows or files, so use it deliberately.

The exact method can vary by accessibility settings, hardware, and user preferences. A keyboard alternative is often available.

## 2. What do desktop icons represent?

A desktop **[[icon|icon]]** is a small visual symbol used to represent a computer item. A labeled icon might stand for a document, folder, app, shortcut, or system location. Although several icons may look alike, the objects they represent can have very different consequences if opened, moved, or deleted.

### Recognize common kinds of desktop items

| Item | What it represents | Typical safe action | Important caution |
| --- | --- | --- | --- |
| App shortcut | A link that opens a program or related destination | Double-click to open an authorized app | Deleting a shortcut does not normally uninstall the app |
| File | Saved information such as a document or photograph | Open to view or work on a copy | Moving or deleting it can affect the actual saved information |
| Folder | A location used to organize files and other folders | Open to examine its contents | Moving or deleting a folder can affect the items inside |
| Recycle Bin | Windows location for many items sent to be deleted | Open only to inspect, if permitted | Emptying it can permanently remove its contents |
| System icon | A special Windows entry such as This PC | Open to inspect available locations | Some settings and system locations require extra care |

A **[[shortcut|shortcut]]** is generally a reference to something elsewhere; it is not necessarily the thing itself. Many Windows shortcuts display a small arrow overlay, although overlays and icon appearances can be changed or hidden. Not every icon with a particular appearance should be judged only by its picture. Read its label and, when necessary, ask the computer's owner or administrator.

### Select versus open

A single click on an ordinary desktop icon usually **selects** it. The item may change color or show a highlight. Selection alone does not normally open the item. A double-click typically **opens** a file, folder, or shortcut in Windows' default configuration.

This distinction matters when you are learning. If the assignment says “select the folder,” you need not double-click or open it. If it says “open the folder,” you usually need the second action. Some computers are configured to open items with a single click instead, so observe the device rather than assuming every machine uses the same setting.

### A folder icon does not tell you what is inside

A folder may contain documents, photographs, other folders, or shortcuts. Opening a folder shows its contents through File Explorer or another file-management interface. This does not automatically change those contents. Renaming, moving, deleting, or overwriting files is a separate action, and beginners should avoid such changes to shared materials unless authorized.

### The meaning of the Recycle Bin

Windows provides the **[[recycle-bin|Recycle Bin]]** as a location for many deleted files and folders. It can offer an opportunity to restore some items, but it is **not** a substitute for a backup. Some deletions bypass the Recycle Bin; storage devices and organization policies can affect what happens; and emptying the Recycle Bin can remove items permanently.

**Do not delete a real document merely to test how the Recycle Bin works.** In this lesson, recognizing the icon is enough.

### Desktop clutter and purposeful organization

If dozens of icons cover the desktop, it can become difficult to find work. A useful practice is to keep commonly used shortcuts easy to recognize and store documents in appropriate folders. However, the desktop itself can also hold real files. Do not assume everything visible there is merely decorative or a shortcut.

> **Safety rule:** If you did not create an item, do not rename, drag, delete, or empty it as part of this lesson. All required practice can be completed without changing someone else's files.

### Mini-scenario: What would you click?

You see three items: a folder labeled “School Work,” a shortcut labeled “Calculator,” and a document labeled “Budget.” To do arithmetic, opening the Calculator shortcut is appropriate. To locate existing homework, opening School Work is appropriate. Opening Budget may reveal private financial information and is not necessary. The **label**, the **type of item**, and your **permission to access it** should guide your decision.

## 3. What is the taskbar, and what does it show?

In Windows 11, the **[[taskbar|taskbar]]** is normally a horizontal strip along the bottom of the screen. It serves as a navigation and status area: it contains a way to reach Start, can display Search and other controls, and shows app buttons for programs that are pinned or running. It also includes system information near the far end.

The arrangement can change. A person can adjust the alignment of taskbar icons and hide some controls. Taskbar buttons might be grouped, labels might be available under certain settings, and a touch-oriented layout may behave differently. Learn each element's **function**, not just its precise position in one screenshot.

### A simplified taskbar map

| Area | What you may see | What it is for |
| --- | --- | --- |
| Start | Windows logo | Opens access to apps and other Start options |
| Search | Magnifying glass, search box, or search control | Helps find apps, files, and settings |
| App buttons | Icons such as File Explorer, a browser, or Calculator | Open or return to those apps; indicate running status |
| Task View, if shown | Task View control | Displays open windows and virtual desktops |
| Notification area or system tray | Selected status and background-app icons | Shows certain system and app status controls |
| Quick settings area | Icons such as network, sound, and battery when applicable | Provides access to common device controls |
| Clock and notification controls | Time, date, or notification indicators | Helps check time and view notices |

The Start menu itself is the main subject of **Lesson 3: Start Menu and App Launching**. Here, you only need to recognize the Start button. Detailed system icons and notifications are covered in **Lesson 5: Notifications and System Icons**.

### Pinned apps and running apps are different

A **[[pinned-app|pinned app]]** has a persistent shortcut on the taskbar so you can reach it easily. Pinning does not mean the app is running all the time. A **[[running-app|running app]]** is an application with an active process; when it has a window, that app can usually be reached through its taskbar button.

When an app is running, Windows typically displays a visual indication on or beneath its taskbar icon. Depending on taskbar preferences and the number of open windows, the indicator may look different. An app can be both pinned and running, pinned but not running, or running without being pinned.

Consider a browser icon:

1. **Pinned but closed:** Its taskbar icon can remain visible so you can start the browser.
1. **Pinned and open:** The icon remains and normally indicates that the browser is running.
1. **Not pinned but open:** The app can appear temporarily on the taskbar while its window is available.
1. **Not pinned and closed:** It may no longer have a taskbar button, even though the app is still installed.

A taskbar icon therefore represents a **way to reach an app**, not proof that the application is installed in a particular folder or that all its windows are visible.

### Use a taskbar button to switch to a window

Suppose a browser and Calculator are both open:

1. Select the browser's taskbar button to bring the browser forward.
1. Select Calculator's taskbar button to bring Calculator forward.
1. If you see a preview of more than one window, choose the appropriate preview.
1. If a taskbar button appears to minimize an already active window, select it again or use **Alt + Tab** to return.

Windows can group several windows under one app icon. Hovering over the icon with a mouse may display **[[window-preview|window previews]]**. Preview behavior can vary by the program and by settings. On a touchscreen or with a screen reader, the way to access available windows may differ.

### What is a system tray?

The **[[notification-area|notification area]]**, sometimes called the **system tray**, is the region near the right end of the Windows taskbar where certain status or background-app icons appear. For example, an organization-approved communication app might show a background status icon there. Additional icons may be available in an overflow panel.

Near that area, Windows often shows network, audio, battery status when applicable, and the clock. The exact controls can change with hardware. A desktop computer without a battery may not show a battery symbol, and a computer without an active network connection may show a different network status icon.

> **Important:** A status symbol may tell you something about a connection or setting. It does not necessarily tell you that every application or online service is working. You will learn to interpret common notifications and system controls in Lesson 5.

### The taskbar does not display every background process

Some programs work in the background without presenting an ordinary window, and the taskbar does not list each internal system activity. It is primarily a user-facing navigation interface, not a complete technical inventory of all running software.

## 4. How do you control an app window?

An **[[app-window|app window]]** is a bounded area that displays part of an application. It may contain text, pictures, buttons, menus, and other controls. When you open File Explorer, Calculator, or a web browser, you generally see a window. Some programs use more than one window; others use tabs within a single window.

### Recognize the main parts of a window

| Window feature | Purpose | What to observe |
| --- | --- | --- |
| Title bar or top area | Displays app or document context and often supports moving the window | App name, document title, or draggable region |
| Minimize button | Hides the window from the desktop while keeping it available | Usually a dash-shaped button near the upper-right corner |
| Maximize or Restore button | Expands a window or returns it to its prior adjustable size | Usually a square or overlapping squares |
| Close button | Closes the current window | Usually an X near the upper-right corner |
| Window border or edge | Often permits manual resizing | Pointer may change shape near an adjustable edge |
| Work or content area | Displays the task you are performing | Text, images, spreadsheets, controls, or website content |

These descriptions fit many conventional Windows desktop applications. Some programs have custom title bars, full-screen modes, or simplified controls, so they may look different.

### Minimize: Put the window out of sight

**[[minimize|minimizing]]** hides a window from the desktop without ordinarily closing it. The app may continue running. For example, if you minimize a browser, it may remain open and retain its tabs. You can bring it back by selecting its taskbar button or using a window-switching command.

Minimize is useful when you want a clearer view of another task but are not finished with the first one. It is **not** the same as saving. An unsaved document can still be lost if the computer shuts down or the app crashes while minimized.

### Maximize and Restore: Change the size

**[[maximize|maximizing]]** normally expands a window to use most of the available desktop work area. In a maximized window, the taskbar can remain visible, depending on the system's display configuration.

**[[restore|Restoring]]** a maximized window returns it to a previous, adjustable size. The same button often changes between Maximize and Restore as the window changes state.

A maximized window is not always **full-screen mode**. Some apps' full-screen modes hide the title bar or taskbar and may be controlled differently. For this lesson, use an ordinary practice window and its visible Maximize/Restore button.

### Close: End the window you are using

**[[close-window|Closing a window]]** removes that window from your workspace. For a simple one-window app, this often ends the application. For a multi-window app, other windows or background processes may remain. Some programs continue running in the system tray after their visible window closes. Consequently, **closing a window is not always the same as quitting every part of an app**.

Before closing an editor or document, check whether any work needs to be saved. Apps may prompt you to save, discard, or cancel. The wording differs among programs. If you are unsure, choose the option that preserves your work or **Cancel** while you confirm what needs to be done.

> **Never confuse these actions:** **Minimize** hides a window. **Maximize** enlarges it. **Restore** returns it to an adjustable size. **Close** dismisses the window and may terminate the program or prompt about unsaved changes.

### Move a window without moving its files

You can often reposition a restored window by dragging its title bar:

1. Open or choose a harmless practice window, such as Calculator.
1. If it is maximized, use Restore first.
1. Point to an empty part of its title bar that is suitable for dragging.
1. Hold the primary mouse button and move the window a short distance.
1. Release the button when the window is in a comfortable position.

Dragging the *window's title bar* moves the window. Dragging a *file icon* or selection inside a file manager can move a file instead. Be certain which item you are manipulating.

### Resize a window

When an ordinary window is not maximized, you may be able to resize it by dragging an outer edge or corner. The pointer may become a double-headed arrow. Some windows have minimum sizes, and some apps do not permit arbitrary resizing. You can also use keyboard-assisted Snap arrangements described in the next section.

### Window versus tab

A browser often displays several **[[tab|tabs]]** inside one window. Selecting a tab changes the page within that window; it does not necessarily switch to a different app window. Closing a browser tab removes that tab, while clicking the window's Close button can close the entire window. Read the control and any confirmation prompts carefully.

## 5. How do you switch between and arrange windows?

Once two or more windows are open, you can choose which one to use, temporarily display the desktop, or organize windows to see information side by side. This is a core everyday skill for studying, comparing documents, and entering information from one app into another.

### The active window

The **[[active-window|active window]]** is the window currently selected to receive your normal keyboard input. If you click inside a notes window, your typing usually goes to that window. If you then choose Calculator, the calculator becomes active and receives your next clicks or keyboard input.

This matters for privacy and accuracy. Before entering information, glance at the active app and the visible field. Typing a password, private note, or financial detail into the wrong window can expose information or cause mistakes.

### Three practical switching methods

**Method A — Taskbar buttons**

Select the taskbar button for the window or app you want to use. If Windows shows multiple previews for that app, choose the correct window. This is often the easiest visual method for beginners.

**Method B — Alt + Tab**

1. Keep one finger on **Alt**.
1. Press **Tab** to display the window switcher.
1. Press Tab again, if needed, to move to another visible option.
1. Release Alt when the desired window is selected.

This is a useful keyboard shortcut for switching among open windows. Some application tabs may appear in the switcher depending on system settings, so the exact list can vary.

**Method C — Select the visible window**

If parts of two windows are visible, click the one you want. The selected window generally comes to the foreground. This also changes where subsequent typing goes.

### Show the desktop without closing apps

Press **Windows logo key + D** to show the desktop by hiding or minimizing open windows. Press it again to restore the view in many ordinary situations. You can use this to locate an icon or simply see the workspace underneath.

This is **not** a command to save, close, or delete the open apps. If work is unsaved, it remains unsaved. Some full-screen applications, remote sessions, or organization policies can alter how the shortcut behaves.

Windows 11 can also offer a **Show desktop** control at the far corner of the taskbar, depending on taskbar settings. Because its availability may vary, the keyboard shortcut is a more consistent teaching method.

### Place two windows side by side

**[[snap|Snap]]** is a Windows feature that helps position windows in defined areas of the screen. It can be useful when you want to read from one window while working in another. On many Windows 11 computers:

1. Open two ordinary practice windows, such as a browser and Calculator.
1. Select the first window.
1. Press **Windows logo key + Left Arrow** to place it against the left side, if supported.
1. Select or choose the second window for the remaining space when prompted.
1. Confirm that both windows are visible and sufficiently large to use.

You may also drag a window to an edge or use a Snap layout shown when hovering over or selecting a window's Maximize control. Layout availability depends on screen size, settings, and the application. **Windows logo key + Right Arrow** can position the active window to the right in supported arrangements.

If you cannot use Snap, simply position two restored windows next to each other, or complete the exercise by imagining the arrangement.

### Task View and virtual desktops

**[[task-view|Task View]]** is a Windows tool for viewing open windows and managing **[[virtual-desktop|virtual desktops]]**, which are separate on-screen workspaces. Press **Windows logo key + Tab** to open Task View on a typical Windows 11 system. A Task View icon may also be available on the taskbar.

For example, someone might keep study windows on one virtual desktop and personal windows on another. These are **not separate physical computers** and are **not automatically separate security accounts**. Files and apps still belong to the underlying device and user account. In this beginner lesson, simply identify Task View; creating or deleting virtual desktops is optional and not required.

### Quick keyboard reference

| Keyboard action | Typical Windows 11 result | Beginner use |
| --- | --- | --- |
| Alt + Tab | Switch between available open windows | Return to another app |
| Windows key + D | Show or restore the desktop view | See desktop icons without closing work |
| Windows key + Tab | Open Task View | Inspect windows and virtual desktops |
| Windows key + Left Arrow | Snap active window to the left, when supported | Arrange two windows |
| Windows key + Right Arrow | Snap active window to the right, when supported | Arrange two windows |
| Alt + F4 | Request closing the active window or app | Use only after checking for unsaved work |

Shortcuts use **the Windows logo key**, sometimes labeled **Win**, on a Windows keyboard. On some compact laptop keyboards, key layouts differ. Accessibility features, remote desktop programs, and individual applications may change how a shortcut behaves. Use the pointer controls whenever they are clearer or more comfortable.

> **Practice safeguard:** Never test **Alt + F4** on an important unsaved document. Use a harmless practice program, and check the title of the active window first.

## 6. How do desktop and taskbar layouts vary?

Different people and organizations arrange their workspaces differently. A Windows 11 taskbar may use centered or left-aligned app icons; some taskbar controls may be hidden, and the background image can change. Understanding which features are **customization options** will prevent you from confusing a different appearance with a different operating system.

### Recognize personalization without changing it

**[[personalization|Personalization]]** refers to changing an interface's appearance and some behavior. For example, users may choose a desktop background, adjust a display's scale, or change the appearance of taskbar controls. These choices normally do not alter the underlying purpose of the desktop and taskbar.

On a personal Windows 11 computer, some taskbar options can be viewed by right-clicking an empty taskbar area and choosing **Taskbar settings**. Among the available options may be alignment, automatic hiding, and whether certain controls appear. Names and availability depend on Windows version, hardware, and administrative policy.

You **do not need to change any setting** for this lesson. Changes on a school, library, workplace, or family computer should only be made with permission. The next course lessons will examine Start and Settings in more detail.

### What if there are no desktop icons?

Some users hide desktop icons for a clean workspace. The desktop can still exist even when no icons are displayed. Other computers place commonly used apps only on the taskbar, in Start, or in another launcher. A blank desktop is not necessarily damaged or missing its operating system.

### What if the taskbar is not visible?

An app may be in full-screen mode, the taskbar may be configured to auto-hide, or you may be using a remote session with its own controls. Move the pointer toward the usual edge or use a safe window-switching shortcut if appropriate. Do not restart the computer merely because the taskbar is temporarily out of sight.

### Multiple monitors

Some computers connect to more than one screen. Windows can extend a desktop across displays, duplicate the same picture on several screens, or use a primary display for selected controls. This can make a window seem missing if it opens on another screen. For a beginner, check the other display or ask the device's administrator before changing display settings.

### Mac and Chromebook comparisons

A Mac and a Chromebook provide similar concepts, although the names and arrangement differ.

| Function | Windows 11 | macOS | ChromeOS |
| --- | --- | --- | --- |
| Main graphical workspace | Desktop | Desktop / Finder workspace | Desktop / workspace |
| Frequently used app launcher strip | Taskbar | Dock | Shelf |
| Main apps and system menu entry point | Start | Dock, Launchpad or Apps interface, and Apple menu | Launcher |
| Device status area | Taskbar status area | Menu bar / Control Center | Status area / Quick Settings |
| Switch between apps | Alt + Tab | Command + Tab | Alt + Tab |
| View or manage multiple windows | Task View | Mission Control | Overview |

These are functional comparisons, not exact one-to-one equivalents. For example, the macOS **Dock** sits separately from the **menu bar**, which appears at the top of the display. Windows combines more navigation and status controls in the taskbar. A Chromebook's **shelf** holds app icons and provides access to its launcher and status region. Specific names and layouts can change across OS versions.

**On a Mac:** App windows typically have red, yellow, and green controls near the upper-left corner rather than near the upper-right. The yellow button minimizes a window; the green control manages full-screen or window arrangement behavior depending on the context. Closing a Mac window does not necessarily quit its app. Use **Command + Tab** to move among running apps.

**On a Chromebook:** The shelf provides access to apps and status controls. ChromeOS can show multiple windows and supports switching with **Alt + Tab**. A Chromebook is not a Windows PC, so a Windows-only keyboard shortcut may not apply even when the tasks are similar.

**On phones and tablets:** Mobile operating systems generally use home screens, app switchers, and gesture navigation rather than a traditional Windows taskbar. Some tablets and desktop modes provide more complex multitasking interfaces. This lesson's desktop-focused directions should not be forced onto a phone.

### Accessibility and user preferences

A person may navigate by keyboard, touchscreen, speech commands, magnification, a screen reader, or other assistive technology. Visual clues such as tiny taskbar indicators may be difficult to see at some display settings. It is acceptable to use an alternative route to reach a goal. The skill is **recognizing and controlling the workspace**, not memorizing one motor action.

> **Key distinction:** You can learn what a setting controls by reading about it or observing it. You do not need to alter a shared computer to demonstrate understanding.

## 7. Guided practice: Use the desktop and taskbar

These exercises are intended for a Windows 11 computer. If you have a Mac or Chromebook, complete the **equivalent-function** observations from Section 6. If no computer is available, use the sample descriptions, write your answers on paper, and complete the scenario questions. **Do not modify another person's files, account, wallpaper, taskbar preferences, or software installation.**

### Activity 1: Desktop and taskbar observation (about 6–8 minutes)

**Goal:** Identify five on-screen elements without changing settings.

1. Sign in only to an account you are authorized to use, or observe an approved demonstration screen.
1. Find the desktop background. Describe its appearance without including private information.
1. Identify one desktop icon, if any are visible. Do not open private files.
1. Locate the taskbar and the Start button.
1. Identify one app button and the clock or status area.
1. If a window covers the desktop, observe that the taskbar may still be visible and the desktop is behind it.

*Observation worksheet*

| Element | Where I found it | What it does |
| --- | --- | --- |
| Desktop background | ________ | Visual work surface |
| Desktop icon or shortcut | ________ | ________ |
| Start button | ________ | Gives access to Start |
| App button | ________ | Opens or returns to an app |
| Status or clock area | ________ | ________ |

**If no desktop icons are visible:** Record “No icons visible.” That is a valid observation, not a failed activity.

### Activity 2: Open, minimize, and restore a harmless window (about 7–10 minutes)

**Goal:** See the difference between a hidden window and a closed window.

1. Use a familiar, authorized, non-sensitive app such as Calculator. If you cannot locate it easily, use any safe window that is already open.
1. Look for the window's title or app name and its three familiar controls, if present.
1. Select **Minimize** (the dash-shaped control on a conventional Windows window).
1. Observe that the window disappears from the desktop but is normally still available through its taskbar button.
1. Select the app's taskbar button to bring it back.
1. If supported, choose **Maximize** and then **Restore** to compare the window sizes.
1. Close the practice window only after confirming that no important work is unsaved.

**Record:** Which action merely hid the window? Which action changed its size? Which action dismissed it?

### Activity 3: Switch between two open windows (about 7–10 minutes)

**Goal:** Move between tasks without closing either one.

1. Open two safe apps, such as Calculator and a browser on a harmless page, or use two permitted windows already open.
1. Select the first app using its taskbar button.
1. Select the second app using its taskbar button.
1. Use **Alt + Tab** to return to another available window if your keyboard supports the shortcut.
1. Observe whether either window actually closed during the switch.
1. If several windows are associated with one app, inspect available taskbar previews and choose the correct one.

**Record:** The method that worked best on your device was __________. Switching windows did/did not remove either app: __________.

## 8. Common misconceptions

### “The desktop is the same thing as a desktop computer.”

Not necessarily. *Desktop computer* describes a physical device intended for desk use. *Desktop* in this lesson is the operating system's visual workspace, which can appear on a laptop or other device.

### “Every icon on the desktop is a program.”

No. An icon may represent a shortcut, saved file, folder, Recycle Bin, or special system location. Opening or deleting different kinds of items can have very different effects.

### “Deleting a shortcut uninstalls the application.”

Normally it does not. A shortcut is a reference to an application or another destination. Removing that reference ordinarily leaves the actual program installed. This does not mean deleting any item on the desktop is safe; some desktop items are real files and folders.

### “An app is running whenever its icon is pinned to the taskbar.”

No. Pinning makes the app easy to reach. Running describes the app's current activity. An app can be pinned and closed, pinned and running, or running without being pinned.

### “Minimize closes an app.”

Usually false. Minimizing hides its window but ordinarily keeps the app open. Use the taskbar or window switcher to return to it. Minimize also does not save unfinished work.

### “Closing one window always quits the whole app.”

Not always. Some programs have multiple windows, and some continue background activity or remain in the system tray. The meaning depends on the app.

### “Maximize and full-screen mode are identical.”

Not always. Maximizing typically fills most of the available work area while preserving regular window controls or taskbar behavior. Full-screen modes may hide more interface elements and behave differently.

### “Showing the desktop deletes or closes everything that was on screen.”

No. Windows key + D generally changes the visible arrangement, not the underlying files or app contents. However, it does not save unsaved work either.

### “The taskbar should always be at the bottom with exactly the same icons.”

The familiar Windows 11 default is not universal. Buttons, alignment, visibility, grouping, and other behaviors can change with personal settings, screen size, updates, and organizational controls.

### “If I can see a file on a shared desktop, I have permission to open it.”

Visibility does not establish permission. Open only files and apps relevant to your authorized work. A shared desktop may show filenames that refer to confidential material.

### “A virtual desktop is a private account or a different computer.”

No. Virtual desktops are separate workspaces inside one operating-system session. They are not an automatic privacy boundary or a replacement for separate user accounts.

### “I must use a mouse to navigate the desktop.”

No. Many desktop tasks can be performed with keyboard shortcuts, touch, assistive technology, or alternative pointer devices. The best method depends on the learner and available equipment.

## 9. Essential vocabulary

Terms marked with a dotted underline earlier in the lesson may be selected for a definition. Where a relevant MGU Encyclopedia article is available, its tooltip can also offer further reading. You do not need to memorize every entry immediately; focus on the terms you use during practice.

- **Desktop:** The graphical work area shown in a desktop-style operating system, often behind app windows.
- **Graphical user interface (GUI):** A visual method of using a computer through windows, icons, menus, and controls. [Software Overview](/library/encyclopedia/computer-science/software-systems/software-overview).
- **Icon:** A small picture representing a file, folder, app, shortcut, or other item.
- **Shortcut:** An on-screen reference that opens a program, file, folder, or destination without necessarily containing the target itself.
- **File:** A collection of saved information such as a document, image, or recording.
- **Folder:** A named location for organizing files and other folders.
- **Recycle Bin:** A Windows location for many items selected for deletion; it does not guarantee recovery of every deleted item.
- **Taskbar:** The Windows navigation strip showing Start, app buttons, and system status areas.
- **Pinned app:** An app with a persistent taskbar or launcher entry for easy access.
- **Running app:** A program currently executing; it may have an open window or background activity.
- **Notification area / system tray:** The taskbar region for selected system and background-app indicators.
- **App window:** A bounded on-screen area where an application displays content and controls.
- **Active window:** The selected window that normally receives current keyboard input.
- **Title bar:** The top area of many windows, often showing the app or document name and window controls.
- **Minimize:** Hide a window from the desktop while ordinarily keeping it available.
- **Maximize:** Enlarge a window to use most of the desktop work area.
- **Restore:** Return a maximized or minimized window to a prior visible window state, depending on context.
- **Close window:** Dismiss the current window, sometimes ending the associated app or prompting to save changes.
- **Window preview:** A small representation of a window, sometimes shown from a taskbar button.
- **Tab:** A separate page or document view inside a single app window.
- **Task View:** Windows interface for seeing open windows and organizing virtual desktops.
- **Virtual desktop:** An additional workspace within the same computer session.
- **Snap:** Windows feature for positioning windows in predefined screen areas.
- **Personalization:** Changes to appearance or interface behavior, such as a background picture or taskbar alignment.
- **Operating system (OS):** System software that manages hardware, supports apps, and supplies a working environment. [Operating Systems](/library/encyclopedia/computer-science/software-systems/operating-systems).
