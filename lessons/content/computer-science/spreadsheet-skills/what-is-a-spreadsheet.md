Basic Computer Skills / Spreadsheet Skills

## Lesson 1: What Is a Spreadsheet?

Imagine that you are organizing supplies for a neighborhood event. You have a few item names, quantities, and prices. On paper, you might draw a table, write each item on a line, calculate the cost of each item, and add the costs at the bottom. A [[spreadsheet|spreadsheet]] allows you to organize the same information on a computer. It can also recalculate results when numbers change, keep related information together, and help you recognize patterns.

A spreadsheet does not need to be complicated. You can begin with three rows and a few words. This lesson explains **what a spreadsheet is, what people use it for, how a spreadsheet differs from other documents, and how to recognize its main parts**. Detailed instruction on cell navigation, formatting, formulas, functions, sorting, charts, and budgets appears in later lessons of this course. No previous spreadsheet experience is necessary.

Microsoft Excel on Windows is the primary desktop reference, with Google Sheets and LibreOffice Calc as alternatives. The examples use features common to these applications rather than depending on a particular version or subscription. You may complete the observation and paper exercises without software or an online account. All sample names, figures, and records are fictional.

**Level:** Beginner · **Estimated study time:** 70–95 minutes · **Prerequisites:** Comfortable with basic computer or device navigation; prior spreadsheet experience not required · **Practice equipment:** Paper and pencil, or an available spreadsheet application; internet access is optional · **Safety:** Use fictional entries only; do not enter personal financial records or someone else's private information for practice.

> **Essential idea:** A spreadsheet is a flexible digital grid for **recording, organizing, comparing, and calculating information**. The grid contains rows, columns, and cells. A spreadsheet can help you work accurately, but it does not automatically make the information you enter correct.

### Learning objectives

After completing this lesson, you should be able to:

1. Explain the purpose of a spreadsheet in everyday language.
2. Identify the [[row|row]], [[column|column]], and [[cell|cell]] in a simple worksheet.
3. Distinguish a [[workbook|workbook]] from a [[worksheet|worksheet]] and explain why applications use these terms differently.
4. Recognize ordinary spreadsheet content: text, numbers, dates, and basic [[formula|formulas]].
5. Name at least four everyday uses of spreadsheets and decide when a spreadsheet is appropriate.
6. Describe the difference between changing a number and changing how that number appears.
7. Distinguish common spreadsheet applications and file types at an introductory level.
8. Explain safe habits for creating, checking, saving, and sharing a spreadsheet.
9. Complete a simple fictional supply-list exercise and explain what the grid communicates.

## 1. What is a spreadsheet?

A [[spreadsheet|spreadsheet]] is an electronic document that arranges information in a grid of [[row|rows]] and [[column|columns]]. The smallest ordinary working spaces in that grid are [[cell|cells]]. A cell may contain a label, a number, a date, or a calculation. Spreadsheet software lets you organize cells, change values, and display results.

The important idea is not that a spreadsheet has thousands of boxes. It is that each box can have a **specific purpose**. One column can hold an item name, a second can hold a quantity, and a third can hold a price. The information then becomes easier to compare than a loose collection of notes.

People commonly use spreadsheets to:

- keep lists of supplies, tasks, expenses, or appointments;
- record and compare measurements or scores;
- plan household or project spending;
- calculate totals and other results;
- monitor changes over time;
- make simple tables and charts; and
- share organized records with an authorized person or team.

Some people use a spreadsheet only as a list. Others use it for calculations. Both are legitimate. You do **not** have to write a formula to create a useful spreadsheet.

### An ordinary example

Consider this fictional supply list for a small event:

| Item | Quantity | Unit price |
| --- | --- | --- |
| Pencils | 3 | $2.00 |
| Notebooks | 2 | $4.00 |
| Folders | 1 | $5.00 |

This simple table tells us what is needed, how many are needed, and the price of one unit. A spreadsheet program can hold these entries and, if desired, calculate each item's total cost. Before calculating anything, the grid already solves an organizational problem: the information is presented in consistent categories.

> **Remember:** A spreadsheet is a tool for working with information. Its value depends on clear categories, accurate entries, and sensible interpretation—not on the number of features you use.

### Digital spreadsheet versus a paper table

A ruled paper table can organize information too. A digital spreadsheet adds the ability to edit entries without redrawing the entire table, copy structures, save versions, and perform calculations. It can also cause mistakes more quickly: a mistaken value or formula can be repeated across many rows. Computer assistance makes checking more important, not less.

| Task | Paper table | Digital spreadsheet |
| --- | --- | --- |
| Record a short list | Works well | Works well |
| Change an entry | Erase or rewrite | Select and edit a cell |
| Recalculate many values | Usually by hand | Can use formulas and functions |
| Reorganize a large list | Often requires rewriting | Can use sorting and filtering |
| Keep an extra copy | Photocopy or reproduce | Save or duplicate a file, subject to permissions |
| Share with others | Give or send a copy | Share or export a file; online tools may support collaboration |

### A spreadsheet is not an instruction to collect more information

The grid makes it easy to create additional columns, but that does not mean you should collect every possible detail. A club attendance list might need a first name or a participant code, for example, but not a date of birth, medical information, and a home address. Use only information appropriate to the stated task.

## 2. What can you do with a spreadsheet?

Spreadsheets have three especially important everyday functions: **keeping records, performing calculations, and communicating results**. These functions often appear together. A home repair estimate might list materials, multiply prices by quantities, and show the resulting total to a decision-maker.

### Organize information into categories

A [[list|list]] records items, but a structured spreadsheet adds columns that consistently describe each item. For example, a volunteer coordinator could use the columns *Task*, *Assigned team*, *Due date*, and *Status*. Each new row represents a different task. Separating the details makes the list easier to review.

A spreadsheet does not make a task complete simply because its Status cell says “Done.” The status still must reflect what happened in the real world. A spreadsheet is a record and planning aid, not independent proof.

### Perform and update calculations

Imagine a supply item costs $2 each and you need three. Multiplication gives $6. A spreadsheet can represent that arithmetic with a [[formula|formula]] such as `=B2*C2` if cell B2 contains the quantity 3 and cell C2 contains the numeric price 2. The result would be 6.

You do **not** need to memorize or enter the formula in this introductory lesson. The useful concept is that a formula can refer to another cell rather than requiring you to rewrite the underlying number. When a referenced number changes, the application ordinarily recalculates the formula according to its calculation settings.

| Item | Quantity | Unit price | Item cost |
| --- | ---: | ---: | ---: |
| Pencils | 3 | $2.00 | $6.00 |
| Notebooks | 2 | $4.00 | $8.00 |
| Folders | 1 | $5.00 | $5.00 |
| **Total** | | | **$19.00** |

If the pencil quantity increases from 3 to 4, the pencil cost becomes $8, and the overall total becomes $21—assuming the calculation uses the revised quantity and the other entries stay the same. A spreadsheet can make such revisions easier, but it does not know whether four pencils are actually needed.

### Compare, summarize, and visualize

When a spreadsheet holds many rows, it may be useful to [[sort|sort]] the rows, [[filter|filter]] the records, or turn selected numbers into a [[chart|chart]]. For example, a chart might show how a program's monthly attendance changed. These features are studied in later course lessons. At this stage, understand that the spreadsheet is a common starting place for those tasks.

A useful chart must reflect the underlying values honestly. Attractive formatting cannot repair missing data, inaccurate numbers, or misleading category definitions.

### Match the tool to the task

| Situation | A spreadsheet may help because... | An alternative may be better when... |
| --- | --- | --- |
| Weekly grocery list | Items, quantities, and estimated prices fit columns | You only need a very short, unchanging note |
| Family spending plan | Income and expenses can be organized and totaled | You need linked bank controls or regulated accounting records |
| Club equipment inventory | Rows can track items, condition, and quantities | Many users need strict permissions, audit trails, or complex relationships |
| Class activity tracker | Entries can be arranged by date or activity | The school requires a dedicated approved records system |
| Writing a long letter | A table may organize a short checklist | A word processor handles paragraphs better |
| Creating a presentation | A spreadsheet can calculate supporting figures | Slide software is designed for the final presentation |

### A real-life decision example

Suppose a community group needs to compare three room rental options. The group could create columns for venue, hourly price, capacity, accessibility features, and total expected cost. This makes comparison easier. But the spreadsheet cannot tell the group whether a room is actually available, whether a contract is fair, or whether the accessibility claims have been verified. Those questions require separate evidence and judgment.

## 3. What are the main parts of a spreadsheet?

A blank spreadsheet normally opens as a grid. Across the top are column headings, commonly `A`, `B`, `C`, and so on. Along the side are row numbers, commonly `1`, `2`, `3`, and so on. A single location is identified with a [[cell-reference|cell reference]], combining a column letter and row number: `A1`, `B3`, or `D8`.

### Read this miniature worksheet

The letters across the top and numbers on the left are location guides, **not data typed into the cells**.

| Row / column | A | B | C | D |
| --- | --- | --- | --- | --- |
| **1** | Item | Quantity | Unit price | Item cost |
| **2** | Pencils | 3 | 2 | 6 |
| **3** | Notebooks | 2 | 4 | 8 |
| **4** | Folders | 1 | 5 | 5 |
| **5** | Total | | | 19 |

Notice what the coordinates mean:

- `A1` contains the column heading **Item**.
- `A2` contains **Pencils**.
- `B2` contains the number **3**.
- `C2` contains the number **2**.
- `D2` shows the cost **6**.
- `D5` shows the overall total **19**.

You can identify these cells without opening a spreadsheet application. This is an exercise in reading the grid, not entering formulas.

### Rows and columns

A [[row|row]] stretches horizontally from left to right. A [[column|column]] stretches vertically from top to bottom. In a typical list, one row holds information about **one item or record**, and one column holds **one category**. For example, item names belong in column A, and quantities belong in column B.

That convention is helpful but not mandatory for every spreadsheet. Some spreadsheets are designed as forms, calculators, dashboards, or schedules rather than simple lists.

### Cells and the active cell

A [[cell|cell]] is where a row and column intersect. When you click or navigate to one cell, that cell becomes the [[active-cell|active cell]]: the place where an entry or command would apply. The selection may have a border or highlight. Different applications and accessibility modes show it in different ways.

Some applications provide a [[name-box|name box]] or a similar address indicator to help you see which cell is selected. They also provide a [[formula-bar|formula bar]] or editing area that can display a selected cell's content or formula. This is useful when a cell shows a calculated result rather than the formula behind it.

### Headings and ranges

A [[header-row|header row]] contains labels for columns, such as Item, Quantity, or Unit price. A [[range|range]] is a set of selected cells. For example, `A1:D5` refers to a rectangular block from A1 through D5, including all cells between them. You will work with ranges more closely when the course covers formatting and functions.

### Worksheets, tabs, and workbooks

In Microsoft Excel, a [[workbook|workbook]] is a file that contains one or more [[worksheet|worksheets]]. A worksheet is a particular grid within that workbook, often selected by a [[sheet-tab|sheet tab]] near the bottom. A workbook could contain tabs named *January*, *February*, and *March*.

Google Sheets commonly calls the overall document a “spreadsheet,” and it can contain multiple sheets selected by tabs. LibreOffice Calc likewise provides spreadsheet documents with multiple sheets. The terminology differs somewhat across products, but the practical idea is shared: **one file can contain several separate grids**.

| Term | Everyday meaning | Typical example |
| --- | --- | --- |
| Workbook or spreadsheet file | Overall saved document | `Event-Supplies.xlsx` |
| Worksheet or sheet | One grid within the document | `Supplies` tab |
| Row | Horizontal line of cells | Row 3 |
| Column | Vertical line of cells | Column B |
| Cell | One intersection in the grid | B3 |
| Range | A group of cells | A1:D5 |
| Header | Label identifying a category | “Quantity” in B1 |

> **Check your understanding:** In the miniature worksheet, `B3` is the quantity for notebooks. It is **2**. The coordinate is not a mathematical multiplication instruction; it is a location.

## 4. What kind of information goes into a spreadsheet?

A spreadsheet holds different kinds of [[data|data]]. It is helpful to distinguish the information you **enter**, the way the application **interprets** it, and the way the application **displays** it. These are related but not always identical.

### Text and labels

[[text-value|Text]] includes names, descriptions, category labels, and notes, such as “Pencils” or “Office supplies.” A text label often answers *what is this?* A spreadsheet may also store a long number-like identifier as text when it is not meant for arithmetic—for example, a fictional code `0017` that must retain its leading zeros.

### Numbers

A [[number-value|number]] can represent a quantity, amount, score, or measurement. The values `3`, `2.5`, and `125` can be used in calculations when the application recognizes them as numbers. Do not confuse a number's appearance with its underlying meaning. A quantity of 3 and a dollar amount of $3 are different categories even if their stored numeric value is the same.

### Dates and times

A [[date-value|date]] can record an appointment, purchase date, or deadline. Depending on the software and regional settings, entering `11/12/2026` may be interpreted differently or displayed in another format. For important dates, use an unambiguous date format and verify the result. In a fictional practice sheet, “Nov 12, 2026” is easier for a beginner to discuss than an unexplained short numeric date.

### Formulas and functions

A [[formula|formula]] is an expression that calculates a result. In many spreadsheet programs, a formula begins with `=`. A [[function|function]] is a predefined calculation or operation that can be used within a formula. For example, `=SUM(D2:D4)` asks the application to add numeric values in a range. You will learn formulas and functions in separate, dedicated lessons; here, simply recognize that **a calculated cell may display a result instead of the underlying expression**.

### Empty cells and missing information

A [[blank-cell|blank cell]] is not automatically a zero. It may mean “not collected,” “not relevant,” or “not entered yet.” Using `0` when you really mean “unknown” can mislead anyone who interprets the data. Agree on a clear meaning for blanks in a shared list, and do not guess missing numbers.

### A short data-type comparison

| Example cell entry | Intended meaning | Typical kind of content | What to check |
| --- | --- | --- | --- |
| `Notebooks` | Item description | Text | Spelling and consistency |
| `2` | Number of notebooks | Number | Whether quantity is correct |
| `4` | Price per notebook | Number | Currency and whether it is per unit |
| `Nov 12, 2026` | Event date | Date | Date interpretation and display |
| `=B3*C3` | Quantity times price | Formula | Referenced cells and calculated result |
| *(empty)* | Not entered or not applicable | Blank | What an empty cell means in this list |

### Formatting changes presentation, not necessarily meaning

[[formatting|Formatting]] changes how the information looks: bold headings, currency symbols, decimal places, alignment, or color. A cell containing numeric `2` may be formatted as `$2.00`. That does not mean the number entered was the text “two dollars”; it means the software is displaying a numeric value using a currency format.

Likewise, a percentage may be stored as a fractional numeric value while being displayed with a percent symbol. A displayed amount can be rounded even when the stored value has more decimal places. Never assume the visible number is the exact underlying value when precision matters.

> **Practical caution:** Formatting can help people read a table, but it does not correct an erroneous entry. Coloring a cost red does not prove the amount is wrong, and displaying a dollar sign does not establish what currency or time period the number represents.

## 5. Which programs and files are used for spreadsheets?

The application is the software you use to work with the information; the file is the saved document. Different applications can handle similar spreadsheets, although advanced features and layouts may differ when files move between products.

### Common spreadsheet applications

| Application | Common environment | Beginner perspective |
| --- | --- | --- |
| Microsoft Excel | Windows, Mac, web, and supported mobile devices | Widely used spreadsheet software; some features depend on version, license, and account |
| Google Sheets | Web and supported mobile apps | Browser-oriented spreadsheet work with account-based sharing and collaboration options |
| LibreOffice Calc | Desktop computers | Spreadsheet program in a freely available office suite; commonly saves OpenDocument spreadsheet files |

None of these brands is a required purchase for this lesson. The important ideas—grids, entries, files, and checking results—apply across them. A phone's small screen can make a table difficult to inspect; a computer with a keyboard and larger display is usually more convenient for a larger exercise.

### Beginning a new sheet

The following is a general workflow, not a guarantee that every screen or menu has identical wording:

1. Open an authorized spreadsheet application.
2. Choose **Blank workbook**, **Blank spreadsheet**, or the corresponding new-document command.
3. Locate the row numbers and column letters.
4. Locate cell `A1` and enter the heading **Item**, if you are completing the optional digital activity.
5. Add a few fictional entries.
6. Save or name the file according to the application's method.
7. Reopen or revisit it to verify that the entries were retained.

For a locally saved file, you commonly choose a folder and filename when using **Save** or **Save As**. Some cloud applications save edits automatically under a document name associated with your account. Auto-save and synchronization are not identical to a verified backup. Confirm whether changes actually saved, where the file lives, and who can access it.

### Common spreadsheet file types

| Extension | Typically used for | Beginner caution |
| --- | --- | --- |
| `.xlsx` | Modern Excel workbook | Generally supports multiple sheets, formulas, and formatting; compatibility can vary |
| `.ods` | OpenDocument Spreadsheet, common in LibreOffice Calc | Some features may change when opened in a different program |
| `.csv` | Text-based table of values | Normally stores a single flat table; does not retain workbook tabs or spreadsheet formatting |
| `.pdf` | Fixed-layout document for reading or printing | Not a practical format for editing spreadsheet cells and formulas |

A [[csv|CSV]] file is useful for transferring simple tabular information. However, a CSV file is not the same as a full spreadsheet workbook. A CSV generally carries values from a single table; it does not preserve all the multiple-sheet, formatting, formula, and chart features of a workbook. If you plan to keep working on a detailed spreadsheet, do not treat a CSV export as your only editable original.

### Local files, cloud documents, and sharing

A [[local-file|local file]] is stored on a device or local storage available to it. A [[cloud-file|cloud document]] is stored through an online service. Some applications use both, and some may allow offline editing followed by synchronization. The location matters because it affects access, sharing, recovery, and permissions.

Before sharing a sheet, check **who can open it**, **whether they can edit it**, and **whether it contains anything they should not see**. A link granting edit access is different from a view-only link. Do not assume that a file is private merely because you have not deliberately announced it.

### Accessibility matters

Spreadsheet interfaces often work with keyboards, screen readers, magnification, and other accessibility tools, but the exact supported commands vary by product. For larger lists, use meaningful headings, descriptive sheet names, readable contrast, and a predictable structure. Do not rely on color alone to communicate the difference between two categories. A screen-reader user should not need to guess why a red number differs from a green one.

## 6. How do you use a spreadsheet responsibly?

Spreadsheet work is often described as entering data and calculating totals, but reliable use requires a repeatable process. Think of the process as **PLAN → ENTER → CHECK → SAVE → SHARE CAREFULLY**.

### Plan the purpose

Before creating columns, decide what question the spreadsheet should answer. For the fictional supply example, the question might be, “What items are needed, in what quantities, and what is the estimated total cost?” That purpose suggests columns for Item, Quantity, Unit price, and Item cost.

Avoid starting with dozens of categories just because the software can support them. A simple sheet is easier to inspect and maintain.

### Enter consistent information

Use one unit and meaning per column. If the Unit price column is in U.S. dollars, label it clearly and use that currency consistently. If the Date column records event dates rather than purchase dates, state that. Mixing prices per item and prices per box without clarification can cause incorrect comparisons.

### Check entries and calculations

A spreadsheet can calculate quickly but cannot determine whether the original information is truthful or appropriate. Check spelling, quantities, units, and arithmetic against a separate source where feasible. For a financial decision, compare results to receipts, agreements, bank statements, or approved accounting records as appropriate—not only another formula in the same workbook.

### Save and verify

Give files meaningful names such as `Practice-Supply-List.xlsx`. For real work, add an appropriate date or version convention when useful, rather than maintaining many mysterious files named `final`, `final2`, and `final-really`. Confirm the document's location, save status, and whether it can be opened again.

If working on a shared file, do not overwrite another person's work without authorization. Depending on the service, review version history or recovery options. Keep a suitable independent [[backup|backup]] for important data according to organizational policy.

### Share only what is appropriate

If a spreadsheet lists personal information, financial records, school records, customer details, or staff data, follow the applicable privacy requirements and organizational rules. Remove unnecessary fields, verify recipients, and apply the correct access level. Practice with invented data rather than importing a genuine customer list.

### Recognize when a spreadsheet is not enough

A spreadsheet is flexible, but highly sensitive, complex, or frequently edited multi-user records may require an approved [[database|database]] or specialized information system with stronger validation, permissions, and audit controls. In particular, using a spreadsheet does not substitute for professional accounting, medical record management, or legally required records controls.

### A reliability checklist

| Question to ask | Why it matters | Example response |
| --- | --- | --- |
| What is this sheet for? | Defines the scope | Estimate fictional event supplies |
| What does each column mean? | Prevents mismatched data | Unit price is U.S. dollars per item |
| Where did the numbers come from? | Supports verification | Prices came from an identified approved source |
| Are blanks meaningful? | Avoids false assumptions | Blank means not yet confirmed |
| Are formulas and totals reasonable? | Catches arithmetic mistakes | 6 + 8 + 5 equals 19 |
| Is the latest version saved? | Avoids lost or stale work | Reopened named file and checked entries |
| Who may view or edit it? | Protects records | Only authorized participants |

> **Key habit:** When a spreadsheet's result influences a payment, deadline, report, or other meaningful decision, verify the inputs, calculation, context, and saved version—not just the number shown in a cell.

## 7. Guided practice: Explore a simple spreadsheet

These activities progress from reading a grid to creating a small fictional sheet. **Activities 1–5 can be done entirely on paper.** Activity 6 is an optional application exercise. If you use software, button names may differ across Excel, Google Sheets, and Calc. You do not need to create an account, pay for software, enable sharing, or upload personal data.

### Activity 1: Decide whether a spreadsheet fits (about 8 minutes)

For each situation below, decide whether a spreadsheet is a reasonable tool. Say what it would organize or calculate, or identify another tool that might be preferable.

1. Track the quantities of six classroom supplies.
2. Write a three-page letter to a relative.
3. Compare the price and capacity of three fictional rental rooms.
4. Record the number of people attending four community meetings.
5. Securely store the passwords for all your online accounts.

:::answer Show Activity 1 sample responses
1. **Spreadsheet:** A small table of item names and quantities is appropriate.
2. **Word processor:** A long letter is primarily continuous prose.
3. **Spreadsheet:** Consistent columns help with comparisons; independently verify any real contract or availability.
4. **Spreadsheet:** Attendance totals by date can be organized and compared; use fictional or properly authorized records.
5. **Password manager, not a casual spreadsheet:** Credentials require purpose-built protection and suitable account security.

:::

### Activity 2: Read cell addresses (about 8 minutes)

Use the miniature worksheet in Section 3. Do not guess from the order in which items were discussed; locate the row and column intersection.

1. What value is in `A4`?
2. What value is in `B2`?
3. What heading is in `C1`?
4. Which cell contains the number **8**?
5. What value is displayed in `D5`?
6. Does the number 5 on the left side of the grid count as the value in a cell?

:::answer Show Activity 2 answers
1. `A4` contains **Folders**.
2. `B2` contains **3**.
3. `C1` contains **Unit price**.
4. **D3** contains 8.
5. `D5` contains **19**.
6. **No.** The row number 5 is an interface heading identifying a row, not a value typed in the worksheet grid.

:::

### Activity 3: Identify what each entry means (about 10 minutes)

Match each sample entry to the information it represents. Some entries may have different *appearances* depending on formatting.

| Sample | Entry or display | Your interpretation |
| --- | --- | --- |
| A | `Folders` | __________ |
| B | `1` in a quantity column | __________ |
| C | `$5.00` in a price column | __________ |
| D | `Nov 12, 2026` | __________ |
| E | `=B4*C4` | __________ |
| F | Empty cell | __________ |

:::answer Show Activity 3 sample interpretations
- **A:** A text label naming an item.
- **B:** A numeric quantity, meaning one item in this context.
- **C:** A price displayed in currency format; check the actual currency, unit, and numeric value.
- **D:** A date entry or date-formatted value; verify the intended date.
- **E:** A formula that multiplies two referenced cells; do not assume the result until the input values are checked.
- **F:** A blank value, whose meaning depends on the list's rules; it is not automatically zero.

:::

### Activity 4: Check the fictional supply total (about 10 minutes)

Return to the fictional supply list. You do not need software for this calculation.

1. Calculate the cost of 3 pencils at $2 each.
2. Calculate the cost of 2 notebooks at $4 each.
3. Calculate the cost of 1 folder at $5.
4. Add the three item costs to find the total.
5. Now change the pencil quantity from 3 to 4. Recalculate the pencil cost and overall total.
6. Explain why checking the quantities matters even if the software calculates the arithmetic correctly.

:::answer Show Activity 4 answers
1. Pencils: **3 × 2 = $6**.
2. Notebooks: **2 × 4 = $8**.
3. Folders: **1 × 5 = $5**.
4. Original total: **$6 + $8 + $5 = $19**.
5. Revised pencil cost: **4 × 2 = $8**. Revised total: **$8 + $8 + $5 = $21**.
6. The application may calculate perfectly from a mistaken quantity. Correct arithmetic does not prove the inputs were correct.

:::

### Activity 5: Design a simple sheet on paper (about 10–15 minutes)

Draw a grid for a fictional reading log with these columns: **Book title**, **Pages read**, **Reading date**, and **Notes**. Write a header row and two invented records. Give one plausible cell reference for the title of the first book and another for the pages read for the second book.

Use the following example only if you need help getting started:

| Book title | Pages read | Reading date | Notes |
| --- | ---: | --- | --- |
| Sample Book A | 12 | Nov 10, 2026 | First session |
| Sample Book B | 18 | Nov 12, 2026 | Second session |

:::answer Show Activity 5 sample layout and explanation
If the headings occupy row 1 and the table starts in column A, the first invented book title appears in **A2**, and the second book's pages-read value appears in **B3**. Other book titles and dates are fine if they are fictional and the column meanings stay consistent.

:::

### Activity 6: Optional — create and save a fictional list (about 15–20 minutes)

Only complete this activity if a spreadsheet application is already available and you are authorized to use it. Observation is an acceptable alternative.

1. Open the spreadsheet application and choose a new blank document.
2. Find column letters `A` through `D` and row numbers `1` through `5`.
3. Enter **Item**, **Quantity**, **Unit price**, and **Item cost** in the first row, one label per cell.
4. Enter the three fictional supply records from Section 3. In the Item cost column, enter the known values **6**, **8**, and **5**; formulas are optional and not required in this introductory activity.
5. In the fifth row, enter **Total** in column A and **19** in column D.
6. Examine one cell containing a number and one containing text. Explain how you know which cell is selected.
7. Save or name the document **Practice-Supply-List** using a permitted location. If you are using an online application, verify that its save or synchronization status is complete.
8. Reopen the file, or revisit the saved document through its normal file list, and confirm that the three items and total are still present.
9. Leave the file private. Do not enable public access, invite collaborators, or replace an existing document for this exercise.

**Alternative without a device:** Draw the same four-column, five-row worksheet on paper. Label cells A1 through D5, fill in the entries, and explain where you would save a digital copy and how you would confirm it saved.

## 8. Common misconceptions

### “A spreadsheet is only for professional accountants.”

Spreadsheets are used in accounting, but also in classrooms, households, volunteer organizations, offices, research, and small projects. A shopping list or simple reading log can be an appropriate spreadsheet.

### “I must understand advanced math before using a spreadsheet.”

No. A beginner can make an organized list without formulas. Basic arithmetic is helpful for some activities, and later lessons will teach simple calculations step by step.

### “A workbook and a worksheet always mean the same thing.”

In Excel, the workbook is the overall document, while a worksheet is one grid inside it. Other spreadsheet programs may use “spreadsheet” and “sheet” for related ideas. Use the application's terminology carefully.

### “If the screen shows $5.00, the cell must contain the text ‘$5.00’.”

Not necessarily. A numeric value can be formatted to appear as currency. Check the underlying value and format when precision matters.

### “A blank cell always means zero.”

No. Blank can mean not entered, not applicable, or unknown. Replacing missing information with zero can produce misleading totals or comparisons.

### “A formula guarantees that the answer is correct.”

A formula may be written incorrectly or refer to wrong cells. Correct formulas using wrong input values still produce unreliable results. Check the assumptions and data.

### “Changing a cell updates every related figure automatically in all cases.”

Many spreadsheet formulas recalculate when a referenced value changes, but this depends on formulas, calculation settings, connected data, and whether the related cells actually reference the changed value. A manually typed total will not necessarily update itself.

### “Every spreadsheet file preserves everything if I export it as CSV.”

CSV is primarily a flat, text-based table of values. It ordinarily does not preserve multiple worksheets, most formatting, charts, or formula behavior. Retain an appropriate workbook file when those features matter.

### “If an online sheet saves automatically, I no longer need to check it.”

Auto-save can be useful, but connectivity, access permissions, synchronization status, version changes, and storage limits can still cause problems. Verify important changes and maintain authorized backups where appropriate.

### “A spreadsheet is private until I send the file to someone.”

Privacy depends on where the file is stored and which people or services have access. Shared folder permissions, view links, accounts, and organization policies all matter. Check access before storing sensitive information or sharing a link.

### “Bright colors and many charts make a spreadsheet trustworthy.”

Appearance can improve comprehension, but it is not evidence of correctness. Clearly labeled columns, documented sources, reasonable calculations, and appropriate review are more important.

### “If a database is more powerful, spreadsheets are useless.”

Spreadsheets and databases serve different needs. A spreadsheet can be an efficient flexible tool for small, understandable tasks; a database or approved application may be better for complex, sensitive, or high-volume records.

## 9. Essential vocabulary

The dotted-underlined terms in this lesson open definitions where the MGU dashboard supports tooltips. The glossary below is also readable independently. The definitions in the `:::terms` block at the end of this file supply the dashboard's machine-readable term data.

### The grid and its structure

- **Spreadsheet:** A digital document that organizes information into rows and columns and can perform calculations.
- **Grid:** The arrangement of rows and columns in a spreadsheet.
- **Row:** A horizontal set of cells, ordinarily identified by a number.
- **Column:** A vertical set of cells, ordinarily identified by a letter.
- **Cell:** One box at the intersection of a row and column.
- **Cell reference:** An address such as `B3` that identifies a cell.
- **Active cell:** The cell currently selected for entry or editing.
- **Name box:** An interface field that may show the selected cell's address.
- **Range:** A group of cells, often described by first and last addresses.
- **Header row:** A row containing labels that identify categories of information.
- **Worksheet:** One grid or sheet within a spreadsheet document.
- **Workbook:** A complete Excel document containing one or more worksheets.
- **Sheet tab:** A control used to switch among sheets in a document.
- **Formula bar:** An interface area used to view or edit a selected cell's contents.
- **Record:** A row or entry representing one item or observation in a structured list.
- **Field:** A category of information, typically represented by a column in a list.

### Values and calculations

- **Data:** Information entered or stored for use and interpretation.
- **Text value:** Words, labels, or identifiers treated as text rather than arithmetic quantities.
- **Number:** A numeric value that the software may use in calculations.
- **Date:** A calendar value represented and possibly formatted by a spreadsheet.
- **Blank cell:** A cell without an entered value, which does not necessarily mean zero.
- **Formula:** A spreadsheet expression used to calculate a result.
- **Function:** A predefined calculation or operation that can be used in a formula.
- **Cell dependency:** A relationship in which a formula refers to another cell's value.
- **Recalculation:** Updating calculated results when the relevant data or settings change.
- **Formatting:** Changing how a cell or value appears, such as number style or color.
- **Currency format:** A display format for monetary values, often with a currency symbol and decimals.
- **Percentage format:** A display format that expresses a numeric value as a percentage.
- **Data validation:** A rule or check used to limit or review the entries allowed in a cell.
- **Error checking:** Reviewing entries, formulas, units, and results for possible mistakes.

### Common tasks and uses

- **List:** A collection of entries arranged for reference or action.
- **Sort:** Arrange records in a chosen order, such as alphabetically or numerically.
- **Filter:** Temporarily display records meeting selected conditions.
- **Chart:** A graphic representation of data intended to help show comparisons or patterns.
- **Budget:** A plan that organizes expected income, expenses, or available resources.
- **Inventory:** A record of items and their quantities or characteristics.
- **Template:** A prearranged document structure intended to be reused.
- **Estimate:** An approximate calculation based on stated assumptions.

### Software, files, and protection

- **Spreadsheet application:** Software that creates and edits spreadsheets.
- **Microsoft Excel:** A spreadsheet application from Microsoft.
- **Google Sheets:** A web-oriented spreadsheet application from Google.
- **LibreOffice Calc:** A spreadsheet application in the LibreOffice office suite.
- **File extension:** A suffix, such as `.xlsx`, that conventionally identifies a file type.
- **XLSX:** A common file format for Excel workbooks.
- **ODS:** OpenDocument Spreadsheet file format.
- **CSV:** Comma-separated values, a plain-text way to store a flat table.
- **Local file:** A file stored on a device or locally accessible storage.
- **Cloud document:** A document kept through an online storage or application service.
- **Auto-save:** A feature that attempts to save changes without requiring each manual save command.
- **Synchronization:** Keeping data or file versions aligned between locations or devices.
- **Backup:** A separate recoverable copy of important information.
- **Sharing permission:** A rule specifying who can view or edit a file.
- **View-only access:** Permission to inspect content without editing it through the granted access.
- **Edit access:** Permission to make changes to a shared document.
- **Database:** A system for storing and managing structured data, often with stronger controls than an informal spreadsheet.
