Basic Computer Skills / File and Folder Skills

## Lesson 1: Files vs Folders

Imagine receiving an email attachment, downloading a family photograph, and saving a letter for work. Each action leaves you with information you may want again. If you do not know what a **file** is, where it belongs, or why a **folder** matters, those everyday tasks can quickly become confusing. You might remember saving something but not remember where to look for it.

This lesson introduces the two building blocks of everyday computer organization: [[file|files]] and [[folder|folders]]. A file holds a particular item of saved information. A folder organizes files and, often, other folders. Once you can tell them apart and recognize how they relate, later tasks such as saving, finding, renaming, moving, and backing up become easier to understand.

Windows 11 is the primary demonstration environment. You will also see how the same ideas apply to a Mac, Chromebook, phone, tablet, and cloud storage. The lesson does not assume you have worked in an office or used a computer before. You can complete every exercise by reading the examples and writing answers on paper; a computer is helpful but not required.

**Level:** Beginner · **Estimated study time:** 75–105 minutes · **Prerequisites:** Computer Basics recommended; no file-management experience required · **Practice equipment:** Windows 11 computer preferred; macOS, ChromeOS, mobile, or paper-based practice is suitable · **Safety:** Observation-first; do not delete, move, rename, download, or open unknown files for this lesson

> **Essential idea:** A **file** is a saved item of information; a **folder** is an organizing container for files and other folders. A **location** tells you where an item is saved. You can identify a file or folder before you take any action that changes it.

### Learning objectives

After completing this lesson, you should be able to:

1. Explain the difference between a file, a folder, an application, and a storage location in everyday language.
1. Identify common file examples, including documents, photographs, audio, videos, and spreadsheets.
1. Recognize that a folder can contain both files and smaller folders.
1. Read a simple [[folder-tree|folder tree]] and identify parent folders, subfolders, and a file's location.
1. Distinguish a file's name from its [[file-extension|file extension]], and recognize common extensions without treating them as proof that a file is safe.
1. Recognize folders and files in the Windows 11 File Explorer interface without accidentally changing them.
1. Identify the corresponding file-browsing tools on a Mac, Chromebook, phone, or tablet.
1. Explain why two files can share the same name when stored in different folders, and why similar-looking icons do not guarantee identical content.
1. Distinguish local storage, cloud storage, shortcuts, and ZIP archives at a beginner level.
1. Complete observation-based exercises, interpret realistic mistakes, and choose a sensible next action.

## 1. What is a file?

A [[file|file]] is a named collection of information saved by a computer system. In everyday use, you can think of a file as **one saved item** that you can locate, open with an appropriate application, copy, move, share, or delete if you have permission. The item might be a letter, photograph, spreadsheet, song, scanned receipt, slide presentation, or video.

The word *file* comes from office recordkeeping, where papers might be stored together in a filing cabinet. A digital file is different from a sheet of paper: it can contain text, sound, images, complex formatting, or information that people cannot read directly. But the everyday organizing principle is familiar. Just as you can distinguish a letter from a cabinet drawer, you can distinguish a digital file from the folder that helps organize it.

Consider four examples:

- `meeting-notes.txt` is a text file that might contain notes from a meeting.
- `family-photo.jpg` is an image file that might contain a photograph.
- `monthly-budget.xlsx` is a spreadsheet file that might contain numbers and formulas.
- `class-recording.mp4` is a video file that might contain an audiovisual recording.

These are illustrative names, not files you need to download. The text before the final period helps describe each item. The portion after the period often identifies its **format**. The underlying information is different in each case. You will study names and extensions in Section 4.

### What does a file actually contain?

A computer stores file content as digital data. A writing application may interpret some of that data as words, a photo viewer as an image, and an audio player as sound. You do not need to understand the internal coding to use the file. You do need to recognize that a file's *contents* and the way its *name or icon* appears are not the same thing.

For example, someone may call a file `FinalReport.pdf`. The name suggests that the contents are a report and the format is PDF. You cannot know from the name alone whether the document is accurate, complete, safe, or really the intended report. Opening it in suitable software or checking its trusted source may provide more information—but you should never open an unexpected attachment merely to discover what it is.

### What are common categories of files?

| File category | Everyday example | Typical use |
| --- | --- | --- |
| Text document | `notes.txt` | Plain written notes |
| Formatted document | `letter.docx` | Letters and other editable documents |
| PDF document | `receipt.pdf` | A document intended for reliable viewing or sharing |
| Image | `portrait.jpg` | Photographs and other images |
| Audio | `interview.mp3` | Sound recordings |
| Video | `training.mp4` | Moving images, usually with sound |
| Spreadsheet | `budget.xlsx` | Tables, figures, and calculations |
| Presentation | `slides.pptx` | Sets of presentation slides |
| Compressed archive | `photos.zip` | One package that can contain many files and folders |
| Application or installer | `setup.exe` | Software that may execute instructions; treat unfamiliar copies cautiously |

A file's format usually affects which programs can open it. A PDF and an editable word-processing document might show nearly identical pages to a reader while still being different file types.

### Is an app the same as a document file?

No. An [[application|application]] is software used to perform tasks. A document is information you work on using an application. A word processor can open many document files; the same document may be opened by more than one compatible application. A photograph can be viewed in a photo application or inserted into a document. **The file is not the app, and the app is not the folder containing the file.**

Applications and system software also consist of files behind the scenes, but beginners should distinguish **a personal working file** from **a program used to work with files**. Windows may display an application icon beside an associated document. That icon is a clue to how the document may open; it does not make the document an application.

### What can you learn about a file without opening it?

A [[file-manager|file manager]] often displays a file's name, a type or kind description, approximate [[file-size|size]], and when it was changed. Those details are called [[metadata|metadata]]. A file might be large because it contains a long video, or small because it contains a short note. The size alone does not establish quality, safety, or importance.

> **Remember:** A file is a saved item. Its visible icon and name help you recognize it, but neither guarantees what its contents are. When unsure, first check its source and type rather than opening it indiscriminately.

### Quick distinction: file or application?

Suppose you type a letter using a word-processing application and save it as `application-letter.docx`. The word processor is the **application**. The saved letter is a **file**. If you later close the program, the saved letter can still remain on your storage device. The application can be used to open that file again when needed.

A file can also be stored without a suitable program being installed. In that case, the computer may display its name but not know how to open it. That does not automatically mean the file is missing or damaged; you may simply need a compatible app, appropriate permission, or the correct format.

## 2. What is a folder?

A [[folder|folder]] is an organizing container used by a file system to group files and, frequently, other folders. On many computers, it is shown using a folder-shaped icon. In technical writing, a folder is commonly called a [[directory|directory]]. In this introductory course, the everyday terms are interchangeable unless a specific program makes a distinction.

Imagine a folder labeled *Family Photos*. You could save one photo in it, twenty photos in it, or separate smaller folders for different events. The outer folder helps you remember where related items belong. The individual photos are files; the labels and organizing structure are the folders.

### How is a folder different from a file?

| Question | File | Folder |
| --- | --- | --- |
| What is its main everyday role? | Stores a particular item of information | Organizes files and other folders |
| Common example | `report.pdf` | `Reports` |
| Can you normally open it? | Opens or previews with a suitable application | Opens to display its contents |
| Can it be empty? | Yes, a file may contain no content | Yes, a folder may contain no items |
| Can it contain other ordinary folders? | Not in the same way a directory does | Yes, normally |
| Does a name ending in `.pdf` identify it reliably? | It suggests a PDF file, but is not proof | Folder names can include periods too |

The most important distinction is **role**, not icon color or name. A file contains saved data; a folder provides an organizational location. A folder is also represented by data in the file system, but that technical detail does not change the practical distinction a beginner needs.

### What is a subfolder?

A [[subfolder|subfolder]] is a folder inside another folder. A parent folder can hold several subfolders. For example, `Photos` might contain `2025` and `2026`; the `2026` folder might contain `Graduation`, `Holidays`, and `Travel`. You can keep organizing into additional levels when they help, although unnecessary depth can make items difficult to find.

The folder containing another folder is called the [[parent-folder|parent folder]]. The smaller folder is the subfolder relative to that parent. A folder can be both a subfolder of one folder and a parent of another folder.

### Why use folders instead of putting everything in one place?

If every document, image, download, and recording were mixed into one long list, you would spend more time searching. Folders support simple organization by purpose, project, topic, date, or person. Different approaches may be appropriate for different tasks:

- **By purpose:** `Schoolwork`, `Work`, `Personal`, and `Receipts`.
- **By project:** `Community-Garden`, `Website-Launch`, and `Family-Reunion`.
- **By time period:** `2026`, `2026-October`, and `2026-November`.
- **By material type:** `Photos`, `Documents`, `Audio`, and `Videos`.

These are examples, not a universal filing rule. A small number of clear, predictable folders is often easier to maintain than a complicated system with dozens of nearly empty levels.

### Can a folder be empty?

Yes. An empty folder is still a folder, and it may be useful as a place for future files. For example, a new employee could create a `Training` folder before receiving any training documents. The folder can exist even when there are no files inside it. Folders do not become files merely because they are empty.

### Are folders always ordinary folders?

Not exactly. File managers sometimes display [[virtual-location|virtual locations]], collections, recent-file lists, cloud locations, or shortcuts alongside ordinary folders. Some of these are views of items stored elsewhere rather than independent storage directories. A *Recent* section, for example, usually helps you access items but is not a new copy of each file. We will return to this distinction when discussing file managers.

> **Remember:** A folder is best understood as an organizing location. Opening a folder usually reveals more items; opening a file usually asks an app to show or work with the file's content.

## 3. How do files and folders fit together?

Files and folders form an organized structure. A useful way to picture this is a [[folder-tree|tree]]: large branches lead to smaller branches, and each branch represents a place where items belong. This organization is called a [[hierarchy|hierarchy]]. You do not have to memorize computer commands to read one.

### A simple example: a student's materials

The following is a **fictional example**. It shows the folder `Schoolwork`, two subfolders, and four saved files. Indentation indicates containment.

```text
Schoolwork/
    Science/
        lab-notes.docx
        volcano-diagram.png
    History/
        reading-list.pdf
        interview-notes.txt
```

`Schoolwork` is the main folder. `Science` and `History` are subfolders of `Schoolwork`. The `Science` folder contains the document `lab-notes.docx` and the image `volcano-diagram.png`. The `History` folder contains `reading-list.pdf` and `interview-notes.txt`.

From this diagram, answer a few questions mentally: Is `Science` a file or folder? Does `interview-notes.txt` belong directly in `Schoolwork` or inside `History`? How many files are represented? If you can answer **folder**, **inside History**, and **four**, you are reading the structure correctly.

### Parent folders, subfolders, and siblings

Two folders can be at the same level under one parent. In the example, `Science` and `History` are both inside `Schoolwork`. They are separate subfolders, sometimes called sibling folders. A file in one is not automatically a file in the other.

A [[path|path]] describes where an item is located by naming a sequence of folders. In everyday speech, you might say, "The lab notes are in the Science folder inside Schoolwork." A computer path expresses that same route using folder names and separators.

### Understanding a Windows path

Here is a **hypothetical Windows example**, not a path you must find on your own machine:

```text
C:\Users\Alex\Documents\Schoolwork\Science\lab-notes.docx
```

Read it from left to right:

1. `C:` identifies a drive location in this example.
1. `Users` is a folder.
1. `Alex` is the example user's account folder.
1. `Documents` is a folder commonly used for saved documents.
1. `Schoolwork` and `Science` are additional folders.
1. `lab-notes.docx` is the file at the end of this path.

Windows commonly uses the backslash character `\` between path components. macOS, Linux, and many web or cloud systems commonly display forward slashes `/` in path-style notation. File managers may instead show the location using clickable breadcrumb labels. You do not need to type a full path to locate a folder manually.

### Does the filename tell you where the file is stored?

No. The filename and location are separate pieces of information. For example, two different folders could contain a file named `notes.txt`:

```text
Schoolwork\History\notes.txt
Schoolwork\Science\notes.txt
```

These are distinct file locations. The two files could have different contents, or they could happen to contain the same words. A filename is not a globally unique identification number. Do not assume that the presence of `notes.txt` in one folder proves the file is identical to another `notes.txt` elsewhere.

Within a typical single folder, the file system generally does not allow two separate items with exactly the same name under its applicable naming rules. When you save another item with the same name in that folder, a system or app may warn you, offer to replace a file, or create a differently named copy. Always read such messages before acting.

### A folder can contain both kinds of items

Consider a fictional small-business workspace:

```text
Business/
    Customers/
        customer-meeting-notes.txt
    Invoices/
        invoice-001.pdf
        invoice-002.pdf
    Business-Plan.docx
    logo.png
```

`Business` contains two subfolders *and* two files directly. A folder does not need to contain only files or only subfolders. This is an important source of confusion for beginners who expect everything in one place to look alike.

### What is the root or starting location?

A [[root|root]] is the top of a particular file-system hierarchy. On a Windows drive, you may see a starting location such as `C:\`. On other systems, the root is represented differently. In this beginner lesson, you only need to understand that a path begins somewhere and leads through folders to the chosen item. A path shown in an example might not exist on your device because usernames, storage drives, and settings differ.

### A filing-cabinet analogy—with limits

The filing-cabinet comparison can help: a cabinet is somewhat like a storage location; its drawers and folders organize related material; individual papers resemble files. But computer files are more flexible. A file can hold a large video or database, the same content can be copied rapidly, and some services show one file in multiple views without physically duplicating it. Use the analogy for organization rather than as a literal model of how digital storage works.

> **Core principle:** To locate an item, ask three questions: **What is the file called? What folder contains it? What storage location contains that folder?** You do not need the answer to all three immediately, but each narrows the search.

## 4. How do file names, extensions, and types work?

A [[filename|filename]] is the visible name assigned to a file. A name helps you recognize the item, while a [[file-extension|file extension]] often indicates the file's format. In `meeting-agenda.pdf`, `meeting-agenda` is the descriptive part of the filename, and `.pdf` is the extension.

File extensions often appear after the final period. Their length varies; extensions can have two, three, four, or more characters. Some files have no visible extension. Some systems hide common extensions by default, so a document displayed as `meeting-agenda` could still have the complete filename `meeting-agenda.pdf`.

### Common file extensions in everyday life

| Extension | Common content | Typical application or use |
| --- | --- | --- |
| `.txt` | Plain text | Text editor |
| `.pdf` | Portable document | PDF reader or browser |
| `.docx` | Word-processing document | Compatible word processor |
| `.xlsx` | Spreadsheet workbook | Compatible spreadsheet app |
| `.pptx` | Slide presentation | Compatible presentation app |
| `.jpg` or `.jpeg` | Photograph or other image | Image viewer |
| `.png` | Image, sometimes with transparency | Image viewer or editor |
| `.mp3` | Audio | Media player |
| `.mp4` | Video, often including audio | Video player |
| `.csv` | Tabular text data | Spreadsheet or data application |
| `.zip` | Compressed archive | Archive or file manager |
| `.exe` | Executable program on Windows | Potentially runs software; do not open an untrusted copy |

A **file format** describes how data is structured and interpreted, while an extension is a naming convention that suggests that format. These often correspond, but an extension can be wrong or misleading. Renaming `picture.jpg` to `picture.pdf` does not turn a photograph into a real PDF document.

### Why do file icons look different?

A [[file-icon|file icon]] is a small graphic a device displays to help identify a file or associated program. Image files may appear with image thumbnails; PDF files may show a PDF-related icon; a document may show the icon of a word-processing application. An icon's appearance can change depending on the installed apps and system settings.

Folders usually have a folder-like icon, but not every folder icon will be the same color. File icons can also resemble folders, and an archive such as `project.zip` may appear like a special kind of folder in some interfaces. **Always consider the name, type, and context—not the icon alone.**

### What is a thumbnail?

A [[thumbnail|thumbnail]] is a small preview of content, such as a tiny version of a photo or a video frame. It is meant to make visual files easier to recognize. A thumbnail is not a separate full-sized photo file simply because it appears in File Explorer. The preview may be cached or generated by the operating system.

### Can you safely change a file's extension?

Not as a method of conversion. Changing a visible extension is not the same thing as exporting or converting the file to another format. It can stop an application from recognizing an otherwise usable file. For this introductory lesson, **observe extensions but do not change them**. The later lesson on naming files will cover safe naming conventions, and more advanced instruction can explain proper format conversion.

### Why should you be careful with filenames?

A file may be named to look familiar or harmless even when it is not trustworthy. For instance, `invoice.pdf.exe` is an executable filename ending with `.exe`, not a normal PDF just because the middle of its name includes `.pdf`. A file might also be disguised by a misleading icon or description. If it arrives unexpectedly, do not run it, approve a security prompt, or enable macros just to investigate.

The safest beginner habit is to identify the source, inspect the available type information, and seek appropriate help before opening or running unfamiliar files. File extensions and icons are useful **clues**, not guarantees of safety.

### What does file size mean?

A file's [[file-size|size]] indicates approximately how much storage space its data occupies. A short text note may be only a few kilobytes, while a video may be hundreds of megabytes or more. Common units include [[kilobyte|kilobytes]] (KB), [[megabyte|megabytes]] (MB), and [[gigabyte|gigabytes]] (GB). The terms are introduced here only to help you read a file manager; exact unit calculations are not required.

A folder's displayed size, when available, may reflect the files and nested folders inside it. Some file managers must calculate that total. A large file is not necessarily more important than a small one. A short document could be essential, while a large recording could be replaceable.

### Example: one family event, several file types

Suppose you organized a birthday gathering. You might have `invitation.pdf` to share, `guest-list.xlsx` to track responses, `birthday-photo.jpg` as a picture, and `celebration-video.mp4` as a recording. Those are four files with different roles. They can all belong in one folder named `Birthday-2026`. The folder name communicates the event; each file's name and type communicate the kind of material it contains.

## 5. How do you recognize files and folders in Windows 11?

Windows 11 includes [[file-explorer|File Explorer]], a program for viewing storage locations and working with files and folders. You can use File Explorer to see names and locations without changing anything. For this lesson, the goal is **recognition and navigation**, not editing or cleanup.

### Opening File Explorer

On an authorized Windows computer:

1. Press **Windows key + E**, or choose the File Explorer icon from the taskbar or Start menu.
1. Allow the File Explorer window to open. It may show **Home**, **This PC**, a recent location, or a location configured by the user.
1. Look for the left [[navigation-pane|navigation pane]], the main list of files and folders, and the bar near the top that shows your current location.
1. Read the names of several items. Do not open unfamiliar downloads or system files to complete this activity.

If you use a school or work computer, some folders may be hidden or unavailable because of account permissions. That is not a problem; the observation steps can be performed in an accessible location such as Documents, Downloads, or a teacher-provided practice folder.

### Understanding the major parts of the File Explorer window

| Area or feature | What it commonly shows | Beginner question to ask |
| --- | --- | --- |
| Left navigation pane | Home, pinned folders, drives, cloud locations | Which broad location am I using? |
| Main content area | Files and folders inside the current location | Is this item a file or a folder? |
| Address bar or breadcrumbs | The folder route or current location | Where am I? |
| Search box | Results matching a name or other searchable information | Am I viewing a folder or search results? |
| View options | Icons, lists, or details | Would another view make the type clearer? |
| Details columns or properties | Names, file types, sizes, or dates | What information can I see without opening the file? |

Windows updates and display settings may change the exact placement or wording of controls. You do not need an identical screenshot to recognize the underlying functions.

### Home, Quick access, and recent items

In modern Windows 11 versions, **Home** can show pinned folders and recently used files. A recent-file entry is an access point to an item, not necessarily a second copy of the file. You may see **Desktop**, **Documents**, **Downloads**, **Pictures**, **Music**, and **Videos** among your available shortcuts or familiar locations, depending on configuration.

A folder appearing in Home is not always directly inside a real folder named `Home`. Similarly, a file appearing under *Recent* is not necessarily stored in a folder called `Recent`. The view can point to files located elsewhere. Learning the difference between **where a file appears in a list** and **where the file is actually saved** prevents confusion.

### Selecting versus opening

A single click on an item in the usual Windows configuration often **selects** it; a double-click often **opens** it. Keyboard users can navigate with arrow keys and commonly use Enter to open the selected item. Windows can be configured differently, so rely on your computer's displayed behavior rather than assuming every device works the same way.

If you open a folder, you normally see another list of items. If you open a file, Windows generally asks a compatible application to display or work with its contents. Do not use unknown or suspicious files for practice. Practice with a known safe folder or read the examples instead.

### Changing the view without changing the files

File Explorer offers various views, including icon layouts and a **Details** view. Changing how items are displayed does not itself rename, delete, or move the files. Details view may help you read the **Type**, **Size**, and **Date modified** columns. If the window is narrow, some columns may not be visible without adjustment.

You can use **View → Show → File name extensions** in Windows 11 to make common filename extensions visible. This changes display settings, not the contents of files. On a shared or managed computer, ask before changing even a display preference; observation-only practice is fully acceptable.

### A short, safe walkthrough

1. Open File Explorer on an authorized Windows 11 device.
1. Select a familiar folder, such as **Documents**, in the navigation pane if it is available.
1. Look at the item names and icons without opening anything.
1. Identify at least one item that seems to be a folder. If you can see a safely recognizable personal file, note its displayed type.
1. Read the location shown near the top of the window.
1. If comfortable, switch between an icon view and Details view; observe whether the files themselves change (they should not).
1. Close File Explorer when finished. Do not rename, move, copy, or delete any item during this exercise.

> **Safety checkpoint:** Seeing the **Delete**, **Cut**, **Rename**, or **Move** command does not mean you need to try it. A beginner can learn the interface by reading and navigating only. The course teaches those operations separately, with appropriate safeguards.

## 6. How do files and folders appear on other devices?

The concept of a file and folder is not exclusive to Windows. Most current computing systems organize substantial amounts of saved information into files and directories, although the interface and available locations vary. The differences you notice are usually differences in **how the system presents or manages files**, not changes in the basic idea.

### macOS: Finder

On a Mac, [[finder|Finder]] is the standard file-management interface. It can show Desktop, Documents, Downloads, iCloud Drive, and attached storage locations in its sidebar. You may use icon, list, column, or gallery views. Opening a folder shows its contents; opening a file may launch the associated app. In column view, you can see several levels of a folder structure side by side.

Macs use different keyboard shortcuts and visual conventions from Windows, but the meaning of a file, folder, parent folder, and subfolder remains consistent. A Windows `.docx` document may be usable on a Mac with compatible software; the file does not stop being a file when the device changes.

### ChromeOS: the Files app

On a Chromebook, the [[chromeos-files|Files app]] provides access to locally available files, Downloads, Google Drive, and other supported locations. Open the Launcher and look for **Files**. The left side displays available locations, while the main area shows contents. Some items may exist in a cloud location and require a connection or offline availability before their contents can be opened.

Chromebook menus may use names that differ from Windows File Explorer. The same beginner question still works: **Which location is this, and is the visible item a file or a folder?**

### iPhone and iPad: Files

On iPhone and iPad, Apple's **Files** app provides a way to browse many documents and storage locations. The **Browse** area may show **On My iPhone** or **On My iPad**, **iCloud Drive**, and compatible third-party locations. A tap opens a location or an item. Some photos and app content may be primarily managed through the Photos app or another app rather than appearing as ordinary documents in Files.

The touch interface does not change the distinction between a document and the folder that contains it. However, some files may be stored only inside a particular app or service, and not every system folder is visible to the user.

### Android: file-management apps

Android devices typically have a file-management interface, sometimes labeled **Files**, **Files by Google**, **My Files**, or another manufacturer-specific name. Many versions show categories such as Images, Audio, Documents, and Downloads, plus access to internal storage. A category view may gather files from multiple folders, while a storage view may show the underlying directory structure more directly.

An Android phone may display photographs in a Photos or Gallery application even when image files are held in device storage or a cloud account. The way content is presented depends on the app, its permissions, and the device. The broad concept remains: pictures and documents are file-based information, while folders and categories help people find them.

### Where is a file physically or logically saved?

A [[storage-location|storage location]] is a place where information is kept or made available. In everyday use, you may encounter:

| Location | Example | Important distinction |
| --- | --- | --- |
| Local internal storage | A computer's internal SSD | Usually part of the device; may be inaccessible if the device fails |
| External storage | USB flash drive or external disk | Separate device that may be disconnected |
| Cloud storage | OneDrive, Google Drive, iCloud Drive | Depends on account and service; offline access can vary |
| Shared or network storage | Workplace shared folder | May require network access and permission |
| Application-managed storage | Documents inside an app | May not appear like an ordinary user folder |

A [[cloud-storage|cloud storage]] service keeps information on systems operated by a service provider and may show it in an app or file manager. A file can appear in Windows File Explorer or Mac Finder even when the full contents are not currently stored locally. Some systems use placeholders and download data when needed. **Being visible on the screen is not proof that the file is available offline.**

### A shortcut is not always the actual file or folder

A [[shortcut|shortcut]] is an access link or pointer to an item, rather than a separate copy of all its contents. On Windows, a shortcut might point to a folder or a document somewhere else. On the Mac, an [[alias|alias]] often serves a related purpose. A pinned folder or a cloud link can also be a convenient way to reach material stored elsewhere.

Suppose a desktop shortcut named `Class Notes` points to a folder inside Documents. Deleting the shortcut and deleting the actual folder are different operations. The distinction depends on what item is selected, which is why you should verify a location before deleting anything. This lesson requires recognition only, not testing deletion.

### ZIP archives: why something may look like a folder but be a file

A [[zip-archive|ZIP archive]] bundles one or more files and folders into a single `.zip` file. Many file managers can display what is inside a ZIP as if you were browsing a folder. That interface is convenient, but the ZIP itself is still an archive **file**, not an ordinary folder. The archive may contain its own internal folder structure and usually needs an extraction or opening step to work with its contents normally.

For example, `class-materials.zip` could hold `outline.pdf`, `reading.txt`, and an `Images` subfolder. You may inspect an archive supplied by a trusted source with appropriate tools, but you should not treat an unexpected archive as automatically safe or run programs found inside it.

### Cloud storage is not the same thing as a backup

A [[backup|backup]] is an additional, recoverable copy of information kept to protect against loss. Cloud synchronization may keep copies of files on several devices, but synchronized mistakes or deletions can sometimes spread to other locations. Some services provide file history or recovery, but that is not guaranteed in every configuration. Later in this course you will study **Basic Backups** and learn how to distinguish convenient access from reliable recovery.

> **Transferable skill:** Whatever device you use, identify the **item**, its **organizing folder or collection**, and its **actual storage location**. These three questions are more useful than memorizing one manufacturer's icons.

## 8. Common misconceptions and common problems

Knowing a definition is helpful, but mistakes often happen because the screen makes different things look similar. This section turns common errors into simple questions you can use before taking action.

### Misconception 1: "The folder is the document."

A folder organizes saved items; a document file contains the document. A folder can hold a document, but you generally open the folder to find the document rather than editing the folder as though it were a letter.

### Misconception 2: "If a folder has nothing in it, it must not be a real folder."

An empty folder is still an organizing location. It may be waiting for future work or be empty because items were moved elsewhere. Do not assume that an empty folder can be deleted without consequences: applications and other people may rely on its existence.

### Misconception 3: "Every file has to be inside my Documents folder."

Files may appear in Downloads, Pictures, another folder, external storage, cloud storage, shared locations, or app-managed storage. Documents is a useful common location, not a universal requirement. The next lesson addresses where files are saved in more detail.

### Misconception 4: "If I see a file under Recent, that is its real folder."

Recent-file lists commonly provide convenient links to items stored elsewhere. The file's true storage location may be in Documents, a cloud drive, or another folder. Learn to check the location instead of assuming the list is an ordinary folder.

### Misconception 5: "Two files with the same name must be identical."

Two folders can contain separate files named `notes.txt`. Their contents may be identical, similar, or completely different. Compare the full location and other available information rather than relying on the name alone.

### Misconception 6: "A ZIP archive is just a normal folder."

A ZIP archive is a file containing packaged data. A file manager may browse it as though it were a folder, but this does not turn the archive into an ordinary directory. Recognize the `.zip` extension and the different role of an archive.

### Misconception 7: "An icon proves the file's contents are safe."

Icons and names can be misleading. The assigned app, hidden extensions, or a deliberately deceptive filename can produce a false impression. Treat unexpected downloads and attachments cautiously; do not run unfamiliar programs.

### Misconception 8: "Renaming the extension converts the document."

Changing `letter.txt` to `letter.pdf` does not convert its internal content into a PDF. Proper conversion is an application function or export workflow. Changing an extension can make a file harder to open.

### Misconception 9: "If I can see it in the cloud, it must work offline."

Some cloud interfaces display file names even when the actual content must be downloaded or synchronized. A visible name is not a guarantee of offline access. Check the service's indicators and availability before relying on a file away from an internet connection.

### Misconception 10: "A desktop shortcut is always another copy of the file."

A shortcut or alias generally provides a route to a target. It need not contain the target's full data. A shortcut may break if the original is moved or deleted; a separate copy behaves differently.

### Misconception 11: "If I don't see an extension, the file has no extension."

Many systems hide familiar extensions. The visible filename may omit a portion of its complete name. View settings and file properties can help, but they do not independently prove that a file is trustworthy.

### Misconception 12: "A folder's name tells me exactly what's inside."

A folder named `Photos` might contain images, notes, PDFs, videos, and other folders. Folder names are chosen by people or applications; they describe intent, not a guaranteed inventory. You learn the actual contents by browsing a location you are authorized to inspect.

### A practical troubleshooting table

| What you notice | Possible explanation | Safe next step |
| --- | --- | --- |
| You see a name but no extension | Your file manager may hide extensions | Check the displayed Type or view options |
| A familiar document icon looks different | Default application or view settings changed | Read the file type before making changes |
| An expected file is not visible in a folder | It may be saved somewhere else or filtered from view | Check the current location and course guidance on finding files |
| The same filename appears in two places | They may be separate files in different folders | Compare locations; do not overwrite either impulsively |
| Opening a file asks you to choose an app | No default compatible app may be assigned | Pause and identify a trustworthy compatible app |
| A folder has a small arrow or special symbol | It may be a shortcut, alias, cloud item, or special location | Inspect its description or target; avoid deletion |
| A cloud file shows an availability warning | It may need a network connection or authorization | Check account status and offline availability |
| A folder says access is denied | You may not have the required permission | Do not bypass controls; seek authorized access |
| A ZIP displays files inside it | The file manager may support archive browsing | Recognize the archive; do not run unknown contents |
| A file seems to be missing after a view change | A different sorting, grouping, or filter may be active | Recheck the folder path and view before assuming loss |

### The safe sequence before changing anything

Use the five-question check **Identify → Locate → Verify → Decide → Act**:

1. **Identify:** Is the selected object a file, folder, shortcut, archive, or application?
1. **Locate:** What is its actual storage location or path?
1. **Verify:** Do you recognize the source and understand the likely contents?
1. **Decide:** What do you want to accomplish, and do you have permission?
1. **Act:** Only after the previous steps should you open, rename, move, copy, share, or delete anything.

For this lesson, you may stop safely after **Identify** and **Locate**. That is sufficient to demonstrate the foundational skill. Later lessons provide separate practice on actions that modify stored items.

## 9. Essential vocabulary

The dotted terms throughout this lesson open short definitions when the MGU dashboard renders them. The definitions are also presented here in ordinary text so you can study without relying on a mouse, touchscreen, or popover. You do not need to memorize every item: focus first on **file**, **folder**, **subfolder**, **filename**, **file extension**, and **location**.

### The six core terms

- **File:** A named saved item of information, such as a document, photo, or video.
- **Folder:** A container used to organize files and other folders.
- **Subfolder:** A folder inside another folder.
- **Filename:** A file's name, which helps people and software identify it.
- **File extension:** A suffix, commonly after a period, that suggests the file format, such as `.pdf` or `.jpg`.
- **Storage location:** A device, account, or service location in which data is stored or made accessible.

### Organization and navigation terms

- **Directory:** Another term for a folder, particularly in technical explanations.
- **Parent folder:** A folder that directly contains another folder.
- **Folder tree:** A representation of the nested relationship between folders and files.
- **Hierarchy:** An organized structure with levels, such as parent folders and subfolders.
- **Path:** A description of the sequence of locations that leads to an item.
- **Root:** A starting point at the top of a file-system hierarchy.
- **File manager:** An application used to browse and manage files, folders, and locations.
- **File Explorer:** The file-management application provided with Windows.
- **Finder:** The file-management application provided with macOS.
- **Navigation pane:** An interface area providing quick access to available locations.
- **Breadcrumbs:** Clickable labels showing the sequence of folders or locations leading to the current view.

### File identity and format terms

- **File format:** A specification for organizing the data in a file, such as PDF or JPEG.
- **File type:** A description of the kind of file, often inferred from the format or extension.
- **File icon:** A small visual symbol representing a file or associated application.
- **Thumbnail:** A small image preview of a file's content.
- **File size:** An approximate measurement of how much storage space a file uses.
- **Metadata:** Information describing a file, such as its name, size, type, or modification date.
- **Kilobyte (KB):** A small unit used to describe data size.
- **Megabyte (MB):** A larger data-size unit often used for photos and audio.
- **Gigabyte (GB):** A larger data-size unit often used for large files and storage capacity.
- **Application:** Software used to accomplish a task, such as word processing or playing video.
- **ZIP archive:** A file that packages files and folders into one archive, often with compression.

### Access, storage, and safety terms

- **Local storage:** Storage associated with the device itself, such as its internal drive.
- **External storage:** Storage connected separately, such as a USB drive.
- **Cloud storage:** Storage provided through an online service, often integrated into file-management apps.
- **Shortcut:** A link or reference that points to an item rather than a full duplicate of it.
- **Alias:** A Mac reference that generally points to another file or folder.
- **Virtual location:** An interface collection that may display items from other stored locations.
- **Offline access:** The ability to use information without an active internet connection.
- **Synchronization:** The process of keeping selected information or changes consistent between devices or services.
- **Backup:** An additional recoverable copy intended to protect information against loss.
- **Permissions:** Rules affecting who may view, change, or use files and folders.

**Vocabulary practice:** Explain the relationship among `Photos`, `Holidays`, and `photo-01.jpg` if `Photos` contains `Holidays` and `Holidays` contains `photo-01.jpg`. Identify the file, the parent folder of `Holidays`, and the subfolder. Then explain why an extension does not guarantee that a file is safe.

:::answer Reveal the vocabulary practice answer
`photo-01.jpg` is a **file**. `Photos` is the **parent folder** of `Holidays`; `Holidays` is a **subfolder** of `Photos` and directly contains the photo. The `.jpg` extension suggests an image format but does not verify the actual contents or source of the file.
:::
