Basic Computer Skills / Document Skills

## Lesson 1: Creating a Document

A document begins with a simple decision: you have something to communicate, record, or organize, and you want to put it into a form you can use again. A document might be a letter, a meeting notice, a school assignment, a résumé draft, a short report, an instruction sheet, or a personal checklist. You do not need to be an experienced typist or know advanced formatting to create one. This lesson starts with a blank document and ends with a clearly named practice file you can find and reopen.

**Level:** Beginner · **Estimated study time:** 65–85 minutes · **Prerequisites:** Basic familiarity with a mouse, keyboard, or touchscreen is helpful, but not required · **Practice equipment:** A computer, tablet, or smartphone with an available document-writing app; paper and pencil are acceptable alternatives for planning

> **Essential idea:** Creating a document is a repeatable process: **choose a purpose → open a suitable app → start a new document → enter useful content → give it a clear name → save or confirm its storage → reopen and check it.** A blank page is only the starting point, not evidence that something has been saved.

### Learning objectives

After completing this lesson, you should be able to:

1. Explain what a [[document|document]] is and distinguish a new document from an existing one.
1. Select a practical purpose and audience before writing.
1. Recognize a [[word-processor|word-processor]] and choose among a blank document, a [[template|template]], and a simple text editor.
1. Follow beginner-friendly steps to create a new document in an available application.
1. Identify the main areas of a document editor, including the typing area and insertion point.
1. Write a short, appropriately structured practice document using ordinary text.
1. Give the practice file a meaningful name, confirm where it is stored, and reopen it if your application allows.
1. Apply basic privacy, accessibility, and mistake-recovery habits during document creation.

## 1. What is a document?

A [[document|document]] is a recorded piece of information created so it can be read, used, shared, or kept for later. Before computers, many documents were handwritten or produced with typewriters. Today, many are [[digital-document|digital documents]] that can be opened with a suitable app. A digital document may contain plain words, styled paragraphs, lists, pictures, tables, or other material. This lesson concentrates on ordinary text because it provides the foundation for everything else in Document Skills.

You encounter documents when you write to an organization, keep notes from a meeting, prepare a school assignment, create instructions, or provide information to another person. A document does not need to be long to be valuable. A clearly written five-line notice may serve its audience better than a confusing five-page report.

### A document serves a purpose

Consider four common situations:

| Situation | Suitable first document | What the reader needs |
| --- | --- | --- |
| You want to announce a community meeting | Meeting notice | Topic, date, time, place, and contact method |
| You need to ask a landlord to repair something | Maintenance-request draft | Problem, location within the property, and a clear request |
| You want to remember instructions | Personal procedure or checklist | Steps in a useful order |
| You must communicate an absence | Short professional message or letter | Reason as appropriate, dates, and intended next action |

The content, length, tone, and level of detail should fit the [[purpose|purpose]]. You may draft personal material, but **do not use account numbers, passwords, identification numbers, private medical details, or another person's information for this training exercise**.

### Document, file, and page are not identical

A [[file|file]] is a named unit of stored digital information. A document is a kind of content that can be stored as a file or represented in a cloud service. A [[page|page]] is an area of a document displayed or prepared for printing. One document may have one page or many pages. A computer can also store pictures, music, or programs as files, but those are not the word-processing documents discussed here.

When you open a blank Word or Writer document, you may see an empty white rectangle that resembles a sheet of paper. A Google Docs document can look similar. Yet the appearance of a page does **not** prove that your work has been stored under a name or is available on another device. You will check the save or storage status later.

### New document versus existing document

Choosing **New** ordinarily creates a separate document for a new task. Choosing **Open** normally retrieves a document that already exists. If you open an existing file, type into it, and save over it, the original contents may change. For this lesson, use **New** or the app's equivalent whenever possible. If you must work from an existing template or sample, use a copy rather than overwriting the original.

A [[blank-document|blank document]] begins without prewritten body content. A template starts with some prearranged structure or design. Both can be valid starting points, but a blank document makes it easier to learn where to type and how the editor behaves.

> **Check your understanding:** A document can be a short memo, not just a long report. The word *New* means “start a new item”; *Open* means “return to something already created.”

## 2. How do you plan a useful document?

Opening an application is not the first intellectual step. Before typing, decide what you need the document to accomplish. Planning helps you avoid an empty-page problem in which you can operate the computer but do not know what to write.

### Ask four planning questions

1. **Purpose:** Am I informing, requesting, explaining, recording, or organizing something?
1. **Audience:** Who will read it—only me, an instructor, a colleague, a community group, or someone else?
1. **Essential facts:** What must the reader know to take the intended action or understand the message?
1. **Next step:** Do I want to keep the document privately, print it, send it, or improve it later?

For a beginner's practice, select a neutral, low-risk subject. Examples include a library visit checklist, a community-room reservation reminder with invented details, a study schedule, or an instructions sheet about a hobby. The subject only needs to be concrete enough to produce a title and a few sentences.

### Make a small outline

An [[outline|outline]] is a short plan for content and its order. For a one-page notice, the outline may simply be:

1. Title: what the notice concerns.
1. Opening sentence: why it matters.
1. Key facts: date, place, time, or instructions as applicable.
1. Closing: what the reader should do next.

You do **not** have to create a formal heading structure or use bullet-list controls yet. Those topics appear later in Document Skills. In this lesson, your outline can be four lines on paper.

### Compare a vague message with a useful message

**Vague draft:** “We have a meeting soon. Everyone should come.”

**Clearer draft:** “The neighborhood reading group will meet on Tuesday, April 14, at 6:00 p.m. in the community room. Participants may bring one book to discuss. Please confirm with the organizer before Monday.”

The clearer version tells the reader what is happening, when, where, and what to do. The example details are fictional. When creating a real document, verify dates, addresses, deadlines, and contact methods before sharing it.

### Begin with a simple working title

A [[title|title]] tells a reader what the document is about. “Reading Group Meeting Notice” is more informative than “My Document.” A good title can later be changed without losing the underlying document. The title shown inside the page and the name used to save the file may be similar, but they are not automatically the same thing.

A practical rule for this lesson is **one document, one purpose, one descriptive name**. Resist the urge to polish every word before completing a basic first draft. Getting a useful message onto the page is the priority.

## 3. Which application should you use?

A [[word-processor|word processor]] is a program or web service designed to create and edit written documents. Common examples include Microsoft Word, Google Docs, LibreOffice Writer, and Apple Pages. Many people also use simple note-taking tools or text editors. These applications overlap, but their [[menus|menu]], file storage, internet requirements, and available features differ.

### Compare common options

| Application | Where it commonly runs | Typical way to begin | Storage behavior to recognize |
| --- | --- | --- | --- |
| Microsoft Word desktop | Windows or Mac, when installed or available through a license | New, then Blank document | Can save to a computer or a configured cloud location; AutoSave depends on setup |
| Word for the web | Web browser with a suitable Microsoft account or access | Create a blank document | Usually works with OneDrive-backed documents; check account and sync status |
| Google Docs | Web browser or supported app | Blank document | Usually saves changes to Google Drive through the connected account; offline use must be configured |
| LibreOffice Writer | Windows, Mac, or Linux, when installed | File, New, Text Document | Commonly saves to a chosen location, such as a folder on the computer |
| Apple Pages | Mac, iPhone, iPad, or supported iCloud access | Choose a blank template | Can use local or iCloud storage depending on device and settings |
| Basic text editor | Many computers and devices | New file or new note | Useful for plain text; may lack page layout and rich formatting |

These descriptions are typical workflows, not a promise that every version has the same buttons. Work or school accounts may limit creation, downloads, storage, or sharing. Mobile apps may hide menu commands behind an icon or more-options menu. If a particular app is unavailable, choose another accessible app; you do not need to buy software to practice the core skill.

### Word processor versus plain-text editor

A basic [[text-editor|text editor]] such as Notepad is suitable for practicing sentences and file naming. It is less suitable for a formal letter with fonts, page breaks, and arranged images. A word processor can store text and additional structure such as headings, lists, and tables. The word processor is the preferred practice environment if one is available, but using a plain-text editor is still a valid introductory exercise.

### Blank document or template?

A [[template|template]] can contain placeholder text, styles, and a prepared layout for a letter, report, or other common document. Templates are convenient when you already understand what you are trying to produce. For the first exercise, select a blank document unless you need an accessible template to get started. A blank document exposes the fundamental workflow without extra elements to confuse you.

### Online and offline work

An [[online-app|online app]] runs primarily through a browser or communicates with an online service. It may depend on a stable connection to create or synchronize files. An [[offline-app|offline app]] can carry out core work without an active internet connection when installed and appropriately configured. Many products support both patterns in some circumstances. Saving automatically to a cloud account is not the same thing as having a separately downloaded local file.

Choose the option that fits your situation rather than assuming there is only one correct brand or device. When using a shared or public computer, avoid leaving private documents in an account that other people can access. Use a harmless practice subject here.

## 4. How do you start a new document?

The exact buttons vary, but nearly every document editor has a way to begin a new file. Follow the instructions for **one** application you can access. If the interface does not match the directions, look for a similarly labeled command such as **New**, **Create**, **Blank**, **Text Document**, or **Choose a Template**.

### Route A: Microsoft Word on a Windows computer

1. Open Microsoft Word from the Start menu, taskbar, or another authorized shortcut.
1. If Word shows a start screen, look for **Blank document** and select it.
1. If Word is already showing another document, look for **File → New → Blank document**.
1. Wait until an empty editing page appears. On a computer that uses a mouse, click in the body area if the typing cursor is not already visible.
1. Type a test phrase such as **Practice Notice**. You have started a new document.

Do not assume that every desktop Word installation saves automatically. A document stored in a cloud location with AutoSave enabled behaves differently from a new local document that still needs its first save. You will verify the location and storage status in the exercise.

### Route B: Google Docs in a web browser

1. Open [Google Docs](https://docs.google.com/) in a browser and use your own authorized account if prompted.
1. On the Docs home screen, look for **Blank** or the new-document plus symbol and select it.
1. A document editor opens, often with a temporary title such as **Untitled document** near the top.
1. Click or tap the document's typing area and enter **Practice Notice**.
1. Replace the temporary document name with a descriptive one when instructed below.

Google Docs normally uses automatic saving for changes associated with its account-based storage, but offline status, connection problems, access restrictions, or account mix-ups can still interfere with your expectation that a document is available later. Do not close the tab until you have checked the document name and status.

### Route C: LibreOffice Writer

1. Open LibreOffice Writer, or open LibreOffice and choose to create a **Text Document**.
1. If you are already in a LibreOffice window, choose **File → New → Text Document**.
1. Click in the blank document's page area if necessary.
1. Type **Practice Notice**.
1. When you reach the saving exercise, choose the file name and folder explicitly.

LibreOffice typically uses the OpenDocument text format (`.odt`) by default. That is a standard document format, not an error. A later lesson will cover file types and exports in greater depth.

### Route D: Apple Pages

1. Open Pages on a Mac, iPhone, or iPad that has the app available.
1. Choose to create a new document. On Mac, you may see a template chooser.
1. Choose **Blank** (or another suitable basic word-processing template), not a special page-layout template.
1. Click or tap the writing area and type **Practice Notice**.
1. Identify the document name and storage location when you save or rename it.

Pages has different word-processing and page-layout document types. For an ordinary letter or notice, a blank word-processing document is normally the simpler choice. Exact menu names differ by device and version.

### Route E: Another word processor or a text editor

If you use a different app, look for the equivalent actions: **Open app → New or Create → Blank or empty page → click the writing area → type a test phrase**. If an account sign-in or permission is required, use the app only if you are authorized. You can also complete the content-planning parts of this lesson on paper.

### How do you know a new document opened?

Look for three signals: a writing area is present, a cursor or [[insertion-point|insertion point]] can be placed in it, and typing adds text to the new item rather than changing a different document. Do not rely on the document title alone. A tab that says “Untitled” may be a new unsaved document, a cloud document without a useful name, or a new file with a temporary label.

> **Beginner caution:** Before typing, confirm that you are not inside an existing personal or workplace file. If unsure, use the app's **New** command again rather than editing or deleting unfamiliar content.

## 5. What do you see in the document editor?

When you open a word processor, the screen can seem crowded with buttons. You only need to recognize a few areas to write your first document. The location and names of controls vary, but their purposes are similar.

### The principal screen areas

| What you may see | What it usually means | Beginner action |
| --- | --- | --- |
| App or browser title area | Shows the app, document name, or tab | Confirm you are in the expected document |
| Menu or ribbon | Gives access to commands such as New, Open, or Save | Use only the commands needed for this lesson |
| Toolbar | Holds quick controls for common actions | Leave most controls alone initially |
| White page or editing canvas | Displays the document content | Click or tap here to start entering words |
| Blinking insertion point | Marks where newly entered text will appear | Place it where you want the next character |
| Scroll bar or page navigation | Lets you view other areas of a long document | Scroll without changing the text |
| Status or save indicator | May show pages, words, file status, or storage messages | Check whether changes have been stored |

The [[ribbon|ribbon]] in Word organizes many commands into tabs. Google Docs uses [[menus|menu]] and [[toolbars|toolbar]]. Writer and Pages use their own menus, tools, and panels. You are not expected to memorize every command.

### The insertion point is not the mouse pointer

The mouse [[pointer|pointer]] is the visible symbol used to click and select things on the screen. The text [[insertion-point|insertion point]] is the place where typed characters will appear. It often looks like a thin blinking line inside the text. You can move the pointer across the page without moving the insertion point; in most editors, you click a location to place the insertion point there.

If you type and nothing appears, check whether the document itself has [[focus|focus]]. The active target may be the address bar, search box, file-name box, or another control. Click or tap the document's writing area, then try a harmless word.

### Enter, Space, Backspace, and Undo

The **Space** key separates words. **Enter** generally ends one [[paragraph|paragraph]] and begins another. **Backspace** normally deletes the character immediately before the insertion point. The [[undo|Undo]] command reverses a recent edit when supported. These actions are sufficient for a basic paragraph. They will be practiced more fully in the next lesson, **Typing, Editing, and Saving**.

Avoid repeated spaces to move words across a page or repeated Enter presses to force a layout. Those shortcuts can make later editing difficult. The dedicated formatting lesson explains better ways to control position and spacing.

### Recognize the difference between the page and the file name

A document may contain the heading **Practice Notice** inside the page while still being named **Untitled document** outside the page. That is normal until you rename it. Similarly, a file named `practice-notice.docx` may have a different title within its content. Both can be useful, but they serve different purposes: the on-page title informs readers, and the file name helps you identify the saved item.

### Accessibility is part of good document work

You may enlarge the view using a [[zoom|zoom]] control, use a keyboard to navigate, or rely on a built-in screen reader or voice input where the application supports it. The exact accessibility controls depend on the device and app. A higher zoom level generally changes the view rather than the document's actual text size. If visual or motor accessibility settings are already configured for you, keep using them; the lesson does not require changing those settings.

A clear title and logical paragraph order also improve understanding for readers. More formal accessible heading styles and alternative text for images are covered in later lessons. For now, focus on a meaningful text-first document.

## 6. How do you create your first useful document?

You will create a short, fictional **community reading group notice**. This example is deliberately simple: it does not need a real address, account, recipient, or personal contact information. You may instead choose an equally harmless topic, provided it has a title, a purpose, and several useful sentences.

### Step 1: Start from a new blank document

Use the application route from Section 4. Verify that typing will change the new document and not an older file. If you see an existing letter or someone else's material, stop, close that item without saving changes if appropriate, and create a new blank document.

### Step 2: Enter a descriptive title

Type the following text on the first line:

**Community Reading Group Notice**

Then press Enter once to begin another paragraph. You do not need to change font sizes, center the title, or make it bold using toolbar controls. The plain words are sufficient at this stage.

### Step 3: Enter a clear opening statement

Type this sentence:

“The community reading group is planning a short meeting to discuss books and select a future reading topic.”

Press Enter. Notice that the next text begins on a new paragraph or line, depending on the editor. The important point is that the message remains easy to read.

### Step 4: Add essential details

Add these lines, using the fictional facts for practice:

- Date: Tuesday, April 14 (practice date only)
- Time: 6:00 p.m.
- Location: Community room (example location only)
- Bring: One book you enjoyed

For this introductory lesson, you may type the dash at the start of each line or write each item as a short sentence. Do not worry about activating the app's automatic bulleted-list feature. Structured lists are treated in the later **Headings, Lists, and Spacing** lesson.

### Step 5: Add a closing instruction

End with a sentence such as:

“Please review the meeting details and bring one suggestion for the next book.”

Your document now has a title, an opening, key details, and a closing action. The example is not intended to be sent or posted as a real meeting announcement.

### What your first draft should contain

> **Community Reading Group Notice**
>
> The community reading group is planning a short meeting to discuss books and select a future reading topic.
>
> Date: Tuesday, April 14 (practice date only)
>
> Time: 6:00 p.m.
>
> Location: Community room (example location only)
>
> Bring: One book you enjoyed
>
> Please review the meeting details and bring one suggestion for the next book.

The block above demonstrates *content*, not a required font or visual style. Word, Docs, Writer, and Pages may display the text a little differently. It is more important that the document communicates a complete message than that it looks identical across applications.

### Step 6: Give the item a meaningful name

Choose a name such as **Community Reading Group Practice** or `community-reading-group-practice` rather than “Document1,” “New File,” or “asdf.” A [[filename|file name]] should help you recognize the document later, even if you create many more documents.

On a desktop app, you may need **File → [[Save|save]]** or **[[Save As|save-as]]** to name a new file. On an online app, you may edit the document title in the top area and then look for a saved-status indication. Names and locations are different controls in different programs.

### Step 7: Confirm its storage location

A [[folder|folder]] groups files in a computer or account. A [[cloud-storage|cloud storage]] service stores files using an online account, although synchronization may also keep local copies. If you are using [[local storage|local-storage]], choose an understandable location such as your own **Documents** folder. If using a cloud editor, check which account owns or contains the document and whether [[synchronization|synchronization]] has completed.

| If you use… | Check this before closing |
| --- | --- |
| Word desktop | The file has a name, the desired local or cloud location, and no unresolved save warning |
| Word for the web | The correct account and document name appear and cloud changes are saved or synchronized |
| Google Docs | The correct account and descriptive name are shown and any pending save or offline status is resolved |
| LibreOffice Writer | The file is saved to the chosen folder and the title is no longer merely an unnamed document |
| Pages | The document has an identifiable name and a known local or iCloud location |
| Text editor | Its Save command created a file in a known folder with an appropriate extension |

Do not assume that “I can still see the words” means “the file is safely stored.” Some programs display text in memory even when the first save has not occurred. Likewise, an automatic-save message should be interpreted together with the account, folder, and synchronization status.

### Step 8: Reopen the saved document

If possible, close the document only **after** confirming that the save or sync operation has completed. Then use the app's **Recent**, **Open**, or file-browser function to reopen the item. Check that the title and text are still present. If your editor uses a browser tab, revisit the document from the service's file list rather than depending only on the browser's Back button.

If you cannot reopen it, do not immediately repeat all the typing. First check the account, location, document name, and any saved-status messages. The next lesson provides a fuller treatment of saving and recovery.

> **Success standard:** You can explain what the document is for, show where you typed its content, identify its name and storage location, and retrieve the same content again. That is a complete beginner document-creation cycle.

## 7. Guided practice: Create a document

These exercises progress from planning to creating and checking a saved document. They are designed for repetition. Use the same harmless practice topic throughout if that makes the process easier. If you do not have an editor available, you can plan the content on paper and perform the file-handling portions later.

### Activity 1: Identify a document's purpose (about 5–8 minutes)

Consider the three situations in the table. Choose the kind of document that would help, then write one sentence explaining why. Your answers may differ from the examples; a reasonable explanation matters more than memorizing a label.

| Situation | Your document choice | Intended reader |
| --- | --- | --- |
| You want to remember steps for watering houseplants | __________ | __________ |
| You want to invite a study group to meet | __________ | __________ |
| You need to record a question to ask at a meeting | __________ | __________ |

Ask yourself: “What should this reader know or do after reading it?”

:::answer Show suggested Activity 1 answers
1. A personal instruction sheet or checklist; the intended reader could be you.
1. A short invitation or meeting notice; the intended readers are group participants.
1. A note or agenda; the intended reader could be you or the meeting facilitator.

The same situation may support multiple reasonable document types. The goal is to connect the purpose to the audience.
:::

### Activity 2: Locate the new-document command (about 5 minutes)

1. Open one app that can create text documents, or use the written app descriptions in Section 4.
1. Find the command that starts a **new** document.
1. Locate the **blank** option if the app presents templates.
1. Start a new document but do not type into any file that already contains someone else's work.
1. Record the app name and the labels you selected.

| App used | New-document command | Blank option available? |
| --- | --- | --- |
| __________ | __________ | Yes / No / Not shown |

If your device is unavailable, imagine using one of the documented routes and describe the sequence. Do not create an account or download software solely for this activity.

### Activity 3: Build the notice (about 10–15 minutes)

1. On the first line, type a title describing the topic.
1. Write an opening sentence that explains the document's purpose.
1. Enter at least three important details or instructions.
1. Write one closing sentence that tells the reader what to do or remember.
1. Read the text from beginning to end and confirm that it makes sense without additional explanation.

*Content checklist*

- [ ] I started with an empty document or a safe new copy.
- [ ] I added a useful title inside the document.
- [ ] I explained why the document exists.
- [ ] I included at least three supporting facts or directions.
- [ ] I ended with a clear next step.
- [ ] I used fictional or non-sensitive practice information.

A document may pass this checklist without colored fonts, images, borders, or special layout features.

### Activity 4: Name, save, and find the file (about 8–12 minutes)

1. Choose a descriptive document name, such as `reading-group-practice`.
1. Save it or verify that your online application has stored and synchronized the latest changes.
1. Record whether the document is located in a local folder or an online account.
1. With the save operation finished, reopen the document using the app's Recent/Open view or file list.
1. Compare the reopened text with the text you wrote. If a sentence is missing, check for account, folder, or synchronization problems before starting again.

| Record | Your answer |
| --- | --- |
| Document name | __________ |
| App used | __________ |
| Local folder or online account | __________ |
| Evidence that it was saved | __________ |
| Reopened successfully? | Yes / Not yet |

Do not write a password or actual account identifier on this worksheet. “My documents folder” or “my cloud documents” is enough.

### Activity 5: Repeat with a different purpose (about 8–12 minutes)

Create a second, short document from a different prompt: **“Three steps for preparing for a library visit.”** Give it a title, an opening sentence, three ordinary numbered or separate lines, and a closing sentence. Use a new name such as `library-visit-steps`; do **not** overwrite your first notice.

When finished, explain the difference between the two documents. What changed because the purpose changed? Did the title, details, audience, or closing action change? This comparison is an important transferable skill.

### Activity 6: Practice recovering from a harmless mistake (about 5 minutes)

1. In a practice document, type a harmless extra word at the end of a sentence.
1. Use the app's **Undo** command, if available, to reverse that change.
1. Explain where the insertion point is after undoing the edit.
1. If Undo is unavailable, remove only the extra word using Backspace or another safe editing method.
1. Confirm the intended text remains and save or confirm the latest change as appropriate.

Do not practice recovery by deleting an entire document or closing an unsaved file. A small reversible change is enough.

> **Privacy and accessibility rule:** Practice in a document you control. Do not use someone else's account or files; do not upload confidential material; do not disclose passwords or other identifying details. If you use a screen reader, enlarged display, voice dictation, or touch controls, the activity goals remain the same even when the exact gestures differ.

## 8. Common mistakes and troubleshooting

### “I opened Word, so my document must already be saved.”

Opening an editor is not a save operation. A new document may exist only in the current session until it receives a name and is stored. Check the file name, location, and save status. In some online editors, a new cloud file is created automatically; you should still check its account and name.

### “I gave the document a title on the page, so I also named the file.”

These are separate things. The title inside the document is content. The filename or online document name is what you look for in a file list. Use both in your practice document.

### “I clicked Open when I wanted to make a new document.”

**Open** accesses an existing item. **New** creates a new item. If you accidentally opened an old file, leave it unchanged and use New. Do not clear its content to simulate a blank page.

### “I cannot see the place where I type.”

Try clicking or tapping the document body. Look for the insertion point. If the screen has a dialog box, close or finish it safely first. If the file is [[read-only|read-only]], you may need a document you can edit, not a forced change to its permissions.

### “I started typing, but the words appeared in a search box.”

The text input [[focus|focus]] was in the wrong place. Select the writing area and try a short word again. On touch devices, the on-screen keyboard may appear when you tap an editable field.

### “The page looks different from the example.”

Applications differ in margins, toolbars, default font, and displayed page size. That does not make the content incorrect. The initial benchmark is a complete message with a title and useful details, not a pixel-perfect visual match.

### “I cannot find a Save button in Google Docs.”

Google Docs generally saves through its account-based storage rather than requiring a conventional desktop Save button for each change. Check the document name, current account, any offline or syncing indication, and whether you can find the file in the Docs or Drive list. Never assume synchronization succeeded if the app shows an error.

### “My document is in the wrong account or folder.”

Check which account or location you selected. On shared devices, multiple users may have different documents with similar names. Avoid copying a private document into a shared location without authorization. If your first document is harmless practice text, you can create a new copy in the correct location after confirming your access.

### “A blank page is showing but typing does nothing.”

Check for read-only or preview mode, an inactive window, a dialog box, or a page that is only a visual preview. A browser may display a PDF rather than an editable document. Use a new editable document in an appropriate application instead of assuming every displayed page is writable.

### “I made a mistake and need to start again.”

Usually not. Many editors provide Undo for recent changes. Read the surrounding words before deleting anything. Replacing one incorrect word is safer and faster than recreating the entire file. Frequent checks make correction manageable.

### “The document is on a public computer.”

Public devices can retain files, browser sessions, and cached data. For the practice task, use fictional information and follow the institution's sign-out and file-cleanup policy. Do not assume that simply closing a browser tab signs you out or removes locally stored material.

### “Should I print, convert to PDF, or add pictures now?”

Not yet. Those skills have dedicated lessons later in Document Skills. First complete the new-document workflow, including naming, storing, and reopening the draft. Once that works, formatting and distribution become much easier.

### Quick diagnosis table

| Problem | First safe check | Next action |
| --- | --- | --- |
| Cannot begin typing | Is the insertion point in an editable document? | Click the writing area or start a new editable document |
| Cannot find the document | Do you know its name, location, and account? | Search Recent or the selected folder or cloud list |
| Changes did not appear after reopening | Was the save or sync completed? | Check warnings, correct account, and last saved copy |
| Existing document changed by mistake | Can you still use Undo or version history? | Stop editing and recover carefully before doing anything else |
| No word processor installed | Is another authorized editor available? | Use an existing supported app or plan on paper |
| Unfamiliar toolbar | Does the writing area still work? | Focus on New, typing, file name, and save status |

## 9. Essential vocabulary

Some terms in earlier sections have a dotted underline and can be selected to show definitions. A term's optional additional-reading link appears only where an appropriate resource is available. The glossary below consolidates the concepts you need for this lesson.

- **Document:** Recorded information prepared to be read, used, or shared.
- **Digital document:** A document stored and handled electronically.
- **File:** A stored unit of information that a computer or service can identify and retrieve.
- **Page:** A displayed or printable area within a document.
- **Word processor:** Software for writing and editing documents with text and layout features.
- **Text editor:** Software used to enter and edit primarily plain text.
- **Blank document:** A new document without prewritten body text.
- **Template:** A reusable starting design or structure for a document.
- **Purpose:** The intended reason a document is being created.
- **Audience:** The person or group expected to read the document.
- **Outline:** A brief plan showing the document's important ideas in order.
- **Title:** A short heading that identifies the document's subject.
- **Draft:** A version of writing that can be reviewed or improved.
- **New:** A command that starts a new item rather than retrieves an existing one.
- **Open:** A command that retrieves an existing file or document.
- **Editing area:** The portion of an app where a document's content can be entered or changed.
- **Insertion point:** A marker showing where newly typed characters will appear.
- **Pointer:** The on-screen mouse or trackpad indicator used to select controls.
- **Focus:** The current active control that receives keyboard input.
- **Menu:** A collection of commands that can be selected.
- **Toolbar:** A group of visible buttons for common commands.
- **Ribbon:** A tabbed command area found in some applications, including Word.
- **Paragraph:** A related group of sentences, typically ended by pressing Enter.
- **Undo:** A command that reverses a recent editing action when supported.
- **File name:** A label used to identify a stored file.
- **Folder:** A container used to organize files.
- **File extension:** An ending such as `.docx`, `.odt`, or `.txt` that indicates a file format.
- **Save:** A command or process that stores a document's information for later retrieval.
- **Save As:** A command commonly used to save a first file or create a separately named copy.
- **AutoSave:** A feature that automatically stores changes when enabled and working under the app's conditions.
- **Cloud storage:** Storage accessed through a connected online account or service.
- **Local storage:** Storage available on the device or a connected local drive.
- **Synchronization:** The process of updating copies of data across an app, device, and/or online service.
- **Online app:** An application that uses a browser or network service for some or all operations.
- **Offline app:** An application able to work without an active network connection when installed and configured appropriately.
- **Read-only:** A state in which content can be viewed but not directly changed in the current copy.
- **Accessibility:** Designing or adjusting tools so people with different needs can use them effectively.
- **Zoom:** A viewing control that enlarges or reduces the displayed document without necessarily changing the stored font size.
- **Word wrap:** Automatic movement of text to the next display line when it reaches the available width.
- **Recent files:** A list of previously accessed documents shown by some applications.
- **Version history:** A feature that can show or restore earlier states of a document in supported apps.
