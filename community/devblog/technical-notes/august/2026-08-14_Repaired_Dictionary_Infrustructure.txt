## Engineering Log — August 19, 2026

Completed troubleshooting and repair of the Malone Global University General English Dictionary infrastructure.

Identified and corrected the dictionary index path so the main dictionary page properly loads `/library/dictionary/general-english/dictionary-index.json`. Investigated non-responsive letter shards and confirmed that the root `.gitignore` rule for `data/` prevented the dictionary JSON shard directory from being deployed. Renamed the production shard directory to `shards/` and updated dictionary paths accordingly.

Verified that dictionary letter shards now load successfully and populate the A–Z index with word entries. Repaired the entry-page wiring so `entry.js` loads correctly and retrieves definitions from the appropriate shard.

Audited `entry.js` and confirmed support for lemma-based lookup, variant lookup, multiple senses, examples, synonyms, antonyms, etymology, explanation, audio playback, and text-to-speech fallback. Determined that the renderer currently displays only one pronunciation field because it prioritizes `phonetic` over `ipa`. Established a requirement to display both IPA transcription and reader-friendly phonetic pronunciation.

Reviewed the General English JSON schema and confirmed that metadata fields—including lemma, tier, difficulty, part of speech, pronunciation, synonyms, antonyms, etymology, explanation, audio, update date, and senses—are intended as mandatory record data. Missing values will be treated as data-quality issues rather than hidden by the renderer.

Added a dictionary resource link to the MGU International Phonetic Alphabet textbook at `/library/textbooks/01-humanities/ipa/` to support users learning how to interpret IPA pronunciation notation.

**Status:** Dictionary indexing, shard retrieval, and entry rendering are operational. Remaining work centers on JSON metadata completion, IPA normalization, and updating `entry.js` to display both pronunciation systems.
