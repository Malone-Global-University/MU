WORKFLOW NOTE

Title
PowerShell Recent File Lookup Command

Date
2026-05-21

Area
PowerShell / File Management / MGU Local Workflow

Problem
The user needed a quick way to identify recently saved files from PowerShell. The correct command needed to support both the current folder and recursive searches across a larger working directory such as `C:\MGU`.

Intended Goal
Provide simple PowerShell commands that list recently modified files, sorted by newest first, with options for current-folder search, recursive search, result limits, and recent time windows.

Root Cause
PowerShell does not have a single plain-English “recent files” command. The task requires combining `Get-ChildItem`, `Sort-Object`, `Select-Object`, and optionally `Where-Object` to filter and display files by `LastWriteTime`.

Steps Taken

1. Provided a basic command for listing recently saved files in the current folder using `Get-ChildItem -File`.
2. Added a recursive version using `-Recurse` to search the current folder and all subfolders.
3. Added a limited-output version using `Select-Object -First 25` to avoid overwhelming results.
4. Added a date-filtered version using `(Get-Date).AddDays(-1)` to show files saved in the last day.
5. Added an MGU-specific example targeting `C:\MGU` and showing the newest 50 files.

Key Change
The main correction was sorting files by `LastWriteTime` in descending order so the newest saved files appear first.

Outcome
The user now has reusable PowerShell commands for finding recent files quickly, either in the current directory or across the full MGU project folder.

Validation
The commands use standard PowerShell cmdlets and properties: `Get-ChildItem`, `LastWriteTime`, `Sort-Object`, `Where-Object`, and `Select-Object`. The examples are syntactically valid and can be pasted directly into PowerShell.

Rules Going Forward
Use `-File` when looking only for files, not folders. Use `-Recurse` when searching subfolders. Use `Select-Object -First` to keep results manageable. Use `FullName` instead of `Name` when the file path matters.

Notes
For large folders like `C:\MGU`, recursive searches may take longer. Limiting results to the newest 25, 50, or 100 files is usually better than printing every match.
