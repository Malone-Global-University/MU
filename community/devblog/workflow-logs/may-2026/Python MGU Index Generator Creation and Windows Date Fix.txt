WORKFLOW NOTE

Title
Python MGU Index Generator Creation and Windows Date Fix

Date
2026-05-21

Area
MGU automation tooling / encyclopedia index generation system

Problem
A reusable automation tool was needed to generate complete `index.html` files across MGU folder structures from PowerShell. The system needed to support selectable root folders, optional recursive walking of subfolders, automatic link generation, and complete MGU HTML page scaffolding. During testing on Windows PowerShell, the script failed while generating new files due to an invalid Unix-style date formatting string in Python.

Intended Goal
Create a portable Python-based index generation utility that:

* Runs directly from PowerShell
* Allows the user to select a target folder
* Allows recursive or non-recursive operation
* Generates complete MGU-branded `index.html` files automatically
* Safely skips or overwrites existing indexes
* Works correctly on Windows systems

Root Cause
The script originally used Unix/Linux-specific `strftime()` format flags (`%-m` and `%-d`) that are unsupported in Windows Python environments. The failure occurred only when the script attempted to generate a new file and entered the HTML build routine.

Steps Taken

1. Designed a full Python folder-walking utility using `pathlib` for cross-platform filesystem handling.
2. Added PowerShell terminal prompts for:

   * target folder selection
   * recursive traversal selection
   * overwrite behavior
3. Built automatic HTML index generation including:

   * full MGU site shell
   * navigation structure
   * generated link lists
   * title formatting from folder names
4. Added logic to:

   * skip ignored folders
   * avoid indexing existing `index.html` files
   * normalize generated links
5. Identified the Windows compatibility failure caused by:

   ```python
   strftime("%-m-%-d-%Y")
   ```
6. Replaced Unix-only formatting with a manual cross-platform date builder:

   ```python
   today = f"{today_obj.month}-{today_obj.day}-{today_obj.year}"
   ```
7. Recommended converting hardcoded upload dates into configurable constants for easier maintenance.

Key Change
The most important correction was replacing Unix-specific `strftime()` formatting with a Windows-safe manual date construction method.

Outcome
The script became compatible with Windows PowerShell environments and can now safely generate MGU `index.html` pages recursively across encyclopedia directory structures without crashing during file creation.

Validation
Validation was performed by:

* running the script directly from PowerShell
* testing recursive traversal in `C:\MGU\library\encyclopedia`
* confirming correct skip behavior for existing indexes
* identifying the exact failure point during new file generation
* verifying the replacement date logic is platform-safe

Rules Going Forward

* Avoid Unix-specific `strftime()` flags in Windows-targeted Python scripts.
* Centralize reusable constants such as uploaded dates near the top of scripts.
* Use `pathlib` for filesystem operations to improve portability and readability.
* Ensure generated HTML shells are structurally complete before deployment.
* Test automation scripts on the actual deployment OS before large recursive runs.

Notes
Possible future improvements include:

* automatic breadcrumb generation
* metadata extraction from existing pages
* preservation of original uploaded dates during regeneration
* alphabetical grouping systems
* configurable HTML templates
* automatic department/library theme selection
* optional sitemap or JSON index export generation
