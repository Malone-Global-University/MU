WORKFLOW NOTE

Title
Automatic H3 Spacing Fix

Date
2026-05-21

Area
CSS / HTML Text Formatting

Problem
H3 headings were running too closely into the following content, requiring manual `<br>` tags after each `</h3>`.

Intended Goal
Create automatic visual spacing after every H3 heading using CSS instead of repeated HTML line breaks.

Root Cause
The page styling did not define enough bottom margin for `h3` elements.

Steps Taken

1. Identified that CSS cannot literally add structural HTML after `</h3>`.
2. Reframed the issue as a spacing/layout problem.
3. Recommended adding `margin-bottom` to the `h3` selector.

Key Change
Added automatic bottom spacing to all H3 headings with CSS.

Outcome
Every H3 heading can now display with consistent space beneath it without manually adding `<br>` tags.

Validation
Confirmed that `<h3>` is already block-level and that `margin-bottom` is the correct clean solution for visual spacing.

Rules Going Forward
Use CSS margins for layout spacing instead of repeated `<br>` tags.

Notes
Use `0.5em`, `1em`, or `2em` depending on how much space is needed.
