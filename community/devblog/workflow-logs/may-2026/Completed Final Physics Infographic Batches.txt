WORKFLOW NOTE

Title
Completed Final Physics Infographic Batches

Date
2026-05-21

Area
MGU Library / Reference / Physics Infographics / “How Things Work” and physics concept visual reference production

Problem
The physics infographic series was near completion, but several remaining topic batches still needed to be generated as individual files in the same 1536×1024 educational infographic style as the uploaded Impulse reference image. During the session, a few generation attempts stalled or produced a combined collage instead of separate individual files, which did not match the intended delivery format.

Intended Goal
Produce individual infographic files, one per physics topic, matching the layout, dimensions, and visual style of the Impulse infographic: large title, subtitle, numbered content panels, equations, examples, sample problems, key points, real-world applications, summary box, and “In Short” footer.

Root Cause
The image generation workflow sometimes interpreted a batch request as a request for a combined multi-topic poster rather than separate files. In addition, larger image-generation batches occasionally stalled, requiring the request to be restarted with clearer wording emphasizing “individual files.”

Steps Taken

1. Generated the remaining modern physics and nuclear physics batch as individual infographic files for topics including wave-particle-duality, atomic-models, quantum-mechanics-basics, uncertainty-principle, schrodinger-conceptual-overview, atomic-nucleus, radioactive-decay, half-life, nuclear-fission, and nuclear-fusion.

2. Generated the nuclear astrophysics and cosmology batch as individual infographic files for binding-energy, stellar-life-cycle, hertzsprung-russell-diagram, black-holes, neutron-stars, galaxies, dark-matter, dark-energy, big-bang-theory, and expansion-of-the-universe.

3. Attempted the fluids/materials overview batch, observed a stall, then restarted the request with clearer wording that the output needed to be ten different individual files matching the Impulse infographic dimensions and style.

4. Generated the fluids, materials, and overview batch as individual infographic files for fluid-mechanics, density-and-pressure, buoyancy, bernoullis-principle, fluid-dynamics, aerodynamics, stress-and-strain, elasticity-of-materials, physics-foundations, and classical-mechanics.

5. Attempted the final eight overview topics, observed that the system first produced a combined collage instead of separate files, then corrected the request by explicitly asking for “8 individual infographic files.”

6. Generated the final eight individual overview infographic files: work-energy-momentum, waves-sound, thermodynamics, electricity-magnetism, optics, modern-physics, nuclear-astrophysics, and applied-physics.

Key Change
The batch request wording was corrected from broad “send the batch” phrasing to explicit “individual infographic files” phrasing, which prevented collage-style output and restored the intended one-topic-per-file workflow.

Outcome
The remaining physics infographic topics were completed as individual 1536×1024-style educational reference images. The overall physics infographic set now includes the final overview and branch-level files needed to close the planned sequence.

Validation
The delivered images visually matched the Impulse reference style: wide 1536×1024 landscape format, navy title, blue subtitle, bordered educational panels, equations, diagrams, example sections, key points, applications, summaries, and a bottom “In Short” strip. The correction was confirmed when the final eight were delivered as separate files instead of a single combined collage.

Rules Going Forward
Always state “individual infographic files” when requesting batches.
Keep batch size at ten or fewer images.
Use the Impulse infographic as the style and dimension anchor.
If a generation stalls, stop and restart the same batch with clearer delivery wording.
If a collage is produced, reject it as the wrong format and restate that each topic must be its own separate file.
Maintain filename slugs that match the requested topic names as closely as possible.

Notes
The final batch completed the remaining high-level physics overview topics. The most reliable phrasing was: “Send me [number] individual infographic files of the following topics.”
