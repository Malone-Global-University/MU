WORKFLOW NOTE

Title
Base44 News App Local Port Recovery

Date
2026-05-21

Area
Malone Panther Pulse / The Malone Panther news app

Problem
The Base44-generated news app could not be cleanly downloaded as source code, so the files were manually copied into local storage. When run locally on `localhost:5173`, the Vite app produced internal 500 errors caused by CSS/PostCSS parsing issues.

Intended Goal
Run the Malone Panther news app locally without depending on Base44, while preserving the generated app structure, pages, sections, comments, admin tools, and news workflow.

Root Cause
Base44 generated the application inside its own managed environment, but the project had to be reconstructed manually outside that environment. During the local port, copied files and configuration differences caused Vite, Tailwind, PostCSS, or related parsing tools to fail.

Steps Taken

1. Built the original Base44 app concept for The Malone Panther with AI-generated news sections, Campus manual posts, admin generation tools, article pages, and responsive navigation.
2. Added article comments, logged-in student discussion, timestamps, flagging, and admin moderation tools.
3. Requested and reviewed the generated file hierarchy so the project could be manually reconstructed outside Base44.
4. Clarified the difference between downloading uploaded app storage files and downloading the actual generated source code.
5. Manually copied the generated files into local storage under the MGU project directory.
6. Ran the project locally through Vite at `localhost:5173`.
7. Identified and corrected the Vite/PostCSS parsing errors until the app could run independently from Base44.

Key Change
The Malone Panther app was successfully moved from a Base44-managed build into a local Vite project that can be edited, debugged, and maintained directly.

Outcome
The app is no longer dependent on Base44 for local development. The project can now be managed as a normal local codebase, with future work focused on replacing any remaining Base44-specific services such as AI generation, authentication, comments, storage, or deployment wiring.

Validation
Validation was confirmed by resolving the internal 500 errors and getting the locally ported app running without the Base44 environment.

Rules Going Forward
Keep a full local copy of all generated source files before making major changes. Treat Base44 output as a scaffold, not the long-term source of truth. Replace managed Base44 integrations with explicit local or hosted services before deploying to `news.maloneuniversity.org`. Verify each migration step through the local Vite server before pushing to production.

Notes
The next structural task is to audit the app for remaining Base44 dependencies, especially API client calls, authentication context, AI news generation, storage, comment persistence, and admin moderation logic.
