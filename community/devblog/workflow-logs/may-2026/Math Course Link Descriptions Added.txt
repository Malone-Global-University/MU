WORKFLOW NOTE

Title
Math Course Link Descriptions Added

Date
2026-05-21

Area
MGU Mathematics Department course catalog section

Problem
The math course links were listed as plain links without descriptive paragraphs, while the computer science course catalog used richer course summaries beneath each link.

Intended Goal
Give the math catalog the same explanatory link style used by the computer science catalog, with each course title followed by a short `<p class="wide">` description.

Root Cause
The math section had not yet been expanded from a simple link list into the newer descriptive catalog format.

Steps Taken

1. Reviewed the existing math course list.
2. Matched the structure to the computer science catalog pattern.
3. Added a descriptive paragraph under each math course link using `<p class="wide">`.

Key Change
Each mathematics course link now includes a concise catalog-style description explaining the course focus and academic purpose.

Outcome
The math catalog is more readable, more informative, and visually consistent with the computer science catalog format.

Validation
Checked that each course remained inside its original `<li>` element and that every listed math course received a matching descriptive paragraph.

Rules Going Forward
Course catalog link sections should use descriptive paragraphs when the department page is meant to function as an academic catalog rather than a simple directory.

Notes
The math list still contains a few numbering/path mismatches worth reviewing later, such as `pde-150` displaying “Partial Differential Equations 155” and `abstract-algebra-155` displaying “Abstract Algebra 160.”
