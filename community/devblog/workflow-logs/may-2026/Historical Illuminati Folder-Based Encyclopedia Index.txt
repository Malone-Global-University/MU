WORKFLOW NOTE

Title
Historical Illuminati Folder-Based Encyclopedia Index

Date
2026-05-21

Area
MGU Library / Encyclopedia / Illuminati / Historical Illuminati

Problem
The Illuminati encyclopedia section needed a deeper and more scalable article structure. The first index identified major topic categories, but the next issue was how those category links should be organized for long-term growth. Standalone page links would work for short articles, but they would not support a deeper encyclopedia hierarchy as cleanly.

Intended Goal
The Historical Illuminati section should function as a category hub that links to folder-based subtopic hubs. Each major topic should be able to grow into its own `index.html` page and later contain additional nested article folders.

Root Cause
The encyclopedia taxonomy was expanding from a simple list of article pages into a multi-level knowledge structure. Because the Historical Illuminati topic includes major subareas such as Bavarian Illuminati, Adam Weishaupt, founding structure, suppression, and historical documents, each topic needed room to become a folder-based mini-hub rather than a single flat page. The uploaded index already showed links written without `.html`, such as `bavarian-illuminati`, `adam-weishaupt`, and `historical-documents`, which supports this folder-based direction. 

Steps Taken

1. Reviewed the Historical Illuminati index page structure and confirmed that the category links were already written as folder-style routes rather than direct `.html` page links.
2. Identified the clean folder model for the section: `historical-illuminati/index.html` as the parent hub, with child folders such as `bavarian-illuminati/index.html`, `adam-weishaupt/index.html`, `founding-and-organization/index.html`, `suppression-and-decline/index.html`, and `historical-documents/index.html`.
3. Recommended using each child folder as a mini-hub, allowing future nested article folders such as `origins-and-context/`, `membership-and-recruitment/`, `bavarian-edicts/`, `confiscated-papers/`, and `scholarly-interpretations/`.
4. Suggested using consistent folder links, preferably with trailing slashes, so the encyclopedia clearly distinguishes directory routes from standalone files.
5. Clarified the broader encyclopedia rhythm: domain page, category page, subcategory page, then deeper article or micro-topic folder.

Key Change
The Historical Illuminati section was shifted from a flat article-link model into a scalable folder-based encyclopedia hierarchy.

Outcome
The structure is now better suited for long-term expansion. Each major Historical Illuminati topic can begin as a folder index and later grow into a deeper cluster of articles without breaking the main navigation pattern. The section also remains historically focused, separating the documented Bavarian Illuminati from later conspiracy mythology.

Validation
The uploaded index confirms that the category links already use folder-style hrefs rather than `.html` page links, and the visible structure supports a clean nested directory model. The proposed hierarchy matches the existing categories and preserves the page’s purpose as a Historical Illuminati hub. 

Rules Going Forward
Use folder-based links for encyclopedia category and subcategory pages.
Prefer `topic-name/` over `topic-name.html` when the topic may grow into multiple articles.
Each major folder should contain an `index.html` page.
Keep Historical Illuminati pages grounded in documented history, while placing modern symbolic or conspiracy claims in separate sections.
Use breadcrumbs that reflect the folder hierarchy clearly.

Notes
The strongest next improvement would be to create a reusable encyclopedia folder-index template. That template could include a hero, breadcrumb, overview section, topic list, evidence note, related topics section, and bottom navigation.
