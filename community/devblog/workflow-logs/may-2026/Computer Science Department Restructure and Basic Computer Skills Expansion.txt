WORKFLOW NOTE

Title
Computer Science Department Restructure and Basic Computer Skills Expansion

Date
2026-05-21

Area
MGU Computer Science Department taxonomy, Applied Computing pages, Theory and Foundations pages, DevOps and Cloud pages, Basic Computer Skills division

Problem
The Computer Science department structure had become too mixed together. Degree programs, theory, applied technical training, beginner computer literacy, web courses, PowerShell, office skills, cybersecurity, networking, and experimental work were not clearly separated by educational purpose. This made it hard to decide where beginner PowerShell, PC literacy, office productivity, and serious professional technical courses should live.

Intended Goal
Create a scalable Computer Science department architecture that separates degree programs, theoretical computer science, applied technical computing, specialization tracks, labs, experimental work, tools/resources, and beginner nontechnical computer skills. The correct state is a department that can serve hobbyists, office workers, beginners, technical professionals, and serious academic learners without confusing their pathways.

Root Cause
The older structure was organized mostly by existing folders and subject names rather than by learner type, educational purpose, and level of technical depth. Beginner computer use, professional IT operations, academic theory, and degree-program organization were competing inside the same space.

Steps Taken

1. Reframed the Computer Science department around major divisions instead of scattered programs: degree programs, theory and foundations, applied computing, specialization tracks, labs and projects, research/experimental work, tools/resources, and later basic computer skills.

2. Created a clean Applied Computing model focused on practical technical work: programming and development, web development, scripting and automation, systems administration, networking practice, cybersecurity operations, and DevOps/cloud.

3. Generated a downloadable folder bundle for the rebuilt Computer Science department structure.

4. Wrote homepage/division snippets for the new Computer Science division cards and Applied Computing branch cards.

5. Generated multiple full HTML index pages using the MGU shell format, including Applied Computing branch pages and many child-course index pages across digital literacy, office productivity, programming, web development, scripting, systems administration, networking, cybersecurity, and DevOps/cloud.

6. Packaged the five DevOps and Cloud child pages into a ZIP bundle with nested folder paths under `department/computer-science/applied-computing/devops-and-cloud/`.

7. Displayed and analyzed the Theory and Foundations tree, then generated a ZIP bundle containing full HTML index files for its branch and child topic pages.

8. Identified that nontechnical learners needed a separate Basic Computer Skills division rather than being forced into Applied Computing.

9. Built out the Basic Computer Skills tree with beginner-friendly branches for computer basics, operating system basics, file and folder skills, internet and web skills, email/calendar skills, document skills, spreadsheet skills, presentation skills, digital safety, troubleshooting, everyday productivity, and beginner practice labs.

10. Generated a ZIP bundle for Basic Computer Skills containing the nested folder structure and full `index.html` files.

Key Change
The most important correction was separating nontechnical Basic Computer Skills from professional Applied Computing so beginner computer literacy no longer competes with advanced technical subjects like DevOps, cybersecurity, networking, and systems administration.

Outcome
The Computer Science department now has a much clearer academic and practical structure. Applied Computing is cleaner and more technical, Theory and Foundations has its own full scaffold, DevOps and Cloud has packaged course pages, and Basic Computer Skills now exists as a dedicated nontechnical learner pathway with 119 HTML index files.

Validation
The structure was validated by walking through the hierarchy branch by branch, checking whether each area served a distinct learner purpose, confirming page counts for generated bundles, and producing downloadable ZIP files with nested paths that match the intended MGU directory structure.

Rules Going Forward
Keep degree programs as pathway maps, not duplicated content folders. Keep Theory and Foundations for conceptual and academic material. Keep Applied Computing for technical building, automation, administration, security, infrastructure, and development work. Keep Basic Computer Skills for nontechnical computer literacy and office-user confidence. Avoid mixing beginner office-computer content with professional systems, networking, cybersecurity, or DevOps tracks.

Notes
The Basic Computer Skills division should probably be added to the Computer Science department homepage as a top-level division card. Applied Computing should be revised so it no longer includes beginner digital literacy or office productivity as its primary nontechnical entry point. Future bundle generation should continue in manageable batches, with paths nested exactly where they will live in the MGU site.
