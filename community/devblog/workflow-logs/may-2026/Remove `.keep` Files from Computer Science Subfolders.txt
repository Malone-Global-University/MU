WORKFLOW NOTE

Title
Remove `.keep` Files from Computer Science Subfolders

Date
2026-05-21

Area
MGU Department File Cleanup / Computer Science Folder Tree

Problem
The `computer-science` folder tree contained `.keep` files inside subfolders. These files are useful when preserving empty folders in Git or ZIP structures, but they become unnecessary once the folder tree is populated with real HTML files, index pages, or content assets.

Intended Goal
Delete all `.keep` files from the `computer-science` folder and its subfolders without accidentally deleting real content files.

Root Cause
The `.keep` files were likely created as placeholders when the folder structure was generated before the actual content files existed. After the Computer Science folder tree was built out, those placeholder files were no longer needed.

Steps Taken

1. Identified that the target cleanup should only affect files named exactly `.keep`.

2. Used `Get-ChildItem` with `-Recurse`, `-File`, and `-Filter ".keep"` to search through the `computer-science` folder and all nested subfolders.

3. Recommended first previewing the files before deletion with:

```powershell
Get-ChildItem -Path "C:\MGU\department\computer-science" -Filter ".keep" -File -Recurse
```

4. Provided the deletion command:

```powershell
Get-ChildItem -Path "C:\MGU\department\computer-science" -Filter ".keep" -File -Recurse | Remove-Item
```

5. Provided a safer confirmation-based version using `Remove-Item -Confirm`.

6. Provided a verification command to confirm that no `.keep` files remain after deletion.

Key Change
The cleanup was narrowed to files named exactly `.keep` inside the `computer-science` folder tree, preventing broader or unsafe deletion.

Outcome
The user now has a safe PowerShell method for removing placeholder `.keep` files from all Computer Science subfolders while preserving actual course, index, and content files.

Validation
Validation is performed by rerunning the recursive search command after deletion:

```powershell
Get-ChildItem -Path "C:\MGU\department\computer-science" -Filter ".keep" -File -Recurse
```

If the command returns no results, the cleanup succeeded.

Rules Going Forward
Use a preview command before destructive file operations.
Use `-Filter ".keep"` instead of a broader wildcard unless intentionally deleting multiple file types.
Use `-File` to avoid matching folders.
Use `-Recurse` when the target files may exist in nested subfolders.
Run the same search command afterward to verify the result.

Notes
`.keep` files are useful during early folder-tree construction, especially when empty folders need to be preserved in a repository or ZIP bundle. Once real files exist in those folders, `.keep` files can usually be removed safely.
