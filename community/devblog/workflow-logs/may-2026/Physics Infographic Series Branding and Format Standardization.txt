WORKFLOW NOTE

Title
Physics Infographic Series Branding and Format Standardization

Date
2026-05-21

Area
MGU Physics Infographic Production / Physics Reference Graphics

Problem
The session began with a need to establish a repeatable infographic style for the MGU physics reference series. Early posters used the MGU seal, navy-and-gold academic framing, and a formal “MGU Library / Physics Reference Infographic” footer. Later in the session, the desired format changed: future infographics should use the cleaner, nonbranded educational format used for the impulse infographic, with a wide 1536 × 1024 pixel layout.

Intended Goal
Create a consistent physics infographic production style that can be used across many high school physics topics, first with MGU-branded academic poster styling, then later with a simplified nonbranded format. The graphics should be visually clean, topic-specific, student-friendly, and suitable for use as reference posters in the MGU physics curriculum.

Root Cause
The initial goal was branding consistency using the uploaded MGU logo. As more physics topics were produced, the user found that the cleaner nonbranded format worked better for later physics reference sheets, especially for compact equation-heavy topics. The format needed to be standardized going forward so future posters would not drift between styles.

Steps Taken

1. Saved the Malone Global University logo for future reference and used it as the branding basis for early MGU physics infographics.

2. Created a branded MGU infographic style using a navy-and-gold academic frame, central top MGU seal, serif headings, section bars, boxed topic panels, icons, equations, examples, and an “MGU Library / Physics Reference Infographic” footer.

3. Generated a sequence of branded MGU physics posters, including topics such as What Physics Is, SI Units and Measurement, Scientific Notation in Physics, Significant Figures, Dimensional Analysis, Scalars vs Vectors, Vector Addition and Resolution, Coordinate Systems, Experimental Error and Uncertainty, Kinematics Overview, Distance vs Displacement, Speed vs Velocity vs Acceleration, Kinematic Equations, Projectile Motion, Free-Body Diagrams, Newton’s Third Law, Inclined Plane Problems, Circular Motion, and Conservation of Momentum.

4. Identified that several later generated posters had drifted into a cleaner nonbranded classroom handout style rather than the MGU-branded poster style.

5. Accepted the user’s new direction to use the nonbranded format from the impulse infographic going forward.

6. Standardized the future infographic size requirement as 1536 × 1024 pixels.

7. Continued the nonbranded wide-format series with later topics including Elastic Collisions, Inelastic Collisions, Center of Mass, Universal Gravitation, Gravitational Fields, Orbital Motion, and Newton’s Third Law.

Key Change
The physics infographic series shifted from an MGU-branded navy-and-gold poster format to a clean, nonbranded 1536 × 1024 educational infographic format modeled after the impulse poster.

Outcome
The session produced a large set of physics reference infographic concepts across foundations, measurement, kinematics, dynamics, energy, momentum, rotation, gravitation, and collisions. The style direction is now clearer: future infographics should use the nonbranded impulse-style format unless branding is specifically requested again.

Validation
The user approved the early branded style after the SI Units and Measurement poster and later explicitly approved the nonbranded impulse-style format as the standard going forward. The requested topics were generated sequentially, and the final instruction clarified both the design format and pixel dimensions.

Rules Going Forward
Use the clean nonbranded infographic format from the impulse poster for future physics infographics.

Create future infographics at 1536 × 1024 pixels.

Do not include the MGU logo or MGU-branded footer unless explicitly requested.

Use concise student-facing language, organized numbered sections, clean boxed panels, simple diagrams, formulas, examples, key takeaways, and an “In Short” summary bar.

Maintain topic-specific content while keeping the visual structure consistent across the series.

Notes
The earlier MGU-branded format remains useful for official MGU Library or department-facing posters. The newer nonbranded format is better for compact classroom reference sheets, especially equation-heavy topics where clarity and horizontal space matter more than institutional branding.
