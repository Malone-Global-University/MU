WORKFLOW NOTE

Title
Mathematics Infographic Library Expansion and Reference Index Planning

Date
2026-05-21

Area
MGU Library Reference System / Infographics / Math Visual Reference Collection

Problem
The MGU infographic reference collection for mathematics was incomplete, lacked standardized indexing structure, and had no established compression/export workflow for efficient GitHub and web deployment. Filename inconsistencies and missing curriculum branch planning also created long-term maintenance risks.

Intended Goal
Create a large-scale, curriculum-oriented mathematics infographic reference library with standardized naming, web-optimized delivery workflow, organized indexing, and expansion planning for future STEM infographic systems including physics, biology, art, computer science, and chemistry.

Root Cause
The infographic collection evolved organically through iterative generation sessions without an established taxonomy, naming convention, deployment workflow, or centralized index structure. File sizes were also unnecessarily large for efficient static hosting.

Steps Taken

1. Generated a large mathematics infographic collection covering arithmetic, algebra, geometry, trigonometry, precalculus, calculus, statistics, probability, and applied mathematics topics.

2. Expanded the collection with advanced and applied topics including:

   * Linear Programming
   * Parametric Equations
   * Diophantine Equations
   * Radical Expressions
   * Completing the Square
   * Measures of Centrality
   * Work Rate Problems
   * Mixture Problems
   * Scientific Notation
   * Number Sets
   * Blackboard Letters

3. Counted and audited the infographic collection multiple times to establish the current total and identify missing curriculum gaps.

4. Planned future infographic libraries by branch for:

   * Physics
   * Biology
   * Art
   * Computer Science
   * Chemistry

5. Designed a static-reference hosting strategy using `.webp` images stored directly in reference directories.

6. Established a WebP conversion workflow using ImageMagick and PowerShell to reduce infographic file sizes for GitHub/web deployment.

7. Created batch conversion commands to export PNG infographic files into a separate `/webp/` directory while preserving originals.

8. Designed HTML embedding patterns using:

   * `<img>`
   * `<picture>`
   * direct hyperlink references
   * reference index structures

9. Built a full HTML hyperlink list for the mathematics infographic reference index located at:
   `C:\MGU\library\reference\infographics\math`

10. Audited infographic filenames and identified typo/inconsistency corrections including:

* `covnert` → `convert`
* `exponetial` → `exponential`
* `mixure` → `mixture`
* `theorum` → `theorem`

11. Recommended broader filename normalization rules for long-term asset consistency.

Key Change
The mathematics infographic collection evolved from a loose image set into a structured curriculum-scale visual reference library with deployment, indexing, compression, and expansion planning workflows.

Outcome
MGU now has a rapidly growing STEM infographic framework capable of scaling into a full encyclopedia/reference visual system across multiple academic disciplines. The math collection alone now functions as a substantial curriculum-aligned infographic library suitable for browser-based reference navigation.

Validation

* Verified successful WebP conversion workflow.
* Confirmed direct browser compatibility for `.webp` embedding and linking.
* Reviewed filename consistency and typo detection.
* Confirmed HTML reference index structure correctness.
* Verified broad curriculum coverage across multiple mathematics branches.
* Confirmed scalable taxonomy planning for future disciplines.

Rules Going Forward

* Preserve original master PNG assets locally.
* Use compressed WebP files for web deployment.
* Standardize filenames using lowercase kebab-case.
* Avoid typos and inconsistent singular/plural naming.
* Maintain curriculum-based branch organization for all future infographic systems.
* Separate reference index pages from raw image asset directories.
* Expand infographic systems by academic branch rather than random topic accumulation.

Notes
The infographic system is beginning to resemble a full visual academic reference layer for MGU. Future improvements could include:

* automatic index generation
* thumbnail preview grids
* searchable infographic catalogs
* metadata tagging
* lazy loading
* responsive `<picture>` delivery
* encyclopedia cross-linking
* downloadable ZIP reference packs by subject branch.
