WORKFLOW NOTE

Title
Dedicated MGU Site Navigation Layer Defined

Date
2026-05-17

Area
MGU site architecture, navigation system, library collections, tutorials, reference organization

Problem
Malone Global University has grown to more than 11,000 pages, but the site did not yet have a dedicated human-readable navigation layer explaining how the major site areas are organized. The existing library categories created uncertainty about where navigation explanations should belong. Navigation guides were being considered under Reference, Guides, or Tutorials, but none of those placements fully matched the purpose of explaining the entire site structure across Main, Community, Department, Library, and Malone Panther.

Intended Goal
Create a clear information architecture where users can understand the full MGU site layout before digging into deep folders. The correct structure should separate whole-site navigation from task-based tutorials, formal classes, reference lookup, dictionary definitions, and encyclopedia articles.

Root Cause
The site had expanded from a smaller static-page structure into a large multi-domain system. At that scale, ordinary menus and folder indexes are not enough. The site needed an explanatory orientation layer, not just more links. The confusion came from trying to place a sitewide navigation function inside library-specific collections such as Reference, Guides, or Tutorials.

Steps Taken

1. Reviewed the role of navigation guides in relation to the Library, Reference, Guides, and Tutorials collections.

2. Clarified that Reference should remain reserved for lookup and verification materials such as tables, formulas, specifications, standards, and structured source material.

3. Clarified that Tutorials should stay inside the Library as supplemental task-based instruction for topics not yet covered in formal classes.

4. Defined Tutorials as provisional and support-oriented: tutorials may later be moved into formal class lessons when they grow into full instructional sequences.

5. Determined that the navigation layer should not be buried inside Library, Reference, or Tutorials because it must explain the entire MGU site, not only the Library.

6. Established the need for a top-level Navigation area that explains Main, Community, Department, Library, Malone Panther, and other major site paths.

7. Distinguished the major content functions: Navigation explains where things are; Tutorials explain how to do tasks; Reference supports lookup; Dictionary defines terms; Encyclopedia explains subjects; Department/class areas provide formal learning sequences.

Key Change
MGU should add a dedicated top-level Navigation layer for whole-site orientation instead of treating navigation guides as a Library-only or Reference-only collection.

Outcome
The site architecture is now clearer: Navigation becomes the human-readable map and explanation layer for the full 11,000-page site, while Library Tutorials remain a separate supplemental instructional collection. This reduces category confusion and gives users a better way to understand the site before entering deep content areas.

Validation
The decision was checked against the actual scale and structure of the site. Because the navigation layer must explain multiple top-level domains, including Main, Community, Department, Library, and Malone Panther, it does not fit cleanly inside Reference or Library Tutorials. The final model preserves clean boundaries between navigation, tutorials, reference, dictionary, encyclopedia, and formal classes.

Rules Going Forward
Navigation pages should explain site structure, major domains, subdomains, user pathways, and where to find information.

Tutorials should remain task-based and practical, covering setup steps, workflows, and focused skills not currently covered in formal class lessons.

Reference should remain a lookup and verification area, not a home for explanatory navigation pages.

Formal course and class lessons should remain the preferred destination for full instructional sequences.

If a tutorial grows into a complete lesson sequence, move it into the appropriate class or department area.

Do not bury sitewide orientation pages inside a narrow collection when they explain the entire MGU system.

Notes
Recommended top-level folder: `/navigation/`

Recommended library tutorials folder: `/library/tutorials/`

Working distinction:

Navigation = where things are and how the site is organized.
Tutorials = how to complete practical tasks.
Reference = quick lookup and verification.
Dictionary = precise definitions.
Encyclopedia = subject explanation.
Department/classes = formal instructional pathways.
Library = organized knowledge collections.
