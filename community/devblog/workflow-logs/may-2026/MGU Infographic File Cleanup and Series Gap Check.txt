WORKFLOW NOTE

Title
MGU Infographic File Cleanup and Series Gap Check

Date
2026-05-21

Area
MGU visual assets / How Things Work infographic series / `C:\MGU\desk\webp`

Problem
The infographic image folder had become difficult to track because loose `.png` files, duplicate category folders, inconsistent folder names, typo-heavy filenames, and overlapping series names were mixed together. It was no longer clear which files already existed, which planned sets were complete, and which planned infographic batches still needed to be created.

Intended Goal
Organize the existing infographic files into clean MGU category folders, correct obvious filename typos, move loose files into the correct series folders, and compare the current inventory against the uploaded planning list to identify remaining missing sets.

Root Cause
The asset library grew quickly across multiple batches without a final normalization pass. Some folders used title case, some used lowercase slug format, and some categories overlapped. Several filenames also contained spelling errors, punctuation inconsistencies, duplicate concepts, or unfinished names, which made automated counting and planning harder.

Steps Taken

1. Reviewed the current `C:\MGU\desk\webp` folder listing, including both existing folders and loose `.png` files.
2. Consolidated the folder taxonomy into clean MGU-style category folders such as `physics-foundations`, `physics-laws`, `home-and-building-systems`, `civil-infrastructure`, `transportation-and-vehicle-systems`, `energy-and-power-systems`, `computing-and-electronics`, and related series folders.
3. Identified duplicate or outdated folder names that should be merged, including variants like `Aerospace and Navigation`, `Aerospace and Space Systems`, `Civil Infrastructure`, `civic-engineering-systems`, `Everyday Technology`, `everyday engineering`, `scientific foundations`, and `scientific-laws`.
4. Listed typo corrections for filenames such as `conseration-of-momentum`, `lens-rquation`, `trignometric-components`, `how-a-refridegerator`, `how-gps-wprks`, `how-antilock-brajes-work`, `how-night-vison-works`, and `how-the-eletrical-grid-works`.
5. Created a PowerShell move-map script to move corrected or known filenames into their proper category folders.
6. Reviewed leftover loose files after the first move pass, including `how-a-battery-works.png`, `how-a-dam-spillway-works.png`, `how-a-fire-sprinkler-system-works.png`, `how-a-submarine-works.png`, `how-an-electric-car-works.png`, `how-rack-and-pinion-steering-works.png`, and `ohms-laws.png`.
7. Provided a smaller cleanup script to move those remaining files into the correct folders.
8. Compared the organized current inventory against the uploaded infographic planning list.
9. Identified completed or mostly completed sets, including Physics Foundations, Physics Laws, and Home and Building Systems.
10. Identified remaining planned sets still needing creation, including Scientific Process & Research Graphics, Astronomy & Cosmology Scale Series, Mathematical Visualization Series, Failure Modes, Visual Taxonomy Maps, and remaining branch batches for Civil Infrastructure, Aerospace, Transportation, Medical Technology, Computing, Energy, Defense/Safety, and Food/Agriculture.

Key Change
The infographic asset library was converted from a loose mixed folder into a clean category-based structure with corrected filenames and a clearer remaining-production roadmap.

Outcome
The current files are now organized into meaningful series folders, making it easier to count completed assets, locate individual graphics, avoid duplicates, and continue building the planned MGU “How Things Work” and reference poster collections. The remaining gaps are now visible by category instead of being hidden inside a mixed file dump.

Validation
The user ran the folder cleanup and confirmed completion. Remaining loose files were identified and then accounted for with an additional move script. The final comparison showed which major sets are already complete or mostly complete and which planned sets still need to be created.

Rules Going Forward
Use lowercase hyphenated folder names and filenames.
Keep one canonical folder per category.
Avoid punctuation in filenames, especially apostrophes, semicolons, equals signs, and commas.
Use the pattern `how-[subject]-works.png` or `how-[subject]-works.webp` for cutaway/system graphics.
Use simple topic slugs such as `newtons-laws`, `ohms-law`, and `unit-conversion-flowcharts` for reference posters.
Run a loose-file check after each batch:

```powershell
Get-ChildItem -Path "C:\MGU\desk\webp" -File
```
