WORKFLOW NOTE

Title
Textbook Prompt Bundle Creation for Discrete Mathematics, Combinatorics, and Linear Algebra

Date
2026-05-17

Area
MGU Mathematics Series / Library Textbook Edition / Chapter Prompt Production

Problem
Several MGU mathematics textbook projects had chapter outlines and instructional framing, but they still needed reusable master instruction sheets and chapter-by-chapter drafting prompts. Without bundled prompt files, each chapter would require manually rebuilding the same prompt structure before sending it to Claude or another drafting model.

Intended Goal
Create organized downloadable prompt bundles for multiple MGU mathematics textbooks. Each bundle should include a master instruction sheet, a README, and one copy/paste-ready prompt file per chapter. The prompts should follow the MGU textbook style: full textbook chapters, meaning before procedure, patient student-facing explanation, worked examples, applications, common mistakes, review, checkpoints, and bridge notes.

Root Cause
The outlines existed as planning documents, but they had not yet been converted into production-ready drafting prompts. The same structure needed to be repeated consistently across every chapter so future chapter generation would be faster, less error-prone, and aligned with the intended textbook identity.

Steps Taken

1. Created a Discrete Mathematics prompt bundle using the non-calculus outline and instructional model.
2. Included a master instruction sheet for Discrete Mathematics emphasizing algebra, logic, proof, counting, graph theory, recursion, algorithms, and computer-science applications.
3. Generated 14 chapter-specific Discrete Mathematics prompts and packaged them into a zipped folder.
4. Created a Combinatorics master instruction sheet using the uploaded non-calculus combinatorics outline.
5. Generated 14 chapter-specific Combinatorics prompts covering counting foundations, permutations, combinations, binomial coefficients, repetition, inclusion-exclusion, pigeonhole arguments, combinatorial proof, recurrences, generating functions, graph counting, designs, and capstone applications.
6. Packaged the Combinatorics master sheet, README, and chapter prompts into a zipped folder.
7. Created a Linear Algebra master instruction sheet using the uploaded outline that positions the book as a non-calculus bridge from Precalculus to Calculus.
8. Generated 14 chapter-specific Linear Algebra prompts covering vectors, systems, matrices, inverses, determinants, transformations, vector spaces, span, rank, orthogonality, eigenvalues, diagonalization, and applications.
9. Packaged the Linear Algebra master sheet, README, and chapter prompts into a zipped folder.
10. Confirmed that each bundle used the correct MGU textbook identity, series label, non-calculus framing where required, and chapter sequence.

Key Change
Converted three MGU mathematics textbook outlines into reusable production prompt bundles with master instructions and chapter-specific drafting prompts.

Outcome
The session produced downloadable prompt bundles for Discrete Mathematics, Combinatorics, and Linear Algebra. Each bundle is ready to use with Claude or another drafting model to generate full textbook chapters without manually reconstructing the instructions each time.

Validation
The generated bundles were checked against the provided outlines and framing. Discrete Mathematics was preserved as algebra-, logic-, proof-, counting-, graph theory-, recursion-, algorithm-, and computer-science-based. Combinatorics was preserved as non-calculus, algebra-, counting-, recursion-, finite-structure-, proof-, graph-counting-, and discrete-modeling-based. Linear Algebra was preserved as non-calculus and designed as a bridge from Precalculus to Calculus.

Rules Going Forward
Use a consistent bundle structure for future textbook prompt packages: README, master instruction sheet, and one chapter prompt per chapter. Preserve the exact textbook title, MGU Mathematics Series identity, Library Textbook Edition label, chapter sequence, and prerequisite framing. Do not make non-calculus books calculus-based. Keep chapter prompts copy/paste-ready and complete enough to guide full textbook chapter generation.

Notes
This workflow is now a reusable production pattern for other MGU mathematics textbooks. Future bundles can be created for Probability and Statistics, Numerical Methods, Scientific Computing, Machine Learning Mathematics, Artificial Intelligence Foundations, or other MGU series books using the same structure.
