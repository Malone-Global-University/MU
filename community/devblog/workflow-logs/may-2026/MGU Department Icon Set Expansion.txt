WORKFLOW NOTE

Title
MGU Department Icon Set Expansion

Date
2026-05-07

Area
MGU folder icons, department branding, academic logo assets

Problem
The MGU folder system needed a broader set of custom branded icons for organizing academic and administrative folders. The existing folder icons were not visually unified across departments, course areas, science branches, humanities, professional studies, and specialty topic folders.

Intended Goal
Create a consistent visual family of MGU-style folder logos using a navy, gold, and white academic crest style suitable for folder icons, course folders, and department navigation assets.

Root Cause
The folder structure had grown faster than the icon system. Different folders represented different academic domains, but they lacked matching visual identifiers, which made the system feel less unified and harder to scan visually.

Steps Taken

1. Created a custom panther-head icon for the Malone Panther Newspaper folder, using a black panther head with gold accents suitable for icon use.

2. Created an MGU-branded DOC file icon with a panther/document theme, then revised it by removing the torch after review.

3. Created a general math folder logo in the MGU navy-and-gold academic emblem style.

4. Generated a first math department set for:
   arithmetic-74, pre-algebra-96, algebra-101, geometry-105, and trigonometry-110.

5. Generated an advanced math department set for:
   calculus-120, combinatorics-140, discrete-mathematics-130, ode-145, pde-150, statistics-115, and statistics-135.

6. Created a general science logo using symbols such as atoms, lab equipment, DNA, astronomy, and graphs.

7. Generated a core science set for:
   biology, chemistry, earth science, and physics.

8. Generated a specialty science set for:
   geology, astrology, astrophysics, geophysics, and biophysics.

9. Generated an applied physics set for:
   cosmology, medical physics, computational physics, and atmospheric physics.

10. Generated a broader department set for:
    history, religion, engineering, language, political science, and art.

11. Generated an institutional department set for:
    computer science, K-12, and professional studies.

12. Generated a specialty category set for:
    defense, conspiracy, culinary, and communication.

13. Generated an exploration and institutional science set for:
    space, exploratory, aerospace, and corporate science.

Key Change
The icon system was expanded from a few isolated folder graphics into a large, unified MGU-branded visual library for departments, subjects, and specialty folders.

Outcome
MGU now has a broad family of matching navy-and-gold academic crest icons that can be used across folder structures, department directories, course assets, and subject collections. The icons now share a recognizable visual language: deep navy background, gold accents, white serif lettering, academic symbols, and crest-like composition.

Validation
Each set was visually checked as it was generated. The user confirmed the early math department set looked good, and subsequent sets continued the same successful style. The torch was removed from the DOC icon after review, confirming that individual icon details can be revised to better match the desired brand language.

Rules Going Forward
Future MGU folder icons should preserve the established visual system: navy background, gold trim, white lettering, academic crest layout, clear subject-specific symbols, and strong readability at icon size. Avoid unnecessary symbols that do not belong to the folder purpose. Keep department names large, centered, and readable.

Notes
Some generated icons may need later cleanup, resizing, transparent-background conversion, or final export as 512×512 PNG/ICO files for direct Windows folder use. Future batches should continue using the same visual family so the full MGU folder system feels intentional and unified.
