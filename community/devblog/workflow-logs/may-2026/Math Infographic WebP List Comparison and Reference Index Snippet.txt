WORKFLOW NOTE

Title
Math Infographic WebP List Comparison and Reference Index Snippet

Date
2026-05-21

Area
MGU Library / Encyclopedia / Reference Index / Infographics

Problem
The math infographic source list and the existing `.webp` file list did not clearly match. Some entries had different names, pluralization differences, shortened filenames, duplicate exports, or missing converted files. In addition, the Reference Index needed a matching list-item snippet for an Infographics category.

Intended Goal
Identify which infographic topics already had matching `.webp` files, which files were missing, which names were divergent, and provide a clean HTML `<li>` snippet that fits the existing Reference Index category structure.

Root Cause
The infographic list used human-readable topic names, while the file list used slug-style filenames. Several filenames were shortened, renamed, pluralized, duplicated, or misspelled during export, which made it difficult to tell which source topics had already been converted.

Steps Taken

1. Compared List 1 topic names against List 2 `.webp` filenames by meaning rather than exact spelling alone.
2. Identified clear missing conversions, including `complex-numbers.webp`, `limits.webp`, `integrals.webp`, and a likely missing `solution-problems.webp`.
3. Separated true missing files from renamed matches, such as `Numberline infographic` matching `number-line.webp`, `Trig identities infographic` matching `trigonometric-identities.webp`, and `function infographic` matching `functions.webp`.
4. Flagged duplicate or alternate export files, including `exponential-growth-and-decay-1.webp`, `exponential-growth-and-decay-2.webp`, and `special-product-formulas-2.webp`.
5. Noted spelling and naming cleanup candidates, including `pythagoras-theorum.webp`, `scientific-notations.webp`, `normal-distributions.webp`, and `diophantine.webp`.
6. Reviewed the uploaded Reference Index page structure and matched its existing category-list format.
7. Created an HTML list-item snippet for `Infographics` using the same `<li>`, `<a>`, and `<p>` structure as the existing Reference Index categories.

Key Change
The session clarified the difference between missing infographic conversions and simple filename mismatches, then added a properly formatted Infographics category snippet for the Reference Index.

Outcome
The missing conversion candidates were narrowed to a short actionable list, and the Reference Index now has a ready-to-paste Infographics category item that fits the existing page style.

Validation
The comparison was checked by mapping topic meaning to filename slugs rather than relying only on exact string matches. The HTML snippet was validated against the uploaded page’s existing category pattern: each category uses a list item with a linked folder name and a short descriptive paragraph.

Rules Going Forward
Use consistent slug names for infographic filenames. Prefer singular topic names unless the topic is naturally plural. Avoid duplicate numbered exports unless they represent intentional alternate versions. Keep Reference Index category entries alphabetized and formatted with the same `<li>`, `<a>`, and `<p>` structure.

Notes
Recommended missing or follow-up conversion checks: `complex-numbers.webp`, `limits.webp`, `integrals.webp`, and `solution-problems.webp`. Optional cleanup candidates include renaming typo or unclear files such as `pythagoras-theorum.webp`, `scientific-notations.webp`, `normal-distributions.webp`, `diophantine.webp`, `sine-waves.webp`, and `statistics-cheat-sheet.webp`.
