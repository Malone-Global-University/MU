WORKFLOW NOTE

Title
Offline Note Writer with Social Media Blank-Line Support

Date
2026-05-21

Area
Offline HTML utility application / text editor and export workflow

Problem
A lightweight offline note-writing tool did not exist for quickly drafting notes, temporary writing, Markdown documents, HTML snippets, or social media comments. Standard browser text areas also made it difficult to preserve intentional blank lines for social media platforms that collapse empty whitespace during paste operations.

Intended Goal
Create a self-contained offline writing application with a text editor panel, live preview system, and export controls capable of saving content as `.txt`, `.md`, or `.html`. Add a dedicated mechanism for inserting protected blank lines that survive paste behavior on many social media platforms.

Root Cause
Browsers and social media platforms often collapse consecutive whitespace and remove empty lines during rendering or paste processing. Traditional blank lines are treated as structurally empty and may not persist unless they contain a non-collapsing invisible character.

Steps Taken

1. Built a standalone offline HTML application with:

   * text editor panel
   * live preview panel
   * filename input
   * export buttons for `.txt`, `.md`, and `.html`
   * responsive layout and local draft persistence

2. Implemented browser-side file export using Blob generation and automatic download handling for:

   * plain text files
   * Markdown files
   * generated standalone HTML documents

3. Added live statistics tracking including:

   * word count
   * character count

4. Added localStorage persistence so draft content and filenames survive browser refreshes.

5. Implemented lightweight Markdown-style preview rendering including:

   * headings
   * lists
   * blockquotes
   * inline code
   * bold/italic formatting

6. Added social-media-specific protected blank-line functionality using the Unicode zero-width-space character (`U+200B`).

7. Added a dedicated interface button labeled:

   * “Insert Social Media Blank Line”

8. Implemented insertion logic that injects:

   * newline
   * zero-width space
   * newline

9. Updated editor cursor handling so insertion occurs at the active caret position without disrupting typing flow.

Key Change
The editor gained a dedicated protected blank-line insertion system using invisible Unicode characters so intentionally spaced social media formatting survives paste operations more reliably.

Outcome
The resulting application functions as a lightweight offline writing environment capable of:

* drafting notes
* drafting Markdown
* generating standalone HTML documents
* preserving formatted spacing for social media workflows

The utility now supports both normal writing and platform-aware formatting behavior for pasted comments and posts.

Validation

* Verified `.txt`, `.md`, and `.html` downloads generate correctly.
* Verified exported HTML files render independently in a browser.
* Confirmed local draft persistence survives page refresh.
* Confirmed live preview updates dynamically during typing.
* Confirmed protected blank-line button inserts the intended Unicode sequence at the cursor position.
* Confirmed editor remains fully offline and self-contained.

Rules Going Forward

* Preserve offline-first behavior with no server dependency.
* Keep export generation browser-native using Blob downloads.
* Use invisible Unicode whitespace when preserving social-media spacing behavior.
* Avoid relying on raw HTML whitespace for pasted social content because many platforms collapse it.
* Maintain self-contained portability in a single HTML file whenever practical.

Notes
Potential future improvements:

* keyboard shortcut for protected blank lines
* autosave snapshots/history
* drag-and-drop file loading
* dark mode toggle
* syntax highlighting modes
* side-by-side raw Markdown and rendered preview
* optional filesystem API support for direct folder saves in supported browsers
