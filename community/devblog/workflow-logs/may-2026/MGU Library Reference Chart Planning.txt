WORKFLOW NOTE

Title
MGU Library Reference Chart Planning

Date
2026-05-21

Area
MGU Library / Reference Section / Charts

Problem
The MGU Library reference section needed a clearer plan for what kinds of charts should be created. The existing content strategy already included lessons, encyclopedia articles, ebooks, and explanatory infographics, but the specific role of quick-reference charts was not yet fully separated from those other formats. A specific chart topic, currency symbols, also needed placement, structure, and naming guidance.

Intended Goal
The reference section should contain compact visual charts that help users quickly compare, identify, classify, convert, or recall information. These charts should function as a practical lookup layer for the MGU Library, separate from full lessons, encyclopedia pages, and explanatory infographics.

Root Cause
The library taxonomy had strong content categories, but the chart layer had not yet been defined as its own reusable reference format. Without that distinction, chart topics could become mixed with infographics, lessons, or encyclopedia articles instead of serving as fast-access reference tools.

Steps Taken

1. Defined the purpose of MGU reference charts as quick-access visual tools for comparison, classification, conversion, identification, and recall.

2. Proposed major chart categories for the MGU Library, including universal reference, math, science, computer science, business, law, history, geography, language, art, medical, defense, religion, philosophy, and conspiracy studies.

3. Identified recommended chart types, including formula charts, comparison charts, timeline charts, classification charts, process charts, matrix charts, symbol charts, and anatomy charts.

4. Proposed a top-level folder structure for the chart section under:

`/library/reference/charts/`

5. Recommended a first high-value starter batch of charts, including metric prefixes, unit conversions, Greek alphabet, math symbols, fraction-decimal-percent chart, periodic table, truth tables, HTTP status codes, risk matrix, logical fallacies, and evidence-analysis framework.

6. Developed the currency symbols chart as a specific reference item under the universal chart category.

7. Recommended the currency symbols chart filename and placement:

`/library/reference/charts/universal/currency-symbols.webp`

8. Recommended an editable/vector companion version:

`/library/reference/charts/universal/currency-symbols.svg`

9. Defined the currency symbols chart structure using columns for symbol, ISO code, currency name, country or region, and usage notes.

10. Identified important currency-symbol ambiguity issues, including shared use of `$`, `¥`, `kr`, `R`, and `£`.

Key Change
The MGU Library reference section was clarified as a dedicated chart-based lookup layer, distinct from lessons, encyclopedia articles, ebooks, and explanatory infographics.

Outcome
The chart section now has a clearer production direction, including subject categories, chart types, folder structure, starter priorities, and a complete model for the first specific chart topic: Currency Symbols Reference Chart.

Validation
The plan was checked against MGU’s existing content architecture by separating each format by function: lessons teach sequentially, encyclopedia pages explain topics, ebooks provide complete source texts, infographics explain concepts visually, and charts provide fast reference lookup. The currency symbols chart also fits the universal-reference category because it supports business, finance, economics, geography, trade, accounting, and history.

Rules Going Forward
Reference charts should be compact lookup tools, not full lessons. Each chart should have a clear title, stable filename, logical folder placement, and a consistent visual purpose. Use charts for formulas, symbols, timelines, comparisons, classifications, processes, matrices, and quick-reference tables. Avoid making single charts too dense; large topics should be split into overview charts and companion detailed charts.

Notes
Currency Symbols should be treated as a universal reference chart. The first version should focus on major and commonly confused currencies rather than trying to include every world currency in one image. A separate companion chart can be created later for full currency codes, world currencies by region, reserve currencies, exchange-rate terms, historical currency symbols, and cryptocurrency symbols or tickers.
