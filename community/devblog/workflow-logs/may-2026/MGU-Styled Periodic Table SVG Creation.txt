WORKFLOW NOTE

Title
MGU-Styled Periodic Table SVG Creation

Date
2026-05-21

Area
MGU Chemistry Reference / Science Visual Assets / SVG Infographic Production

Problem
The initial request began with whether a periodic table could be made from an SVG file, but the actual need shifted to creating a periodic table from scratch. The first output was an image-style periodic table, not an editable SVG. The user then needed a true SVG file, and later clarified that the final version should be closer to Malone Global University styling and must include atomic numbers.

Intended Goal
Create a complete periodic table as a standalone SVG file that includes all 118 elements, atomic numbers, symbols, element names, group numbers, period numbers, category color coding, lanthanide and actinide rows, and MGU-style visual branding suitable for use as a chemistry reference asset.

Root Cause
The first generated version was treated as an infographic image rather than a structured vector source file. The visual direction was useful, but the user needed an actual editable SVG asset with readable atomic numbers and a style aligned with MGU branding instead of a generic classroom chart.

Steps Taken

1. Created an initial periodic table layout from scratch with all 118 elements, including element symbols, names, atomic numbers, group numbers, period numbers, lanthanide and actinide rows, and a color-coded family legend.

2. Generated a polished poster-style periodic table image to establish the visual direction and verify the desired structure.

3. Converted the periodic table into a standalone SVG file so it could be edited, scaled, and used as a true vector asset.

4. Revised the design direction toward MGU styling: dark navy typography, muted academic colors, light parchment-style background, university-reference layout, formal title area, and “Malone Global University • Chemistry Reference” subtitle.

5. Built the final SVG version with atomic numbers clearly shown in the upper-left corner of every element tile, large centered element symbols, and element names below.

6. Added complete category color coding for alkali metals, alkaline earth metals, transition metals, post-transition metals, metalloids, other nonmetals, halogens, noble gases, lanthanides, and actinides.

7. Added group numbers 1–18, period numbers 1–7, placeholder cells for 57–71 and 89–103, separated lanthanide and actinide rows, and an MGU-style footer motto.

Key Change
The periodic table was converted from a generated image concept into a true MGU-styled SVG source file with atomic numbers and full editable vector structure.

Outcome
A usable SVG file was produced: `periodic_table_mgu_atomic_numbers.svg`. It contains the full periodic table with atomic numbers, symbols, names, category colors, group/period labels, lanthanide and actinide rows, MGU-style header treatment, and formal academic visual styling.

Validation
The SVG file was generated directly as text-based vector markup, saved successfully, and confirmed to exist as a downloadable file. The element layout was built from a structured element list rather than manually placed from an image, reducing the chance of missing elements or broken table structure.

Rules Going Forward
For MGU science reference visuals, distinguish clearly between image infographics and editable SVG source assets. When the user requests an SVG, produce an actual `.svg` file rather than an image approximation. Periodic table files should include atomic numbers by default unless specifically removed. MGU-styled reference charts should use restrained academic colors, navy headings, formal typography, and clean vector structure.

Notes
The generated image versions were useful for exploring visual style, but the final deliverable needed to be the SVG file. Future improvements could include making an HTML-wrapped interactive version, adding links for each element, adding atomic weights/electron configurations, or producing separate print and web-optimized SVG variants.
