WORKFLOW NOTE

Title
Infographic Filename List Comparison Cleanup

Date
2026-05-21

Area
MGU file inventory / infographic asset naming

Problem
Two filename lists, `file-list.txt` and `sorted-list.txt`, were compared with PowerShell using `Compare-Object`. The output showed that several infographic image filenames did not match across the two lists. Some differences were caused by true extra files, while others were caused by spelling, spacing, or naming inconsistencies.

Intended Goal
The two lists should use consistent, clean, predictable filenames so missing files, duplicate concepts, and typo-based mismatches can be identified accurately.

Root Cause
The mismatch occurred because the two lists were not using the same filename conventions. Some files had typographical errors, alternate MGU-prefixed names, duplicate generated variants, or incorrect separator characters.

Steps Taken

1. Ran a PowerShell `Compare-Object` command comparing the sorted contents of `C:\mgu\file-list.txt` and `C:\mgu\sorted-list.txt`.

2. Interpreted the `SideIndicator` output:
   `=>` indicated files present only in `file-list.txt`;
   `<=` indicated files present only in `sorted-list.txt`.

3. Identified the clean filenames present in one list only:
   `center-of-mass.webp`
   `potential-energy.webp`
   `what-is-physics.webp`

4. Identified the mismatched or extra filenames present in the other list:
   `center-of mass.webp`
   `mgu-concept.png-2.webp`
   `mgu-concept.png-3.webp`
   `mgu-concept.webp`
   `mgu-periodic.table.webp`
   `mgu-what-physics-is.webp`
   `newtons-third-law-2.webp`
   `periodic-table.webp`
   `potenial-energy.webp`

5. Flagged likely typo corrections:
   `center-of mass.webp` should likely become `center-of-mass.webp`;
   `potenial-energy.webp` should likely become `potential-energy.webp`.

6. Flagged a likely naming-standard mismatch:
   `mgu-what-physics-is.webp` appears to correspond conceptually to `what-is-physics.webp`.

7. Separated probable real extras from likely typo-based mismatches so the list can be cleaned without accidentally deleting valid files.

Key Change
The comparison output was converted from a raw PowerShell diff into a clear cleanup map showing which filenames are typos, which are alternate names, and which may be extra generated files.

Outcome
The filename discrepancy is now understandable and actionable. The cleanup task can proceed by correcting obvious typos, deciding whether to keep or remove duplicate generated variants, and standardizing concept names across the infographic inventory.

Validation
The mismatch was validated directly from the `Compare-Object` output. The most obvious errors were confirmed visually: `center-of mass.webp` uses a space instead of a hyphen, and `potenial-energy.webp` misspells `potential`.

Rules Going Forward
Use one filename convention for all MGU infographic assets: lowercase words, hyphen separators, no spaces, no accidental `.png-2.webp` conversion artifacts, and no unnecessary duplicate prefixes unless they are part of the official naming scheme.

Before finalizing an asset set, compare the expected filename list against the actual folder listing and resolve typos before creating indexes, download bundles, or link pages.

Notes
The files `mgu-concept.png-2.webp`, `mgu-concept.png-3.webp`, `mgu-concept.webp`, `mgu-periodic.table.webp`, `newtons-third-law-2.webp`, and `periodic-table.webp` should be reviewed manually before deletion because they may represent extra drafts, alternate infographic concepts, or conversion leftovers.
