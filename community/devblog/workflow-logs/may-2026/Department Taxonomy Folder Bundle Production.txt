WORKFLOW NOTE

Title
Department Taxonomy Folder Bundle Production

Date
2026-05-21

Area
MGU file taxonomy / department and encyclopedia folder structures

Problem
Multiple subject-area folder trees needed to be converted into downloadable zipped bundles. The structures had to preserve exact folder names, nesting, and top-level taxonomy organization.

Intended Goal
Each submitted tree should become a clean ZIP file containing only the requested nested folder structure, ready to extract into the MGU site or local taxonomy folders.

Root Cause
The folder taxonomies existed as text outlines, but they needed to be converted into real filesystem folders before they could be used in production.

Steps Taken

1. Converted each pasted tree into a Python folder-generation structure.
2. Created the requested top-level directory and all nested subdirectories.
3. Zipped each completed folder tree into a downloadable bundle.
4. Delivered download links for each completed ZIP file.
5. Created an agriculture taxonomy after identifying the need to add agriculture under science.
6. Delivered the agriculture folder tree as its own ZIP bundle.

Key Change
Text-based taxonomy outlines were converted into real downloadable ZIP bundles with matching nested folder structures.

Outcome
The session produced folder bundles for multiple MGU taxonomy areas, including communication, conspiracy studies, culinary, defense, education, encyclopedia, engineering, geography, history, humanities, illuminati, language, law, math, medical, political science, religion, science, social science, art, business, and agriculture.

Validation
Each bundle was generated through filesystem creation and ZIP packaging, then returned as a sandbox download link. The folder structures were built from the submitted outline names and preserved the requested nesting.

Rules Going Forward
Keep folder names lowercase and hyphenated. Preserve the user’s exact taxonomy unless a new branch needs to be designed. Deliver each tree as a ZIP with the top-level folder included. For multi-level trees, use recursive or nested structure logic so deeper branches are not flattened.

Notes
The agriculture taxonomy was created as a new compartmentalized branch intended to sit under science.
