WORKFLOW NOTE

Title
PowerShell Refresher HTML Snippet and Code Block Styling

Date
2026-05-21

Area
MGU PowerShell tutorial / HTML lesson snippet / code block CSS

Problem
The PowerShell refresher content existed as Markdown and needed to be converted into a reusable HTML snippet. The code examples also needed readable styling so PowerShell commands would stand out clearly on the page.

Intended Goal
Create a clean semantic HTML snippet from the Markdown lesson and add reusable CSS for polished, MGU-branded code blocks.

Root Cause
The original material was written as Markdown, which was useful for drafting but not ready for direct placement into an MGU HTML lesson page. The default browser rendering for `<pre>` and `<code>` blocks would have looked plain and inconsistent with the MGU visual style.

Steps Taken

1. Converted the PowerShell refresher Markdown into semantic HTML using sections, headings, paragraphs, ordered lists, unordered lists, and `<pre><code>` blocks.
2. Added a basic dark code block CSS style for readability.
3. Revised the code block styling into an MGU-branded navy and gold theme.
4. Expanded the styling with a faux terminal/header bar labeled “MGU Code Example.”
5. Preserved PowerShell examples in copy-friendly code blocks with horizontal scrolling for long commands.

Key Change
The PowerShell lesson was transformed from plain Markdown into a reusable HTML snippet with branded, readable code block styling.

Outcome
The content is now ready to paste into an MGU page, and the code examples have a polished terminal-style appearance that fits the MGU navy/gold design language.

Validation
The snippet was checked for semantic structure, readable heading hierarchy, proper code block formatting, and CSS that supports long commands without breaking the page layout.

Rules Going Forward
Use semantic HTML for lesson conversions, keep command examples inside `<pre><code>` blocks, and apply consistent MGU-branded styling to technical tutorial pages.

Notes
A future improvement would be adding language-specific labels through data attributes, such as `data-label="PowerShell"`, so the header bar can display the actual code language instead of a fixed “MGU Code Example” label.
