WORKFLOW NOTE

Title
Encyclopedia Domain Index Snippet Standardization

Date
2026-05-21

Area
MGU Encyclopedia domain index pages

Problem
The encyclopedia domain pages needed reusable paste-ready HTML sections generated from nested folder taxonomies. Early snippets included the hero, breadcrumb, overview, and category links, but the structure needed correction so the output matched the user’s existing page shell.

Intended Goal
Generate consistent HTML snippets for each encyclopedia domain using the structure: hero section, opening `<main id="main-content" role="main">`, breadcrumb navigation, overview section, and category link section, without adding a closing `</main>` because the template already contains it.

Root Cause
The initial output assumed the snippet should be fully self-contained and included both opening and closing main tags. The user’s actual shell already included the closing `</main>`, so future snippets needed to stop before that closing tag.

Steps Taken

1. Reviewed the finished Science index example to match the MGU Encyclopedia pattern.
2. Generated paste-ready sections for multiple domain taxonomies, including Art, Business, Communication, Conspiracy Studies, Culinary, Defense, Education, Engineering, Geography, History, Humanities, Illuminati, Language, Law, Math, Medical, Political Science, Religion, and Social Science.
3. Adjusted output rules after the user clarified that snippets must include the opening `<main>` after the hero but must not include an additional closing `</main>`.

Key Change
Future encyclopedia index snippets now include the opening main tag but omit the closing main tag.

Outcome
The generated snippets now fit directly into the user’s existing MGU HTML shells without requiring manual removal of duplicate closing tags.

Validation
The user showed an incorporated Art page where the hero, main wrapper, breadcrumb, overview, categories, bottom navigation, and closing main tag worked correctly in the full page structure.

Rules Going Forward
Always output encyclopedia domain snippets as one paste-ready section. Include the hero first, then open `<main id="main-content" role="main">`, then include breadcrumb, overview, and categories. Do not include the closing `</main>` unless the user specifically asks for a complete page.

Notes
The taxonomy order being used is `encyclopedia/domain/discipline/subdiscipline/articles`. Future outputs should keep category links relative and use clean title casing for display names.
