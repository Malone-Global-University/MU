WORKFLOW NOTE

Title
Discipline-Level Encyclopedia Index Generation

Date
2026-05-21

Area
MGU Library / Encyclopedia / Domain and Discipline Index Pages

Problem
The encyclopedia discipline pages needed reusable HTML index sections for multiple academic domains. The early generated breadcrumb pattern incorrectly linked the current discipline page instead of linking back to the parent domain. The user clarified that the encyclopedia taxonomy has three levels: domain, discipline, and sub-discipline. Discipline-level index pages should link back to the parent domain and show the current discipline as the final non-linked breadcrumb span.

Intended Goal
Each discipline-level index should include a complete drop-in HTML section set with a hero, main tag, breadcrumb, overview, and alphabetized list of sub-discipline links. Breadcrumbs should follow the correct hierarchy:

Home → Library → Encyclopedia → Domain → Current Discipline

The current page should not be a link.

Root Cause
The initial breadcrumb logic treated the discipline page itself as the final linked breadcrumb before the current-page span. That duplicated the current page in the breadcrumb trail and skipped the correct parent-domain link. The structure needed to be interpreted as a three-level encyclopedia hierarchy rather than a flat list of index pages.

Steps Taken

1. Generated complete discipline-level index blocks using the requested structure: `<section class="hero">`, `<main id="main-content" role="main">`, `<nav class="breadcrumb">`, overview section, and discipline/sub-discipline list section.

2. Corrected the breadcrumb rule after user feedback so discipline-level pages link to the domain index, such as `/library/encyclopedia/communication`, `/library/encyclopedia/business`, `/library/encyclopedia/computer-science`, or `/library/encyclopedia/history`, while the current discipline appears only as a `<span>`.

3. Applied the corrected hierarchy across later domains including Communication, Computer Science, Conspiracy Studies, Culinary, Defense, Education, Engineering, Geography, History, Humanities, and Illuminati.

4. Used alphabetical ordering by discipline filename when requested, especially for the Computer Science tree and subsequent domain batches.

5. Ordered sub-discipline links alphabetically by filename inside each index list, rather than preserving the original tree order when alphabetical ordering was required.

6. Maintained consistent description length and style modeled on the original Art Index example: short hero paragraph, compact overview paragraph, and concise sub-discipline descriptions.

7. Built discipline-level index sections for many domains, including Business, Communication, Computer Science, Conspiracy Studies, Culinary, Defense, Education, Engineering, Geography, History, Humanities, and Illuminati.

Key Change
The breadcrumb system was corrected so discipline index pages link back to their parent domain instead of linking to the current discipline page.

Outcome
The generated encyclopedia index sections are now structurally consistent, easier to paste into MGU pages, and aligned with the intended taxonomy. Each page block includes the required hero, breadcrumb, overview, and discipline list sections. The breadcrumb hierarchy now properly reflects the domain → discipline → sub-discipline model.

Validation
The correction was validated by checking the breadcrumb example against the user’s clarified model. For example, a Strategy discipline page should use:

`/library/encyclopedia/business">Business</a>`
`<span>Strategy Index</span>`

not:

`/library/encyclopedia/strategy">Strategy</a>`
`<span>Strategy Index</span>`

Later generated pages followed this corrected pattern.

Rules Going Forward
For encyclopedia trees, treat the first folder after `/encyclopedia/` as the domain, the second level as the discipline, and the third level as the sub-discipline.

For discipline-level index pages, breadcrumbs should be:

Home → Library → Encyclopedia → Domain link → Current Discipline span

Never link the current page in the breadcrumb.

When the user asks for files alphabetically by filename, deliver discipline sections alphabetically by discipline slug and order all internal links alphabetically by sub-discipline slug.

Keep generated sections drop-in ready and preserve the requested structure:

hero
main opening tag
breadcrumb
overview
disciplines list

Notes
Several earlier Business and Art breadcrumb blocks were created before the corrected breadcrumb rule was clarified. Those older blocks may need a cleanup pass if they are reused. The corrected rule was applied consistently after the user explained the three-level hierarchy.
