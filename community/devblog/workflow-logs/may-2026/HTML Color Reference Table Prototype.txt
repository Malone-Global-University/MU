WORKFLOW NOTE

Title
HTML Color Reference Table Prototype

Date
2026-05-21

Area
MGU reference pages / HTML color tools / web development utilities

Problem
The site needed an HTML color reference page comparable in usefulness to established color chart tools. The existing material was only a pasted list of named HTML/CSS colors grouped by family. It did not yet have an interactive picker, live preview swatch, searchable table, clickable rows, or a working test page.

Intended Goal
Create a prototype HTML page that could be opened locally and tested immediately. The page needed to display named HTML/CSS colors by family, allow a user to type a hex code, show a live swatch preview, display RGB output, and identify exact named-color matches when available.

Root Cause
The color data existed as static reference text, but it had not yet been converted into a functional HTML interface. A plain table would have been useful, but it would not provide the interactive behavior needed for testing color codes, previewing swatches, or navigating a large reference list efficiently.

Steps Taken

1. Reviewed the pasted color list and organized the colors into major families: Red, Orange, Yellow, Green, Cyan, Blue, Purple, Pink, White, Gray, and Brown.

2. Designed a single-file prototype page with embedded HTML, CSS, and JavaScript so it could be tested without external dependencies.

3. Added a hero section, overview section, table of contents, sticky color picker panel, searchable master color table, and separate grouped family sections.

4. Built a live hex input tool that accepts six-digit hex values, normalizes input to `#RRGGBB`, converts the value to RGB, updates a large swatch preview, and reports whether the value matches a named CSS color.

5. Added clickable and keyboard-accessible color table rows so selecting a color updates the preview panel automatically.

6. Added a search box for the master table so colors can be filtered by name, hex code, RGB value, or family.

7. Corrected known data issues from the pasted list, including the `lime` RGB value and the `darkseagreen` hex/RGB pairing.

8. Saved the working prototype as `html_color_reference_table_prototype.html` and provided it as a downloadable file for local testing.

Key Change
The static color reference list was converted into a working interactive HTML color reference prototype with live preview, lookup, search, clickable rows, and grouped reference tables.

Outcome
The page now functions as a practical testing tool instead of a static chart. A user can type a hex code, see the corresponding swatch, view RGB output, identify exact named-color matches, search the full reference list, and click any listed color to load it into the preview panel.

Validation
The prototype was generated as a standalone HTML file and confirmed to load as a downloadable artifact. The user opened or tested it and reported that it looked and worked very nicely, confirming that the core interface and interaction model were successful.

Rules Going Forward
Keep the page self-contained while prototyping so it remains easy to test locally. Preserve the grouped color-family structure for readability. Keep the picker utility above the tables so users can test codes before browsing the reference list. Validate color data carefully before expanding the table. Add new tools incrementally rather than overcomplicating the first working version.

Notes
Useful follow-up improvements include copy buttons for color name, hex, and RGB values; HSL conversion; contrast checking against white and black text; closest named-color matching; a true color-field picker with a movable pointer; and eventually moving the color data into a reusable JSON file if the page becomes part of a larger MGU web-development reference system.
