WORKFLOW NOTE

Title
PowerShell Search for Recently Saved Text Files

Date
2026-05-17

Area
Windows PowerShell / Local File Management / MGU Project Folder

Problem
A recently saved `.txt` file was misplaced and could not be found manually. The file was believed to have been saved today somewhere under `C:\mgu`, but its exact folder location was unknown.

Intended Goal
Use PowerShell to search the MGU project folder recursively, find recently modified `.txt` files, sort them newest first, and identify the missing file quickly.

Root Cause
The file was saved somewhere inside a large folder structure without a remembered final path. Manual browsing was inefficient because `C:\mgu` likely contains many nested folders and files.

Steps Taken

1. Created a general PowerShell command using `Get-ChildItem`, `-Recurse`, `-File`, and `Sort-Object LastWriteTime -Descending` to locate recently saved `.txt` files.
2. Narrowed the search path from the user folder or whole `C:\` drive to the specific project directory: `C:\mgu`.
3. Added a date filter using `(Get-Date).Date` so only files modified today would appear.
4. Provided a broader fallback command to show all file types saved today under `C:\mgu` in case the file extension was not actually `.txt`.
5. Added an `explorer.exe /select` command pattern so a located file could be opened directly in File Explorer.

Key Change
The search was narrowed to today’s modified files under `C:\mgu`, sorted newest first, instead of manually browsing the project folder.

Outcome
The user now has a direct PowerShell method for finding the misplaced text file quickly:

```powershell
Get-ChildItem -Path C:\mgu -Filter *.txt -Recurse -File |
Where-Object { $_.LastWriteTime -ge (Get-Date).Date } |
Sort-Object LastWriteTime -Descending |
Select-Object LastWriteTime, FullName
```

Validation
The command is validated by its logic: it searches only files, includes nested folders, filters to `.txt`, limits results to files modified today, and sorts the newest files first. A broader all-file version was also provided for edge cases where the extension may be wrong.

Rules Going Forward
Use `Get-ChildItem -Recurse -File` with `LastWriteTime` sorting whenever a recently saved file is misplaced inside a large project folder. Narrow the `-Path` first when the likely root folder is known, because searching all of `C:\` is slower and noisier. Use `-Filter` when the extension is known, and remove it when the extension is uncertain.

Notes
For future searches, the same pattern can be adapted for `.html`, `.docx`, `.js`, `.md`, `.webp`, or any other file type used in the MGU project folders.
