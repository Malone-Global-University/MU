WORKFLOW NOTE

Title
Offline Website Task List with JSON File Storage

Date
2026-05-21

Area
Website task utility / offline HTML workflow tool

Problem
The first task-list design was too complex for the intended use. It had a polished dashboard layout with multiple columns, task categories, progress cards, and extra planning sections, but the actual need was much simpler: add a website task, record the date it was added, and assign a priority. The later requirement added offline persistence, specifically the ability to save tasks to a JSON data file and reload them from that file.

Intended Goal
Create a simple offline-friendly HTML task tool that can be used for website maintenance tasks. The tool should allow the user to add a task, set the date added, set the task priority, display the saved tasks, and preserve task data between uses by reading and writing a local JSON file.

Root Cause
The initial design assumed a broader project-management dashboard, while the actual workflow required a small utility. Also, normal offline HTML files are restricted by browser security rules and cannot silently write files into their own folder without user permission, so a folder-selection workflow was needed for local JSON storage.

Steps Taken

1. Replaced the original multi-column “website operations board” with a simpler single-page task form containing only task name, date added, and priority.

2. Added a basic task list display showing the task title, formatted date added, and priority badge.

3. Added JavaScript logic for adding tasks, rendering tasks, deleting tasks, and assigning stable task IDs.

4. Added browser-memory fallback using localStorage so tasks can remain available even when a folder has not yet been connected.

5. Added local JSON file support using the browser File System Access API.

6. Added a “Connect Data Folder” button so the user can choose the folder where the HTML file and task data should live.

7. Added logic to create, read, and update a file named `website-tasks.json` in the connected folder.

8. Added “Read website-tasks.json” and “Write website-tasks.json” controls for manual loading and saving.

9. Added automatic JSON writing after task additions and deletions when a writable folder has been connected.

10. Added status messages explaining whether the page is using the JSON file, browser backup, or needs folder permission.

Key Change
The task tool was converted from a decorative dashboard into a simple offline HTML utility that can store website tasks in a local `website-tasks.json` file after the user connects a folder.

Outcome
The page now supports the intended workflow: add a task, set its date, set its priority, and preserve the task list offline. It can create and update `website-tasks.json` in a user-selected folder, making it suitable for local website task tracking without needing a server or database.

Validation
The structure was reviewed for the required fields and controls: task input, date input, priority selector, add button, task list, delete button, folder connection, JSON read, JSON write, and clear tasks. The browser limitation was accounted for by requiring explicit folder selection before file writing.

Rules Going Forward
Keep this tool focused and minimal. Do not expand it back into a full project dashboard unless needed. For offline HTML utilities, assume browser security restrictions apply: local file writing requires user permission through a file or folder picker. Use `website-tasks.json` as the standard data file name unless a different name is explicitly requested.

Notes
This version should work best in Chrome or Edge because it relies on the File System Access API for direct folder writing. Other browsers may still use the localStorage backup, but may not support creating or updating the JSON file directly from the page.
