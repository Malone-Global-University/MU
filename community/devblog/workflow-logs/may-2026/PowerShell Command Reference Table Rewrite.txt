WORKFLOW NOTE

Title
PowerShell Command Reference Table Rewrite

Date
2026-05-21

Area
MGU Library / Reference Table HTML Page

Problem
The existing HTML example was written for a CSS Cascade and Inheritance Reference Table. It still contained CSS-specific page labels, headings, introductory text, table headers, table rows, examples, and supporting explanations. The structure was usable, but the content did not match the intended PowerShell command reference topic.

Intended Goal
Convert the existing reference-table format into a PowerShell command reference table while keeping the same general HTML structure, table styling pattern, and MGU reference-page layout.

Root Cause
The user had a working reference-table template but needed the subject-specific content cleared and replaced. The original page was built around CSS cascade concepts, so its labels and examples were not reusable without rewriting the semantic text and table data.

Steps Taken

1. Replaced the main section label with `PowerShell Command Reference Table`.
2. Rewrote the introductory paragraph to explain PowerShell cmdlets, verb-noun naming, navigation, files, system information, processes, and output control.
3. Replaced the CSS table columns with PowerShell-appropriate columns: `Command`, `Purpose`, `Example`, and `Practical Use`.
4. Added common PowerShell commands such as `Get-Location`, `Set-Location`, `Get-ChildItem`, `New-Item`, `Copy-Item`, `Move-Item`, `Remove-Item`, `Get-Content`, `Set-Content`, `Select-String`, `Where-Object`, `Sort-Object`, `Select-Object`, `Group-Object`, `Get-Command`, `Get-Help`, `Get-Process`, `Stop-Process`, and `Clear-Host`.
5. Replaced the second CSS inheritance table with a PowerShell pipeline-pattern table.
6. Added practical pipeline examples for listing, sorting, filtering, selecting columns, grouping results, exporting output, and searching inside files.
7. Kept the existing `.table-wrapper` and `.reference-table` structure so the replacement section would fit the existing MGU reference-page style.

Key Change
The CSS cascade reference content was replaced with a practical PowerShell command and pipeline reference while preserving the original reusable HTML table format.

Outcome
The page section now functions as a PowerShell reference table instead of a CSS reference table. The content is clearer for beginners and practical for MGU users working with folders, files, scripts, command discovery, and terminal output.

Validation
The rewritten section was checked for semantic fit, table consistency, usable command examples, and alignment with the original page structure. The command labels, examples, and descriptions now match the intended PowerShell topic rather than the previous CSS cascade topic.

Rules Going Forward
Use existing MGU reference tables as reusable layout templates, but always replace topic-specific metadata, headings, descriptions, table headers, examples, and secondary tables when changing subjects. Keep command-reference pages practical, example-driven, and organized around real tasks users perform in PowerShell.

Notes
This PowerShell table can later be expanded into separate reference pages for file management, pipeline operations, text search, system administration, scripting basics, and PowerShell aliases.
