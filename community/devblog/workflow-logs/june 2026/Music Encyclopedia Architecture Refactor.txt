WORKFLOW NOTE

Title
Music Encyclopedia Architecture Refactor: Department vs Library Separation and Discography System Introduction

Date
2026-06-03

Area
MGU / library / encyclopedia / art / music / discographies / reference structure / index navigation

Problem
The Music system previously contained duplicated and overlapping structures between the Department (instructional content) and Library (reference content). Biographies, discographies, and reference materials were inconsistently placed across `/department/art/music` and `/library/encyclopedia/art/music/reference`, creating navigation ambiguity and redundant categories such as competing biography folders. Index pages also reflected instructional “disciplines” rather than encyclopedia-style reference collections.

Intended Goal
The system should enforce a clean separation between instructional curriculum (Department of Music) and reference knowledge (Music Encyclopedia). The encyclopedia should prioritize lookup-based navigation (biographies, discographies, terms, instruments, timelines), while the department focuses on structured learning pathways. Discographies should be formally introduced as a core reference category aligned with biographies.

Root Cause
Initial AI-generated architecture mixed instructional taxonomy (discipline-based learning structure) with reference taxonomy (lookup-based encyclopedia structure). As content scale increased—particularly rapper biographies—the system organically evolved into a hybrid model without strict separation rules, leading to overlapping folders such as biographies vs artist-biographies and conflicting placement of reference content between department and library layers.

Steps Taken

1. Migrated encyclopedia content from `/department/art/music/reference` into `/library/encyclopedia/art/music/reference` to establish Library as the sole reference system.
2. Removed redundant and overlapping folders, including duplicated biography structures (e.g., artist-biographies vs biographies).
3. Retained only core reference domains: biographies (rappers), music-terms, instruments, and timelines.
4. Established discographies as a new first-class encyclopedia category under `/library/encyclopedia/art/music/discographies`.
5. Defined discography sub-structure (rappers, singers, bands, producers, composers).
6. Updated Music Index page navigation to replace “Disciplines” (departmental framing) with “Reference Collections” (encyclopedia framing).
7. Generated full index pages for discographies and each subpage (rappers, singers, bands, producers, composers).
8. Standardized navigation intent from instructional browsing to lookup-based reference navigation.

Key Change
Discographies were formally introduced as a primary encyclopedia structure and the entire Music reference system was fully consolidated under the Library, eliminating department-library duplication.

Outcome
The Music Encyclopedia now behaves as a coherent reference system with a clear hierarchical model: biographies, discographies, timelines, music-terms, and instruments. Navigation is simplified and consistent, and the Disciplines-based instructional framing has been replaced with reference-oriented collections.

Validation
Verified via directory output that `/library/encyclopedia/art/music/reference` is no longer the primary content location, with 291 biography files now consolidated under `/biographies/rappers`. Index structure reflects reference-based navigation rather than curriculum structure, and discography pages have been successfully created and aligned with the new architecture.

Rules Going Forward
Instructional (Department) and reference (Library) content must remain strictly separated. Reference folders must represent stable lookup domains only. Any category that does not serve high-frequency retrieval or clear conceptual ownership should be removed or merged. New structures should prioritize flat, surface-level accessibility over deep hierarchical nesting unless strong justification exists.

Notes
The system has reached a stable bifurcation point between “learning structure” and “knowledge reference structure.” Future expansion should prioritize cross-linking between biographies, discographies, and timelines to form a navigable knowledge graph rather than increasing folder depth.
