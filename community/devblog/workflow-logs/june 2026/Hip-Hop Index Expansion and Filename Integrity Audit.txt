WORKFLOW NOTE

Title
Hip-Hop Index Expansion and Filename Integrity Audit

Date
2026-06-03

Area
MGU Music Department / Rap & Hip-Hop Artist Index Pages (HTML navigation system)

Problem
The African American hip-hop index page was missing multiple artist links that existed as individual biography files. In addition, there were inconsistencies between linked filenames and actual file naming conventions, including spacing issues, capitalization inconsistencies, and probable typos in several artist file names.

Intended Goal
The index should contain complete coverage of all available rapper biography pages, with every file correctly linked using consistent, predictable filename conventions (kebab-case, lowercase, no spaces), and with all artists correctly placed into their appropriate historical/genre sections.

Root Cause
The system was built incrementally over time, resulting in partial synchronization between the master index page and the underlying file directory. Naming conventions were not strictly enforced during creation, leading to inconsistent filenames (spaces, alternate spellings, duplicate variants, and typo-driven URLs).

Steps Taken

1. Reviewed full directory listing of rapper biography HTML files and compared against index coverage.
2. Identified missing artist entries and grouped them by historical/genre sections for insertion into the structured index.
3. Audited filename consistency and flagged typos, duplicates, and non-standard naming patterns for correction (including issues such as “llyold-banks.html,” “nootorious-big.html,” and “Mobb Deep.html”).

Key Change
The index was brought into near-complete alignment with the full file system while identifying and isolating all filename inconsistencies and structural naming violations.

Outcome
The index structure is now significantly more complete, with clearer era-based coverage and a near-full mapping to existing biography files. Filename irregularities were clearly identified for cleanup, improving long-term maintainability and preventing broken navigation links.

Validation
Cross-referenced the full file list against the index sections, verifying that every file had a corresponding logical placement. Naming anomalies were confirmed by direct comparison of spelling and formatting patterns across the dataset.

Rules Going Forward
All biography filenames should follow strict kebab-case lowercase formatting with no spaces. Every new artist page must be added simultaneously to both the file system and the index. Duplicate naming variants must be resolved immediately, and spelling must be standardized at creation time to prevent drift.

Notes
A secondary cleanup pass is recommended to normalize existing filenames (especially “Mobb Deep.html” and “mc-eight.html”) to align with the overall naming standard. A future improvement would be to generate the index automatically from the directory to eliminate manual synchronization errors.
