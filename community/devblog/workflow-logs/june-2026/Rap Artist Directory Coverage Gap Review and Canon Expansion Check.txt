WORKFLOW NOTE

Title
Rap Artist Directory Coverage Gap Review and Canon Expansion Check

Date
2026-06-03

Area
Music reference library – rappers index (filesystem HTML directory audit)

Problem
The rap artist directory was incomplete in terms of major canonical hip-hop figures. Several foundational, commercially significant, and historically recognized artists were missing from the dataset, which creates gaps in both historical coverage and genre representation. In addition, duplicate and variant entries were present for some artists, creating fragmentation of identity across multiple filenames.

Intended Goal
The system should maintain a comprehensive and deduplicated rap artist index that includes all major foundational, influential, and commercially significant hip-hop artists, while ensuring each artist exists as a single canonical file entry with consistent naming.

Root Cause
The dataset appears to have been built incrementally without a strict canonical authority list or deduplication rules. This allowed parallel entries (multiple filenames for the same artist) and omissions of key artists from different eras and regions. Naming inconsistencies and spelling variations further fragmented entity resolution.

Steps Taken

1. Reviewed the full directory listing of existing rapper HTML files.
2. Identified missing major canonical artists by comparing against widely recognized hip-hop canon coverage.
3. Flagged structural duplication patterns (multiple files per artist, inconsistent naming conventions, and spelling inconsistencies).
4. Suggested missing foundational and modern mainstream artists to restore coverage balance (e.g., Notorious B.I.G., 50 Cent, Drake, Ice-T, MC Hammer, Beastie Boys).
5. Noted normalization issues in filenames requiring standardization (single canonical slug per artist).

Key Change
Identified and clarified that the directory requires both canonical expansion (adding missing major artists) and deduplication/normalization of existing entries.

Outcome
The dataset is now clearly understood to have two structural issues—coverage gaps and duplicate entities—and a prioritized correction path has been established to improve completeness and consistency of the rap artist index.

Validation
Cross-checked against general hip-hop canon groupings and confirmed that multiple widely recognized artists were absent while duplicates existed in the current file structure.

Rules Going Forward
Maintain a single canonical file per artist with a standardized naming convention. All new additions should be validated against the existing index to prevent duplicates. Any artist insertion should include a quick canonical presence check before creation. Structural consistency takes priority over incremental additions.

Notes
Future improvement would benefit from introducing an artist authority list (canonical seed index) to prevent drift, along with an automated deduplication scan that flags near-identical slugs or spelling variants before commit.
