Function

Subfield: Foundations & Logic

Etymology & Roots

A function is a mathematical relationship that assigns each admissible input exactly one output. In modern set-theoretic language, a function from a set $A$ to a set $B$ is written:

$$ \boxed{ f:A\to B }. $$

For every $x\in A$, there is exactly one corresponding value $f(x)\in B$.

The set $A$ is the domain, and $B$ is the codomain. The values actually produced form the range or image of the function.

The word function developed historically from language describing a quantity as depending upon, or being determined by, another quantity. Modern mathematics broadened the concept beyond formulas to arbitrary well-defined mappings between sets.

Thus the central idea is not that a function must possess a particular algebraic formula, but that it obeys the assignment rule:

$$ \boxed{ \text{each input} \longmapsto \text{exactly one output} }. $$

Operational Nuance

Formal Mapping Language

The notation:

$$ f:A\to B $$

means that $f$ is a function whose domain is $A$ and whose codomain is $B$.

Input-Output Rule

If:

$$ x\in A, $$

then the function assigns an output:

$$ \boxed{ f(x)\in B }. $$

Exactly One Output

The defining requirement is uniqueness of output. An input cannot be assigned two different outputs by the same function.

$$ \boxed{ f(x)=y_1 \text{ and } f(x)=y_2 \Longrightarrow y_1=y_2 }. $$

Different Inputs May Share an Output

A function does not require different inputs to have different outputs.

For example:

$$ f(x)=x^2 $$

satisfies:

$$ f(2)=4, \qquad f(-2)=4. $$

This is still a function because each individual input has only one output.

Domain

The domain is the set of allowable inputs:

$$ \boxed{ \operatorname{Dom}(f)=A }. $$

Codomain

The codomain is the declared target set:

$$ \boxed{ f:A\to B }. $$

Here $B$ is the codomain even if some of its elements are never produced.

Range

The range is the set of actual output values:

$$ \boxed{ f(A) = \{f(x):x\in A\} }. $$

Range Is Contained in the Codomain

$$ \boxed{ f(A)\subseteq B }. $$

Equality holds precisely when the function is onto $B$.

Example

Let:

$$ f:\mathbb{R}\to\mathbb{R}, \qquad f(x)=x^2. $$

Then:

$$ \operatorname{Dom}(f)=\mathbb{R}, $$
$$ \operatorname{Codom}(f)=\mathbb{R}, $$

but:

$$ \boxed{ \operatorname{Range}(f) = [0,\infty) }. $$

Function Notation

The notation:

$$ \boxed{ f(x) } $$

means the value of the function $f$ at the input $x$.

Function Notation Is Not Multiplication

The expression $f(x)$ is not ordinarily interpreted as:

$$ f\cdot x. $$

Parentheses indicate evaluation of the function at an input.

Evaluation

If:

$$ f(x)=2x^2-3x+1, $$

then:

$$ f(4) = 2(4)^2-3(4)+1 = 32-12+1 = \boxed{21}. $$

Substitution

Function evaluation is a structured substitution process. Every occurrence of the independent variable is replaced by the supplied input.

Expression Input

If:

$$ f(x)=x^2+1, $$

then:

$$ f(a+h) = \boxed{ (a+h)^2+1 }. $$

Named Variables Are Not Essential

The functions:

$$ f(x)=x^2+1 $$

and:

$$ f(t)=t^2+1 $$

describe the same assignment rule if their domains and codomains are otherwise identical. The input symbol is a placeholder.

Independent Variable

In elementary function language, the input variable is often called the independent variable.

Dependent Variable

If:

$$ y=f(x), $$

then $y$ is commonly called the dependent variable because its value is determined by $x$ through the function.

Function as a Set of Ordered Pairs

Set-theoretically, a function may be represented by ordered pairs:

$$ \boxed{ f = \{(x,f(x)):x\in A\} }. $$

No two ordered pairs may have the same first coordinate and different second coordinates.

Relation vs. Function

Every function can be viewed as a relation, but not every relation is a function.

The relation:

$$ \{(1,2),(1,3)\} $$

is not a function from its first-coordinate set because input $1$ is assigned two different outputs.

Finite Mapping Example

Let:

$$ A=\{1,2,3\}, \qquad B=\{a,b\}. $$

The assignment:

$$ 1\mapsto a,\qquad 2\mapsto b,\qquad 3\mapsto a $$

is a function $A\to B$.

Formula as a Function Rule

A formula can define a function:

$$ \boxed{ f(x)=3x-2 }. $$

But a function need not be specified by one closed-form formula.

Table Representation

A function may be specified by a table assigning one output to each listed input.

Graph Representation

A real-valued function of one real variable can be represented by the set:

$$ \boxed{ \{(x,f(x)):x\in\operatorname{Dom}(f)\} }. $$

Vertical Line Test

A graph in the Cartesian plane represents $y$ as a function of $x$ if every vertical line intersects the graph at most once.

$$ \boxed{ \text{one }x \Longrightarrow \text{at most one plotted }y }. $$

Why a Circle Fails the Vertical Line Test

The circle:

$$ x^2+y^2=1 $$

is not globally the graph of $y$ as a function of $x$ because many $x$-values correspond to two $y$-values.

Implicit Relations Can Define Local Functions

Although:

$$ x^2+y^2=1 $$

is not one global function $y=f(x)$, its upper semicircle can be written:

$$ y=\sqrt{1-x^2}, $$

and its lower semicircle:

$$ y=-\sqrt{1-x^2}. $$

Natural Domain

When a formula is supplied without an explicit domain, one often assumes its natural domain: all values for which the formula is defined in the number system under discussion.

Polynomial Domain

A polynomial function such as:

$$ f(x)=x^3-2x+5 $$

has natural real domain:

$$ \boxed{\mathbb{R}}. $$

Rational-Function Domain

For:

$$ f(x)=\frac{x+1}{x-4}, $$

the denominator requires:

$$ \boxed{x\neq4}. $$

Radical-Function Domain

Over the reals:

$$ f(x)=\sqrt{x-3} $$

requires:

$$ \boxed{x\geq3}. $$

Logarithmic Domain

For:

$$ f(x)=\ln(x+2), $$

one requires:

$$ \boxed{x>-2}. $$

Piecewise Function

A function may use different formulas on different parts of its domain:

$$ \boxed{ f(x)= \begin{cases} x^2, & x\geq0,\\ -x, & x<0. \end{cases} } $$

Piecewise definition does not violate functionhood as long as each input receives exactly one output.

Constant Function

A function may assign the same output to every input:

$$ \boxed{ f(x)=c }. $$

Identity Function

The identity function on a set $A$ is:

$$ \boxed{ \operatorname{id}_A(x)=x }. $$

Every input is mapped to itself.

Injective Function

A function is injective or one-to-one if equal outputs imply equal inputs:

$$ \boxed{ f(x_1)=f(x_2) \Longrightarrow x_1=x_2 }. $$

Equivalent Injectivity Condition

$$ \boxed{ x_1\neq x_2 \Longrightarrow f(x_1)\neq f(x_2) }. $$

Horizontal Line Test

For real graphs, a function is one-to-one if every horizontal line intersects its graph at most once.

Surjective Function

A function:

$$ f:A\to B $$

is surjective or onto if every element of $B$ is produced:

$$ \boxed{ \forall y\in B,\ \exists x\in A \text{ such that } f(x)=y }. $$

Surjectivity and Range

$$ \boxed{ f\text{ is surjective} \iff f(A)=B }. $$

Bijective Function

A function is bijective if it is both injective and surjective.

$$ \boxed{ \text{bijective} = \text{one-to-one and onto} }. $$

Inverse Function

A bijection:

$$ f:A\to B $$

has an inverse:

$$ \boxed{ f^{-1}:B\to A }. $$

satisfying:

$$ \boxed{ f^{-1}(f(x))=x } $$

and:

$$ \boxed{ f(f^{-1}(y))=y }. $$

Inverse Function Is Not Reciprocal

The notation:

$$ f^{-1}(x) $$

usually denotes an inverse function, not:

$$ \frac1{f(x)}. $$

These are generally different objects.

Example of an Inverse

Let:

$$ f(x)=2x+3. $$

Then:

$$ \boxed{ f^{-1}(x)=\frac{x-3}{2} }. $$

Composition

If:

$$ f:A\to B $$

and:

$$ g:B\to C, $$

then their composition is:

$$ \boxed{ (g\circ f)(x)=g(f(x)) }. $$

Composition Order Matters

In general:

$$ \boxed{ g\circ f \neq f\circ g }. $$

Function composition is generally noncommutative.

Composition Example

Let:

$$ f(x)=x+1, \qquad g(x)=x^2. $$

Then:

$$ (g\circ f)(x) = (x+1)^2, $$

whereas:

$$ (f\circ g)(x) = x^2+1. $$

Image of a Set

If $S\subseteq A$, its image under $f$ is:

$$ \boxed{ f(S)=\{f(x):x\in S\} }. $$

Preimage

If $T\subseteq B$, the preimage of $T$ is:

$$ \boxed{ f^{-1}(T) = \{x\in A:f(x)\in T\} }. $$

This set notation makes sense even when $f$ has no inverse function.

Preimage vs. Inverse Function

The notation $f^{-1}(T)$ for a preimage does not require $f$ to be bijective. By contrast, $f^{-1}$ as an inverse function exists only under appropriate invertibility conditions.

Restriction of a Function

A function can be restricted to a smaller domain $S\subseteq A$:

$$ \boxed{ f|_S:S\to B }. $$

Restriction Can Make a Function Invertible

The function:

$$ f(x)=x^2 $$

is not injective on $\mathbb{R}$, but its restriction to:

$$ [0,\infty) $$

is injective and has inverse:

$$ \boxed{ f^{-1}(x)=\sqrt{x} }. $$

Function Equality

Two functions are equal only when their domains, codomains, and assignments agree under the adopted definition of function.

In particular, matching formulas alone may not be sufficient if the domains differ.

Example of Domain Difference

Consider:

$$ f(x)=\frac{x^2-1}{x-1}, \qquad x\neq1, $$

and:

$$ g(x)=x+1, \qquad x\in\mathbb{R}. $$

Their formulas agree wherever $f$ is defined, but their natural domains differ.

Functions Can Have Multiple Inputs

A function may accept an ordered pair:

$$ \boxed{ f:\mathbb{R}^2\to\mathbb{R} }. $$

For example:

$$ f(x,y)=x^2+y^2. $$

Functions Can Have Vector Outputs

A function may map:

$$ \boxed{ F:\mathbb{R}^2\to\mathbb{R}^3 }. $$

Functions are therefore not restricted to scalar inputs or outputs.

Sequence as a Function

A sequence can be viewed formally as a function whose domain is an index set, usually $\mathbb{N}$:

$$ \boxed{ a:\mathbb{N}\to S }. $$

The notation $a_n$ corresponds to the function value $a(n)$.

Finite Sequence

A finite sequence can similarly be viewed as a function on:

$$ \{1,2,\ldots,n\}. $$

Transformation as a Function

Geometric transformations are functions from a space to itself or another space:

$$ \boxed{ T:X\to X }. $$

Linear Transformation

A linear transformation is a function:

$$ T:V\to W $$

preserving vector addition and scalar multiplication:

$$ T(u+v)=T(u)+T(v), $$
$$ T(cv)=cT(v). $$

Probability Random Variable

Formally, a random variable is a function from a sample space into a numerical space, subject to appropriate measurability requirements:

$$ \boxed{ X:\Omega\to\mathbb{R} }. $$

Indicator Function

For a set $A$, an indicator function may be defined:

$$ \boxed{ \mathbf{1}_A(x)= \begin{cases} 1, & x\in A,\\ 0, & x\notin A. \end{cases} } $$

Characteristic Function Terminology

In some areas, the indicator function is called a characteristic function. In probability, however, characteristic function commonly refers to a Fourier-transform-based function associated with a probability distribution.

Function of a Function

In higher mathematics, functions themselves can be inputs to other functions or functionals.

Functional

A functional is commonly a mapping whose inputs are themselves functions and whose outputs are often scalars:

$$ \boxed{ J:\mathcal{F}\to\mathbb{R} }. $$

Operator

An operator is often a function between spaces of structured mathematical objects, especially functions or vectors.

Algorithm and Function

In computer science, the word function may refer to a callable program component. A mathematical function is defined by its input-output assignment, while a program may additionally involve computational procedures, state, or implementation details.

Pure Function

In programming terminology, a pure function more closely resembles the mathematical concept because the same input gives the same output and the operation has no relevant side effects.

Function vs. Formula

A formula is one way to describe a function. A function is the underlying assignment together with its domain and target context.

Function vs. Equation

An equation is a statement of equality. A function is an assignment rule.

The equation:

$$ y=2x+1 $$

can be used to describe the function:

$$ f(x)=2x+1. $$

Function vs. Relation

A relation permits more general pairings. A function requires exactly one output for each input in its domain.

Function vs. Mapping

Function and mapping are often synonyms. Some texts use mapping especially when emphasizing set-to-set structure.

Function vs. Transformation

A transformation is a function, usually one acting on geometric, algebraic, or structured objects.

Function vs. Operator

An operator is a specialized type of function, often acting on vectors, functions, or other structured objects.

Function vs. Sequence

A sequence is a special function whose domain consists of ordered indices, commonly natural numbers.

Function vs. Parameter

A parameter labels or controls members of a family, while a function assigns outputs to inputs. A parameter can itself be used as an input to a broader function.

Function vs. Variable

A variable is a symbol that can represent changing or unspecified values. A function is a relationship assigning outputs to inputs.

Function vs. Value

$f$ denotes the function; $f(x)$ denotes one value produced by that function.

$$ \boxed{ f \neq f(x) \text{ as types of mathematical objects} }. $$

Real-Valued Function

A function whose outputs are real numbers is called real-valued:

$$ f:A\to\mathbb{R}. $$

Real Function of a Real Variable

A common calculus setting is:

$$ \boxed{ f:\mathbb{R}\to\mathbb{R} }. $$

This is only one important special case of the general function concept.

Complex-Valued Function

$$ f:A\to\mathbb{C}. $$

Vector-Valued Function

$$ \boxed{ \mathbf{r}:I\to\mathbb{R}^n }. $$

Parametric curves are standard examples.

Boolean-Valued Function

Logic and computer science often use functions with outputs such as:

$$ \{\text{true},\text{false}\}. $$

Function Families

A collection of functions may depend on parameters:

$$ \boxed{ f_a(x)=ax+b }. $$

Fixing $a$ and $b$ selects one member of the family.

Parameterized Function

A parameterized family can also be viewed as a function of several inputs:

$$ F(a,b,x)=ax+b. $$

Function Iteration

A function may be applied repeatedly:

$$ f^{\circ2}(x)=f(f(x)). $$

More generally:

$$ \boxed{ f^{\circ n} = \underbrace{f\circ f\circ\cdots\circ f}_{n\text{ times}} }. $$

Iteration Notation vs. Exponentiation

Depending on context, $f^2$ can be ambiguous between pointwise squaring and composition with itself. The notation $f^{\circ2}$ makes iteration explicit.

Fixed Point

A fixed point of $f$ is an input satisfying:

$$ \boxed{ f(x)=x }. $$

Zeros of a Function

A zero or root is an input satisfying:

$$ \boxed{ f(x)=0 }. $$

Level Set

For a value $c$, the solutions to:

$$ f(x)=c $$

form a level set or fiber, depending on context.

Fiber

For $y$ in the codomain, the fiber over $y$ is:

$$ \boxed{ f^{-1}(\{y\}) = \{x:f(x)=y\} }. $$

Function Arithmetic

For numerical functions, new functions may be defined pointwise:

$$ (f+g)(x)=f(x)+g(x), $$
$$ (fg)(x)=f(x)g(x). $$

Function Quotient

Where $g(x)\neq0$:

$$ \boxed{ \left(\frac fg\right)(x) = \frac{f(x)}{g(x)} }. $$

Scalar Multiple

For scalar $c$:

$$ \boxed{ (cf)(x)=c\,f(x) }. $$

Calculus

Calculus studies properties and transformations of functions, including limits, continuity, derivatives, integrals, and differential equations.

Derivative as a New Function

If $f$ is differentiable on an interval, then:

$$ \boxed{ f':x\mapsto f'(x) } $$

is itself a function on the appropriate domain.

Integral-Defined Function

A function may be defined using accumulation:

$$ \boxed{ F(x)=\int_a^x f(t)\,dt }. $$

Functional Equation

A functional equation seeks unknown functions satisfying relations such as:

$$ \boxed{ f(x+y)=f(x)+f(y) }. $$

Here the unknown object is a function rather than merely a number.

Functions in Abstract Algebra

Structure-preserving functions include homomorphisms, isomorphisms, embeddings, and automorphisms.

Homomorphism

A homomorphism is a function preserving specified algebraic operations.

Isomorphism

An isomorphism is a bijective homomorphism whose inverse preserves the relevant structure.

Functions in Topology

Continuous functions preserve topological structure in a precise sense involving open sets or limits.

Homeomorphism

A homeomorphism is a bijective continuous function with continuous inverse.

Functions in Logic

Functions are foundational objects in formal semantics, models, operations, and interpretations of mathematical languages.

Functions in Set Theory

Functions support definitions of cardinal comparison, countability, products, choice principles, and transfinite constructions.

Cardinality and Bijections

Sets $A$ and $B$ have equal cardinality when there exists a bijection:

$$ \boxed{ f:A\to B }. $$

Common Error: Multiple Outputs for One Input

An assignment such as:

$$ 2\mapsto3 \quad\text{and}\quad 2\mapsto5 $$

cannot define a function unless $3=5$.

Common Error: Believing Outputs Must Be Unique

Different inputs are allowed to share outputs unless injectivity is explicitly required.

Common Error: Confusing Range and Codomain

The codomain is declared as part of the mapping, while the range consists only of values actually attained.

Common Error: Treating $f(x)$ as Multiplication

Function notation indicates evaluation, not multiplication by a variable.

Common Error: Confusing Inverse and Reciprocal

$$ \boxed{ f^{-1}(x) \neq \frac1{f(x)} } $$

in general.

Common Error: Ignoring the Domain

A formula does not fully specify a function when domain information materially changes the assignment or invertibility.

Common Error: Assuming Every Relation Is a Function

Relations may assign several outputs to one input. Functions may not.

Common Error: Assuming Every Function Has a Formula

Functions may be described by tables, algorithms, cases, mappings, graphs, or abstract existence conditions rather than a single elementary formula.

Common Misconception: A function is not merely an equation, formula, or graph. It is fundamentally an assignment from a domain to a codomain in which every input receives exactly one output. Different inputs may share an output, and the formula alone may not determine the complete function unless its domain and codomain are also understood.

Written vs. Spoken Syntax

Symbolic Notation (Written) Professional Articulation (Spoken)
$f:A\to B$ "F is a function from A to B."
$x\mapsto f(x)$ "X maps to f of x."
$f(x)$ "F of x."
$f(3)=7$ "F of three equals seven."
$(g\circ f)(x)=g(f(x))$ "G composed with f, evaluated at x, equals g of f of x."
$f^{-1}$ "F inverse."
$f|_S$ "The restriction of f to S."

A complete mapping declaration often has two complementary parts:

$$ \boxed{ f:A\to B, \qquad x\mapsto f(x) }. $$

The first specifies the source and target sets; the second describes the assignment.

Defense Notation Advice: Distinguish carefully between the function $f$ and a function value $f(x)$. State the domain when restrictions matter, distinguish codomain from range, and do not use $f^{-1}$ ambiguously when reciprocal notation might be confused with inverse-function notation. When composition order matters, write $(g\circ f)(x)=g(f(x))$ explicitly.

Case Usage & Field Variations

  • Definition: A function assigns each input in its domain exactly one output.
  • Mapping Notation: $$ \boxed{f:A\to B}. $$
  • Evaluation: $f(x)$ denotes the output assigned to $x$.
  • Domain: The set of admissible inputs.
  • Codomain: The declared target set.
  • Range: The set of outputs actually attained.
  • Range-Codomain Relation: $$ f(A)\subseteq B. $$
  • Function Rule: Every input has exactly one output.
  • Shared Outputs: Different inputs may have the same output.
  • Set-Theoretic Form: A function can be represented as a special set of ordered pairs.
  • Relation: Every function is a relation, but not every relation is a function.
  • Formula: One possible representation of a function.
  • Table: A finite or sampled input-output representation.
  • Graph: Represents ordered pairs $(x,f(x))$ in coordinate space.
  • Mapping Diagram: Displays arrows from domain elements to outputs.
  • Verbal Rule: A function may be defined entirely in words.
  • Algorithm: A computational process may determine function outputs.
  • Piecewise Definition: Different formulas may operate on different domain regions.
  • Natural Domain: All inputs for which a given formula is meaningful in the selected number system.
  • Polynomial Function: Has natural real domain $\mathbb{R}$.
  • Rational Function: Excludes denominator zeros.
  • Radical Function: Even roots impose nonnegativity conditions over $\mathbb{R}$.
  • Logarithmic Function: Real logarithm inputs must be positive.
  • Constant Function: Assigns the same output to every input.
  • Identity Function: $$ \operatorname{id}_A(x)=x. $$
  • Injective: Different inputs have different outputs.
  • One-to-One: Common synonym for injective.
  • Surjective: Every codomain element is attained.
  • Onto: Common synonym for surjective.
  • Bijective: Both injective and surjective.
  • Inverse Function: Reverses a bijective assignment.
  • Inverse Identity: $$ f^{-1}(f(x))=x. $$
  • Reciprocal Distinction: $f^{-1}$ does not generally mean $1/f$.
  • Composition: $$ (g\circ f)(x)=g(f(x)). $$
  • Composition Order: Generally noncommutative.
  • Restriction: $f|_S$ limits a function to a smaller domain.
  • Domain Restriction for Invertibility: Can turn a noninjective function into an injective one.
  • Image: $f(S)$ consists of outputs generated by inputs in $S$.
  • Preimage: $f^{-1}(T)$ consists of inputs mapped into $T$.
  • Preimage Caution: Does not require an inverse function.
  • Vertical Line Test: Tests whether a planar graph represents $y$ as a function of $x$.
  • Horizontal Line Test: Tests injectivity for real-valued graph contexts.
  • Independent Variable: Common elementary term for the input variable.
  • Dependent Variable: Common elementary term for an output determined by the input.
  • Sequence: A function whose domain is an ordered index set.
  • Finite Sequence: A function defined on finitely many consecutive indices.
  • Transformation: A function acting on geometric or structured objects.
  • Linear Transformation: A function preserving addition and scalar multiplication.
  • Homomorphism: A structure-preserving function between algebraic objects.
  • Isomorphism: A bijective structure-preserving correspondence.
  • Automorphism: An isomorphism from a structure to itself.
  • Homeomorphism: A topological equivalence defined by a continuous bijection with continuous inverse.
  • Random Variable: A measurable function from a probability sample space to a numerical space.
  • Indicator Function: Encodes set membership using numerical outputs such as $0$ and $1$.
  • Vector-Valued Function: Produces vectors rather than scalars.
  • Real-Valued Function: Has codomain contained in or declared as $\mathbb{R}$.
  • Complex-Valued Function: Produces complex-number outputs.
  • Multivariable Function: Accepts tuples such as $(x,y)$ as inputs.
  • Boolean Function: Produces truth values or binary outputs.
  • Functional: Often maps functions to scalars.
  • Operator: Specialized function acting on structured objects.
  • Function Family: A collection of related functions indexed by parameters.
  • Parameter: May select one member of a function family.
  • Iteration: Repeated composition of a function with itself.
  • Fixed Point: Satisfies $f(x)=x$.
  • Zero: Satisfies $f(x)=0$.
  • Fiber: Set of inputs sharing a specified output.
  • Level Set: Set of inputs satisfying $f(x)=c$.
  • Function Addition: $(f+g)(x)=f(x)+g(x)$.
  • Function Product: $(fg)(x)=f(x)g(x)$.
  • Function Quotient: $(f/g)(x)=f(x)/g(x)$ where $g(x)\neq0$.
  • Scalar Multiple: $(cf)(x)=cf(x)$.
  • Calculus: Limits, derivatives, and integrals are primarily operations and properties involving functions.
  • Derivative Function: Assigns each admissible input the instantaneous rate of change of $f$.
  • Integral-Defined Function: May assign accumulated change to each endpoint.
  • Functional Equation: An equation whose unknown is a function.
  • Set Theory: Functions are fundamental to cardinality, indexing, products, and constructions.
  • Cardinality: Bijections establish equality of set sizes.
  • Countability: A countably infinite set admits a bijection with $\mathbb{N}$.
  • Logic: Functions appear in structures, interpretations, and formal languages.
  • Computer Science: Programming functions are inspired by but not always identical to mathematical functions.
  • Pure Programming Function: Closely resembles deterministic mathematical input-output behavior.
  • Function vs. Formula: Formula is a representation; function is the assignment itself.
  • Function vs. Equation: Equation asserts equality; function assigns outputs.
  • Function vs. Relation: Functions satisfy the unique-output condition.
  • Function vs. Mapping: Usually synonymous.
  • Function vs. Transformation: Transformation is a contextual specialization of function.
  • Function vs. Sequence: Sequence is a function with a discrete ordered domain.
  • Function vs. Value: $f$ is the function; $f(x)$ is one output value.
  • Common Error: Assigning multiple outputs to one input.
  • Common Error: Assuming distinct inputs must always produce distinct outputs.
  • Common Error: Confusing range with codomain.
  • Common Error: Treating $f(x)$ as ordinary multiplication.
  • Common Error: Confusing inverse function with reciprocal.
  • Common Error: Ignoring domain restrictions.
  • Common Error: Assuming a function must be represented by a single algebraic formula.
  • Core Interpretation: A function is a well-defined assignment: $$ \boxed{ f:A\to B, \qquad x\mapsto f(x) } $$ in which every element of the domain $A$ receives exactly one output in the codomain $B$. Functions may be represented by formulas, tables, graphs, mappings, algorithms, or abstract rules, and the concept extends throughout mathematics to sequences, transformations, operators, random variables, homomorphisms, and other structured mappings.
