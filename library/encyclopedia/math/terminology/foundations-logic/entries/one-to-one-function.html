One-to-One Function

Subfield: Foundations & Logic

Etymology & Roots

A one-to-one function is a function in which distinct inputs always produce distinct outputs. Equivalently, no two different elements of the domain are mapped to the same value.

$$ \boxed{ x_1\neq x_2 \Longrightarrow f(x_1)\neq f(x_2) } $$

The standard formal synonym is injective function, and the corresponding property is called injectivity.

$$ \boxed{ \text{one-to-one} = \text{injective} } $$

The phrase one-to-one reflects the idea that each output produced by the function corresponds to only one input from the domain. The phrase does not mean that every possible output in the codomain must be used; that stronger requirement involves surjectivity.

The word injective comes from the idea of injecting or inserting distinct domain elements into the codomain without merging them.

A logically equivalent formulation is:

$$ \boxed{ f(x_1)=f(x_2) \Longrightarrow x_1=x_2 }. $$

This implication is often the most useful form for algebraic proofs.

Operational Nuance

Core Definition

A function:

$$ f:A\to B $$

is one-to-one if:

$$ \boxed{ f(a_1)=f(a_2) \Longrightarrow a_1=a_2 } $$

for every $a_1,a_2\in A$.

Contrapositive Form

Equivalently:

$$ \boxed{ a_1\neq a_2 \Longrightarrow f(a_1)\neq f(a_2) }. $$

Distinct Inputs Stay Distinct

Injectivity means the function does not merge two distinct domain elements into one output.

Mapping-Diagram Interpretation

In a mapping diagram, a one-to-one function never has two different domain arrows ending at the same codomain element.

Example

Let:

$$ f(x)=2x+3. $$

Suppose:

$$ f(a)=f(b). $$

Then:

$$ 2a+3=2b+3. $$

Subtracting $3$ and dividing by $2$ gives:

$$ a=b. $$

Therefore:

$$ \boxed{ f(x)=2x+3 \text{ is one-to-one} }. $$

Linear Function Criterion

A real affine function:

$$ f(x)=mx+b $$

is one-to-one on $\mathbb{R}$ exactly when:

$$ \boxed{ m\neq0 }. $$

Constant Function

A constant function:

$$ f(x)=c $$

on a domain containing more than one element is not one-to-one because different inputs share the same output.

Quadratic Example

The function:

$$ f(x)=x^2 $$

is not one-to-one on $\mathbb{R}$ because:

$$ f(2)=4 \qquad\text{and}\qquad f(-2)=4. $$

Thus:

$$ \boxed{ 2\neq-2 \quad\text{but}\quad f(2)=f(-2) }. $$

Domain Restriction Can Create Injectivity

Restricting:

$$ f(x)=x^2 $$

to:

$$ \boxed{ [0,\infty) } $$

makes it one-to-one.

Alternative Restriction

Restricting the same function to:

$$ (-\infty,0] $$

also makes it one-to-one.

Injectivity Depends on the Domain

One-to-one behavior is a property of the entire function, including its assigned domain, not merely of the algebraic formula.

$$ \boxed{ \text{same formula} + \text{different domain} \Longrightarrow \text{possibly different injectivity} }. $$

Horizontal Line Test

For a graph of a real-valued function, the horizontal line test provides a graphical test for one-to-one behavior.

$$ \boxed{ \text{every horizontal line intersects the graph at most once} \iff f\text{ is one-to-one} } $$

Why the Horizontal Line Test Works

A horizontal line:

$$ y=c $$

represents one output value. If it intersects the graph twice, then two distinct inputs produce the same output.

Vertical Line Test Is Different

The vertical line test determines whether a relation is a function:

$$ \boxed{ \text{vertical line test} \longrightarrow \text{function} } $$

while:

$$ \boxed{ \text{horizontal line test} \longrightarrow \text{one-to-one function} }. $$

Monotonicity

A strictly increasing function is one-to-one on its domain.

$$ \boxed{ x_1<x_2 \Longrightarrow f(x_1)<f(x_2) } $$

guarantees injectivity.

Strictly Decreasing Functions

Likewise:

$$ \boxed{ x_1<x_2 \Longrightarrow f(x_1)>f(x_2) } $$

guarantees injectivity.

Strict Monotonicity Criterion

$$ \boxed{ \text{strictly monotonic} \Longrightarrow \text{one-to-one} }. $$

Converse Caveat

Injectivity does not always imply monotonicity for arbitrary functions on arbitrary domains. Strict monotonicity is a sufficient criterion, not the universal definition.

Continuous Functions on Intervals

A continuous real-valued function on an interval that is one-to-one must be strictly monotonic on that interval.

Derivative Criterion

If a differentiable function satisfies:

$$ f'(x)>0 $$

throughout an interval, then it is strictly increasing there and hence one-to-one.

Negative Derivative Criterion

If:

$$ f'(x)<0 $$

throughout an interval, then the function is strictly decreasing and one-to-one.

Derivative Nonzero Caveat

A derivative being nonzero everywhere on an interval implies constant sign there when the derivative has the intermediate value property, so injectivity follows. But injectivity itself does not require $f'(x)$ to be nonzero at every point.

Example with Zero Derivative

The function:

$$ f(x)=x^3 $$

is one-to-one on $\mathbb{R}$ even though:

$$ f'(0)=0. $$

Inverse Function Connection

A function must be one-to-one in order for its inverse relation to be a function on its range.

$$ \boxed{ f\text{ one-to-one} \Longleftrightarrow f^{-1}\text{ is a function on }\operatorname{Ran}(f) }. $$

Why Injectivity Is Needed for an Inverse Function

If two inputs share one output:

$$ f(a)=f(b), \qquad a\neq b, $$

then reversing the correspondence would require one inverse input to produce two outputs, violating the definition of a function.

Inverse Function Equations

If $f$ is one-to-one, then on the appropriate domains:

$$ \boxed{ f^{-1}(f(x))=x } $$

and:

$$ \boxed{ f(f^{-1}(y))=y }. $$

Inverse Domain and Range

If:

$$ f:A\to B $$

is injective, then the inverse function naturally maps:

$$ \boxed{ f^{-1}:f(A)\to A }. $$

Injective but Not Surjective

A function can be one-to-one without using every element of its codomain.

For example:

$$ f:\mathbb{R}\to\mathbb{R}, \qquad f(x)=e^x. $$

This function is one-to-one, but its range is:

$$ (0,\infty), $$

so it is not onto $\mathbb{R}$.

Surjective but Not Injective

A function may use every codomain value but still assign some value to multiple inputs.

Bijective Function

A function that is both one-to-one and onto is called:

$$ \boxed{ \text{bijective} }. $$

Bijective Criterion

$$ \boxed{ \text{bijective} = \text{injective} + \text{surjective} }. $$

Injectivity and the Codomain

Unlike surjectivity, injectivity is primarily controlled by whether different domain elements collide. Enlarging the codomain without changing the mapping does not destroy injectivity.

Finite-Set Cardinality

If:

$$ f:A\to B $$

is injective and $A$ and $B$ are finite, then:

$$ \boxed{ |A|\leq|B| }. $$

Pigeonhole Principle Connection

If a finite domain has more elements than the codomain:

$$ |A|>|B|, $$

then no function:

$$ f:A\to B $$

can be one-to-one.

Equal Finite Cardinalities

If $A$ and $B$ are finite with:

$$ |A|=|B|, $$

then:

$$ \boxed{ f:A\to B\text{ injective} \iff f\text{ surjective} }. $$

Infinite Sets Behave Differently

For infinite sets, an injective map from a set to a proper subset can exist.

For example:

$$ f:\mathbb{N}\to\mathbb{N}, \qquad f(n)=n+1 $$

is injective even though $1$ is not in its range.

Composition of Injective Functions

If:

$$ f:A\to B $$

and:

$$ g:B\to C $$

are both injective, then:

$$ \boxed{ g\circ f \text{ is injective} }. $$

Proof of Composition Rule

Suppose:

$$ g(f(a))=g(f(b)). $$

Since $g$ is injective:

$$ f(a)=f(b). $$

Since $f$ is injective:

$$ a=b. $$

Composition Converse: Inner Function

If:

$$ g\circ f $$

is injective, then $f$ must be injective.

$$ \boxed{ g\circ f\text{ injective} \Longrightarrow f\text{ injective} }. $$

Outer Function Need Not Be Globally Injective

From injectivity of $g\circ f$, one cannot conclude that $g$ is injective on all of its domain. It need only behave injectively on the range of $f$.

Left Inverse Criterion

If a function $f:A\to B$ has a left inverse:

$$ g\circ f = \operatorname{id}_A, $$

then $f$ is injective.

$$ \boxed{ \text{left inverse} \Longrightarrow \text{injective} }. $$

Set-Theoretic Converse

An injective function admits a left inverse after defining suitable values outside its range when the codomain structure permits such a choice; on its range, the inverse correspondence is already uniquely determined.

Identity Function

The identity function:

$$ \operatorname{id}_A(x)=x $$

is always one-to-one.

Absolute-Value Function

The function:

$$ f(x)=|x| $$

is not one-to-one on $\mathbb{R}$ because:

$$ |a|=|-a| $$

for nonzero $a$.

Exponential Function

For $a>0$ and $a\neq1$:

$$ f(x)=a^x $$

is one-to-one on $\mathbb{R}$.

Logarithmic Function

For $a>0$ and $a\neq1$:

$$ f(x)=\log_a x $$

is one-to-one on:

$$ (0,\infty). $$

Sine Function

The sine function is not one-to-one on all of $\mathbb{R}$ because it is periodic.

Restricted Sine

Restricting sine to:

$$ \boxed{ \left[ -\frac{\pi}{2}, \frac{\pi}{2} \right] } $$

makes it one-to-one and allows the inverse sine function to be defined.

Cosine Restriction

Cosine is commonly restricted to:

$$ \boxed{ [0,\pi] } $$

to define the principal inverse cosine function.

Tangent

Tangent is one-to-one on:

$$ \boxed{ \left( -\frac{\pi}{2}, \frac{\pi}{2} \right) } $$

and this interval is used to define the principal inverse tangent.

Periodic Functions

A nonconstant periodic function cannot be one-to-one on all of $\mathbb{R}$ because:

$$ f(x+T)=f(x) $$

for some nonzero period $T$.

Polynomial Functions

A polynomial of even degree cannot be one-to-one on all of $\mathbb{R}$ because its end behavior goes in the same vertical direction at both ends.

Odd-Degree Polynomials

An odd-degree polynomial may be one-to-one, but odd degree alone does not guarantee injectivity.

Example

The polynomial:

$$ f(x)=x^3 $$

is injective, while:

$$ g(x)=x^3-x $$

is not injective on all of $\mathbb{R}$.

Algebraic Test Strategy

To prove a formula is one-to-one:

  1. assume $f(a)=f(b)$;
  2. use valid algebraic steps;
  3. show that $a=b$.

Counterexample Strategy

To prove a function is not one-to-one, it is enough to find:

$$ \boxed{ a\neq b \quad\text{with}\quad f(a)=f(b) }. $$

One Counterexample Is Sufficient

Injectivity is a universal claim. A single collision of distinct inputs disproves it.

Relation Viewpoint

Every function is a relation in which each input occurs with exactly one output. Injectivity adds the reverse uniqueness condition: each produced output corresponds to at most one input.

Inverse Relation

Swapping coordinates in the graph of a one-to-one function produces the graph of its inverse function.

$$ (x,y) \longleftrightarrow (y,x). $$

Graph Reflection

The graphs of a one-to-one function and its inverse are reflections of each other across:

$$ \boxed{ y=x }. $$

Linear Transformation Interpretation

A linear transformation:

$$ T:V\to W $$

is one-to-one exactly when:

$$ \boxed{ \ker(T)=\{\mathbf{0}\} }. $$

Matrix Criterion

For:

$$ T(\mathbf{x})=A\mathbf{x}, $$

injectivity is equivalent to:

$$ \boxed{ A\mathbf{x}=\mathbf{0} \Longrightarrow \mathbf{x}=\mathbf{0} }. $$

Column Independence

A matrix transformation is one-to-one exactly when its columns are linearly independent.

Full Column Rank

For an $m\times n$ matrix:

$$ \boxed{ T_A\text{ injective} \iff \operatorname{rank}(A)=n }. $$

Square-Matrix Case

For a square matrix $A$:

$$ \boxed{ T_A\text{ one-to-one} \iff A\text{ invertible} }. $$

Rank-Nullity Connection

For finite-dimensional $V$:

$$ \dim V = \operatorname{rank}(T) + \operatorname{nullity}(T). $$

Injectivity means:

$$ \boxed{ \operatorname{nullity}(T)=0 }. $$

Information-Preservation Interpretation

An injective transformation preserves enough information to distinguish every input from every other input.

No Collisions

In computer science and data structures, the intuitive phrase no collisions captures the injective idea: distinct keys or inputs are assigned distinct outputs.

Hash-Function Caveat

Ordinary hash functions usually map a very large input space into a smaller output space, so they cannot be injective over the full input space by the pigeonhole principle.

Encoding

A reversible encoding must be injective on the set of permitted inputs; otherwise two different inputs would share the same encoded representation.

Database Keys

A unique identifier behaves injectively with respect to the records it identifies: distinct records must not share the same identifier.

One-to-One Correspondence

The phrase one-to-one correspondence usually means more than one-to-one function: it generally refers to a bijection.

$$ \boxed{ \text{one-to-one correspondence} \approx \text{bijection} }. $$

Terminology Warning

Thus one-to-one function means injective, while one-to-one correspondence conventionally means both injective and surjective.

One-to-One vs. Onto

One-to-one controls duplication of outputs:

$$ \boxed{ \text{no two domain elements share an output} }. $$

Onto controls coverage of the codomain:

$$ \boxed{ \text{every codomain element is reached} }. $$

One-to-One vs. Bijective

Injective means no collisions. Bijective means no collisions and no unused codomain elements.

One-to-One vs. Inverse

A function can be one-to-one even before an inverse function is explicitly written. Injectivity is the property that makes the inverse relation single-valued on the range.

One-to-One vs. Increasing

Strictly increasing implies one-to-one, but the terms are not synonyms.

One-to-One vs. Nonconstant

Every injective function on a multi-element domain is nonconstant, but many nonconstant functions are not injective.

Example

The function:

$$ f(x)=x^2 $$

is nonconstant but not one-to-one on $\mathbb{R}$.

Common Error: Confusing One-to-One with Being a Function

Every input having one output is the definition of a function. One-to-one adds the requirement that different inputs not share an output.

Common Error: Using the Vertical Line Test

The vertical line test checks function status, not injectivity.

Common Error: Confusing One-to-One with Onto

A one-to-one function may leave many codomain elements unused.

Common Error: Assuming Every Function Has an Inverse Function

A noninjective function's inverse relation is not a function unless the original domain is suitably restricted.

Common Error: Ignoring the Domain

The formula $x^2$ is not injective on $\mathbb{R}$ but is injective on $[0,\infty)$.

Common Error: Checking Only Nearby Inputs

Injectivity is global over the entire stated domain.

Common Error: Assuming a Nonzero Derivative Is Necessary

The function $x^3$ is injective even though its derivative equals zero at the origin.

Common Error: Assuming Odd Degree Guarantees Injectivity

Odd-degree polynomials can turn and repeat output values.

Common Error: Assuming Periodic Functions Can Be Globally Injective

A nonconstant periodic function repeats output values after every period.

Common Error: Reversing the Definition Incorrectly

Injectivity says:

$$ f(a)=f(b) \Longrightarrow a=b. $$

The statement:

$$ a=b \Longrightarrow f(a)=f(b) $$

is true for every function and therefore does not test injectivity.

Common Error: Assuming Different Outputs Imply Different Inputs Is a New Criterion

The useful contrapositive criterion is:

$$ a\neq b \Longrightarrow f(a)\neq f(b). $$

The implication:

$$ f(a)\neq f(b) \Longrightarrow a\neq b $$

is automatically true for every function and does not establish injectivity.

Common Error: Treating a Few Examples as Proof

Checking several input-output pairs cannot prove injectivity over an infinite domain.

Common Error: Forgetting Codomain Language in Finite Sets

If a finite domain has more elements than the codomain, injectivity is impossible.

Common Error: Calling a One-to-One Function a One-to-One Correspondence

The latter phrase normally implies bijectivity.

Common Error: Assuming Injectivity Means Every Output Has Exactly One Preimage

Injectivity guarantees at most one preimage for each codomain element. Elements outside the range have none.

Common Error: Forgetting Range vs. Codomain

Every value in the range of an injective function has exactly one preimage, but a codomain element outside the range has zero preimages.

Common Misconception: "One-to-one" does not mean merely that each input has one output; that is already required of every function. A function is one-to-one only when different inputs cannot produce the same output. Formally, $f(a)=f(b)$ must force $a=b$. This no-collision property is what allows the function to be reversed uniquely on its range.

Written vs. Spoken Syntax

Symbolic Notation (Written) Professional Articulation (Spoken)
$f(a)=f(b)\Rightarrow a=b$ "If f of a equals f of b, then a equals b; therefore f is one-to-one."
$a\neq b\Rightarrow f(a)\neq f(b)$ "Distinct inputs produce distinct outputs."
$f:A\to B$ injective "F from A to B is injective," or "F is one-to-one."
$f^{-1}:f(A)\to A$ "The inverse function maps the range of f back to the original domain."
$\ker(T)=\{\mathbf{0}\}$ "The linear transformation is one-to-one because its kernel is trivial."
$\operatorname{rank}(A)=n$ "The matrix has full column rank, so the associated transformation is injective."
$|A|\leq|B|$ "For finite sets, an injection from A into B requires A to have no more elements than B."

The informal phrase "no repeated outputs" is often useful, but it should be interpreted carefully: repeated outputs are forbidden only when they come from distinct inputs.

The standard proof language is:

$$ \boxed{ \text{"Assume }f(a)=f(b)\text{ and show that }a=b\text{."} } $$

The term injective is especially common in higher mathematics, while one-to-one is common in algebra, precalculus, and introductory function study.

Defense Notation Advice: Use the implication $f(a)=f(b)\Rightarrow a=b$ when proving injectivity algebraically. Do not reverse it into $a=b\Rightarrow f(a)=f(b)$, because that statement holds for every function. State the domain explicitly when restrictions affect injectivity. Use one-to-one correspondence only when bijectivity is intended, and distinguish the horizontal line test for injectivity from the vertical line test for function status.
