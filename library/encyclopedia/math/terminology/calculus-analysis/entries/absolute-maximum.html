Absolute Maximum

Subfield: Calculus & Analysis

Etymology & Roots

An absolute maximum is the greatest value attained by a function over a specified domain.

$$ \boxed{ f(c)\geq f(x) \text{ for every }x\text{ in the domain} } $$

When this condition holds, $f(c)$ is the absolute maximum value and $c$ is a point at which the absolute maximum is attained. The word absolute emphasizes comparison with the entire relevant domain rather than merely nearby inputs.

Operational Nuance

Global Comparison

The defining condition is global:

$$ \boxed{ f(c)\geq f(x) \quad \forall x\in D }. $$

Thus the domain $D$ is part of the statement. Changing the domain can change the absolute maximum.

Maximum Value vs. Maximum Point

If $f(c)$ is largest, then $c$ is a maximizing input while $f(c)$ is the maximum value. These should not be confused.

Example

$$ f(x)=4-x^2, \qquad -3\leq x\leq3. $$

Since:

$$ \boxed{ f(0)=4 } $$

and no other value on the interval exceeds $4$, the absolute maximum value is $4$ at $x=0$.

Absolute vs. Local Maximum

A local maximum need only dominate sufficiently nearby values. An absolute maximum must dominate every function value in the stated domain.

Closed-Interval Method

For a continuous function on a closed interval $[a,b]$, absolute extrema can be found by comparing function values at critical points and endpoints:

$$ \boxed{ a,\ b,\ \text{and interior critical points} }. $$

The largest resulting value is the absolute maximum.

Extreme Value Theorem

If $f$ is continuous on a closed bounded interval $[a,b]$, then $f$ attains both an absolute maximum and an absolute minimum on that interval.

Derivative Clues

Interior absolute extrema of differentiable functions often occur where:

$$ f'(x)=0 $$

or where the derivative fails to exist. These are candidates, not automatic absolute maxima.

Maximum Need Not Exist

A function can be bounded above without attaining its least upper bound. For example, on $0<x<1$:

$$ f(x)=x $$

has supremum $1$ but no absolute maximum because $x=1$ is not in the domain.

Multiple Maximizers

The same absolute maximum value can occur at more than one input. The maximum value is unique as a number, but the maximizing points need not be unique.

Common Misconception

The highest visible point on a partial graph is not automatically an absolute maximum. The entire stated domain must be considered.

Written vs. Spoken Syntax

Symbolic Notation (Written) Professional Articulation (Spoken)
$f(c)\geq f(x)$ for all $x\in D$ "F of c is an absolute maximum value on D."
$\max_{x\in D}f(x)$ "The maximum value of f over D."
$f(0)=4$ "The absolute maximum value is four at x equals zero."
$f'(c)=0$ "C is a critical-point candidate."
$\sup f(D)$ "The supremum of the function values."
$c\in\operatorname*{arg\,max}_{x\in D}f(x)$ "C is a maximizing input."

Absolute maximum and global maximum are commonly used as synonyms. Some authors distinguish carefully between the maximum value and the point where that value is attained.

Defense Notation Advice: State the domain, distinguish the maximizing input from the maximum output value, and compare endpoints as well as interior critical points when working on a closed interval.

Case Usage & Field Variations

  • Core Definition: $f(c)\geq f(x)$ for every $x$ in the specified domain.
  • Synonym: Global maximum.
  • Maximum Value: The largest attained output value.
  • Maximizer: An input at which the maximum value is attained.
  • Local Contrast: A local maximum compares only nearby inputs.
  • Closed Intervals: Compare endpoints and interior critical points.
  • Extreme Value Theorem: Guarantees attainment for continuous functions on closed bounded intervals.
  • Optimization: Absolute maxima represent globally best feasible objective values in maximization problems.
  • Multiple Maximizers: Several inputs may share the same absolute maximum value.
  • Supremum: A least upper bound need not be attained and therefore need not be a maximum.
  • Multivariable Calculus: Absolute maxima are defined by comparison over the entire feasible region.
  • Common Error: Assuming every critical point is an absolute maximum.
  • Common Error: Ignoring endpoints.
  • Common Error: Confusing a local maximum with a global maximum.
  • Common Error: Calling a supremum an absolute maximum when the value is never attained.
  • Core Interpretation: An absolute maximum is the greatest function value actually reached on the stated domain: $$ \boxed{ f(c)=\max_{x\in D}f(x) }. $$ It is therefore a global comparison concept central to extrema, optimization, graph analysis, and calculus.
