Global Maximum

Subfield: Calculus & Analysis

Etymology & Roots

A global maximum is the greatest value attained by a function over its entire stated domain or feasible set. It is also commonly called an absolute maximum.

$$ \boxed{ f(c)\geq f(x) \quad\text{for every }x\in D } $$

The adjective global emphasizes comparison with all permitted inputs, rather than only with nearby points.

Operational Nuance

Definition

If $c\in D$ and:

$$ \boxed{ f(c)=\max_{x\in D}f(x) }, $$

then $f(c)$ is the global maximum value and $c$ is a point where that maximum is attained.

Global vs. Local Maximum

A local maximum only dominates nearby values. A global maximum dominates all values in the domain:

$$ \boxed{ \text{global comparison} \Longrightarrow \text{entire domain}, \qquad \text{local comparison} \Longrightarrow \text{neighborhood} }. $$

Attainment Matters

A function can be bounded above without possessing a global maximum. For example, $f(x)=x$ on $(0,1)$ has supremum $1$, but no input in the domain produces the value $1$.

Critical Points and Endpoints

On a closed interval, global maxima are found among relevant critical numbers and endpoints:

$$ \boxed{ \text{critical numbers} + \text{endpoints} \longrightarrow \text{compare function values} }. $$

Extreme Value Theorem

If $f$ is continuous on a closed bounded interval $[a,b]$, then the Extreme Value Theorem guarantees that a global maximum is attained.

Uniqueness

The maximum value is unique as a number, but it may be attained at more than one input. Thus several points can all be global maximizers.

Common Misconception

A point where $f'(c)=0$ is only a candidate for a maximum. Global maximality requires comparison with the entire domain.

Written vs. Spoken Syntax

Symbolic Notation (Written) Professional Articulation (Spoken)
$f(c)=\max_{x\in D}f(x)$ "F of c is the global maximum value on D."
$f(c)\geq f(x)$ for all $x\in D$ "F of c is at least as large as every value of f on the domain."
$c\in\operatorname*{arg\,max}_{x\in D}f(x)$ "C is a global maximizer."
$\max f$ "The maximum attained value of f."
$\sup f$ "The supremum, which need not be attained."
$f'(c)=0$ "C is a stationary candidate, not automatically a global maximum."

Global maximum and absolute maximum are standard synonyms. The input attaining the value may be called a global maximizer.

Defense Notation Advice: Distinguish the maximizing input $c$ from the maximum value $f(c)$, and distinguish $\max$ from $\sup$ when the upper bound may not be attained.

Case Usage & Field Variations

  • Core Meaning: A global maximum is the greatest value attained over the entire specified domain.
  • Absolute Maximum: Standard synonym for global maximum.
  • Global Maximizer: An input at which the maximum value is attained.
  • Multiple Maximizers: Several inputs may attain the same global maximum value.
  • Closed Intervals: Compare critical-point values and endpoint values.
  • Open Domains: A supremum may exist without any global maximum being attained.
  • Optimization: A global maximum represents the best feasible objective value in a maximization problem.
  • Multivariable Calculus: Global maxima may occur at interior critical points or on the boundary of the feasible region.
  • Compact Domains: A continuous real-valued function on a compact set attains a global maximum.
  • Common Error: Confusing a local maximum with a global maximum.
  • Common Error: Assuming the largest visible value on a graphing window is necessarily global.
  • Common Error: Equating the supremum with the maximum when the upper bound is not attained.
  • Common Error: Treating every solution of $f'(x)=0$ as a global maximizer.
  • Core Interpretation: A global maximum is an attained upper extreme: $$ \boxed{ f(c) \geq f(x) \quad \text{for every permitted }x }. $$ Its defining feature is comparison over the whole domain, not merely nearby behavior.
