Bounded Function

Subfield: Calculus & Analysis

Etymology & Roots

A bounded function is a function whose output values remain within fixed limits over the domain being considered.

$$ \boxed{ |f(x)|\leq M \quad \text{for all }x\in D } $$

for some real number $M\geq0$. The word bounded refers to the existence of numerical barriers beyond which the function values do not pass.

Operational Nuance

Bounded Above

A function is bounded above on $D$ if there exists a number $U$ such that:

$$ \boxed{ f(x)\leq U \quad \forall x\in D }. $$

Bounded Below

A function is bounded below on $D$ if there exists a number $L$ such that:

$$ \boxed{ f(x)\geq L \quad \forall x\in D }. $$

Bounded on Both Sides

A real-valued function is bounded when it is both bounded above and bounded below:

$$ \boxed{ L\leq f(x)\leq U }. $$

Example

The sine function satisfies:

$$ \boxed{ -1\leq\sin x\leq1 } $$

for every real $x$, so $\sin x$ is bounded on $\mathbb{R}$.

Unbounded Example

The function:

$$ f(x)=x^2 $$

is bounded below by $0$ on $\mathbb{R}$ but is not bounded above.

Domain Dependence

Boundedness depends on the domain. Although $x^2$ is unbounded on $\mathbb{R}$, it is bounded on any finite closed interval such as $[-2,3]$.

Supremum and Infimum

For a bounded real-valued function, the set of outputs may have a supremum and infimum:

$$ \boxed{ \inf f(D) \leq f(x) \leq \sup f(D) }. $$

These bounds need not actually be attained by the function.

Bounded Does Not Mean Maximum Exists

On $0<x<1$, the function $f(x)=x$ is bounded, but it has neither an absolute maximum nor an absolute minimum on that open interval.

Continuous Functions on Closed Intervals

By the Extreme Value Theorem, every continuous real-valued function on a closed bounded interval $[a,b]$ is bounded and attains both its maximum and minimum.

Common Misconception

A bounded function does not have to be constant, nor does boundedness guarantee that the upper or lower bound is reached.

Written vs. Spoken Syntax

Symbolic Notation (Written) Professional Articulation (Spoken)
$|f(x)|\leq M$ "F is bounded in magnitude by M."
$f(x)\leq U$ "F is bounded above by U."
$f(x)\geq L$ "F is bounded below by L."
$L\leq f(x)\leq U$ "The function values lie between L and U."
$\sup f(D)$ "The supremum of the range values."
$\inf f(D)$ "The infimum of the range values."

The phrase bounded on $D$ is more precise than simply saying bounded, because changing the domain can change whether the property holds.

Defense Notation Advice: State the domain and distinguish bounded above, bounded below, and bounded. Do not confuse a bound with a maximum or minimum unless the function actually attains it.

Case Usage & Field Variations

  • Core Definition: A function is bounded when its values remain between fixed finite bounds.
  • Bounded Above: There exists $U$ with $f(x)\leq U$ throughout the domain.
  • Bounded Below: There exists $L$ with $f(x)\geq L$ throughout the domain.
  • Two-Sided Form: Equivalent for real-valued functions to $|f(x)|\leq M$ for some $M$.
  • Domain Dependence: A function may be bounded on one domain and unbounded on another.
  • Supremum: The least upper bound need not be attained.
  • Infimum: The greatest lower bound need not be attained.
  • Continuous Functions: Continuity on a closed bounded interval guarantees boundedness.
  • Sequences: A sequence may be viewed as a function on the positive integers and can likewise be bounded.
  • Analysis: Boundedness is central to convergence, compactness, integration, and function-space theory.
  • Common Error: Assuming bounded means the function has a maximum and minimum.
  • Common Error: Forgetting to specify the domain.
  • Common Error: Calling a function bounded merely because it is bounded on one side.
  • Common Error: Confusing a numerical bound with a point where the function attains that value.
  • Core Interpretation: Boundedness means that the function's outputs remain confined within a finite vertical band: $$ \boxed{ L\leq f(x)\leq U \quad \forall x\in D }. $$ It is a domain-dependent property that connects elementary graph behavior with deeper ideas involving extrema, supremum, infimum, convergence, and analysis.
