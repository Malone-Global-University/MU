Hole

Subfield: Calculus & Analysis

Etymology & Roots

A hole is an informal graphical term for a missing point on an otherwise continuous-looking curve. In calculus, it most commonly represents a removable discontinuity.

$$ \boxed{ \lim_{x\to a}f(x)=L \quad\text{but}\quad f(a)\neq L \text{ or }f(a)\text{ is undefined} } $$

The word comes from ordinary geometric language: the graph appears to have a point removed from a location where the surrounding curve would otherwise pass.

Operational Nuance

Removable Discontinuity

A hole occurs when nearby values approach a finite limit but the function does not take that limiting value at the point.

$$ \boxed{ \lim_{x\to a}f(x)=L } $$

If assigning $f(a)=L$ would make the function continuous at $a$, the discontinuity is removable.

Rational-Function Example

Consider:

$$ f(x)=\frac{x^2-1}{x-1}. $$

For $x\neq1$:

$$ f(x) = \frac{(x-1)(x+1)}{x-1} = x+1. $$

The original function is still undefined at $x=1$, so its graph is the line $y=x+1$ with a hole at $(1,2)$.

Cancellation Does Not Restore the Domain

Algebraic cancellation produces an equivalent expression only where the original denominator was nonzero:

$$ \boxed{ \frac{(x-a)g(x)}{x-a} = g(x) \qquad \text{for }x\neq a }. $$

The restriction $x\neq a$ must be retained unless the function is explicitly redefined at $a$.

Hole vs. Vertical Asymptote

A hole has finite limiting behavior. A vertical asymptote instead involves unbounded behavior from at least one side.

$$ \boxed{ \text{hole: finite limit} \qquad \text{vertical asymptote: unbounded behavior} } $$

Open-Circle Notation

On a graph, a hole is usually marked with an open circle at the excluded point. The open circle indicates that the point shown is not included in the graph of the function at that input.

Redefined Point

If the missing value is filled in with the limiting value, the hole disappears and continuity is restored:

$$ \boxed{ f(a):=L } $$

Common Misconception

A hole is not simply any undefined point. An undefined point associated with a vertical asymptote or more complicated limiting failure is not a removable hole.

Written vs. Spoken Syntax

Symbolic Notation (Written) Professional Articulation (Spoken)
$f(a)$ undefined "The function is not defined at a."
$\lim_{x\to a}f(x)=L$ "The function approaches L as x approaches a."
$f(a)\neq L$ "The function value does not match the limiting value."
$(a,L)$ open circle "The graph has a hole at a comma L."
$x\neq a$ "A is excluded from the domain."
$f(a):=L$ "Define f of a to equal L to remove the discontinuity."

Hole is common classroom and graphical language. In formal analysis, removable discontinuity is usually the more precise term.

Defense Notation Advice: After canceling common factors, preserve all restrictions inherited from the original expression. Simplification changes the formula's appearance, not automatically the original function's domain.

Case Usage & Field Variations

  • Core Meaning: A hole is a missing graph point associated with removable discontinuity behavior.
  • Finite Limit: Nearby function values approach a definite finite value at the hole.
  • Undefined Value: The function may be undefined at the input where the hole occurs.
  • Mismatched Value: A function can also have a removable discontinuity when $f(a)$ exists but differs from the limiting value.
  • Rational Functions: Canceled denominator factors frequently reveal holes.
  • Domain Restrictions: A canceled factor does not erase the original excluded input.
  • Graphing: Open circles conventionally indicate omitted points.
  • Continuity: Filling the hole with the limiting value restores continuity at that point.
  • Limit Analysis: A hole illustrates that a limit can exist even when the function itself is undefined at the limiting point.
  • Vertical-Asymptote Contrast: A vertical asymptote is nonremovable and involves unbounded behavior rather than a finite missing value.
  • Piecewise Functions: A deliberately omitted or mismatched point value can create a hole even without a rational expression.
  • Common Error: Substituting an excluded input into a simplified formula and claiming it was part of the original function.
  • Common Error: Calling every denominator zero a hole.
  • Common Error: Confusing an open-circle endpoint with a removable discontinuity when the surrounding domain does not approach the point from the required directions.
  • Core Interpretation: A hole separates limiting behavior from actual point membership: $$ \boxed{ \text{nearby values approach }L \quad\text{but}\quad (a,L)\text{ is missing from the graph} }. $$ It is the graphical signature of a discontinuity that can be repaired by assigning the appropriate point value.
