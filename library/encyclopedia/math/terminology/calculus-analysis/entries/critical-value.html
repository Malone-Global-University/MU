Critical Value

Subfield: Calculus & Analysis

Etymology & Roots

In calculus, a critical value commonly means the function value produced at a critical number. If $c$ is a critical number of $f$, then the associated critical value is $f(c)$.

$$ \boxed{ c\text{ critical} \quad\Longrightarrow\quad f(c)\text{ is a critical value} } $$

The adjective critical indicates a location or value requiring special attention because ordinary local behavior may change there. Terminology varies, however, and some elementary texts use critical value for the input $c$ itself rather than for the output $f(c)$.

Operational Nuance

Critical Number First

For a real-valued function $f$, an interior domain point $c$ is commonly called a critical number when:

$$ \boxed{ f'(c)=0 \quad\text{or}\quad f'(c)\text{ does not exist} } $$

provided $f(c)$ itself is defined. The corresponding output is then $f(c)$.

Example

For:

$$ f(x)=x^2-4x+7, $$

we have:

$$ f'(x)=2x-4, \qquad f'(2)=0. $$

Thus $c=2$ is a critical number and:

$$ \boxed{ f(2)=3 } $$

is the associated critical value under the input-output distinction.

Critical Does Not Mean Extreme

A critical number is only a candidate for a local maximum or minimum. For example, $f(x)=x^3$ has $f'(0)=0$, but $x=0$ is not a local extremum.

Relation to Critical Points

The point on the graph corresponding to a critical number $c$ is:

$$ \boxed{ (c,f(c)) }. $$

This is often called a critical point.

Terminology Warning

Different textbooks use critical number, critical point, and critical value inconsistently. Always inspect whether the author means an input $c$, an output $f(c)$, or the ordered pair $(c,f(c))$.

Statistics Uses a Different Meaning

In hypothesis testing, critical value usually means a cutoff in the distribution of a test statistic that separates rejection and nonrejection regions. That statistical use is distinct from the calculus meaning.

Common Misconception

Solving $f'(x)=0$ finds candidate input locations. It does not by itself identify maximum or minimum values, and it does not automatically produce the function's critical output values until those inputs are substituted back into $f$.

Written vs. Spoken Syntax

Symbolic Notation (Written) Professional Articulation (Spoken)
$f'(c)=0$ "The derivative is zero at c."
$f'(c)$ undefined "The derivative does not exist at c."
$c$ "A critical number, under the standard input convention."
$f(c)$ "The corresponding critical value."
$(c,f(c))$ "The corresponding critical point on the graph."
$f''(c)>0$ "The second derivative is positive at c, supporting a local minimum classification."

Defense Notation Advice: State explicitly whether critical value means the input, output, or statistical cutoff in the source being used. In calculus work, distinguishing $c$, $f(c)$, and $(c,f(c))$ prevents terminology from obscuring the mathematics.

Case Usage & Field Variations

  • Calculus Output Meaning: A critical value may mean $f(c)$ where $c$ is a critical number.
  • Textbook Variation: Some authors instead call the input $c$ a critical value.
  • Critical Number: Commonly an interior domain value where $f'=0$ or $f'$ fails to exist.
  • Critical Point: Often the graph point $(c,f(c))$.
  • Optimization: Critical numbers provide candidates for local and absolute extrema.
  • First-Derivative Test: A sign change in $f'$ can classify a critical number as a local maximum or minimum.
  • Second-Derivative Test: When applicable, the sign of $f''(c)$ can help classify a stationary critical number.
  • Nonextreme Case: A critical number can occur without producing a local maximum or minimum.
  • Nondifferentiable Case: Corners, cusps, and certain vertical tangencies can produce critical numbers when the function is defined there.
  • Statistics: A critical value is instead a decision threshold associated with a test statistic and significance level.
  • Common Error: Calling every solution of $f'(x)=0$ a maximum or minimum.
  • Common Error: Reporting the critical input when the problem asks for the corresponding function value.
  • Common Error: Ignoring points where the derivative is undefined but the function itself is defined.
  • Core Interpretation: Under the input-output distinction used in calculus: $$ \boxed{ \text{critical number }c \longrightarrow \text{critical value }f(c) \longrightarrow \text{critical point }(c,f(c)) }. $$ Because terminology varies across textbooks and fields, the mathematical object intended by the phrase should always be identified from context.
