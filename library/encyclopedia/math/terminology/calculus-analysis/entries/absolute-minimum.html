Absolute Minimum

Subfield: Calculus & Analysis

Etymology & Roots

An absolute minimum is the least value attained by a function over a specified domain.

$$ \boxed{ f(c)\leq f(x) \text{ for every }x\text{ in the domain} }. $$

The word absolute emphasizes comparison with the entire relevant domain, distinguishing the concept from a merely local minimum.

Operational Nuance

Global Comparison

If $D$ is the domain under consideration, then $f(c)$ is an absolute minimum when:

$$ \boxed{ f(c)\leq f(x) \quad \forall x\in D }. $$

Minimum Value vs. Minimizer

The input $c$ is a minimizer, while $f(c)$ is the minimum value. More than one input may attain the same minimum.

Example

$$ f(x)=x^2+1, \qquad -2\leq x\leq3. $$

Since $f(0)=1$ and no value on the interval is smaller:

$$ \boxed{ \min_{-2\leq x\leq3}f(x)=1 }. $$

Absolute vs. Local Minimum

A local minimum is smaller than nearby function values. An absolute minimum must be no greater than every function value in the entire stated domain.

Closed-Interval Method

For a continuous function on $[a,b]$, evaluate the function at all interior critical points and both endpoints. The smallest resulting value is the absolute minimum.

$$ \boxed{ a,\ b,\ \text{and interior critical points} }. $$

Extreme Value Theorem

A continuous function on a closed bounded interval attains both an absolute maximum and an absolute minimum.

Derivative Candidates

An interior absolute minimum of a differentiable function may occur where:

$$ f'(c)=0, $$

but critical points are only candidates and must be compared with all other relevant possibilities.

Minimum Need Not Exist

A function can be bounded below without attaining its greatest lower bound. For example, on $0<x<1$:

$$ f(x)=x $$

has infimum $0$ but no absolute minimum.

Multiple Minimizers

A function can attain the same absolute minimum at several inputs. The minimum value is one number, but the set of minimizing inputs may contain many points.

Common Misconception

The lowest visible point on a partial graph is not necessarily an absolute minimum. The conclusion depends on the entire stated domain.

Written vs. Spoken Syntax

Symbolic Notation (Written) Professional Articulation (Spoken)
$f(c)\leq f(x)$ for all $x\in D$ "F of c is an absolute minimum value on D."
$\min_{x\in D}f(x)$ "The minimum value of f over D."
$f(0)=1$ "The absolute minimum value is one at x equals zero."
$f'(c)=0$ "C is a critical-point candidate."
$\inf f(D)$ "The infimum of the function values."
$c\in\operatorname*{arg\,min}_{x\in D}f(x)$ "C is a minimizing input."

Absolute minimum and global minimum are commonly used as synonyms. In optimization, minimizer refers to the input, while minimum may refer to the attained output value.

Defense Notation Advice: State the domain, distinguish the minimizing input from the minimum value, and do not confuse an infimum with a minimum unless the lower bound is actually attained.

Case Usage & Field Variations

  • Core Definition: $f(c)\leq f(x)$ for every $x$ in the specified domain.
  • Synonym: Global minimum.
  • Minimum Value: The least attained output value.
  • Minimizer: An input where the minimum is attained.
  • Local Contrast: A local minimum compares only nearby inputs.
  • Closed Intervals: Compare endpoints and interior critical points.
  • Extreme Value Theorem: Guarantees an absolute minimum for continuous functions on closed bounded intervals.
  • Optimization: Absolute minima represent globally smallest feasible objective values.
  • Multiple Minimizers: Several inputs may attain the same minimum value.
  • Infimum: A greatest lower bound need not be attained and therefore need not be a minimum.
  • Multivariable Calculus: Absolute minima are determined by comparison over the entire feasible region.
  • Common Error: Assuming every critical point is an absolute minimum.
  • Common Error: Ignoring endpoints of a closed interval.
  • Common Error: Confusing a local minimum with a global minimum.
  • Common Error: Calling an unattained infimum an absolute minimum.
  • Core Interpretation: An absolute minimum is the least function value actually attained on the stated domain: $$ \boxed{ f(c)=\min_{x\in D}f(x) }. $$ It is a global comparison concept central to extrema, optimization, graph analysis, and calculus.
