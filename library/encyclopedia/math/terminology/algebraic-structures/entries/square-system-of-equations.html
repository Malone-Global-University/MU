Square System of Equations

Subfield: Algebraic Structures

Etymology & Roots

A square system of equations is a system having the same number of equations as unknowns. A linear square system with $n$ equations and $n$ unknowns can be written:

$$ \boxed{ A\mathbf{x}=\mathbf{b}, \qquad A\in\mathbb{F}^{n\times n} }. $$

The word square comes from the shape of the corresponding coefficient matrix: $n$ rows for the equations and $n$ columns for the unknowns.

Operational Nuance

Basic Structure

A system such as:

$$ \begin{cases} 2x+y=5,\\ x-y=1 \end{cases} $$

is square because it contains two equations in two unknowns.

Coefficient Matrix

Its matrix form is:

$$ \begin{bmatrix} 2 & 1\\ 1 & -1 \end{bmatrix} \begin{bmatrix} x\\ y \end{bmatrix} = \begin{bmatrix} 5\\ 1 \end{bmatrix}. $$

The coefficient matrix is square because the number of equations equals the number of variables.

Unique Solution

For a linear square system over a field, a unique solution exists for every right-hand side $\mathbf{b}$ exactly when $A$ is invertible:

$$ \boxed{ \det(A)\neq0 \Longleftrightarrow A^{-1}\text{ exists} \Longleftrightarrow \mathbf{x}=A^{-1}\mathbf{b} \text{ is unique} }. $$

Rank Criterion

An $n\times n$ coefficient matrix has full rank when:

$$ \boxed{ \operatorname{rank}(A)=n }. $$

Full rank is equivalent to invertibility for a square matrix.

Singular Square Systems

If:

$$ \det(A)=0, $$

then $A$ is singular. A particular system $A\mathbf{x}=\mathbf{b}$ may then have either no solution or infinitely many solutions, but not exactly one.

Consistency Criterion

A linear system is consistent exactly when:

$$ \boxed{ \operatorname{rank}(A) = \operatorname{rank}([A\mid\mathbf{b}]) }. $$

If this common rank is less than $n$ in a square system, free variables remain and the consistent system has infinitely many solutions over an infinite field.

Square Does Not Mean Unique

Merely having the same number of equations and unknowns does not guarantee a unique solution. The equations may be dependent or inconsistent.

Comparison with Other System Shapes

If there are more equations than unknowns, the system is overdetermined. If there are fewer equations than unknowns, it is underdetermined. A square system lies between these cases by count, though its actual solution behavior still depends on rank and consistency.

Nonlinear Systems

The phrase can also describe a nonlinear system containing the same number of equations as unknowns. In that setting, equal counts alone provide even less information about the number of solutions.

Common Misconception

A square system is defined by its equation-to-unknown count, not by whether it has one solution. A square system can have zero, one, or multiple solutions depending on its structure.

Written vs. Spoken Syntax

Symbolic Notation (Written) Professional Articulation (Spoken)
$n$ equations, $n$ unknowns "A square system of n equations in n unknowns."
$A\in\mathbb{F}^{n\times n}$ "The coefficient matrix is n by n."
$\det(A)\neq0$ "The coefficient matrix is nonsingular."
$\operatorname{rank}(A)=n$ "The coefficient matrix has full rank."
$\mathbf{x}=A^{-1}\mathbf{b}$ "The unique solution is A inverse times b."
$\operatorname{rank}(A)=\operatorname{rank}([A\mid\mathbf{b}])$ "The coefficient and augmented matrices have equal rank, so the system is consistent."

Defense Notation Advice: Do not infer uniqueness merely from the phrase square system. For linear systems, inspect determinant, pivots, or rank. Also distinguish the $n\times n$ coefficient matrix $A$ from the augmented matrix $[A\mid\mathbf{b}]$, which has an additional column.

Case Usage & Field Variations

  • Core Definition: Same number of equations as unknowns.
  • Linear Algebra: A square linear system has an $n\times n$ coefficient matrix.
  • Full Rank: Rank $n$ gives a unique solution for every right-hand side.
  • Determinant: $\det(A)\neq0$ characterizes the invertible linear case.
  • Singular Case: $\det(A)=0$ prevents a unique solution.
  • Consistency: Equal ranks of $A$ and $[A\mid\mathbf{b}]$ characterize solvability.
  • Dependent Equations: A square system may contain redundant equations.
  • Inconsistent Equations: Equal equation and variable counts do not prevent contradiction.
  • Matrix Methods: Gaussian elimination, LU factorization, determinants, and inverse methods are commonly applied.
  • Nonlinear Systems: Equal equation and unknown counts also define a square nonlinear system, but do not determine its number of solutions.
  • Overdetermined Contrast: More equations than unknowns.
  • Underdetermined Contrast: Fewer equations than unknowns.
  • Common Error: Assuming a square system must have exactly one solution.
  • Common Error: Calling the augmented matrix square when the coefficient matrix is square.
  • Common Error: Using equation count alone instead of rank to determine solution behavior.
  • Core Interpretation: A square system is structurally balanced by count: $$ \boxed{ n\text{ equations} \quad\text{and}\quad n\text{ unknowns} }. $$ For linear systems, this produces a square coefficient matrix, but uniqueness requires the stronger condition: $$ \boxed{ \operatorname{rank}(A)=n \Longleftrightarrow \det(A)\neq0 }. $$ Thus "square" describes the system's dimensions, while rank and consistency determine its actual solution structure.
