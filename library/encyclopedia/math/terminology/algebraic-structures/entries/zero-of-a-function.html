Zero of a Function

Subfield: Algebraic Structures

Etymology & Roots

A zero of a function is an input value in the function's domain for which the output equals zero.

$$ \boxed{ f(c)=0 } $$

means that $c$ is a zero of $f$. The term refers to the resulting output value $0$, while closely related terms such as root and solution emphasize the equation $f(x)=0$.

Operational Nuance

Solving for Zeros

Finding the zeros of a function means solving:

$$ \boxed{ f(x)=0 }. $$

For example:

$$ f(x)=x^2-9 $$

has zeros:

$$ \boxed{ x=-3,\qquad x=3 }. $$

Graphical Meaning

For a real-valued function of a real variable, a zero corresponds to a point where the graph meets the $x$-axis:

$$ \boxed{ (c,0) }. $$

The input $c$ is the zero; the point $(c,0)$ is the corresponding $x$-intercept when it lies on the graph.

Factor Connection

For a polynomial $P(x)$, the Factor Theorem gives:

$$ \boxed{ P(c)=0 \Longleftrightarrow (x-c)\text{ is a factor of }P(x) }. $$

Multiplicity

A polynomial zero may occur with multiplicity greater than one. If:

$$ P(x)=(x-c)^mQ(x), \qquad Q(c)\neq0, $$

then $c$ is a zero of multiplicity $m$.

Crossing and Touching

For real polynomial graphs, odd multiplicity generally causes the graph to cross the $x$-axis, while even multiplicity generally causes it to touch the axis and turn around.

Domain Restrictions

A candidate must belong to the function's domain. For example:

$$ f(x)=\frac{x-2}{x-2} $$

is undefined at $x=2$, so $2$ is not a zero of the function even though the unsimplified numerator vanishes there.

Zero Function vs. Zero of a Function

A zero of a function is an input. The zero function is a function whose output is zero for every input in its domain:

$$ \boxed{ f(x)=0 \text{ for all }x }. $$

Common Misconception

The zero of a function is not necessarily the point $(0,0)$ and need not be the number $0$. A function may have zeros at many different input values or have no real zeros at all.

Written vs. Spoken Syntax

Symbolic Notation (Written) Professional Articulation (Spoken)
$f(c)=0$ "C is a zero of f."
$f(x)=0$ "Solve for the zeros of f."
$(c,0)$ "The corresponding x-intercept is c comma zero."
$P(c)=0$ "C is a root, or zero, of the polynomial P."
$(x-c)^m$ "The zero c has multiplicity m."
$Z(f)=\{x:f(x)=0\}$ "The zero set of f."

In elementary algebra, zero, root, and solution of $f(x)=0$ are often used nearly interchangeably. X-intercept refers instead to the graphical point, not merely its input coordinate.

Defense Notation Advice: Distinguish the input value $c$ from the graph point $(c,0)$, and always retain domain restrictions when simplifying an expression before searching for zeros.

Case Usage & Field Variations

  • Core Definition: $c$ is a zero of $f$ when $f(c)=0$.
  • Equation Solving: Zeros are solutions of $f(x)=0$.
  • Graphing: Real zeros correspond to $x$-axis intersections or contacts.
  • X-Intercept: The zero is the input coordinate; $(c,0)$ is the intercept point.
  • Polynomials: Zeros correspond to linear factors through the Factor Theorem.
  • Multiplicity: Repeated polynomial factors produce repeated zeros.
  • Complex Zeros: A polynomial may have zeros that are not visible on a real coordinate graph.
  • Rational Functions: Numerator zeros produce function zeros only when the corresponding input remains in the domain.
  • Zero Set: All zeros may be collected as $Z(f)=\{x\in\operatorname{Dom}(f):f(x)=0\}$.
  • Numerical Methods: Approximate zeros may be found by methods such as bisection or Newton's method.
  • Calculus: Zeros help determine sign intervals, critical behavior, intersections, and boundary conditions.
  • Common Error: Calling the point $(c,0)$ itself the numerical zero without distinguishing point from input.
  • Common Error: Assuming every function has a real zero.
  • Common Error: Accepting an excluded domain value because a numerator becomes zero there.
  • Common Error: Confusing the zero function with a zero of a function.
  • Core Interpretation: A zero is an input that sends a function to the additive identity of its output number system: $$ \boxed{ c\in\operatorname{Dom}(f), \qquad f(c)=0 }. $$ Algebraically it solves $f(x)=0$; graphically, in the real one-variable case, it identifies where the graph reaches the $x$-axis.
