System of Linear Equations

Subfield: Algebraic Structures

Etymology & Roots

A system of linear equations is a collection of linear equations involving the same unknowns and required to hold simultaneously.

$$ \boxed{ \begin{cases} a_{11}x_1+\cdots+a_{1n}x_n=b_1,\\ \vdots\\ a_{m1}x_1+\cdots+a_{mn}x_n=b_m \end{cases} }. $$

The word linear indicates that each unknown appears only to the first power and is not multiplied by another unknown. The word system indicates that all equations are treated as simultaneous constraints.

Operational Nuance

Matrix Form

Every finite linear system can be written compactly as:

$$ \boxed{ A\mathbf{x}=\mathbf{b} }. $$

Here $A$ is the coefficient matrix, $\mathbf{x}$ is the vector of unknowns, and $\mathbf{b}$ is the constant vector.

Example

$$ \begin{cases} 2x+y=5,\\ x-y=1 \end{cases} \Longrightarrow \boxed{(x,y)=(2,1)}. $$

The ordered pair is a solution because it satisfies both equations.

Augmented Matrix

The same system may be encoded as:

$$ \boxed{ [A\mid\mathbf{b}] }. $$

Elementary row operations transform the system without changing its solution set.

Possible Solution Structures

Over a field, a finite linear system has exactly one of three possibilities:

$$ \boxed{ \text{no solution}, \qquad \text{one solution}, \qquad \text{infinitely many solutions} }. $$

Consistency

A system is consistent when at least one solution exists and inconsistent when none exists.

$$ \boxed{ \operatorname{rank}(A) = \operatorname{rank}([A\mid\mathbf{b}]) } $$

is the rank criterion for consistency.

Unique Solution

A consistent system in $n$ unknowns has a unique solution when:

$$ \boxed{ \operatorname{rank}(A)=n }. $$

Free Variables

If a consistent system has rank less than the number of unknowns, at least one free variable remains. Over an infinite field, this produces infinitely many solutions.

Gaussian Elimination

One of the standard methods is to row-reduce the augmented matrix into echelon form and then solve for the unknowns.

$$ \boxed{ [A\mid\mathbf{b}] \longrightarrow \text{row-echelon form} \longrightarrow \text{solutions} }. $$

Other Methods

Small systems may be solved by substitution or elimination. Square nonsingular systems may also be solved using matrix inverses, determinants, or factorizations.

Geometric Interpretation

In two variables, each linear equation represents a line. In three variables, each equation represents a plane. The system's solution set is their common intersection.

Homogeneous Systems

A homogeneous linear system has:

$$ \boxed{ A\mathbf{x}=\mathbf{0} }. $$

It always has the trivial solution $\mathbf{x}=\mathbf{0}$ and may also have nontrivial solutions.

Common Misconception

Having as many equations as unknowns does not guarantee a unique solution. Dependence among equations or inconsistency can still produce infinitely many solutions or no solution.

Written vs. Spoken Syntax

Symbolic Notation (Written) Professional Articulation (Spoken)
$A\mathbf{x}=\mathbf{b}$ "A x equals b."
$[A\mid\mathbf{b}]$ "The augmented matrix of the system."
$(x,y)=(2,1)$ "The ordered-pair solution is two, one."
$\operatorname{rank}(A)=n$ "The coefficient matrix has full column rank."
$A\mathbf{x}=\mathbf{0}$ "A homogeneous system of linear equations."
$S=\varnothing$ "The system is inconsistent."

A linear system and a system of linear equations usually refer to the same structure. The shorter phrase is common when linearity is already clear from context.

Defense Notation Advice: Keep the coefficient matrix $A$, unknown vector $\mathbf{x}$, constant vector $\mathbf{b}$, and augmented matrix $[A\mid\mathbf{b}]$ distinct. Determine solution behavior from rank, pivots, and consistency rather than equation count alone.

Case Usage & Field Variations

  • Core Meaning: Simultaneous linear equations involving common unknowns.
  • Matrix Form: $A\mathbf{x}=\mathbf{b}$.
  • Augmented Matrix: $[A\mid\mathbf{b}]$ encodes coefficients and constants together.
  • Unique Solution: Occurs when the system is consistent and every unknown corresponds to a pivot.
  • No Solution: Occurs when the system is inconsistent.
  • Infinite Solutions: Occur when a consistent system has free variables over an infinite field.
  • Substitution: Replaces an unknown with an equivalent expression.
  • Elimination: Combines equations to remove unknowns.
  • Gaussian Elimination: Uses elementary row operations to reach echelon form.
  • Gauss-Jordan Elimination: Continues reduction to reduced row-echelon form.
  • Homogeneous System: Has the form $A\mathbf{x}=\mathbf{0}$.
  • Geometry: Solutions are intersections of lines, planes, or higher-dimensional hyperplanes.
  • Square System: Same number of equations as unknowns.
  • Overdetermined System: More equations than unknowns.
  • Underdetermined System: Fewer equations than unknowns.
  • Modeling: Linear systems represent simultaneous linear constraints in economics, engineering, science, and data analysis.
  • Common Error: Assuming every square linear system has exactly one solution.
  • Common Error: Treating dependent equations as independent constraints.
  • Common Error: Checking a candidate against only one equation.
  • Core Interpretation: A system of linear equations combines several linear constraints into one simultaneous problem: $$ \boxed{ A\mathbf{x}=\mathbf{b} }. $$ Its solution structure is controlled by consistency, rank, pivots, and free variables rather than simply by the number of equations and unknowns.
