About This Collection

Cloud computing encompasses several interdependent disciplines: the delivery of computing resources as services, the construction of scalable applications, the protection and operation of distributed infrastructure, and the movement of established systems into new environments. This collection brings together fourteen specialized encyclopedia articles that explore those subjects in greater depth than the Cloud Computing overview.

These are sub-articles of Cloud Computing: each concentrates on a component, design decision, or operating practice within that subject. The sequence begins with service and infrastructure foundations, continues through application architecture and deployment, addresses security and ongoing operations, and concludes with hybrid architecture and migration. The articles can be read in sequence or consulted individually.

Service Foundations and Infrastructure

Begin with the services that organizations consume and the compute, storage, and networking capabilities used to construct cloud systems.

  1. Cloud Service Models — Explains Infrastructure as a Service, Platform as a Service, Software as a Service, managed platforms, and the distribution of operating responsibilities between customer and provider.
  2. Virtual Machines and Cloud Compute — Examines virtual servers, hypervisors, instance sizing, CPU and memory allocation, machine images, accelerators, and the operation of cloud compute capacity.
  3. Containers and Cloud Orchestration — Introduces container images, runtime isolation, cluster management, Kubernetes, scheduling, application rollout, service discovery, and persistent workloads.
  4. Cloud Storage Services — Compares object, block, and file storage, with particular attention to durability, replication, storage tiers, backup, restoration, and data lifecycle management.
  5. Cloud Networking and Virtual Private Clouds — Covers virtual networks, subnets, addressing, routing, firewalls, load balancing, DNS, private connections, and content delivery networks.

Applications and Automation

These articles explain how cloud applications are designed, executed, and deployed through software-defined infrastructure.

  1. Cloud-Native Application Architecture — Explores application decomposition, service boundaries, APIs, events, message queues, distributed data ownership, and failure-aware application design.
  2. Serverless Computing — Explains provider-managed execution, functions, event triggers, ephemeral runtimes, durable state, concurrency, service limits, and usage-based billing.
  3. Infrastructure as Code — Examines declarative configuration, repeatable provisioning, version control, state management, automated deployment, change review, and configuration drift.

Security, Reliability, and Operations

Running a cloud system requires protecting its resources, maintaining service continuity, measuring health, and managing expenditure.

  1. Cloud Security and Identity — Develops shared security responsibility, identity and access management, federation, secrets protection, encryption, key management, and security posture.
  2. Cloud Reliability and Disaster Recovery — Explains availability, fault tolerance, failure domains, redundancy, backup strategies, recovery time and point objectives, failover, and recovery testing.
  3. Cloud Monitoring and Observability — Surveys metrics, logs, distributed traces, instrumentation, alerting, service-level objectives, incident investigation, and operational telemetry.
  4. Cloud Cost Management and FinOps — Addresses cloud billing, cost allocation, budgets, forecasting, rightsizing, purchasing commitments, unit economics, and shared financial accountability.

Architecture and Transformation

The final subjects address how organizations combine environments, select workload locations, and transition or modernize existing systems.

  1. Hybrid and Multi-Cloud Architecture — Studies connectivity and workload placement across private infrastructure and cloud providers, including identity, data movement, portability, governance, and resilience.
  2. Cloud Migration and Modernization — Explains workload discovery, migration strategies, dependency mapping, data transfer, production cutover, rollback, modernization, and post-migration validation.

How to Navigate the Articles

Readers seeking an introduction to how cloud services are delivered should begin with Cloud Service Models, then continue to virtual machines, containers, storage, and networking. Those planning applications can move to cloud-native architecture, serverless systems, and infrastructure automation.

For readers responsible for operating an established service, Cloud Security and Identity, reliability and disaster recovery, monitoring and observability, and FinOps form a useful complementary group. Hybrid architecture and migration explain how these technical considerations apply when an organization operates more than one environment or changes its existing systems.

These subject boundaries are educational rather than absolute. A cloud application may simultaneously depend on virtual networks, managed storage, identity policies, automated provisioning, monitoring, and recovery arrangements. The separate articles make those dependencies easier to examine without treating them as isolated technologies.
