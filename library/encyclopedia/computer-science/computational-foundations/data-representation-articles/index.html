Collection Overview

This directory is the subordinate reference index for Data Representation in the MGU Computer Science Encyclopedia. The parent article defines data representation as the set of conventions that makes abstract information expressible as machine-readable patterns. It surveys binary encodings, numbers, text, images, audio, precision, interpretation, and system-design constraints. That existing parent article remains unchanged.

The eighteen proposed specialist entries expand those themes without repeating the general overview. They are arranged around four connected tasks: encoding a value; laying out and transferring the encoded bytes; representing symbolic and sampled media; and preserving the meaning of the result.

Data representation should not be confused with the information itself. For example, the bit pattern 11111111 can denote an unsigned integer of 255 or a signed two’s-complement integer of −1 when interpreted as an eight-bit value. The representation rules, not the raw pattern alone, determine its meaning.

The Layers of Data Representation

Representation decisions occur at several levels. A format that works at one level can still fail when another level is left unspecified: a valid numeric byte sequence may be decoded with the wrong endianness; a valid string may be compared under an unsuitable normalization convention; and a valid measurement can be misinterpreted when its unit is missing.

LayerPrincipal design questionExamples
ValueWhat range and precision are possible?Signed integer width, fixed-point scale, floating-point exponent
LayoutHow do fields occupy bytes or bits?Byte order, padding, bit fields, serialization
MediaHow are symbols or signals sampled and encoded?Unicode text, pixels, audio samples, video frames
SemanticsHow do recipients interpret and validate a value?Schema, units, nullability, format versions, invariants

Encoding, compression, encryption, and storage are related but different operations. This index focuses on representation choices; established articles elsewhere in the encyclopedia cover broad compression methods, security transformations, and storage architectures.

Numerical Values and Finite Precision

These studies explain how abstract numbers become bounded bit patterns and why the choice of a numeric representation influences arithmetic, precision, and exceptional behavior.

  1. Positional Number Systems and Base Conversion — Positional notation, bases two, eight, ten, and sixteen; conversion algorithms; and how written numerals differ from stored numeric values. (planned)
  2. Signed Integer Representation and Two’s Complement — Sign-and-magnitude, ones’ complement, two’s complement, signed ranges, and interpretation of high-order bits. (planned)
  3. Fixed-Point Representation and Scaling — Scaled integers, implicit radix points, decimal fixed-point formats, precision budgets, and use in measurements and financial calculations. (planned)
  4. Floating-Point Representation and Rounding — Sign, exponent, significand, binary floating-point approximations, rounding modes, special values, and their consequences. (planned)
  5. Numeric Range, Overflow, and Underflow — Finite-width limitations, overflow handling, gradual underflow in applicable formats, saturation, and requirements for safe arithmetic. (planned)

Binary Layout and Machine-Level Interpretation

These studies address the placement of encoded values in memory, the boundaries between fields, and the conventions used when transmitting or preserving binary data.

  1. Byte Order and Endianness — Byte ordering for multibyte values, canonical wire encodings, byte swapping, and cross-platform interpretation. (planned)
  2. Bit Fields and Packed Data — Masks, shifts, tightly packed flags, field widths, and the portability limitations of implementation-specific bit-field layouts. (planned)
  3. Alignment, Padding, and Memory Layout — Object alignment, structure padding, contiguous arrays, offsets, and how layout requirements affect binary compatibility. (planned)
  4. Variable-Length Integer Encodings — Compact encodings for integers, continuation bits, signed mappings, decoding limits, and canonical representation concerns. (planned)
  5. Binary Serialization and Deserialization — How structured values are converted to byte sequences, parsed back, validated, versioned, and kept independent of host memory layouts. (planned)

Text, Images, Sound, and Video

Media representations translate symbols or sampled physical signals into structured values. The same byte sequence is meaningful only when the format and interpretation rules are known.

  1. Unicode Code Points and Normalization — Code points versus glyphs, combining sequences, normalization forms, grapheme clusters, and consistent text comparison; complements the existing Character Encoding article. (planned)
  2. Raster Images and Pixel Formats — Pixel grids, channels, bit depth, row stride, alpha, and differences between a pixel buffer and a complete image file format. (planned)
  3. Digital Audio Sample Formats — Sampling rate, channel arrangement, PCM quantization, integer and floating-point samples, and the interpretation of audio streams. (planned)
  4. Color Spaces and Component Representation — RGB and other component models, transfer functions, color profiles, quantization, and the distinction between numerical color values and perceived color. (planned)
  5. Video Frame and Temporal Representation — Frame dimensions, time bases, frame rate, chroma sampling, frame sequences, and timing information required to interpret video data. (planned)

Meaning, Validation, and Interoperability

Representation is also an agreement about meaning: systems need consistent types, conventions, error rules, and metadata to interpret encoded values reliably.

  1. Nullability, Missing Values, and Sentinel Codes — The difference between zero, absent, unknown, invalid, and special marker values, including risks of overloaded sentinel codes. (planned)
  2. Data Types, Schemas, and Semantic Interpretation — Type tags, field definitions, unit conventions, schema evolution, and the link between encoded bytes and domain meaning. (planned)
  3. Representation Fidelity, Validation, and Portability — Round-trip properties, representation invariants, truncation, compatibility testing, and the conditions under which encoded values remain meaningful across systems. (planned)

Suggested Study Pathways

For foundational study: Begin with Data Representation, then study positional number systems, signed integers, fixed-point and floating-point formats, and range limitations. Compare an abstract number with the bounded patterns that can stand for it.

For systems programming: Continue through byte order, bit fields, alignment, variable-length integers, and serialization. Consider which layouts are defined by a format and which are implementation details that cannot safely be transmitted by copying raw process memory.

For multimedia and user-facing software: Study Unicode normalization, image and audio sample formats, color representations, and video timing. Distinguish the representation of media samples from compression or playback policies.

For data architecture and interoperability: Examine null values, schemas, semantic interpretation, validation, and portability. Ask whether two applications agree on a value’s type, unit, precision, missing-value rules, and permitted transformations.
