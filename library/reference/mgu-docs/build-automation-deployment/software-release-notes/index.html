Software Release Notes

Engineering whitepapers, software architecture records, and technical documentation preserving the development of MGU's publishing infrastructure.

Collection Overview

Software Release Notes is a permanent engineering documentation collection within Build, Automation, and Deployment. It preserves MGU technical whitepapers, implementation references, design decisions, and documents recording the evolution of software used to construct or maintain the university's digital publications.

The collection includes technical specifications and system design documentation as well as version histories. It is not limited to short release announcements. Substantive publications are retained as their original PDF documents; this HTML index provides navigation and concise bibliographic descriptions.

Historical scope: The five publications currently indexed were issued in August 2025. They describe the systems and software versions specified in each document; their presence here does not establish that those configurations remain the current production environment.

Version Relationships and Documentary Context

Python Index Generator Documentation addresses the earlier Beta 3.0–3.2 implementation and operational reference, while Evolution of indexer.py covers the subsequent documented progression through Beta 3.3. Read together, the two publications show development of the indexer's metadata and navigation functions.

Centralizing Static Site Generators and Markdown Notation Reference Guide document supporting publishing infrastructure and authoring conventions. The indexer license is a separate permissions document, not a technical release specification. Its terms are reproduced only by linking the original PDF; this index does not independently establish legal status, current licensing policy, or compatibility with other licenses.

Collection Scope and Filing Standards

This collection accepts release-engineering whitepapers, software architecture and implementation reports, version evolution studies, durable technical references associated with MGU publishing tools, and related license documents. Future entries should state their document date, relevant software and version, authorship or issuing unit where known, and publication status.

General build procedures and deployment policy belong in the parent Build, Automation, and Deployment category. Source code and live executable tools remain in their designated code or software locations; PDFs here document those systems rather than serving as their executable distribution. Documents are preserved with original dates and claims, and later revisions or replacements should be identified explicitly.
