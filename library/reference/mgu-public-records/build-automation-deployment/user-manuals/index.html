User Manuals

Operator guides for MGU website maintenance, automation, backup, verification, and safe execution of institutional scripts.

Collection Overview

User Manuals is an operational documentation collection within Build, Automation, and Deployment. It provides practical instructions for running MGU-developed maintenance and infrastructure scripts, including prerequisites, command-line procedures, output interpretation, safeguards, and recovery considerations.

Publication format: The complete manuals are retained as PDF documents. This HTML index provides bibliographic descriptions and navigation; executable scripts remain in their designated operational locations.

Current holdings: Two manuals dated November 22, 2026, covering webpage template modernization and a full-project backup procedure.

Operational Guidance

Before operating a documented utility, consult the relevant manual for its prerequisites and command options. For changes to website source files, use the available scan or preview procedure before authorizing modifications, inspect generated reports, and verify representative pages or backup files after execution.

Version context: These manuals describe the script behavior and fixed configurations documented on November 22, 2026. Later revisions to either script may require revised instructions. The availability of a manual does not establish that a particular script version is installed or running on the production website.

Collection Scope and Filing Standards

This collection houses operator-facing instructions for MGU build utilities, publishing automation, maintenance scripts, backup workflows, and associated support procedures. New entries should identify the documented script or system, manual date, applicable software version where known, and original PDF filename.

Engineering development histories, implementation analyses, and release-evolution documents are maintained in the appropriate technical report or Software Release Notes collections. Executable source files and sensitive local configurations should not be substituted for publicly distributed user-manual PDFs.
