Templates and Style Guides

Institutional template specifications, document formatting requirements, and reusable presentation conventions.

Collection Overview

Templates and Style Guides is the standards and specifications collection within MGU Public Records. It documents the reusable structures, presentation conventions, visual components, and publication formats employed across Malone Global University.

The purpose of this collection is to make existing institutional templates documented, repeatable, and consistently interpretable. Specifications should identify required page elements, permitted variations, template dependencies, accessibility expectations, and the conditions under which a template should be revised.

Formal standards and explanatory publications in this collection are issued as PDF documents only. This HTML page serves as a navigational index. Executable source templates, stylesheets, scripts, and other working assets remain in their appropriate website or software directories rather than being reproduced as standalone files in MGU Public Records.

Published Documents

The prospective titles shown below are proposed publications, not available downloads or adopted standards.

Documentation Scope

  • Page templates: institutional HTML structure, page sections, required navigation, metadata, and reusable page-shell conventions.
  • Academic publishing templates: textbook chapters, encyclopedia entries, biographies, lessons, technical reference pages, and other standardized instructional layouts.
  • Institutional document templates: whitepaper covers, executive summaries, document identification, section hierarchy, tables, references, and PDF presentation rules.
  • Visual and component conventions: shared styles, typography, design tokens, layout patterns, feature boxes, tables, and the approved appearance of recurring site elements.
  • Template lifecycle: template applicability, maintenance responsibilities, backward compatibility, revision documentation, and deprecation of obsolete structures.

Proposed Initial Documentation Series

The following titles establish an initial publication program; no PDF is implied to exist until it is actually issued and linked.

  1. TSG-001 — MGU Universal HTML Page Template Specification. Documents the standard HTML page structure, required shared component integrations, metadata, hero section, breadcrumb, main-content hierarchy, navigation, and prescribed customization boundaries.
  2. TSG-002 — MGU Scholarly Textbook Chapter Template and Formatting Standard. Specifies chapter front matter, section hierarchy, pedagogical feature blocks, references, review apparatus, and navigation requirements for structured scholarly textbook publications.
  3. TSG-003 — MGU Institutional Whitepaper and PDF Publication Style Guide. Establishes presentation standards for institutional reports, including covers, document identifiers, executive summaries, revision status, headings, exhibits, tables, citations, and accessible PDF delivery.
  4. TSG-004 — MGU Website Component and Visual Identity Guide. Documents reusable component presentation, approved visual conventions, stylesheet usage, consistent typographic treatment, and interface patterns across university pages.

Template Documentation and Filing Rules

Each PDF specification should identify the template or design system to which it applies, its applicable version, required and optional elements, dependencies, known limitations, and the effective approval status. Examples may be included in the PDF for illustration, but the operating source file remains authoritative for executable syntax.

When a template changes, the associated specification should be reviewed for consistency. Historical specifications should be retained or identified as superseded according to Document Control and Versioning. An example, draft, or AI-generated proposed specification is not an adopted institutional standard until its status is explicitly established.

Filing Boundaries

Templates and Style Guides specifies how material is formatted and presented. Website Architecture specifies how site systems, routes, and components are organized and interconnected. Build, Automation, and Deployment documents how files and pages are generated, validated, and released.

Curriculum Frameworks establishes teaching and assessment design rather than visual layout. Editorial and Publication Standards governs factual accuracy, evidence, citations, editorial review, and publication acceptance. The actual completed lessons, chapters, and reference works remain within their academic or Library collections.
