Persian and Iranian History Audits

Chapter-level assessment and publication review records for Malone Global University's Persian and Iranian History textbook series.

Collection Overview

This register links only to Persian and Iranian History audit records identified in the supplied institutional directory inventory. Records are arranged by chapter; chapters with no recorded audit are omitted. Where multiple audits exist for a chapter, each is listed.

Inventory scope: 27 chapters (Chapters 34–61); 27 existing audit records. The linked source records currently carry .md extensions, so these are links to the inventory's recorded files, not converted PDF editions. Final audit labels reflect file titles and do not independently certify external peer review.
