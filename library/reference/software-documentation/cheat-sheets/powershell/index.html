How to use this collection

Start with enumeration and counting, then choose the sheet corresponding to your operational task. Each sheet provides copyable command examples, operational notes, and a Microsoft Learn reference. Replace example paths with your own approved locations. For write operations, use staging, verified backups, and preview commands before deployment.

Compatibility and safety

Check your shell with $PSVersionTable. PowerShell 7 and Windows PowerShell 5.1 differ in text encoding and some parameters. Review the version labels and use the matching encoding option. Preview commands are not transactions; verify the actual result after making changes.
