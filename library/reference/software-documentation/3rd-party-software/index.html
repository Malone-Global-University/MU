Third-Party Software

Product-specific documentation and technical references for software developed outside Malone Global University.

Overview

Third-Party Software is the subdivision of the Software Documentation collection reserved for product-specific reference materials concerning externally developed software. The collection may include documentation for applications, operating systems, programming tools, libraries, frameworks, and other software systems used in institutional development, coursework, and independent projects.

Documentation for software developed by Malone Global University is maintained separately in the MGU Licensed Software collection.
