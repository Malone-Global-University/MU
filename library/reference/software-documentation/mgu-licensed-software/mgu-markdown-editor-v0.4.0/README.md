## Reusable renderer

After building, import `public/renderer.mjs` using a relative URL from your consumer. It bundles the parser and KaTeX; no editor UI, CodeMirror or CDN dependency is needed for its core operation. Keep the bundle version pinned and preserve source and root lockfile for reproducibility. Do not copy an unbuilt source module into a browser and expect bare npm imports to resolve.

```javascript
import {renderMarkdown, exportHTML, publicationCSS, RENDERER_VERSION} from './renderer.mjs';
const result = renderMarkdown('# MGU\n\n$x^2$', {
  inertLinks: true,
  sourceMap: true,
  outline: true,
  features: {tables: true, math: true}
});
// result.html is a fragment; diagnostics contains errors or warnings.
// result.outline contains {level, line, text} records (line is zero-based).
const documentResult = exportHTML('# Report', {preset: 'technical', title: 'Report'});
// documentResult.valid indicates whether export succeeded.
```

Use `examples/index.html` as a working browser consumer after building, and `examples/verify-bundle.mjs` for the Node import smoke check. The source API is also available from `src/renderer-entry.mjs` in a Node project with dependencies installed. The default `renderMarkdown` contract from prior versions is preserved; pass `inertLinks:true` for read-only previews. `exportHTML` defaults to inert links. Never interpolate untrusted content directly into an HTML host page; use appropriate sandboxing/CSP and a reviewed integration. The consuming app is responsible for handling diagnostics, display, permissions, and trust boundaries.

## Options

`renderMarkdown(source, options)` accepts `inertLinks`, `sourceMap`, `outline` and `features`. Recognized feature flags are `tables`, `fences`, `strikethrough`, `math`, `doubleRule`. A flag of `false` disables that feature; otherwise defaults remain enabled. Raw HTML and images cannot be enabled by feature flags. The source is not changed. A fresh parser configuration is cached per combination; only 32 combinations are possible. `outline` is optional and omitted unless requested on successful renders. Check diagnostics before consuming output.

`publicationCSS({preset,customCSS,fontSize,print})` returns a stylesheet; preset IDs: `standard`, `academic`, `technical`, `corporate`. Font size 12–32 px. `validateCustomCSS(css)` returns normalized approved rules or throws. Supported selectors: body, main, h1–h6, p, ul, ol, li, blockquote, table, th, td, pre, code, hr, a, .preview-link, .mgu-double-rule, .mgu-math-block, .mgu-math-inline. Comma-separated selectors allowed. Properties: color, background-color, border-color, font-family, font-size, font-weight, font-style, line-height, text-align, text-decoration, margin/padding and their four sides, max-width, border-width, border-style. Values are restricted to approved literal forms (no functions, at-rules, CSS escapes, comments, quoted strings or arbitrary selectors). Custom CSS limited to 8,000 characters.

`exportHTML(source,{format,title,preset,customCSS,fontSize,activeLinks,features})` returns `{html,diagnostics,valid}`. Formats `document` (default; includes CSS, metadata and CSP) or `fragment` (markup only). `activeLinks` defaults false. The default raw renderer's safe link policy remains unchanged. Invalid style/format inputs throw; source-limit failure returns `valid:false`. Export does not modify source or saved file state. `htmlFilename(name)` suggests a normalized .html name.

## Build artifacts and boundaries

- `public/editor.js`: browser editor runtime, generated by esbuild.
- `public/renderer.mjs`: independent ESM renderer, generated by esbuild.
- `src/`: source modules. `tests/`: automated suite. `examples/`: independent consumer and bundle check.
- PDF export and automatic recovery are deferred. Browser/file access behavior remains subject to permissions and environment. See release notes for verification limits.
