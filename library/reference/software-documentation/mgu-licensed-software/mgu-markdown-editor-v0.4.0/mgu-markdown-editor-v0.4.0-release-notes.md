# MGU Markdown Editor v0.4.0 — Release Notes

**Status:** Development candidate — local build and smoke test pending. November 27, 2026.

## New features

- Independent renderer distribution: `public/renderer.mjs` is generated by the build and can be imported without the editor or CodeMirror. Its source API is `src/renderer-entry.mjs`.
- Publication presets: Standard, MGU Academic, Technical Report and Corporate Report. Change styles without modifying Markdown.
- Custom CSS dialog: Apply, Clear and Cancel. Supports an approved subset of selectors and literal typography, color, border and spacing declarations; rejects arbitrary CSS, remote resources and markup.
- Copy HTML and Download HTML: export a fragment or complete self-contained HTML document from the **current source**, even when the preview is stale. Full documents include the selected stylesheet and basic print CSS. Fragments contain markup only; the consuming site must supply styles.
- Optional active links in exported HTML; preview links remain inactive. Raw HTML, images and unsafe TeX remain restricted.
- Heading-based Outline with source-line navigation; repeated headings remain distinguishable by line number. Disabled when preview is stale or unavailable.
- Consumer API feature switches for tables, fenced code, strikethrough, math and double rules. All enabled by default. Security restrictions cannot be disabled via these switches.
- Standalone browser integration example and automated bundle-import smoke check.
- The corrected v0.3.0 security assertion is included; **no manual test-file patch is required**. Existing editing and file features are retained.

## Installation and build (Windows PowerShell 5.1)

Extract `mgu-markdown-editor-v0.4.0.zip` into the parent folder below. The ZIP contains the versioned directory. Do not create a second identical nested folder.

```
C:\MGU\library\reference\software-documentation\mgu-licensed-software\
```

No additional npm dependencies are required if v0.3.0 built successfully. Keep your existing root npm configuration. The build uses markdown-it, KaTeX 0.16, CodeMirror 6 packages and esbuild already installed at `C:\MGU`.

```powershell
$Project = "C:\MGU\library\reference\software-documentation\mgu-licensed-software\mgu-markdown-editor-v0.4.0"
Set-Location $Project
.\build.ps1
```

If Windows blocks the trusted script because of execution policy, use a temporary process-only adjustment, after reviewing the script:

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\build.ps1
```

The build runs 38 automated tests, generates `public/editor.js` and `public/renderer.mjs`, then imports the standalone bundle in Node as a smoke check. Continue only if all steps succeed.

If the existing localhost server is not running, open another PowerShell window:

```powershell
Set-Location C:\MGU
& ".\node_modules\.bin\esbuild.cmd" --servedir="C:\MGU" --serve=127.0.0.1:8000
```

Launch the editor at:

http://127.0.0.1:8000/library/reference/software-documentation/mgu-licensed-software/mgu-markdown-editor-v0.4.0/

Independent renderer demo:

http://127.0.0.1:8000/library/reference/software-documentation/mgu-licensed-software/mgu-markdown-editor-v0.4.0/examples/

## Short acceptance test

1. Confirm 38/38 tests and the standalone bundle check pass. Open `smoke-test.md` in the editor; confirm normal rendering, including tables, code and math. The final invalid formula intentionally produces a nonfatal warning.
2. Switch publication presets and apply `h1, h2 { color: #704020; }` in Custom CSS; confirm the preview changes without altering source. Try `@import` or a URL declaration and confirm it is rejected; cancel the dialog.
3. Use Outline to jump between repeated headings and check synchronized scrolling. Disable Live Preview, edit a heading and confirm the outline is unavailable until Render Now.
4. Copy a fragment into Notepad. Download a full HTML document and open it in a browser; confirm the chosen style and math survive, and preview security remains intact. Try the standalone example. Save/reopen one disposable Markdown file.

If satisfactory, lock and archive the build, including root npm manifests and generated bundles. No repeat of the 122-item audit is required.

## Verification and limitations

14 dependency-free tests passed in the packaging environment; JavaScript syntax checks passed. The remaining 24 source tests, browser build, standalone bundle check and manual smoke test require the local dependencies/workstation. No generated JavaScript bundles are included in the source ZIP. No local build or browser acceptance is claimed here.

Styling presets are proposed designs, not adopted institutional publication standards. Custom CSS is intentionally not a general-purpose CSS editor; custom font declarations can override preset typography. Style settings are session-only, not written to Markdown. Fragments require host styles; direct PDF export, PDF pagination/templates and autosave remain future work. Exports retain the 200,000 UTF-16 code-unit input limit and math limits. Exported active links, if selected, may navigate to external or relative destinations when clicked; use trusted documents and check links before publication. This is not a comprehensive security certification.
