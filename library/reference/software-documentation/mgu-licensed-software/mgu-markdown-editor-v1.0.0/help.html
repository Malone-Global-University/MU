MGU Markdown Editor v1.0.0

Help, usage boundaries and community feedback.

Authoring and publishing

Open or create a Markdown document; use the source editor and live preview. Save or Save As writes to disk when browser support and permission allow it. Download creates a separate copy. Use publication styles, HTML export, Page setup and Print / Save PDF for publication. Choose the browser's native Save as PDF where possible; inspect pagination and links in the resulting file.

Local recovery and privacy

Autosave recovery stores copies in this browser, not on disk. Other scripts on the same website origin may access this storage. It is not encrypted by the editor. Save important work independently before clearing browser data, changing versions or closing after a storage warning. Disable recovery or remove stored copies in Drafts & recent. Clearing document data retains preferences including PDF metadata.

v1.0.0 uses a new storage namespace. To move drafts from v0.6.0, open that version, save each needed document to disk, and open those files in v1.0.0. Settings start at defaults. No previous local data is deleted by this release.

Known boundaries

Rendered source is limited to 200,000 UTF-16 code units; local recovery allows 500,000 per source or saved baseline and a combined 1,500,000-unit record, subject to browser quota. Eight kept drafts and five recent copies are supported. Use one editing tab. External images and raw HTML are disabled. PDF metadata, pagination and link preservation depend on the browser. MGU extensions may not render in other Markdown applications.
