Custom publication CSS

Restricted styles only. Example: h1, h2 { color: #193c60; }. No external URLs, scripts, functions or arbitrary selectors. Apply or clear without modifying Markdown.

PDF publication settings

Settings apply to a fresh render of the current Markdown. Print using the browser's Save as PDF option. Page size, margins and running text are requested through CSS; verify them in print preview.

Publication style, custom CSS and active export links follow the main toolbar. Running headers, footers and page numbers need at least 15 mm at the relevant edge. Use :::mgu-page-break on its own line for a manual page break.

Local drafts and recent documents

Copies are stored in this browser, not on disk. Opening a copy does not reopen the original file. Use Save As to preserve it independently. Other pages on this origin may access local storage.

Autosave off removes the active recovery snapshot and stops new automatic recent copies. Kept drafts and existing recent copies remain until removed.
