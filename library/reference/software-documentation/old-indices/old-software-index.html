Software Documentation

The central MGU Library reference collection for software architecture, technical documentation, user manuals, software guides, and practical operational references covering MGU-developed and external software.

Overview

Software Documentation serves as the central repository for publications concerning software development, operation, configuration, and maintenance. The collection supports institutional development, technical reference, coursework, laboratories, projects, and independent software engineering.

The collection distinguishes documentation for software developed by Malone Global University from reference materials concerning externally developed software. MGU software records are maintained within the dedicated MGU Licensed Software collection, while the other reference categories provide practical guidance for using external software, tools, platforms, and development environments.

Resource Categories

  • MGU Licensed Software

    The dedicated documentation repository for software developed by Malone Global University, including web-based applications, standalone utilities, automation software, libraries, and other internally developed software systems. Publications include software architecture documents, technical specifications, historical and engineering records, release notes, user manuals, technical references, and licensing documentation where applicable. Records are organized by software product.

  • Cheat Sheets

    Condensed quick-reference materials for externally developed software, summarizing commands, syntax, workflows, configuration patterns, and commonly needed technical information for rapid operational lookup.

  • Setup Guides

    Step-by-step instructional guides for installing and configuring external software, preparing development environments, provisioning systems, and establishing technical workspaces for institutional and independent activities.

Documentation Scope

Software documentation is distinct from the operational software itself. This collection preserves publications about software, while the Developer Tools directory provides access to MGU-built utilities and other development resources.

Website-wide architecture and shared platform components remain documented in Website Architecture. Existing historical publications concerning MGU-developed build and deployment software may remain in Build, Automation, and Deployment pending their future migration to the MGU Licensed Software collection.
